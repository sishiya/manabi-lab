# うんちく台本: 神の視点マップ（god-view）

### god-view-1  型E  「宇宙のまん中の大きさは、髪の毛1本」　◎おすすめ
- 題名: 【うんちく】いちばん小さい長さと、いちばん大きい長さ。そのまん中は？ ／ EN: Did you know? Halfway between the smallest and the largest is a hair
- 尺: 30秒　しゃべり: (2)　へぇ度: ★5
- フック（0〜1.5秒の画面）: 髪の毛1本のどアップ。文字「これが 宇宙の"まん中"の大きさ」
- 台本:
  | 秒 | 画面 | しゃべり／字幕 |
  |---|---|---|
  | 0–3 | 髪の毛1本 | 「この髪の毛の太さ。じつは、宇宙の"まん中"の大きさです。」 |
  | 3–10 | アプリの録画: 髪の毛の太さから、10倍ずつ寄っていく（細胞 → 原子 → 原子核 → …）。左上に「10⁻⁴ m → 10⁻³⁵ m」 | 「ここから10倍ずつ寄っていく。細胞、原子、原子核…。物理で意味のあるいちばん小さい長さ、プランク長まで、31回。」 |
  | 10–18 | 同じく髪の毛から10倍ずつ引いていく（人 → 町 → 地球 → 太陽系 → 銀河 → 観測できる宇宙）。「10⁻⁴ m → 10²⁷ m」 | 「こんどは引いていく。人、町、地球、銀河…。観測できる宇宙の端から端まで、これも31回。」 |
  | 18–24 | 数の線（ものさし）の上に、左端・右端・まん中の髪の毛。まん中に印 | 「小さいほうにも、大きいほうにも、10倍を31回。そのちょうどまん中が、0.1ミリ。」 |
  | 24–30 | 髪の毛にもどる（ループ） | 「あなたの髪の毛は、宇宙のまん中にいる。」 |
- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: プランク長 1.6×10⁻³⁵ m と 観測できる宇宙の直径 8.8×10²⁶ m の、桁でみたまん中（幾何平均）は 1.2×10⁻⁴ m ＝ 0.12 mm。髪の毛の太さ（0.02〜0.18 mm、多くは 0.1 mm 前後）くらい。両側とも 10倍を約31回。
- 絵の作り方: アプリの録画（ホイールで寄る・引く。スケール値 L の表示が −4 から −35 へ、−4 から 27 へ。ものさしの身近なたとえが変わっていくところ）／Canvas の図（−35〜27 の数の線と、まん中の印）
- 出どころ:
  - CODATA 2022（NIST）: プランク長 1.616 255(18)×10⁻³⁵ m, https://physics.nist.gov/cgi-bin/cuu/Value?plkl（WebFetch で確認）
  - Encyclopaedia Britannica「observable universe」: 直径 約930億光年（検索で確認）
  - 髪の毛の太さ 17〜181 μm: Ley（1999）The Physics Factbook, https://hypertextbook.com/facts/1999/BrianLey.shtml（検索で確認。元は化粧品会社の説明をなおした値で、測定の論文ではない → 字幕は「髪の毛くらい」とぼかす）
- 推定・注意: プランク長は「これより小さいと今の物理が使えない目安」で、「世界でいちばん小さい長さ」と決まったわけではない → 字幕は「物理で意味のあるいちばん小さい長さ（の目安）」。観測できる宇宙の大きさは宇宙のふくらみ方のモデルによる値。「まん中」は桁（対数）で見たまん中（足して2で割るのではない）→ 字幕に「10倍ずつで数えると」。
- コメント欄の問い（任意）: 「あなたの身長は、宇宙のものさしの左から何%のところ？」（答え: 約57%。まん中より少し大きいほう）

計算:
- 観測できる宇宙の直径 D = 930億光年 × 9.4607×10¹⁵ m = 8.80×10²⁶ m（log₁₀ = 26.94）
- プランク長 l_P = 1.616×10⁻³⁵ m（log₁₀ = −34.79）
- まん中 = √(l_P × D) = √(1.616×10⁻³⁵ × 8.80×10²⁶) = 1.19×10⁻⁴ m = 0.12 mm（log₁₀ = −3.92）
- 10倍の回数: 小さいほう −3.92 − (−34.79) = 30.9 回、大きいほう 26.94 − (−3.92) = 30.9 回 → 「31回」
- 身長 1.7 m（log₁₀ = 0.23）: (0.23 + 34.79) / (26.94 + 34.79) = 35.02 / 61.73 = 0.567 → 約57%

### god-view-2  型B  「地球をこなごなにするには？」
- 題名: 【うんちく】人類のエネルギーで地球をこなごなにするには何年？ ／ EN: Did you know? How long to blow up Earth with all our energy
- 尺: 28秒　しゃべり: (2)　へぇ度: ★4
- フック（0〜1.5秒の画面）: アプリの地球がちぎれて、かけらが四方へ散る。文字「これに要るエネルギーは？」
- 台本:
  | 秒 | 画面 | しゃべり／字幕 |
  |---|---|---|
  | 0–3 | 地球がちぎれる（アプリの録画） | 「地球を、こなごなにして、かけらを二度と集まらないところまでとばす。」 |
  | 3–9 | 地球が自分の重力でかけらを引きもどすアニメ。「2.2〜2.5×10³² J」 | 「ちぎっても、地球は自分の重力でかけらを引きもどす。それに勝つエネルギーは、約2×10³²ジュール。」 |
  | 9–16 | 人類が1年に使うエネルギー「約600エクサジュール」→ 何年？ の数字が回る | 「人類が1年に使うエネルギーを、ぜんぶつぎこんだら、何年かかる？」 |
  | 16–22 | 「約4000億年」＝「宇宙の年齢の約30倍」 | 「答えは約4000億年。宇宙ができてから今までの、約30倍。」 |
  | 22–28 | 太陽「約1週間」 | 「でも、太陽が出す光なら…約1週間ぶん。太陽って、ほんとうに桁ちがい。」 |
- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: 地球の重力による結びつきのエネルギー 2.2〜2.5×10³² J。人類の1年分（約6×10²⁰ J）で 3700億〜4200億年（宇宙の年齢 138億年の 27〜30倍）。太陽の光（3.83×10²⁶ W）なら 7〜7.5日。
- 絵の作り方: アプリの録画（地球をちぎる SPH。指でちぎるとかけらが散り、また集まる場面）／Canvas の図（数字のアニメ・時間の帯）
- 出どころ:
  - NASA Earth Fact Sheet（質量 5.9722×10²⁴ kg・半径 6,371 km）, https://nssdc.gsfc.nasa.gov/planetary/factsheet/earthfact.html（WebFetch で確認）
  - 一様な球の重力の結びつきのエネルギー U = 3GM²/(5R)（教科書）。中心ほど重い本当の地球（PREM のモデル）では約 2.49×10³² J（Wikipedia「Gravitational binding energy」の値。元の論文はたどれていない → 字幕は「約2×10³²」と、一様な球の計算の値を下限として使う）
  - Energy Institute（2026）Statistical Review of World Energy: 2025年の世界のエネルギー供給は 600 EJ をこえた（DieselNet の紹介記事, https://dieselnet.com/news/2026/07energyreview.php、WebFetch で確認）
  - NASA Sun Fact Sheet（光の出る強さ 3.828×10²⁶ W）, https://nssdc.gsfc.nasa.gov/planetary/factsheet/sunfact.html（WebFetch で確認）
- 推定・注意: 「こなごなにする」は「全部のかけらを無限に遠くまでとばす」最低のエネルギー（岩を砕くエネルギーなどは小さいので無視）。人類のエネルギーは年によって増えるので「いまのペースで」と字幕に。もしも計算なので、方法（どうやってつぎこむか）は言わない。
- コメント欄の問い（任意）: 「月をこなごなにするなら、太陽の光で何分？」（答え: 一様な球として 約1.2×10²⁹ J → 約5分）

計算（G = 6.674×10⁻¹¹）:
- U = 3GM²/(5R) = 3×6.674×10⁻¹¹×(5.9722×10²⁴)² / (5×6.371×10⁶) = 2.24×10³² J
- 人類: 2.24×10³² / 6×10²⁰ = 3.7×10¹¹ 年（PREM の 2.49×10³² なら 4.15×10¹¹ 年）→ 「約4000億年」
- ÷ 宇宙の年齢 1.38×10¹⁰ 年 = 27〜30 倍 → 「約30倍」
- 太陽: 2.24×10³² / 3.828×10²⁶ = 5.86×10⁵ s = 6.8 日（PREM なら 7.5 日）→ 「約1週間」
- 月（質量 7.35×10²² kg・半径 1.737×10⁶ m、一様とする）: U = 3×6.674×10⁻¹¹×(7.35×10²²)²/(5×1.737×10⁶) = 1.25×10²⁹ J → ÷3.828×10²⁶ = 326 s ≈ 5.4 分（月の値は今回 WebFetch していない。コメント欄に使うときに NASA Moon Fact Sheet で確かめる）

### god-view-3  型D  「この30秒で、あなたが動いた距離。3つ目がいちばんヤバい」
- 題名: 【うんちく】すわっているだけで、30秒にこれだけ移動している ／ EN: Did you know? How far you moved in these 30 seconds
- 尺: 30秒　しゃべり: (2)　へぇ度: ★4
- フック（0〜1.5秒の画面）: 画面のすみに 30 秒のタイマーがスタート。文字「この30秒で、あなたは何km動く？」
- 台本:
  | 秒 | 画面 | しゃべり／字幕 |
  |---|---|---|
  | 0–3 | タイマー開始・すわっている人 | 「すわっているだけのあなた。この30秒で、どれだけ動くでしょう。3つ目がいちばんヤバい。」 |
  | 3–10 | 1つ目: アプリの地球が自転。日本の上の点が動き、距離のメーターが回る「約11km」 | 「1つ目。地球の自転。日本のあたりだと、30秒で約11km。」 |
  | 10–18 | 2つ目: 引いて、太陽のまわりを回る地球。「約900km」＝東京〜札幌の直線距離より遠い | 「2つ目。太陽のまわりを回る公転。30秒で約900km。」 |
  | 18–27 | 3つ目: さらに引いて、宇宙の"残り火"（宇宙背景放射）を背景に、太陽系ごと動く矢印。「約1万1千km」＝ 地球の直径に近い | 「3つ目。宇宙のはじめの光、"宇宙の残り火"にくらべると、太陽系ごと秒速370km。30秒で約1万1千km。地球1個ぶん近く動いています。」 |
  | 27–30 | タイマー 30秒で止まる | 「…はい、30秒。いま、地球1個ぶん近く、動きました。」 |
- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: 30秒で 自転 約11km（東京の緯度）・公転 約890km・宇宙背景放射に対して 約1万1千km（地球の直径 1万2742km に近い）。
- 絵の作り方: アプリの録画（地球 → 太陽系 → 銀河へ引くズーム。昼夜の境目が動く）／Canvas の図（距離のメーター、30秒タイマー、矢印）
- 出どころ:
  - NASA Earth Fact Sheet（公転の平均の速さ 29.78 km/s・赤道半径）, https://nssdc.gsfc.nasa.gov/planetary/factsheet/earthfact.html（WebFetch で確認）
  - Planck Collaboration（2020）"Planck 2018 results. I. Overview and the cosmological legacy of Planck", A&A 641, A1: 宇宙背景放射に対する太陽系の速さ 369.82±0.11 km/s, https://arxiv.org/abs/1807.06205（検索で値を確認）
  - 自転の速さは 赤道半径 6,378.137 km と 1恒星日 86,164 s からの計算
- 推定・注意: 3つ目は「宇宙背景放射の向きのかたより（双極子）を、全部わたしたちの動きのせいとしたとき」の値（ふつうはそう考えるが、研究で確かめ中）→ 字幕に小さく「宇宙の残り火を止まった目印にすると」。地球は太陽のまわりを回っているので、季節で ±30 km/s 変わる（30秒で ±900km）→ 「約1万km」と丸めてもよい。「東京〜札幌」は直線で約830km の目安（地図で確かめてから使う。使わないなら「約900km」だけ）。速さを足し合わせない（向きがばらばら）。
- コメント欄の問い（任意）: 「いちばん速く動いているのは、1年のうちいつ？」

計算（30秒）:
- 自転: 2π × 6,378,137 m / 86,164 s = 465.1 m/s（赤道）× cos 35.7°（東京）= 377.8 m/s → × 30 s = 11.3 km
- 公転: 29.78 km/s × 30 s = 893 km
- 宇宙背景放射に対して: 369.82 km/s × 30 s = 11,095 km（地球の直径 2 × 6,371 = 12,742 km の約87%）
