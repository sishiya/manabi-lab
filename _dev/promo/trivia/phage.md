# うんちく台本: phage（細菌にとりつくウイルス）

2026-11-02 台本作家（サブエージェント）。型は PATTERNS.md。ファージ（細菌のウイルス）の話で、人の病気・治療の話はしない（入れるなら字幕だけか、ユーザーの声）。

### phage-1  型C  「この動画を見ているあいだに、海では」　◎おすすめ
- 題名: 【うんちく】この30秒で、海ではウイルスの感染が 3×10²⁴ 回 ／ EN: Did you know? 10²³ viral infections happen in the ocean every second
- 尺: 30秒　しゃべり: (1) 字幕だけ（BGM＋カウントの音）　へぇ度: ★5
- フック: 右上に時計（0.0秒から進む）と、桁がふえ続けるカウンター。「この動画のあいだに、海で」
- 台本:
  | 秒 | 画面 | しゃべり／字幕 |
  |---|---|---|
  | 0–2 | 時計とカウンターが動き出す | この動画を見ているあいだに、海で起きていること。 |
  | 2–7 | 青い海、細菌にウイルスが刺さる（アプリの着陸の場面） | ウイルスが、細菌にとりつく。 |
  | 7–12 | カウンターが 10²³ を1秒ごとに足していく | その回数、1秒に、およそ10の23乗回。 |
  | 12–18 | 地球の人の数（82億）で割る図 | 世界の人ひとりあたり、1秒に約12兆回。 |
  | 18–24 | 海全体のウイルスの数 10³⁰ | 海のウイルスは、ぜんぶで10の30乗。海でいちばん多い「いのちのようなもの」。 |
  | 24–30 | 時計が30秒に。カウンター 3×10²⁴ | この30秒で、およそ3×10の24乗回。…いまも。（最初の時計へ） |
- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: 1秒に約10²³回。人ひとりあたり1秒に約12兆回（10²³ ÷ 82億 ≒ 1.2×10¹³）。30秒で 3×10²⁴ 回。
- 絵の作り方: アプリの録画（タブ1「着陸させる」でファージが細菌に刺さる瞬間、タブ2の細菌の中で増える早回し）＋ promo.js の数字カウンター。
- 出どころ: Suttle, C. A. (2007) Marine viruses — major players in the global ecosystem, Nature Reviews Microbiology 5, 801–812（PubMed の要旨で「海のウイルス 約10³⁰」「1秒に約10²³回の感染」を確認） https://pubmed.ncbi.nlm.nih.gov/17853907/ 。人の数は国連の世界人口推計（約82億、2024〜25年）。
- 推定・注意: 10²³ は桁の見積もり（「およそ」と画面に）。海のウイルスのすべてがファージではない（多くは細菌・ラン藻にとりつくもの、と字幕を「ウイルス」で統一）。人の数の出どころは収録前に国連の最新値で。
- コメント欄の問い: 「いま何秒で見るのやめた？（その回数を計算してみて）」

### phage-2  型H  「ウイルスの頭の中の圧力、シャンパンの何倍？」
- 題名: 【うんちく】ウイルスの頭の中は、シャンパンの10倍の圧力 ／ EN: Did you know? A phage packs its DNA at 10x champagne pressure
- 尺: 25秒　しゃべり: (2) VOICEVOX　へぇ度: ★5
- フック: シャンパンの瓶の線画と、ファージの頭。「中の圧力、どっちが高い？」3択「シャンパン／同じ／ウイルス」
- 台本:
  | 秒 | 画面 | しゃべり／字幕 |
  |---|---|---|
  | 0–2 | 瓶とファージの頭、3択 | シャンパンの瓶と、ウイルスの頭。中の圧力が高いのは？ |
  | 2–4 | カウント | — |
  | 4–8 | 「ウイルス」に丸、60気圧 | ウイルス。およそ60気圧。シャンパンの約10倍。 |
  | 8–15 | 長いDNAのひもが、頭の小さな入口から吸いこまれる | ファージは、自分の長いDNAを、モーターで頭に押しこむ。 |
  | 15–21 | 力くらべ: 筋肉のモーター 5 ／ ファージ 57〜60（ピコニュートン） | その力は、筋肉を動かす分子のモーターの10倍以上。 |
  | 21–25 | 細菌に刺さると、圧力でDNAが流れ出す（アプリの場面） | だから刺さった瞬間、DNA がいきおいよく流れこむ。 |
- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: 約60気圧（＝約6MPa。シャンパンの瓶は5〜6気圧）。モーターの力 57〜60pN、筋肉のミオシンは約5pN。
- 絵の作り方: Canvas で瓶とファージの頭・力くらべの棒グラフ。最後にアプリの録画（タブ1、さやが縮んで DNA が流れこむところ）。
- 出どころ: Smith, D. E.; Tans, S. J.; Smith, S. B.; Grimes, S.; Anderson, D. L.; Bustamante, C. (2001) The bacteriophage φ29 portal motor can package DNA against a large internal force, Nature 413, 748–752。UC バークレーの発表 (2001-10-18) で 60気圧・シャンパンの10倍・57〜60pN・ミオシン約5pN を確認 https://newsarchive.berkeley.edu/news/media/releases/2001/10/18_motor.html
- 推定・注意: 測ったのはファージ φ29（アプリの T4 とは別のファージ）。字幕で「ファージ φ29 の測定」と書く。DNA が流れこむのを圧力だけで説明しきれるかは研究で議論があるので、最後の行は「いきおいよく」程度にとどめる。
- コメント欄の問い: 「60気圧、どのくらいの深さの海と同じでしょう？」（答え: 約600m。水深10mで約1気圧ふえる）

### phage-3  型F  「ウイルスどうしが“相談”して、殺すか待つかを決める」
- 題名: 【うんちく】ウイルスは、なかまと合図を送りあう ／ EN: Did you know? Some phages talk to each other before deciding to kill
- 尺: 35秒　しゃべり: (2) VOICEVOX 2人　へぇ度: ★4
- フック: 「え、ウイルスって会話するの？」「する種類がいるのよ」
- 台本:
  | 秒 | 画面 | しゃべり／字幕 |
  |---|---|---|
  | 0–2 | 2つのファージがふきだしなしで向き合う | A「え、ウイルスって会話するの？」 B「するのが見つかったの。2017年」 |
  | 2–9 | 細菌の中で2つの道: 破って出る／DNAにかくれて待つ | B「ファージは細菌に入ると、すぐ破って増えるか、細菌の DNA にもぐって待つかを選ぶ」 |
  | 9–16 | 破れた細菌から、小さな粒（6つのアミノ酸の合図）が出る | B「増えるとき、6つのアミノ酸の小さな合図をまわりに出しておくの」 |
  | 16–24 | まわりの合図がふえる（濃さのメーター） | A「それで？」 B「あとから入ったファージは、合図が多いと『もうなかまが多い』と知って、待つほうを選ぶ」 |
  | 24–30 | 細菌が全部いなくならず、残る | A「細菌を食べつくさないように？」 B「そう。ファージごとに合図の“ことば”もちがう」 |
  | 30–35 | 2つのファージがうなずく | A「ウイルス、空気よむんだ…」 |
- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: 合図はアミノ酸わずか6個。ファージの種類ごとに別の「ことば」（例: SAIRGA と GMPRGA）。
- 絵の作り方: Canvas で合図の粒と濃さのメーター。アプリの録画（タブ2「細菌の中」の、増えて破れる場面）を背景に。※アプリの T4 はこのしくみを持たない（かくれて待つ道もない）ので「別のファージの話」と字幕に。
- 出どころ: Erez, Z. ほか (2017) Communication between viruses guides lysis–lysogeny decisions, Nature 541, 488–493, doi:10.1038/nature21049（枯草菌のファージ SPβ のなかま。phys.org (2017-01-19) で「6アミノ酸の合図」「多いほど待つ道を選ぶ」を確認） https://phys.org/news/2017-01-phages-peptide.html
- 推定・注意: 「相談」「空気をよむ」はたとえ。意思はなく、合図の濃さで遺伝子のスイッチが切りかわるしくみ、と最後に小さく。「細菌を食べつくさないため」は研究者の解釈として「らしい」。
- コメント欄の問い: 「ほかに“会話”する小さな生きもの、知ってる？」
