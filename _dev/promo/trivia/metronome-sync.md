# メトロノームがそろうまで（metronome-sync）うんちくショート台本

2026-11-02 作。PATTERNS.md の型で3本（A・F・H）。「板が1mmゆれるからそろう」は作り済みなので使わない。テーマは「勝手にそろう」を、メトロノームの外（橋・拍手・最初の発見）に広げる。

### metronome-sync-1  型A  「橋がゆれたから、人がそろった」　◎おすすめ
- 題名: 【うんちく】人が足並みをそろえて橋をゆらした…は逆だった ／ EN: Did you know? The bridge didn't wobble because people marched in step — it was the other way round
- 尺: 40秒　しゃべり: (2) VOICEVOX　へぇ度: ★5
- フック（0〜1.5秒の画面）: 横から見た細い吊り橋の線画が左右にゆれる。大きく「原因と結果が、逆。」
- 台本:

| 秒 | 画面 | しゃべり／字幕 |
|---|---|---|
| 0–2 | 線画の橋がゆれる | 橋がゆれた原因と結果は、逆だった。 |
| 2–7 | 「2000年 ロンドン・テムズ川の新しい歩道橋」日付 6/10 | 2000年、ロンドンに新しい歩道橋ができた。開通の日、橋は横にゆれはじめた。 |
| 7–12 | 「横の揺れ 最大 0.25 g」「2日後に通行止め」 | 横ゆれは最大で重力の4分の1。2日後には、通行止めに。 |
| 12–17 | 点の人がばらばらに歩く（新しい計算: 人＝点、足の位相を色で） | 「みんなが足並みをそろえたから、ゆれた」…と思うよね。 |
| 17–25 | 人数のカウンターが増える。ある人数で、橋のゆれと人の色が同時にそろう | でも、はじめはみんなばらばら。人数がある数をこえた瞬間、ほんの少しゆれた橋に合わせて、人のほうが歩き方を合わせた。 |
| 25–31 | 「ゆれる → そろう → もっとゆれる」の輪の矢印 | そろうから、ゆれる。ゆれるから、そろう。どっちが先でもない、ひとつの輪。 |
| 31–36 | 試験の人数「約160人」 | 試験では、160人くらいをこえたところで、急にはじまった。 |
| 36–40 | アプリの録画: 板の上のメトロノームがそろう（短く） | 板の上のメトロノームと、同じしくみ。人も、振り子だった。 |

- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: 約160人で突然はじまる（それより少ないと何も起きない）。開通の日は最大 2,000 人がいっぺんに乗っていた。橋の揺れをおさえる力（減衰）は、なおす前 0.5%、なおした後 20%（40倍）。
- 絵の作り方: Canvas の図（橋の線画、点の人）／新しい計算（Strogatz ほか 2005 の式: 橋＝ばね・おもり・ダンパー、人＝自分の歩く速さを持つ振り子が橋のゆれに少し引っぱられる。人数を少しずつ増やす）／アプリの録画（最後の数秒）。
- 出どころ:
  - Strogatz, Abrams, McRobie, Eckhardt, Ott (2005) "Crowd synchrony on the Millennium Bridge", Nature 438, 43–44. https://dmabrams.esam.northwestern.edu/pubs/ （PDF を取得し本文を確認: 開通の日に横ゆれ、多くの人が橋のゆれに合わせて歩いた、ゆれとそろいは臨界の人数で同時に起きる、2000年12月の人数を増やす試験）
  - Douglas P. Taylor "Damper Retrofit of the London Millennium Footbridge — a case study in biodynamic design", Taylor Devices, https://www.taylordevices.com/wp-content/uploads/66-Damper-Retrofit-of-London.pdf （PDF の本文を確認: 2000-06-10 開通、初日に約10万人、最大2,000人、横の加速度 最大 0.25 g、6/12 に通行止め、減衰 0.5% → 20%）
  - 試験で揺れが始まった人数: phys.org (2005-11) https://phys.org/news/2005-11-millennium-bridge.html の「約160人」（検索結果の要約）。資料により 156〜166 人。
- 推定・注意:
  - 人数は資料で 156〜166 とばらつく → 画面は「約160人」。Arup の元の報告（Dallard ほか 2001, The Structural Engineer 79(22)）は取得できなかった。
  - 新しい計算の人の動きはモデル（Strogatz ほか 2005）と画面に。橋の名前を出すのはよい（建物は人物でない）。橋の写真は使わない（線画）。
- コメント欄の問い（任意）: 「人がそろってしまうもの、ほかに何がある？」

### metronome-sync-2  型F  「ホイヘンスは、寝こんでいた」
- 題名: 【うんちく】振り子がそろうのを見つけた人は、ベッドで寝こんでいた ／ EN: Did you know? Synchronization was discovered by a man stuck in bed
- 尺: 35秒　しゃべり: (2) VOICEVOX 2人（聞き手・答える人）　へぇ度: ★4
- フック（0〜1.5秒の画面）: 壁に並んだ2つの振り子時計の線画と、ベッドの線画。「1665年2月」
- 台本:

| 秒 | 画面 | しゃべり／字幕 |
|---|---|---|
| 0–3 | 時計2つ＋ベッド | A「振り子がひとりでにそろうって、だれが見つけたの？」 B「寝こんでた人。」 |
| 3–9 | 「1665年2月26日 父への手紙」 | B「1665年、オランダのホイヘンス。数日ベッドから出られなくて、部屋の時計2つをずっと見てたの。」 |
| 9–15 | 2つの振り子が逆向きにそろってゆれる（アプリで板を固定した逆向きの場面、または新しい計算） | A「ひまだね。」 B「そしたら、2つの振り子が、ぴったりそろってる。」 |
| 15–21 | 1つをわざとずらす → 時計の針で30分 → またそろう | B「わざとずらしても、30分たつと、また元どおり。」 A「こわい。」 |
| 21–28 | 「空気？」に × 、「かけてある木の梁がほんの少し動く」に ○ | B「本人ははじめ、振り子が起こす空気の流れのせいだと思った。でも本当は、時計をかけた木が、目に見えないくらい動いて、つないでいた。」 |
| 28–35 | 2002年の再現の文字、逆向きにそろう2本 | B「340年後に同じ時計を作った実験でも、やっぱりそろった。いつも、逆向きに。」 A「寝こむのも、むだじゃないね。」 |

- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: ずらしても「30分」で元にもどる（アニメ1話より少し長いくらい）。
- 絵の作り方: Canvas の線画（時計・ベッド・木の梁）／アプリの録画（2台、そろう場面。逆向きの場面は床をぬらす設定＝PLAN の「Huygens の時計と同じ」）。
- 出どころ:
  - Pikovsky, Rosenblum, Kurths (2001) "Appendix A1: Discovery of synchronization by Christiaan Huygens", Synchronization: A Universal Concept in Nonlinear Sciences, Cambridge Univ. Press, pp. 357–361, doi:10.1017/CBO9780511755743.017. https://www.cambridge.org/core/books/abs/synchronization/discovery-of-synchronization-by-christiaan-huygens/32B8ED5D53825A22A014C67140C1D0CE （WebFetch で確認: 1665-02-26 の手紙、「数日ベッドにいなければならず」、30分後にはいつもそろいにもどる、「一種の共感（sympathy）」、空気の動きのせいと考えた）
  - Bennett, Schatz, Rockwood, Wiesenfeld (2002) "Huygens's clocks", Proc. R. Soc. Lond. A 458, 563–579。再現の時計がいつも逆向きにそろったこと: Scientific American (2000-09-11) "Swinging through Time" https://www.scientificamerican.com/article/swinging-through-time/ （WebFetch で確認: 実物どおりの複製、梁（台）の目に見えない動きをホイヘンス自身が推測、父への手紙）。「いつも逆向きに」は ScienceDaily (2000-09-21) https://sciencedaily.com/releases/2000/09/000921072258.htm （WebFetch で確認: 「これまでのところ、逆向きにしかそろわなかった」。そろわずに片方か両方が止まってしまう「振幅の死」もあった）
- 推定・注意:
  - 手紙の「ベッドにいた」理由（かぜ・病気）は資料に書いていない → 「寝こんでいた」までにして、病名は言わない。
  - 「逆向きにそろう」は Bennett ほか 2002 の再現の結果。手紙の訳では「そろった」とだけ書く資料もある。
  - 聞き手のセリフ「こわい」は軽い言い回しとして。
- コメント欄の問い（任意）: なし

### metronome-sync-3  型H  「拍手がそろうと、音は？」
- 題名: 【うんちく】拍手がそろうと、会場の音は大きくなる？小さくなる？ ／ EN: Did you know? When applause synchronizes, the hall gets quieter
- 尺: 30秒　しゃべり: (1) 字幕だけ（拍手の効果音つき）　へぇ度: ★4
- フック（0〜1.5秒の画面）: 「拍手がそろうと、音は？ ①大きくなる ②小さくなる」
- 台本:

| 秒 | 画面 | しゃべり／字幕 |
|---|---|---|
| 0–3 | 2択 | 拍手がそろうと、会場の音は？ ①大きくなる ②小さくなる |
| 3–5 | カウントダウン 2・1 | （考える時間） |
| 5–9 | 答え「② 小さくなる」 | 答えは②。そろうと、平均の音は小さくなる。 |
| 9–15 | 天井のマイクの音の波形（新しい計算: ばらばら → そろう）。そろうと山は高いが、すきまが空く | ルーマニアとハンガリーの劇場で、天井にマイクを置いて測った研究。 |
| 15–21 | 1人の手のたたく間かくの図: 「速い」→ そろう瞬間に「間かくが2倍」 | そろう瞬間、みんな、たたく速さを半分に落としていた。ゆっくりだと、ばらつきが小さくて、そろえやすい。 |
| 21–26 | 間かくがだんだん短く → そろいがくずれる | でも、もっと盛り上げたくて速くたたくと、またばらばらに。 |
| 26–30 | 「そろう ↔ くずれる」をくり返す線 | だから拍手は、そろって、くずれて、またそろう。 |

- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: そろうとき、たたく間かくが2倍（速さが半分）になる。
- 絵の作り方: 新しい計算（人＝点、蔵本モデルのばらつきの大小で、そろう／くずれるを見せる。波形はそこから作る）／Canvas の図（間かくのグラフ）。アプリの「位相の円」の見た目を借りてもよい。
- 出どころ:
  - Néda, Ravasz, Brechet, Vicsek, Barabási (2000) "The sound of many hands clapping", Nature 403, 849–850. arXiv:cond-mat/0003001 https://arxiv.org/abs/cond-mat/0003001 （PDF の本文を確認: ルーマニアとハンガリーの劇場、天井のマイク、そろうと平均の音の強さが下がる、たたく周期が急に2倍、盛り上げようと速くするとそろいが消える、高校生73人の実験で2倍の周期の方がばらつきが小さい）
- 推定・注意:
  - 「東ヨーロッパではほぼ毎回、西ヨーロッパや米国ではたまに」は論文の推測としての記述 → 入れるなら「論文では」とつける（台本には入れていない）。
  - 何 Hz かは本文に数字がないので言わない。
- コメント欄の問い（任意）: 「日本のライブの拍手、そろう？」
