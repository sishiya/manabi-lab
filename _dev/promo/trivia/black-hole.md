### black-hole-2  型A  「大きなブラックホールは、平均すると空気より軽い」　◎おすすめ
（2026-11-02 批評で直した: 題名を言い切りに・0秒の画面から「平均すると」・EN に on average・「軽い」より「すかすか」）
（番号は既存の trivia1 のつぎから）
- 題名: 【うんちく】大きなブラックホールは、平均すると空気より軽い ／ EN: Did you know? A giant black hole is less dense than air — on average
- 尺: 30秒　しゃべり: (2)　へぇ度: ★5
- フック（0〜1.5秒の画面）: 黒い穴の横に風船。文字「平均すると、空気よりすかすか」（「平均すると」を0秒から同じ大きさで）
- 台本:
  | 秒 | 画面 | しゃべり／字幕 |
  |---|---|---|
  | 0–2 | 黒い穴と風船。文字「平均すると、空気よりすかすか」 | 「ブラックホールは、ものすごく詰まっている。…大きいものは、平均すると、ちがいます。」 |
  | 2–8 | 太陽が縮んで直径6kmの球に。「1cm³で 180億トン」 | 「太陽をブラックホールにすると、直径たった6km。地平線の内側の平均は、1cm³で180億トン。」 |
  | 8–15 | 重さを100倍・1万倍…と上げると、球がどんどん大きく、数字（密度）がどんどん下がる | 「でも、重くするほど、地平線は重さに比例して大きくなる。体積は3乗で増えるので、平均の密度は下がっていきます。」 |
  | 15–19 | 太陽の1億4千万倍の点で「水と同じ」 | 「太陽の1億4千万倍で、水と同じ。」 |
  | 19–26 | アプリの録画（影と光の輪）＋「M87：太陽の65億倍」「平均 0.44 kg/m³ ＜ 空気 1.2 kg/m³」 | 「人類が初めて写したM87のブラックホールは、太陽の65億倍。平均すると、空気より軽い。」 |
  | 26–30 | 字幕「重いほど、すかすか（平均すると）」 | 「重いほど、すかすか。…なのに、光も出られない。」 |
- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: M87* の地平線の内側の平均の密度 約0.44 kg/m³。地上の空気（約1.2 kg/m³）の約3分の1。
- 絵の作り方: アプリの録画（a を小さめ、映画版オフで影と光の輪をゆっくり回る）／Canvas の図（重さのつまみで地平線の球が大きくなり、密度の数字が下がる。水・空気の線）
- 出どころ:
  - EHT Collaboration（2019）"First M87 Event Horizon Telescope Results. VI. The Shadow and Mass of the Central Black Hole", ApJL 875, L6（M = 6.5±0.7×10⁹ 太陽質量）, https://arxiv.org/abs/1906.11243（検索で要旨の値を確認）
  - シュヴァルツシルト半径 r = 2GM/c²（一般相対論の教科書。例: Schutz『A First Course in General Relativity』）
  - 空気の密度 1.225 kg/m³（国際標準大気、海面・15℃）
- 推定・注意: 「平均の密度」は「重さ ÷（半径 r の、ふつうの球の体積）」という目安。曲がった時空では「地平線の内側の体積」ははっきり決まらないし、中に物がふつうに詰まっているわけでもない → 画面に「重さを地平線の球の大きさで割ると」と必ず出す。回転（カー）の地平線はもう少し小さいが、桁は変わらない。「軽い」は浮くという意味ではない（字幕では「すかすか（平均すると）」）。
- コメント欄の問い（任意）: 「水と同じ密度になるブラックホール、地平線の大きさはどれくらい？」（答え: 半径 約4億km、地球〜太陽の約2.7倍）

計算（G=6.674×10⁻¹¹, c=2.998×10⁸, 太陽 1.989×10³⁰ kg）:
- 太陽の重さ: r = 2GM/c² = 2.95 km（直径 5.9 km）。密度 = M/(4/3·π·r³) = 1.84×10¹⁹ kg/m³ = 1cm³ あたり 1.84×10¹³ g = 約180億トン
- 密度は M⁻² に比例: ρ(M) = 1.84×10¹⁹ kg/m³ × (M/太陽)⁻²
- 水（1000 kg/m³）になる重さ: √(1.84×10¹⁹/1000) = 1.36×10⁸ 太陽 → 「1億4千万倍」。r = 2.95 km × 1.36×10⁸ = 4.0×10⁸ km
- M87*（6.5×10⁹ 太陽）: r = 1.92×10¹³ m、ρ = 1.84×10¹⁹ / (6.5×10⁹)² = 0.44 kg/m³
- 0.44 / 1.225 ≈ 0.36（空気の約3分の1）

### black-hole-3  型H  「引きちぎられるのは、どっち？」
- 題名: 【うんちく】大きいブラックホールほど、落ちてもちぎれない ／ EN: Did you know? Bigger black holes are gentler at the edge
- 尺: 25秒　しゃべり: (1) 字幕だけ　へぇ度: ★4
- フック（0〜1.5秒の画面）: 小さい黒丸と大きい黒丸。まん中に棒人間。「地平線で 引きちぎられるのは？」
- 台本:
  | 秒 | 画面 | しゃべり／字幕 |
  |---|---|---|
  | 0–3 | 2択: A 太陽の10倍のブラックホール／B 太陽の400万倍（天の川のまん中） | 「地平線まで落ちたとき、体が引きちぎられるのはどっち？」 |
  | 3–6 | カウント 3・2・1 | 「A 小さい　B 大きい」 |
  | 6–12 | A: 人がスパゲッティのようにのびる。「頭と足の引っぱりの差 ＝ 2000万G」 | 「答えは A。地平線で、頭と足の引っぱりの差は2000万G。」 |
  | 12–18 | B: 人はそのまま、ふつうに通過。「1万分の1G」 | 「天の川のまん中のブラックホールなら、たった1万分の1G。気づかずに地平線をこえます。」 |
  | 18–23 | 図: 地平線の大きさは重さに比例、引っぱりの差は距離の3乗で弱まる → 重さの2乗で弱くなる | 「大きいほど地平線が遠く、引っぱりの"差"が小さくなるから。」 |
  | 23–25 | 字幕「ただし、出られない」 | 「ただし、どちらも二度と出られない。」 |
- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: 身長2mの人の頭と足の引っぱりの差（地平線で）: 太陽10倍 → 約2×10⁸ m/s²（地球の重力の約2000万倍）、いて座A*（約400万倍）→ 約1.3×10⁻³ m/s²（約1万分の1G。エレベーターが動きだすときよりずっと小さい）。
- 絵の作り方: Canvas の図（2つの穴と人、のびる人のアニメ、数字）／アプリの録画（近づくカメラ。r を小さくしていく場面）
- 出どころ:
  - EHT Collaboration（2022）"First Sagittarius A* Event Horizon Telescope Results. I"（質量 ～4×10⁶ 太陽）と同 IV（4.0 +1.1/−0.6 ×10⁶）, https://arxiv.org/abs/2311.08697（検索で要旨の値を確認）
  - 潮汐の差 Δa ≈ 2GM·L/r³（ニュートンの近似。シュヴァルツシルト時空で自由落下する人の動径方向の潮汐も同じ形）。地平線では Δa = c⁶L/(4G²M²) で M⁻² に比例。Astronomy 誌（2023年2月号）も太陽質量で約 1.96×10¹⁰ m/s²、1億太陽で約 1.9×10⁻⁶ m/s² と同じ桁（検索で確認）
- 推定・注意: 2m の人・まっすぐ足から落ちる場合の目安。大きいブラックホールでも、中に入ってから中心に近づくと引きちぎられる（字幕の最後でにごさない: 「出られない」）。
- コメント欄の問い（任意）: 「地平線で"1G"の差になるのは、太陽の何倍のブラックホール？」（答え: 約4万6千倍）

計算（L = 2 m）:
- 地平線 r = 2GM/c²、Δa = 2GM·L/r³
- 太陽10倍: r = 29.5 km、Δa = 2×(6.674×10⁻¹¹×1.989×10³¹)×2 / (2.954×10⁴)³ = 2.06×10⁸ m/s² → ÷9.81 = 2.1×10⁷ G（2000万G）
- いて座A*（4.0×10⁶ 太陽）: r = 1.18×10¹⁰ m、Δa = 1.29×10⁻³ m/s² → 1.3×10⁻⁴ G（約1万分の1G）
- 1G になる重さ: Δa ∝ M⁻² → 10 太陽 × √(2.1×10⁷) ≈ 4.6×10⁴ 太陽

### black-hole-4  型F  「地平線の内側の、のこり時間」
- 題名: 【うんちく】ブラックホールに落ちたら、のこり何秒？ ／ EN: Did you know? Inside a black hole, you have at most this long
- 尺: 32秒　しゃべり: (2) 声2つ（聞き手・答える人）　へぇ度: ★4
- フック（0〜1.5秒の画面）: 地平線をこえる瞬間。大きく「のこり ？秒」
- 台本:
  | 秒 | 画面 | しゃべり／字幕 |
  |---|---|---|
  | 0–3 | 地平線をこえる | 聞き手「ブラックホールに落ちたらさ、中心まで、どれくらい？」 |
  | 3–8 | タイマー「最長 1分」＋天の川のまん中の図 | 答え「天の川のまん中のブラックホールなら、地平線をこえてから、どうがんばっても最長で約1分。」 |
  | 8–12 | 聞き手の顔文字（字幕）「え、1分しかないの？」 | 聞き手「ロケットでふんばれば？」 |
  | 12–19 | 道すじの図: 中は「中心へ向かう道」しかない | 答え「中では、中心は"場所"じゃなくて"未来"。どっちへ吹かしても、未来へは進んじゃう。いちばん長いのは、地平線で止まった状態から、ただ落ちるとき。」 |
  | 19–26 | 3つのタイマー: 太陽10倍「0.00015秒」／天の川「約1分」／M87「約28時間」 | 答え「長さは重さに比例。星くらいの小さいのは1万分の1.5秒。M87なら28時間。」 |
  | 26–32 | 聞き手「28時間あれば…」→ 答え「出られはしないけどね」 | 聞き手「28時間あれば、映画10本見られる！」 答え「出られはしないけどね。」 |
- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: 地平線の内側で過ごせる最長の時間（本人の時計）τ = πGM/c³。いて座A* 約62秒、M87* 約28時間、太陽10倍 約0.15ミリ秒。
- 絵の作り方: Canvas の図（タイマー3つ・地平線の中の道すじ。中では光の円すいが中心へ倒れる図）／アプリの録画（地平線へ近づくカメラ、黒い影が画面いっぱいになるところ）
- 出どころ:
  - Lewis & Kwan（2007）"No Way Back: Maximizing Survival Time Below the Schwarzschild Event Horizon", PASA 24, 46: 「地平線の下で経験できる最長の時間は τ = πm」「これは地平線で静止した状態から落ちる人の時間」「星の重さなら1秒に満たず、超大質量なら数時間にもなる」, https://ar5iv.arxiv.org/html/0705.1029（WebFetch で確認）
  - 質量: EHT（2019）M87* 6.5×10⁹ 太陽、EHT（2022）Sgr A* 約4×10⁶ 太陽（black-hole-2・3 と同じ）
- 推定・注意: 回転しないブラックホール（シュヴァルツシルト）での値。M87* も Sgr A* も実際は回っていて、中のつくりは分かっていない（字幕に「回っていないとして」）。「中心は未来」は一般相対論のふつうの説明（地平線の内側では r が時間のようにふるまう）だが、言いすぎないよう「…みたいなもの」とやわらげてもよい。映画10本は 1本2.8時間の目安（ネタなので数字は出さなくてもよい）。
- コメント欄の問い（任意）: 「のこり28時間、あなたなら何をする？」

計算（GM_sun/c³ = 4.93×10⁻⁶ s）:
- τ = π × 4.93×10⁻⁶ s × (M/太陽)
- 太陽10倍: 1.55×10⁻⁴ s（0.15ミリ秒＝1万分の1.5秒）
- Sgr A*（4.0×10⁶）: 61.9 s（約1分）。4.3×10⁶ の値を使っても 66 s
- M87*（6.5×10⁹）: 1.006×10⁵ s = 27.9 時間（約28時間）
