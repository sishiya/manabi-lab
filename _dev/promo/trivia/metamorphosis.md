# うんちくショート台本 — さなぎの中で（metamorphosis）

2026-11-02 作成（台本の候補。ユーザーが選ぶ前）。仕様は `PATTERNS.md`。
モデルの虫はタバコスズメガ（*Manduca sexta*）。虫の写真は使わない（アプリの模式図・Canvas の線画だけ）。こわがらせるだけの絵にしない。

アプリで作れる絵: 体を横から見た模式図を時間のスライダーで。器官を「壊れる／残って作りかえる／新しく作る／材料」の色分けで、透かす・割る・外から見る。

---

### metamorphosis-1  型F  「イモムシのときの記憶、ガになっても残る？」 ◎おすすめ
- 題名: 【うんちく】イモムシのときに覚えたこと、ガになっても覚えていた ／ EN: Did you know? Moths remember what they learned as caterpillars
- 尺: 40秒　しゃべり: (1) 字幕の掛け合い か (2) VOICEVOX 2人　へぇ度: ★5
- フック（0〜1.5秒の画面）: イモムシの模式図 → さなぎ → ガ。頭の中の小さな点（記憶）がずっと光ったまま。文字「この記憶、残る？」
- 台本:
  | 秒 | 画面 | しゃべり／字幕 |
  |---|---|---|
  | 0–4 | イモムシの模式図 | 聞き手「さなぎの中って、ぜんぶドロドロになるんでしょ？ じゃあ記憶も消える？」 |
  | 4–12 | Y字の通路の図。片方からにおい（酢酸エチル＝接着剤や除光液にも使われるにおい）、そのあと小さな電気 | 答え「2008年の実験。イモムシに、あるにおいのあとで弱い電気を感じさせる。8回くり返す」 |
  | 12–16 | 「78% がにおいをさけた」 | 「するとイモムシは、そのにおいをさけるようになった」 |
  | 16–22 | アプリの録画: スライダーを進めてさなぎの中。筋肉は壊れ（朱色）、脳と神経は残って作りかえ（空色） | 聞き手「でも、さなぎで体はつくりかえでしょ？」　答え「そう。でも脳と神経は、ぜんぶは壊れない」 |
  | 22–30 | ガになって Y字の通路へ。「77% がにおいをさけた」 | 「ガになってから同じ通路に入れると…77% がにおいをさけた」 |
  | 30–36 | 「においが残ってただけ？」→ さなぎを洗う／さなぎににおいをつける図 | 聞き手「体ににおいが残ってただけじゃない？」　答え「さなぎを洗っても残った。教えていないさなぎににおいをつけても、さけなかった」 |
  | 36–40 | 3つ目の結果: 「3齢（若いころ）に教えたら、ガでは忘れていた」 | 「ただし、若すぎるころに覚えたことは、ガになると消えていた」 |
- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: 5齢（最後のイモムシ）で教えると、ガの 77% がさけた（何もしない虫はほぼ半々）。3齢で教えると、イモムシのうちは 81% 覚えていたのに、ガでは覚えていなかった。
- 絵の作り方: アプリの録画（幼虫 → 蛹 → 成虫のスライダー。透かして見るで、壊れる筋肉と残る神経の色）／Canvas（Y字の通路と数字）。
- 出どころ: Blackiston D.J., Silva Casey E., Weiss M.R.（2008）Retention of memory through metamorphosis: can a moth remember what it learned as a caterpillar?, PLoS ONE 3(3):e1736, https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0001736 （WebFetch で本文を確認: 酢酸エチル、8回の組み合わせ、5齢 78%・成虫 77%（N=27）、3齢 → 5齢 81%・成虫では有意でない、洗った蛹・においをつけた蛹の対照）。
- 推定・注意: 電気は「弱い」とだけ言い、いたそうな絵にしない。「酢酸エチル＝除光液のようなにおい」はたとえ（除光液の主成分はアセトンのことが多いので、言うなら「接着剤や除光液にも使われるにおい」）。「ぜんぶドロドロ」は聞き手のセリフ（俗説として）で、答えで直す。
- コメント欄の問い（任意）: 子どものころの記憶、いちばん古いのは何歳？

### metamorphosis-2  型A  「さなぎの中はドロドロ…半分ウソ。しかも出てきたあと、神経の半分が死ぬ」
- 題名: 【うんちく】さなぎの中は「ぜんぶドロドロ」じゃない ／ EN: Did you know? A pupa is not just soup
- 尺: 35秒　しゃべり: (1) 字幕だけ　へぇ度: ★4
- フック（0〜1.5秒の画面）: 文字「さなぎの中は ドロドロのスープ」→ 半分だけ × 。
- 台本:
  | 秒 | 画面 | しゃべり／字幕 |
  |---|---|---|
  | 0–4 | 半分 × | 「さなぎの中はドロドロのスープ。…半分ウソ」 |
  | 4–12 | アプリの録画（割って見る → 透かして見る）。朱色の筋肉がかけらに分かれて消える | 「たしかに、イモムシの筋肉の多くはこわれて、材料になる」 |
  | 12–20 | 空色の神経が残り、枝をのばし直す | 「でも、体を動かす神経の細胞は、ほとんどが生き残る。つなぐ先をイモムシの筋肉から、ガの筋肉へ切りかえる」 |
  | 20–24 | 青緑の翅・脚が小さな芽から育つ | 「翅や脚は、小さな芽から新しく作る」 |
  | 24–32 | 羽化。そのあと腹の神経の点が半分消える（時計: 羽化から 2 日） | 「そしてガになったあと。お腹の神経の約半分が、決まった順番で死ぬ。羽化のときにしか使わなかった神経」 |
  | 32–35 | 「つくりかえ ＋ 使い終わったら片づける」 | 「スープじゃなくて、順番どおりの工事」 |
- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: 羽化のあと、お腹の神経（介在ニューロン・運動ニューロン）の約 50% が決まった順に死ぬ。合図はホルモン（エクジソン）が下がること。
- 絵の作り方: アプリの録画（スライダーで P0 → 羽化。透かして見る／割って見る）。羽化後の神経が消える段は、アプリにない場合は Canvas の点で（新しい小さなアニメ）。
- 出どころ: Truman J.W., Schwartz L.M.（1984）Steroid regulation of neuronal death in the moth nervous system, J Neurosci 4(1):274–280, https://www.jneurosci.org/content/jneuro/4/1/274.full.pdf （PDF は 403 で読めず、検索結果の要旨で確認: 羽化のあと腹の介在・運動ニューロンの約50%が決まった予定で死ぬ、合図はエクジステロイドの低下）。運動ニューロンが生き残って相手を変える: Levine R.B., Truman J.W.（1985）J Neurosci（検索結果の要旨で確認: 多くの幼虫の運動ニューロンが蛹で相手を失うが生き残り、成虫の筋肉へつなぎ直す）。
- 推定・注意: 「羽化のときにしか使わなかった神経」はやさしい言い方（論文は羽化のころの行動・筋肉の変化と結びつけている）→ 「羽化のころの仕事を終えた神経（と考えられている）」に。日にち（2日）は Truman らの記述の検索結果からで、本文の図で取り直すとよい。アプリの「残る＝空色」は器官ごとの色なので、細胞の半分が死ぬ話とずれないよう字幕で分ける。
- コメント欄の問い（任意）: さなぎを見たことある？

### metamorphosis-3  型B  「もし人の赤ちゃんがイモムシの速さで育ったら」
- 題名: 【うんちく】イモムシは数週間で1万倍。人の赤ちゃんなら？ ／ EN: Did you know? A caterpillar grows 10,000× in weeks. What if a baby did?
- 尺: 25秒　しゃべり: (1) 字幕 か (2) VOICEVOX　へぇ度: ★4
- フック（0〜1.5秒の画面）: 文字「数週間で 1万倍」。小さな点が画面いっぱいにふくらむ。
- 台本:
  | 秒 | 画面 | しゃべり／字幕 |
  |---|---|---|
  | 0–4 | 0.001 g の点 | 「タマゴから出たばかりのイモムシは 1 ミリグラム。米つぶ（約20mg）の20分の1」 |
  | 4–10 | 数週間で 12〜15 g。点がふくらむ。体重計 | 「数週間後、12〜15グラム。1万倍以上」 |
  | 10–14 | グラフ: 増えた重さの9割は最後の脱皮のあと | 「しかも増える重さの約9割は、最後の1回の脱皮のあと」 |
  | 14–22 | もしも: 3 kg の赤ちゃんの線画 → 1万倍＝30トン。大型トラックの線画と並ぶ | 「もし 3キロの赤ちゃんが1万倍になったら、30トン。大型トラックくらい」 |
  | 22–25 | アプリの録画: 終齢の大きな体 → さなぎ | 「そして、その体を、さなぎの中で作りかえる」 |
- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: 0.001 g → 12〜15 g（1万倍以上、数週間）。重さの増加の約90%は5齢（最後の幼虫）で。3 kg × 1万 = 30 トン（計算）。
- 絵の作り方: Canvas（点がふくらむアニメ、体重計、もしもの線画）／アプリの録画（終齢 → 前蛹 → 蛹）。
- 出どころ: Woods H.A.（2013）Ontogenetic changes in the body temperature of an insect herbivore, Functional Ecology（データの説明 https://datadryad.org/stash/dataset/doi:10.5061/dryad.8sd03 を WebFetch:「数週間で1万倍以上、0.001 g の孵化幼虫から 12〜15 g の5齢」）。Grunert L.W. ほか（2015）A quantitative analysis of growth and size regulation in Manduca sexta, PLoS ONE 10(5):e0127988, https://pmc.ncbi.nlm.nih.gov/articles/PMC4444085 （WebFetch: 最大の幼虫の重さ 11.3±1.5 g、重さの増加の約90%は5齢、えさの期間は条件で12〜45日）。
- 推定・注意: 「3週間」は題名で使うなら条件しだい（12〜45日）と注意 → 題名は「数週間で1万倍」の方が安全。「米つぶ 約20 mg」は出どころを取っていない目安なので、使うなら確かめる（取れなければ「1ミリグラム」だけ）。赤ちゃんの例はただの掛け算（成長のしかたの比較ではない）と分かる言い方に。大型トラックの重さも目安（車両総重量 20〜25 t 級）なので「トラック数台ぶん」でもよい。
- コメント欄の問い（任意）: あなたは生まれてから何倍になった？
