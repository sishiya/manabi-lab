# うんちく台本: passkey（パスキーのしくみ）

2026-11-02 作成（台本だけ）。仕様は `PATTERNS.md`。
アプリで作れる絵: 絵の舞台（スマホの金庫・門番＝ブラウザ・家＝サイト・わるもの）、小包が飛ぶ、色の模様で鍵やサインを見せる。
**決まり**: 本物のログイン画面に似せた絵は使わない（入力欄・ロゴ・ボタンの形をまねない）。こわがらせるだけにしない（どの台本も「だから安心できる」で終わる）。

---

### passkey-1  型A  「パスキーは指紋をサイトに送っている…じゃない」　◎おすすめ
- 題名: 【うんちく】パスキーで指紋を当てても、指紋はどこにも送られない ／ EN: Did you know? Your fingerprint never leaves your phone with passkeys
- 尺: 30秒　しゃべり: (1) 字幕だけ　へぇ度: ★4
- フック（0〜1.5秒の画面）: 指の線画 → 矢印 → 家（サイト）に赤い ✕
- 台本:

  | 秒 | 画面 | しゃべり／字幕 |
  |---|---|---|
  | 0–3 | 指 → 家 に ✕ | パスキーでログイン。指紋がサイトに送られる…じゃない |
  | 3–9 | アプリの録画: スマホの金庫に 👆。指はスマホの中だけで確かめられる | 指紋や顔は、スマホの中で「金庫をあけてよいか」を確かめるだけ |
  | 9–16 | 金庫の中の鍵が、くじ（その場で作った数）にサインして小包に | 送るのは、その場かぎりのサイン。毎回ちがう |
  | 16–23 | 家の側には「鍵穴の形（公開鍵）」だけ | サイトが持っているのは、鍵穴の形だけ。合言葉もない |
  | 23–30 | わるものが鍵穴の形を持っていっても扉は開かない | だから、サイトの中身が盗まれても、あなたの鍵は作れない |

- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: サイトに渡るのは「鍵穴の形（公開鍵）」と「毎回ちがうサイン」だけ。指紋・顔のデータは 0 バイト。
- 絵の作り方: アプリの録画（パスキーのモードで登録 → ログイン、金庫・門番・家・小包の舞台。わるものが盗む実験の場面）／Canvas（指 → 家の ✕ の線画）
- 出どころ:
  - FIDO Alliance, Passkey Central「How Passkeys Work」https://www.passkeycentral.org/introduction-to-passkeys/how-passkeys-work （WebFetch 済み: 生体・PIN での解錠はその端末の中だけ、サイトは公開鍵とサインだけを受けとる、パスワードのハッシュにあたるものをサイトは持たない、登録したサイトにしか出さない）
  - W3C「Web Authentication Level 3」https://www.w3.org/TR/webauthn-3/ （WebFetch 済み: 資格情報は RP ID に結びつき、その RP に属する origin からしか使えない）
- 推定・注意:
  - 「サイトの中身が盗まれても、その公開鍵ではログインできない」まで。サイトの別の弱さ（中で別のことをされる）までは言わない。
  - 端末どうしで同期するパスキーは、秘密鍵が暗号化されて自分の端末の間を移ることがある。「指紋は送られない」は正しいが、「秘密鍵は1台から一歩も出ない」とは言わない。
- コメント欄の問い（任意）: 「指紋がサイトに送られてると思ってた？」

### passkey-2  型H  「にせのサイトにだまされたら、鍵はどうなる？」
- 題名: 【うんちく】あなたがだまされても、パスキーはだまされない ／ EN: Did you know? Even if you're fooled, your passkey isn't
- 尺: 30秒　しゃべり: (2) VOICEVOX か (1)　へぇ度: ★4
- フック（0〜1.5秒の画面）: 2つの家（そっくり）。「あなたは、どっちが本物かわからない」
- 台本:

  | 秒 | 画面 | しゃべり／字幕 |
  |---|---|---|
  | 0–3 | そっくりの家が2つ（家の名前の札だけ1文字ちがう、架空の .example） | そっくりのにせサイトに、うっかり入ってしまった。パスキーはどうなる？ |
  | 3–6 | 3択「A 鍵を盗まれる／B 鍵が答えない／C 両方にサインする」 | A、B、C、どれ？ |
  | 6–8 | 2・1 | （考える間） |
  | 8–15 | 「B」。アプリの録画: 門番（ブラウザ）が行き先の札を読み、スマホの金庫に「この住所の鍵ある？」→ 無い | 答えは B。門番＝ブラウザが、いまいる住所を見て、その住所の鍵だけを探す |
  | 15–22 | サインの小包に住所が書きこまれる | しかもサインには、住所がいっしょに書きこまれる。にせの住所のサインは、本物では通らない |
  | 22–30 | 「あなたがだまされても、鍵はだまされない」 | 見た目で見分けるのは、人がしなくていい |

- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: パスワードは「人の目」で住所を確かめるしかない。パスキーは機械が住所を1文字ずつくらべる（1文字ちがっても別の家）。
- 絵の作り方: アプリの録画（にせものサイトの実験をパスキーで。サムネイル用の止めた場面がある＝ `_dev/tools/thumb.html` の SETUP）／Canvas（3択の札）
- 出どころ:
  - W3C「Web Authentication Level 3」https://www.w3.org/TR/webauthn-3/ （WebFetch 済み: clientDataJSON の origin はよび出したページの origin、RP ID は origin の有効なドメインと同じかその登録できる上位でないと SecurityError、資格情報はその RP の origin からしか使えない）
  - FIDO Alliance, Passkey Central「How Passkeys Work」（上と同じ。登録したサイトにしか出さない、相手のサイトに打ちこむことがない）
- 推定・注意:
  - 家の名前は架空（.example）。本物の会社・サービスの名前やロゴは使わない。にせの家も、本物のログイン画面に似せない（屋根と壁の家の絵のまま）。
  - 「人が気をつけなくていい」のはパスキーで入る場面のこと。ほかのこと（変なアプリを入れる等）まで大丈夫とは言わない。
- コメント欄の問い（任意）: 「にせサイトに入りかけたこと、ある？」

### passkey-3  型E  「パスキーを当てずっぽうで当てるには」
- 題名: 【うんちく】パスキーを総当たりで当てるには、宇宙の年齢の360倍 ／ EN: Did you know? Guessing a passkey takes 360 times the age of the universe
- 尺: 35秒　しゃべり: (1)　へぇ度: ★3
- フック（0〜1.5秒の画面）: 「宇宙の年齢 ×360」
- 台本:

  | 秒 | 画面 | しゃべり／字幕 |
  |---|---|---|
  | 0–3 | 「×360 宇宙の年齢」 | パスキーを当てずっぽうで当てる。かかる時間は、宇宙の年齢の360倍 |
  | 3–9 | 4けたの暗証番号: 1万通り → 「一瞬」 | 4けたの数字なら、1万通り。機械なら一瞬 |
  | 9–15 | 桁がふえていく: 10^4 → 10^12 → 10^24 → 10^38 | パスキーの鍵（P-256）は、強さで言うと 2の128乗。3.4のあとに0が38個 |
  | 15–23 | 「世界一のスパコン 1秒に 2.2×10^18 回」 | 世界一のスパコンが、1回の計算で1つためせると、とても甘く考えても… |
  | 23–30 | 年の桁: 4.9兆年 → 宇宙 138億年の約360倍 | 約4.9兆年。宇宙ができてからの時間の、約360倍 |
  | 30–35 | アプリの録画: スマホの金庫の鍵（色の模様） | だからわるものは、鍵ではなく人をだまそうとする。でも、それも…（→ passkey-2 へ） |

- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: 2^128 ≈ 3.4×10^38 通り。世界一のスパコンでも約4.9兆年（宇宙の年齢の約360倍）。
- 絵の作り方: Canvas（桁がのびる数字のアニメ、時計の針が回りつづける）／アプリの録画（金庫の鍵の色の模様）
- 出どころ:
  - NIST SP 800-57 Part 1 Rev. 5（2020）表2: ECC の鍵 256〜383 ビット ＝ 安全の強さ 128 ビット（P-256）。https://csrc.nist.gov/pubs/sp/800/57/pt1/r5/final （本文は開けず、解説サイトで照合。要確認）
  - TOP500（2026年6月）Highlights: 1位 LineShine、Rmax 2.198 Eflop/s https://top500.org/lists/top500/2026/06/highs （WebFetch 済み）
  - 宇宙の年齢 約138億年（Planck Collaboration 2018: 13.787±0.020 Gyr）
- 推定・注意:
  - 「1回の浮動小数点の計算で1つの鍵をためせる」と**とても甘く**見積もった（本当は1つためすのに何千回もの計算がいる）。それでも宇宙の年齢をこえる、という話。画面に「とても甘い見積もり」。
  - 量子コンピューターの話はしない（言うなら「将来の量子計算機には別の対策が進んでいる」まで。こわがらせない）。
  - NIST の表は一次資料を開けていない。使う前に PDF の表2を目で確かめる。
- 計算（途中の値）:
  - 2^128 = 3.403×10^38
  - 3.403×10^38 ÷ 2.198×10^18 /秒 = 1.548×10^20 秒
  - ÷ 3.156×10^7 秒/年 = 4.905×10^12 年（約4.9兆年）
  - ÷ 1.379×10^10 年 = 356 → 約360倍
- コメント欄の問い（任意）: 「4けたの暗証番号、何年使ってる？」
