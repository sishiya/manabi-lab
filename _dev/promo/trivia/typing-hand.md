# うんちく台本 — タイピングする手（typing-hand）

2026-11-02 作成（台本作家のサブエージェント）。型・決まりは `PATTERNS.md`。
手・指の話なので、しゃべりは (1) 字幕だけ か (3) ユーザーの声。
アプリの指の動きは計算したシミュレーション（測った人の指ではない）。録画を使う場面には、画面の下に小さく「指の動きはコンピュータの計算です」を必ず出す（アプリの決まり）。

アプリで作れる絵: キーボード7種類（JIS・US・ノートパソコン・小さな英語配列・左右に分かれた形・格子配列・手動のタイプライター）と両手の3D、ながめる（速さ 60〜1080 キー/分）、自分で打つ（キーの位置と時刻だけ読んで再現）、皮ふ・骨・筋肉の見せ方。

数はすべて Dhakal ほか (2018) の本文と表3（PDF で確かめた）。オンラインで集めた 168,960 人・1億3685万打鍵、英文を写して打つテスト。参加した人は自分から来た人（「ふつうの人の平均」とは少しちがう、と画面に）。
出どころ: Dhakal, Feit, Kristensson & Oulasvirta (2018) "Observations on Typing from 136 Million Keystrokes", CHI 2018. https://userinterfaces.aalto.fi/136Mkeystrokes/resources/chi-18-analysis.pdf
（論文の本文に書かれた結果を引くだけ。データは研究と非商用の利用だけなので、数値の表を写したり、データから絵を作ったりはしない。）

---

### typing-hand-1  型H  「キーを押している時間、速い人と遅い人でどれだけちがう？」　◎おすすめ
- 題名: 【うんちく】タイピングが速い人は「押す」のが速い…わけじゃない ／ EN: Did you know? Fast typists don't press keys any faster
- 尺: 30秒　しゃべり: (1)（字幕だけ＋打鍵の音）　へぇ度: ★4
- フック（0〜1.5秒の画面）: キーを押しているアップ。大きく「速い人と遅い人 押している時間のちがいは？」。
- 台本:
  | 秒 | 画面 | しゃべり／字幕 |
  |---|---|---|
  | 0〜1.5 | キー1つのアップ。字幕の問い | 字幕「キーを押している時間。速い人と遅い人で、どれだけちがう？」 |
  | 1.5〜4 | 札3つ「A 5倍ちがう／B 2倍ちがう／C ほぼ同じ」、カウントダウン | 字幕「考えてみて」 |
  | 4〜8 | 「C」が光る。2本の短い棒「速い人 0.104秒」「遅い人 0.129秒」 | 字幕「答え：ほぼ同じ。どちらも 約0.1秒」 |
  | 8〜16 | 同じ文を ×1 で打つ2つの録画を上下に（上＝打つ速さ 約420 キー/分＝毎分 約84語／下＝約120 キー/分＝毎分 約24語。論文の速い人・遅い人に合わせる）。キーの下に「押している」の帯 | 字幕「では、何がちがう？ キーとキーの“すきま”。速い人 0.12秒、遅い人 0.48秒」 |
  | 16〜24 | Canvas: 時間の線にキーの帯を並べる。速い人は帯が重なる | 字幕「しかも速い人は、前のキーを離す前に、次のキーを押している」 |
  | 24〜30 | もう一度キーのアップ | 字幕「押す速さは、みんな同じ。差がつくのは、押していない時間」 |
- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: キーを押している長さは 速い人（上位10%、毎分 約78語より速い）平均 104ms・遅い人（下位10%）129ms。差は 25ms ほど。キーとキーの間（押してから次を押すまで）は 速い人 122ms・遅い人 481ms で約4倍。論文も「押す長さが速い人と遅い人で似ていることは、これまで報告されていなかった」と書いている。
- 絵の作り方: アプリの録画（ながめる、JIS かノートパソコン。速い人・遅い人の2本を上下に並べる。アプリの速さは 60〜1080 の9段なので、近い段を選び、字幕には論文の数だけ出す。カメラは手の横）／Canvas の図（3択の札・2本の棒・時間の線に帯）。帯の長さは論文の平均値で描く（録画の手の帯とは別。録画はシミュレーション）。
- 出どころ: 上の Dhakal ほか (2018)。表3: Keypress duration 116.25ms（全体）・104.49（速い）・128.99（遅い）、IKI 238.66・121.70・481.03。本文「keypress duration is similar across slow and fast participants」の段落。
- 推定・注意: 速い・遅いの線引きは論文のまま（上位10%・下位10%）。「押す長さ」は押してから離すまで。英語の文を打つテスト。
- コメント欄の問い（任意）: 「A・B・C どれだと思った？」

### typing-hand-2  型G  15秒ループ「離す前に、次を押す」
- 題名: 【うんちく】速い人は、キーを離す前に次のキーを押している ／ EN: Did you know? Fast typists press the next key before releasing the last
- 尺: 15秒　しゃべり: (1)（字幕だけ）　へぇ度: ★3
- フック（0〜1.5秒の画面）: 「t」と「h」の2つのキーが同時に沈んでいるアップ。「2つ 同時に 押されてる」。
- 台本:
  | 秒 | 画面 | しゃべり／字幕 |
  |---|---|---|
  | 0〜2 | T と H のキーのアップ。両方沈んでいる | 字幕「速い人は、前のキーを離す前に、次のキーを押す」 |
  | 2〜6 | Canvas: 時間の線。T の帯と H の帯が 0.03 秒重なる。重なりが光る | 字幕「重なりは平均 0.03秒。長いと 0.1秒」 |
  | 6〜10 | 速い人の棒（キーの4〜7割）、遅い人の棒（ほぼ0） | 字幕「速い人の多くは、キーの4〜7割をこの打ち方で。遅い人はほとんどしない」 |
  | 10〜13 | アプリの手動タイプライター（キーを1つずつ打つ録画） | 字幕「昔の機械のタイプライターでは、できなかった打ち方」 |
  | 13〜15 | T と H のアップにもどる | 字幕「だから、速い人は…」（→ 最初の「前のキーを離す前に」へ） |
- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: 重ね打ち（rollover）の割合は全体の平均 25%。速い人の多くは 40〜70%、遅い人はほぼ 0。重なりは平均 30ms、最大 100ms（ふだんのものとのくらべは、出どころを確かめたものがないので入れない）。打つ速さとの相関 r = 0.73（論文の中でとくに強い）。
- 絵の作り方: Canvas の図（キー2つのアップは描く。時間の線と帯）／アプリの録画（手動のタイプライター `KB_TYPES.typewriter`。※ アプリの手が重ね打ちをしているかは未確認。録画は「タイプライター」の場面だけに使い、重ね打ちの絵は Canvas で描く）。
- 出どころ: 上の Dhakal ほか (2018)。「Rollover Behaviour」の節（平均 25%・SD 17%、速い人の多くが 40〜70%、重なり平均 30ms・最大 100ms、「機械のタイプライターではできなかった」）と表3。
- 推定・注意: 「機械のタイプライターではできなかった」は論文の書き方（キーを押しきらないと次が打てない仕組みのため）。字幕は「昔の機械のタイプライター」と書き、電動など全部の機械とは言わない。
- コメント欄の問い（任意）: 「自分が重ね打ちしているか、ゆっくり打って確かめてみて」

### typing-hand-3  型A  「習えば速くなる…差は毎分5語」
- 題名: 【うんちく】タイピングを習った人と習っていない人、速さの差は意外と小さい ／ EN: Did you know? Typing lessons make less difference than you think
- 尺: 30秒　しゃべり: (3)（ユーザーの声。むずかしければ (1)）　へぇ度: ★3
- フック（0〜1.5秒の画面）: 大きく「習っても 速くならない？」。
- 台本:
  | 秒 | 画面 | しゃべり／字幕 |
  |---|---|---|
  | 0〜1.5 | 「習っても 速くならない？」 | 「タイピングは、習った人のほうがずっと速い…と思いますよね」 |
  | 1.5〜8 | 2本の棒「習った 毎分54語」「習っていない 毎分49語」 | 「16万人をくらべると、差は1分に5語ほど」 |
  | 8〜14 | 2本の棒のまわりに大きなばらつきの帯（±20語） | 「同じ“習った人”の中のばらつきのほうが、ずっと大きい」 |
  | 14〜22 | アプリの録画（ながめる。両手） | 「30人の指の動きを測った研究では、10本ぜんぶ使わない、習ってもいない人でも、習った人と同じくらい、それより速い人もいました」 |
  | 22〜28 | 「速い人の共通点」: ①指の使い方がいつも同じ ②次のキーへ先回り ③手全体はあまり動かさない | 「速さに効いていたのは、いつも同じ指で打つこと、先回り、手を動かしすぎないこと」 |
  | 28〜30 | 最初の文字 | 「習ったかより、どう打っているか」 |
- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: 習ったと答えた人 毎分 54.35語、習っていないと答えた人 49.00語（どちらも SD 約20語、効果の大きさ d = 0.27＝小さい）。打つ間隔の差も小さい（d = 0.2）。
- 絵の作り方: Canvas の図（棒2本とばらつきの帯・共通点3つ）／アプリの録画（ながめる、カメラを回す。下に「指の動きはコンピュータの計算です」）。
- 出どころ:
  - 上の Dhakal ほか (2018)。表3（Trained 54.35・Untrained 49.00、d 0.27）と本文「Trained typists in our sample type, on average, 5 WPM faster」。
  - Feit, Weir & Oulasvirta (2016) "How We Type: Movement Strategies and Performance in Everyday Typing", CHI 2016。※ 中身は Dhakal 2018 の本文での紹介（30人のモーションキャプチャ。いつも同じ指・先回りの動き・手全体の動きが小さいことが速さを予測し、10本を使わず習っていない人でも同じかそれより速い人がいた）で確かめた。Feit 2016 の本文そのものは読んでいない。データ（CC BY-NC）は使わない。
- 推定・注意: 「習った・習っていない」は自己申告。同じ論文で、指の数（自己申告）は速さと関係があった（速い人 8.4本・遅い人 5.3本、r = 0.38）。「指の数は関係ない」とは言わないこと（字幕でも言わない）。台本は「習ったかどうか」の差が小さい、に絞る。
- コメント欄の問い（任意）: 「タイピング、習いましたか？ 何本の指で打っていますか？」
