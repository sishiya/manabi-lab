# うんちく台本: wifi-wave（電波の見える部屋）

2026-11-02 作成（台本だけ。録画・公開はまだ）。仕様は `PATTERNS.md`。
アプリで作れる絵: 真上から見た家の中を WiFi の波（2.4GHz／5GHz）が広がり、壁で弱まる FDTD の絵。受信の強さ（dBm）の読み取り。

---

### wifi-wave-1  型A  「電子レンジは“水の周波数”じゃない」　◎おすすめ
- 題名: 【うんちく】電子レンジの電波は「水がいちばん好きな周波数」…じゃない ／ EN: Did you know? Microwave ovens are NOT tuned to water
- 尺: 30秒　しゃべり: (1) 字幕だけ　へぇ度: ★4
- フック（0〜1.5秒の画面）: 大きな文字「電子レンジ＝水の共振」に赤い ✕。下に小さく「2.45GHz」
- 台本:

  | 秒 | 画面 | しゃべり／字幕 |
  |---|---|---|
  | 0–2 | 「水の共振」に ✕ | 電子レンジは、水がいちばんふるえる周波数…じゃない |
  | 2–8 | 横軸＝周波数（対数）の図。2.45GHz に縦線、水が電波のエネルギーをいちばん受けとる山は、もっと右（数GHz〜100GHz のあたり） | 水が電波からいちばん熱をもらうのは、もっと高い周波数 |
  | 8–15 | 2つの断面の図: 左「もし山の上の周波数なら」→ 表面だけ赤くなり中は冷たい。右「2.45GHz」→ 中まで赤い | もしその周波数にしたら、表面だけ焼けて、中は冷たいまま |
  | 15–22 | 2.45GHz のまわりに帯（2.4〜2.5GHz）。「電波の決まりで、レンジなどに使ってよい帯」 | 2.45GHz に決まったのは、物理より「電波の決まり」の都合 |
  | 22–28 | アプリの録画: 家の中を 2.4GHz の波が広がる | そして、同じ帯を使っているのが…WiFi |
  | 28–30 | 文字「レンジとWiFi、おとなりさん」 | （字幕のみ） |

- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: 2.45GHz は、水が電波をいちばん吸う帯（数GHz〜100GHz。Kiel 大の教材）より下。わざと下にして、波が食べ物の中まで入るようにしている。波の長さは約12cm（スマホの長さくらい）。
- 絵の作り方: Canvas の図（周波数の軸と吸収の山＝形は模式図と明記、断面の温まり方の模式図）／アプリの録画（2.4GHz、ルーターから波が広がる場面）
- 出どころ:
  - C. Baird（West Texas A&M 大）「Why are the microwaves in a microwave oven tuned to water?」2014, https://www.wtamu.edu/~cbaird/sq/2014/10/15/why-are-the-microwaves-in-a-microwave-oven-tuned-to-water/ （WebFetch 済み: 水の共振ではない・最初の共振は 1THz より上・周波数は規制で割り当てられたもの、Ron Schmitt『Electromagnetics Explained』を引用）
  - H. Föll（Kiel 大）「Cooking with Microwaves」https://www.tf.uni-kiel.de/matwis/amat/elmat_en/kap_3/advanced/t3_4_1.html （WebFetch 済み: 水の損失の山はおよそ 5〜100GHz、2.45GHz はそれより下で、表面で吸われきらず中まで入るため）
- 推定・注意:
  - 吸収の山の位置は資料で幅がある（Chaplin の Water Structure and Science は約20GHz と書いているが、ページが開けず未確認）。画面には「数GHz〜100GHz のあたり（教科書によって幅あり）」と書き、1つの数字にしない。
  - 断面の図は模式図（計算ではない）と小さく書く。
  - 「同じ帯」は 2.4GHz 帯（2.4〜2.5GHz）のこと。WiFi のチャンネル6は 2437MHz（IEEE 802.11）。
  - 健康の話にはしない（「レンジとWiFiは危ない」とも「安全」とも言わない）。
- コメント欄の問い（任意）: 「レンジを使うと WiFi が遅くなったことある？」

### wifi-wave-2  型E  「スマホに届くのは、ルーターの10億分の1」
- 題名: 【うんちく】あなたのスマホは、ルーターの電波の10億分の1で動いている ／ EN: Did you know? Your phone runs on a billionth of your router's signal
- 尺: 35秒　しゃべり: (1) か (2)　へぇ度: ★4
- フック（0〜1.5秒の画面）: 「1/1,000,000,000」の大きな数字と、点のように小さいスマホ
- 台本:

  | 秒 | 画面 | しゃべり／字幕 |
  |---|---|---|
  | 0–2 | 「10億分の1」 | スマホに届く WiFi は、ルーターが出した電波の…10億分の1 |
  | 2–7 | ルーター。「100mW（ミリワット）」 | ルーターが出すのは、だいたい 0.1ワット |
  | 7–13 | 円が広がる。1m の輪「1万分の1」 | 1m はなれただけで、1万分の1 |
  | 13–19 | 10m の輪「100万分の1」 | 10m で、100万分の1。ここまで、壁なしで |
  | 19–26 | アプリの録画: 壁を通るたびに色が暗くなる | 壁を何枚か通ると、10億分の1 |
  | 26–32 | 「10億円のうち、1円」 | 10億円のうち、1円ぶん。それでも動画が見られる |
  | 32–35 | 文字「スマホの耳は、すごくいい」 | （字幕のみ） |

- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: 0.1W → 約 0.1nW（ナノワット）。10億円のうちの1円。
- 絵の作り方: Canvas（同心円と桁の数字のアニメ、10倍ずつ引くズーム）／アプリの録画（受信の読み取りを壁の向こうの部屋で出す場面）
- 出どころ:
  - ITU-R P.525-5（2024-11）「Calculation of free-space attenuation」https://www.itu.int/rec/R-REC-P.525/en （WebFetch 済み: 版と題名。式 L = 32.4 + 20 log f(MHz) + 20 log d(km) は P.525 の自由空間の式）
  - IEEE 802.11 のチャンネル6 = 2437MHz（アプリの DEVNOTES の出典の記録）
- 推定・注意:
  - ルーター出力 20dBm（100mW）と「壁ごしで -70dBm」は**目安**（規格の値ではない。アプリも目安と明記）。画面に「目安」。
  - 1m・10m は何もない空間（自由空間）の計算。本当の部屋は反射でもう少し強いことも弱いこともある。
- 計算（途中の値）:
  - 自由空間の損失 L = 32.4 + 20 log10(2437) + 20 log10(d[km])。20 log10(2437) = 67.74
  - d = 1m（0.001km）: L = 32.4 + 67.74 − 60 = 40.1 dB → 20 − 40.1 = −20.1 dBm ≈ 9.8µW → 100mW の約 1/10,000
  - d = 10m: L = 60.1 dB → −40.1 dBm ≈ 0.098µW → 約 1/1,000,000
  - 壁ごし −70dBm: 20 − (−70) = 90 dB → 10^9 = 10億分の1、0.1nW
- コメント欄の問い（任意）: 「家でいちばん WiFi が弱いのはどの部屋？」

### wifi-wave-3  型G  「WiFi は、光だ」
- 題名: 【うんちく】WiFi の正体は「見えない光」 ／ EN: Did you know? WiFi is light you can't see
- 尺: 16秒（ループ）　しゃべり: (2) VOICEVOX　へぇ度: ★3
- フック（0〜1.5秒の画面）: 「WiFi は 光」の文字。うしろに波
- 台本:

  | 秒 | 画面 | しゃべり／字幕 |
  |---|---|---|
  | 0–3 | 「WiFi は 光」 | WiFi は、光。目に見えないだけの、光と同じ電磁波 |
  | 3–7 | 2本の波を同じ幅で: 緑の光（細かい）と WiFi（ゆったり） | ちがうのは、1秒にふるえる回数だけ |
  | 7–11 | 「緑の光 540兆回／WiFi 24億回」→「約22万分の1」 | WiFi は、緑の光の 22万分の1 のゆっくりさ |
  | 11–14 | アプリの録画: 波が部屋に広がる。波の長さ 12cm の物差し | 波1つの長さは 12cm。でも、進む速さは同じ。なぜなら… |
  | 14–16 | 最初の文字に戻る | WiFi は、（→ ループで「光」） |

- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: ふるえる回数が緑の光の約22万分の1。波の長さ 12cm（スマホくらい）。
- 絵の作り方: Canvas（2本の波のアニメ、数字）／アプリの録画（2.4GHz の波の山と谷がはっきり見える寄りの場面）
- 出どころ: 光の速さ c = 299,792,458 m/s（SI の定義）。WiFi のチャンネル6 = 2437MHz（IEEE 802.11）。緑の光は 555nm（目がいちばん感じやすい波長。CIE の明るさの感じ方の曲線の山）
- 推定・注意: 「同じ速さ」は空気・真空の中での話（ガラスや壁の中ではどちらも遅くなる）。体への影響の話はしない。
- 計算（途中の値）:
  - 緑の光の振動数 = 2.998×10^8 ÷ 555×10^-9 = 5.40×10^14 回／秒（540兆回）
  - WiFi = 2.437×10^9 回／秒（約24億回）
  - 比 = 5.40×10^14 ÷ 2.437×10^9 = 2.22×10^5 → 約22万分の1
  - WiFi の波の長さ = 2.998×10^8 ÷ 2.437×10^9 = 0.123 m
- コメント欄の問い（任意）: 「もし WiFi が目に見えたら、家はどう見える？」
