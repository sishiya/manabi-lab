# うんちく台本: phonograph（エジソンの蓄音機）

2026-11-02 作成（台本だけ）。仕様は `PATTERNS.md`。
アプリで作れる絵: 1878年のすず箔の蓄音機。声で振動板がふるえ、針が箔に溝を刻み、なぞってまた音に戻る（全部計算）。溝の断面へのズーム（0.05mm の世界）、なぞるたびにすり減る。
（エジソンの逸話は脚色が多い。ここでは 1878年の本人の文・研究所や博物館の記録でたどれた話だけ。昔の録音の復元音は流さない＝アプリの決まり）

---

### phonograph-1  型H  「エジソンが考えた蓄音機の使いみち、1番は？」　◎おすすめ
- 題名: 【うんちく】エジソンは蓄音機を「音楽の機械」だと思っていなかった ／ EN: Did you know? Edison didn't think the phonograph was for music
- 尺: 35秒　しゃべり: (2) VOICEVOX か (1)　へぇ度: ★5
- フック（0〜1.5秒の画面）: 「1878年 エジソンの書いた“使いみちリスト”。1番は？」
- 台本:

  | 秒 | 画面 | しゃべり／字幕 |
  |---|---|---|
  | 0–3 | 3択「A 音楽を聴く／B 手紙と口述筆記／C しゃべるおもちゃ」 | 1878年、エジソンが雑誌に書いた蓄音機の使いみち。いちばん最初に書いたのは？ |
  | 3–5 | 2・1 | （考える間） |
  | 5–12 | 「B 手紙と口述筆記」 | 答えは B。速記の人なしで手紙を書く。声のまま手紙を送る |
  | 12–20 | リストが上から並ぶ: 手紙・口述 → 本（目の見えない人のための朗読） → 話し方の練習 → 音楽 → 家族の記録 → おもちゃ → しゃべる時計… | 音楽は、そのあと。しゃべる時計まで書いてある |
  | 20–28 | アプリの録画: 声 → 振動板 → 溝 | 「声をしまっておける」ことが、いちばんの発明だった |
  | 28–35 | 文字「同じ箔で 50〜100回くり返せる、と書いた」→ アプリの録画: 数回なぞると溝がすり減り音が消える | エジソンは 50〜100回くり返せると書いた。すず箔で試すと…（すり減る絵） |

- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: 使いみちの1番目は「手紙・口述筆記」。音楽はリストの中ほど。
- 絵の作り方: Canvas（リストが1行ずつ出る。文字は自分で組む。古い雑誌の紙面は写さない）／アプリの録画（録音 → 再生、何回もなぞってすり減る場面）
- 出どころ:
  - T. A. Edison「The Phonograph and Its Future」North American Review 126（1878年5〜6月号）pp. 527–536。書きおこし: Phonozoic Text Archive, Document 020, https://phonozoic.net/primtexts/n0020.htm （WebFetch 済み: 用途は 手紙・口述筆記・本・教育（話し方）・音楽・家族の記録・オルゴールとおもちゃ・時計・広告・演説・電話の改良 の順。「50 から 100 回のくり返し」の記述）
  - 米議会図書館（LOC）「History of the Cylinder Phonograph」も同じリストを「手紙と口述」から並べる（検索の要約で確認。ページは 403 で開けず）
- 推定・注意:
  - 本文には番号がない（並んだ順）。「1番目に書いた」と言い、「1位」とは言わない。音楽が何番目かは数え方で4〜5番目になるので、「そのあと」「中ほど」と言う。
  - 「50〜100回」はエジソンが計画中の再生の板について書いた見込み。すず箔が本当に何回で聞こえなくなったかは、アプリのモデル（推定）の絵として見せ、数字は言わない。
  - 「メリーさんのひつじ」を最初に録った話は有名だが、1877年の録音は残っておらず本人の思い出話がもとなので使わない。
- コメント欄の問い（任意）: 「いまの録音、いちばん何に使ってる？」

### phonograph-2  型A  「世界最古の録音はエジソン…じゃない」
- 題名: 【うんちく】最古の録音はエジソンより17年前。しかも“聴けない”録音だった ／ EN: Did you know? The oldest recording predates Edison — and was never meant to be heard
- 尺: 35秒　しゃべり: (1)　へぇ度: ★4
- フック（0〜1.5秒の画面）: 「最古の録音＝エジソン（1877）」に ✕ →「1860」
- 台本:

  | 秒 | 画面 | しゃべり／字幕 |
  |---|---|---|
  | 0–3 | ✕ → 1860 | 世界最古の録音は、エジソン…じゃない |
  | 3–10 | 「1860年4月9日 パリ」すすを塗った紙に波の線（自分で描く線画） | 1860年、パリのスコット。すすを塗った紙に、声の波を線で描いた |
  | 10–17 | 「聴くための機械は、なかった」 | でも、それを音に戻す方法は作らなかった。見るための記録だった |
  | 17–25 | 「2008年」紙の線を写真で読み、計算で音に | 148年後の2008年。紙を細かく撮って、線の形を計算で音に戻した |
  | 25–31 | アプリの録画: 溝の形だけから音を計算する（再生） | 形が残っていれば、音は計算で取りもどせる |
  | 31–35 | 文字「エジソンが初めてだったのは、“聴きかえせる”録音」 | エジソンがはじめてだったのは、自分の機械で聴きかえせる録音 |

- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: 1860年に録って、音になったのは 2008年（148年後）。エジソンの蓄音機（1877年）より17年前。
- 絵の作り方: Canvas（すすの紙に波を描く線画。本物の紙の写真・復元音は使わない）／アプリの録画（溝の形から再生する場面、溝のズーム）
- 出どころ:
  - First Sounds「Édouard-Léon Scott de Martinville」https://www.firstsounds.org/sounds/scott.php/ （WebFetch 済み: 1860年4月9日の「月の光に（Au Clair de la Lune）」、スコットは自分の録音を再生するつもりがなかった）
  - First Sounds「Our Approach」https://firstsounds.org/sounds/approach.php （WebFetch 済み: 2007年12月〜2008年3月に方法を作り、紙を高い解像度で撮り、ローレンス・バークレー国立研究所のソフトをもとに音へ。2008年3月に公開）
- 推定・注意:
  - 歌っている人が女の人だと思われていた、という話は出どころでたしかめられなかったので**使わない**。
  - 「最古」は言いきらず「いまわかっている最古の一つ」と字幕に小さく（スコットには 1860年より前の紙もあるとされるが、今回たどれていない）。
  - 曲名は字幕で「月の光に」とだけ（歌詞は出さない）。
- 計算（途中の値）: 2008 − 1860 = 148年。1877 − 1860 = 17年。
- コメント欄の問い（任意）: 「録ったのに聴けない録音、ほかに何がある？」

### phonograph-3  型G  「1878年の声は、光で聴かれた」
- 題名: 【うんちく】1878年のすず箔の録音は、針でなく“光”で再生された ／ EN: Did you know? An 1878 recording was played back with light
- 尺: 18秒（ループ）　しゃべり: (1)　へぇ度: ★3
- フック（0〜1.5秒の画面）: 光の線が箔の溝をなぞる
- 台本:

  | 秒 | 画面 | しゃべり／字幕 |
  |---|---|---|
  | 0–3 | 光が溝をなぞる | 1878年の声は、光で聴かれた |
  | 3–7 | 「1878年 セントルイス／78秒」 | セントルイスで録った、78秒のすず箔 |
  | 7–11 | アプリの録画: 針でなぞるたびに溝が平らになる | 針でなぞれば、溝はつぶれて消えてしまう |
  | 11–15 | 「2012年 深さまで測るカメラで撮影 → 計算で音に」 | だから 2012年、深さを測るカメラで溝を撮り、計算で音にした |
  | 15–18 | 最初の絵に戻る | 針がふれてはいけない声。だから、（→ ループで「1878年の声は、光で聴かれた」） |

- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: 1878年の78秒を、134年後に「さわらずに」再生。
- 絵の作り方: アプリの録画（溝の断面ズーム・すり減る場面）／Canvas（光の線が溝をなぞる絵）
- 出どころ:
  - PBS NewsHour「Digital Technology Helps Researchers Hear Earliest Recording」(2012) https://www.pbs.org/newshour/show/digital-technology-helps-researchers-hear-earliest-recording （WebFetch 済み: 78秒、コルネットの独奏と童謡を唱える男の声、箔はもろく破れていて再生にたえない（C. Haber）、深さを測れるカメラで撮り約4,000メガピクセルの絵にして、針の動きを逆算）
  - Infodocket（AP, 2012-10-25）https://www.infodocket.com/2012/10/25/soundtrack-to-history-1878-edison-audio-unveiled/ （WebFetch 済み: 1878年セントルイス、78秒、光で針の働きをまねて 3D の絵、ローレンス・バークレー国立研究所の C. Haber のチーム）
- 推定・注意:
  - 話している人は Thomas Mason と**考えられている**（確定ではない）。名前を出すなら「〜とされる」。
  - 録音日の 1878年6月22日は報道（NPR 2021 の要約）にあるが、ページを開けず未確認なので言わない。
  - 復元された音そのものは流さない（アプリの決まり）。
- 計算（途中の値）: 2012 − 1878 = 134年。
- コメント欄の問い（任意）: 「さわると消える記録、ほかに知ってる？」
