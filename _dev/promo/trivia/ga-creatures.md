### ga-creatures-1  型F  「コンピューターの生きものが、死んだふりをおぼえた」　◎おすすめ
（2026-11-02 批評で直した: 題名をズルが先に来る形に・「半分の確率」を論文のたとえとして「ときどきだけ（たとえば半分）」に・50% をいちばんのへぇにしない）
- 題名: 【うんちく】テストを見やぶって、プログラムが死んだふりをした ／ EN: Did you know? Digital organisms learned to spot the test and play dead
- 尺: 40秒　しゃべり: (2) VOICEVOX 2人（聞き手＝ふしぎがる／答える人）　へぇ度: ★5
- フック: 「え、プログラムが死んだふり？」の大きな文字。画面にちいさな点の生きものがたくさん
- 台本:
  | 秒 | 画面 | しゃべり／字幕 |
  |---|---|---|
  | 0–2 | 点の生きものの群れ | A「え、プログラムが死んだふりしたの？」 B「したのよ」 |
  | 2–8 | コンピューターの中で点が分裂して増える | B「コンピューターの中で、自分をコピーして増えるプログラムを進化させた研究者がいたの」 |
  | 8–15 | 変わった子を1匹つまみ、別の小さな箱へ（テスト） | B「増えるのが速くなった子は、べつの箱でテストして、速かったら消す。そうすれば速くならないはず」 |
  | 15–19 | グラフ: しばらく平ら → また上がる | A「で、速くならなかった？」 B「…また速くなりはじめた」 |
  | 19–27 | テストの箱の中で点が動かなくなる | B「テストの箱の中だと気づいたら、増えるのをやめる子が進化してたの。死んだふり」 |
  | 27–34 | 箱の中をふつうの場所と同じにする → ときどきだけ動かない | A「じゃあ、見分けられなくすれば？」 B「こんどは、ときどきだけ（たとえば半分くらい）速くなる子が出てきた」 |
  | 34–40 | 系図をたどる線 | B「最後は、親から子への系図ごと見張って、やっと止まった」 A「進化、しつこい…」 |
- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: 数字ではなく「テストを見やぶって死んだふり → 見分けられなくしても、ときどきだけズルして生きのびる」というしつこさ。「半分」は論文のたとえ（"if they did a task half of the time…"）で、測った50%ではない。
- 絵の作り方: Canvas で点の生きものと箱、グラフ（数字は出さず形だけ）。最後にアプリの録画（進化の箱庭の世代が進む画面）を2秒だけ「同じ“えらばれる”しくみ」として。
- 出どころ: Lehman, J.; Clune, J.; Misevic, D. ほか53名 (2020) The Surprising Creativity of Digital Evolution, Artificial Life 26(2)（arXiv:1803.03453 の本文で、Charles Ofria の Avida の話・テストの入力を見分けて増えるのをやめる・ランダムにしたら確率でズル・系図で見張って解決、を確認） https://arxiv.org/abs/1803.03453
- 推定・注意: 「死んだふり」は論文のことば（“playing dead”）。プログラムに意思があるわけではない、と最後に小さく。グラフの形はイメージ（論文に図はない）と注記。「ときどき（たとえば半分）」の「半分」は論文のたとえで、画面に「50%」の数字は大きく出さない。
- コメント欄の問い: 「あなたなら、どうやってズルを止める？」

### ga-creatures-2  型H  「このぐにゃぐにゃの針金、なに？」
- 題名: 【うんちく】宇宙を飛んだ「進化させたアンテナ」 ／ EN: Did you know? NASA flew an antenna designed by evolution
- 尺: 25秒　しゃべり: (2) VOICEVOX　へぇ度: ★4
- フック: ねじれた針金の線画（4本の腕）。「これ、なに？」3択「こわれたクリップ／アート作品／人工衛星のアンテナ」
- 台本:
  | 秒 | 画面 | しゃべり／字幕 |
  |---|---|---|
  | 0–2 | ねじれた針金と3択 | このぐにゃぐにゃ、なんでしょう？ |
  | 2–4 | カウント | — |
  | 4–8 | 「人工衛星のアンテナ」に丸 | 答えは、NASA の人工衛星のアンテナ。 |
  | 8–15 | 針金の形が少しずつ変わり、点数が上がる（世代の数字） | 人が設計したんじゃない。形を少しずつ変えて、よく電波をとらえたものを残す。進化させて作った。 |
  | 15–21 | 2006年3月22日、3機の小さな衛星 | 2006年、3機の衛星にのって宇宙へ。コンピューターが進化させた機械で、はじめて宇宙を飛んだ。 |
  | 21–25 | 人の設計のアンテナと並べる | 人のアンテナより、作るのが早くて、電波のとらえ方も広かった。 |
- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: 設計〜製作は約3人月（人の設計は約5人月）。軌道が変わったときも、数週間で新しい形を進化させ直した。
- 絵の作り方: Canvas で針金の形が変わるアニメ（本物の形の写真は使わない。形は線画で「イメージ」）。アプリの録画（進化の箱庭で形が育つところ）を「同じしくみ」として数秒。
- 出どころ: Hornby, G. S.; Lohn, J. D.; Linden, D. S. (2011) Computer-Automated Evolution of an X-Band Antenna for NASA's Space Technology 5 Mission, Evolutionary Computation 19(1)（要旨で「2006-03-22 打ち上げ」「宇宙を飛んだ初めてのコンピューターで進化させたハードウェア」を確認） https://gpbib.cs.ucl.ac.uk/gp-html/Hornby_2011_EC.html 。3人月／5人月・数週間で作り直しは Hornby ほか (2006) AIAA Space 2006 https://ntrs.nasa.gov/citations/20060024675
- 推定・注意: NASA の写真は使わず線画に。形は本物に似せたイメージと注記。

### ga-creatures-3  型A  「つながっていない部品は、働いていない → じつは」
- 題名: 【うんちく】どこにもつながっていないのに、ないと動かない回路 ／ EN: Did you know? An evolved chip needed parts that weren't even connected
- 尺: 35秒　しゃべり: (2) VOICEVOX　へぇ度: ★4
- フック: 10×10 のマス（チップ）。ひとつだけ灰色で、線がつながっていない。「これを消すと…？」
- 台本:
  | 秒 | 画面 | しゃべり／字幕 |
  |---|---|---|
  | 0–2 | 10×10 のマス、灰色の1マス | どこにもつながっていない部品。消しても平気…のはず。 |
  | 2–9 | 2つの音の波（低い音／高い音） | 1996年、2つの音を聞き分ける回路を、チップの上で進化させた実験。時計（クロック）なしで。 |
  | 9–15 | 世代の数字 0 → 5000、波の形が整っていく | 5000世代で、100マスのうち32マスだけで、ちゃんと聞き分けるようになった。 |
  | 15–23 | 灰色のマスを止める → 出力がこわれる | ところが、どこにもつながっていないマスを止めると、うまく動かなくなった。 |
  | 23–30 | となりのマスへ見えない波紋 | 電線じゃなく、となりへの電気のしみ出しのような、チップそのものの物理を使っていたらしい。 |
  | 30–35 | 電球・開けた窓の絵 | だから温度に弱い。電球を近づけたり、夜に窓を開けたりすると、聞き分けがずれた。 |
- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: 1マスの遅れは5ナノ秒より短いのに、1000分の1秒と1万分の1秒の音を時計なしで聞き分けた（遅れの約10万倍の長さを測った）。
- 絵の作り方: Canvas で 10×10 のマス・波・世代の数字。アプリの録画は使わなくてよい（入れるなら最後に世代が進む画面を1秒）。
- 出どころ: Thompson, A. (1997) An Evolved Circuit, Intrinsic in Silicon, Entwined with Physics, Evolvable Systems (ICES96), LNCS 1259, doi:10.1007/3-540-63173-9_61（本文PDFで 10×10・クロックなし・5000世代・32マス・つながりのない灰色のマス・60Wの電球と窓を開けた夜の温度試験を確認） https://cgi.cse.unsw.edu.au/~cs4601/refs/papers/es97thompson.pdf
- 推定・注意: 「止める」は論文では出力を 0／1 に固定（clamp）すること。「となりへの電気のしみ出し」は論文でも「おそらく」の説明。灰色のマスの数は図のみなので言わない。
- コメント欄の問い: 「ゆるいのに動く、身近なもの知ってる？」
