# うんちくショート台本 — 錯覚の美術館（illusions）

2026-11-02 作成（台本の候補。ユーザーが選ぶ前）。仕様は `PATTERNS.md`。
錯視は画面そのものが体験になる。絵はすべてプログラムで描く（作品の画像は写さない。アプリと同じ）。

アプリで作れる絵: 長さ・大きさ（ミュラー・リヤーほか、自分で測ると % が出る）、線のかたむき（曲がり盲 2017 ほか）、消える（トロクスラー）など。

---

### illusions-1  型H  「ジグザグはどれ？」（曲がり盲） ◎おすすめ
- 題名: 【うんちく】この中にジグザグの線は何本？ ／ EN: Did you know? How many of these lines are zigzags?
- 尺: 20秒　しゃべり: (1) 字幕だけ　へぇ度: ★5
- フック（0〜1.5秒の画面）: 灰色の背景に、横の波線が上下に何本も。上半分は白黒の切りかわりが「山と谷の間」、下半分は「山と谷のてっぺん」。文字「ジグザグは何本？」
- 台本:
  | 秒 | 画面 | しゃべり／字幕 |
  |---|---|---|
  | 0–4 | 絵だけ。文字「ジグザグの線は何本？」 | （字幕）「ジグザグの線は何本？」 |
  | 4–7 | 時計 3 秒 | 「数えて…」 |
  | 7–10 | 答え「0本」 | 「答えは 0本。ぜんぶ同じ、なめらかな波」 |
  | 10–14 | 背景の灰色がゆっくり白へ → 下半分もなめらかな波に見える | 「背景を白にすると…ほら、波」 |
  | 14–18 | 色の切りかわりが山のてっぺんにある所を光らせる | 「線の明るさが、波のてっぺんで入れかわると、脳は『角だ』と思ってしまう。ゆるいカーブほどだまされる」 |
  | 18–20 | 灰色に戻して最初の絵 | 「2017年、日本の高橋康介さんが見つけた『曲がり盲』。…もう一度、何本？」（ループ） |
- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: ジグザグに見える線＝0本。見つかったのは 2017年（まだ新しい錯視）。実験では、ゆるい波で色がてっぺんで変わると、正しく答える割合が当てずっぽう（半分）より下がった。
- 絵の作り方: アプリの「曲がり盲」の展示の録画（背景を灰→白に切りかえる操作）／同じ式で縦 1080×1920 用に描き直す（線を太く・本数を減らす）。
- 出どころ: Takahashi K.（2017）Curvature Blindness Illusion, i-Perception 8(6), doi:10.1177/2041669517742178, https://doaj.org/article/bc91122374594a1bad60ca50a8f499ab （検索結果で要旨を確認: 線の明るさの正負がてっぺんで入れかわる・曲がりがゆるいとき・ジグザグと答えて正答率がチャンスより下）。
- 推定・注意: 「脳は角だと思う」は著者の考え（ゆるいカーブを見るしくみと角を見るしくみが競って、角が勝つ）を短くしたもの → 字幕に「という説」。スマホの小さな画面では弱まることがあるので、線は太めに。
- コメント欄の問い（任意）: 最初、何本に見えた？

### illusions-2  型A  「この錯覚、効かない人たちがいる」
- 題名: 【うんちく】有名な錯覚「矢羽の線」、効かない人たちがいた ／ EN: Did you know? The famous arrow illusion barely works on some people
- 尺: 35秒　しゃべり: (1) 字幕 か (2) VOICEVOX　へぇ度: ★5
- フック（0〜1.5秒の画面）: ミュラー・リヤーの2本（外向き矢羽／内向き矢羽）。文字「同じ長さ。…でも、全員がだまされるわけじゃない」
- 台本:
  | 秒 | 画面 | しゃべり／字幕 |
  |---|---|---|
  | 0–4 | 2本の線。下の方が長く見える | 「この2本、同じ長さ。教科書でおなじみ」 |
  | 4–8 | 「錯覚は人類共通」に × | 「錯覚は人類みんな同じ…じゃなかった」 |
  | 8–16 | 世界地図に16の点。1960年代、子どもと大人に「同じに見えるまで長さを合わせて」 | 「1960年代、世界の16の地域で、同じに見える長さを合わせてもらった」 |
  | 16–23 | 棒グラフ: アメリカの大学生 約20%／…／カラハリ砂漠のサンの人たち ほぼ 0% | 「アメリカの大学生は、片方を約2割長くしないと同じに見えなかった。カラハリ砂漠で狩りと採集をして暮らすサンの人たちは、ほぼ0。だまされていない」 |
  | 23–30 | 四角い部屋・まっすぐな角の線画 → 丸い家と砂漠の線画 | 「研究者の説: まっすぐな壁と直角の角に囲まれて育つと、目がそれに合わせてしまう」 |
  | 30–35 | 最初の2本に戻る | 「あなたは何%だまされた？」 |
- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: アメリカの大学生 約1/5（20%）長く ⇔ サンの人たち 0 と区別できない。16の社会のうち14が小さな伝統社会。
- 絵の作り方: アプリの「ミュラー・リヤー・自分で測る」の録画（長さを合わせると % が出る）／Canvas の棒グラフ（Henrich 2010 の図2 から読んだ値は「目安」）。
- 出どころ: Henrich J., Heine S.J., Norenzayan A.（2010）The weirdest people in the world?, Behavioral and Brain Sciences 33:61–83, https://www2.psych.ubc.ca/~henrich/pdfs/WeirdPeople.pdf （PDF を読んで確認: Segall ほか 1966 の16社会、PSE は「a を b より何%長くすると同じに見えるか」、アメリカの大学生は約1/5、サンの人たちは0と区別できない、「直角の角」の説）。元の研究は Segall, Campbell & Herskovits（1966）。
- 推定・注意: 原因（直角の多い環境）は説で、2025年に「文化のせいとは言い切れない」という反論もある（Psychological Review 2025、検索で見出しのみ確認 https://philpapers.org/rec/AMIIVP ）→ 字幕に「説」。測ったのは60年前、いまのサンの人たちが同じとは言えない。実在の人々なので「目が劣る／すぐれる」と言わない（環境で目のくせがちがう、まで）。サンの人たちの写真は使わない。
- コメント欄の問い（任意）: 育った家、角ばってた？

### illusions-3  型G  「見つめると消える」（トロクスラー）
- 題名: 【うんちく】まん中を見つめて。まわりが消えます ／ EN: Did you know? Stare at the center — the rest disappears
- 尺: 20秒　しゃべり: (1) 字幕だけ　へぇ度: ★4
- フック（0〜1.5秒の画面）: うすい灰色の背景に、ぼんやりした色のにじみ（ふちのぼけた円）が4つ、まん中に小さな＋。文字「＋だけを見て」
- 台本:
  | 秒 | 画面 | しゃべり／字幕 |
  |---|---|---|
  | 0–3 | ＋と4つのにじみ | 「＋だけを見て。目を動かさないで」 |
  | 3–12 | 何も変えない（画面は止まったまま）。カウント 10 → 0 | 「…まわりの色、消えてきた？ 画面は1ミリも変わっていません」 |
  | 12–16 | ＋を少しずらす → にじみがパッと戻る | 「目が動くと、戻る」 |
  | 16–20 | 説明の1行 → 最初の画面 | 「止まった物は、脳が『もう知ってる』と消してしまう。1804年、スイスのトロクスラーが気づいた。…＋だけを見て」（ループ） |
- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: 1804年（220年以上前）から知られている。目が勝手に小さくふるえる動き（マイクロサッカード）が減ると消え、増えると戻る、と2006年の実験。
- 絵の作り方: アプリの「トロクスラー効果」の展示を縦の画面用に描き直す（ぼけたふち・低いコントラスト）。動画の圧縮でにじみが崩れないよう、ふちは大きめのぼかし。
- 出どころ: Martinez-Conde S., Macknik S.L., Troncoso X.G., Dyar T.A.（2006）Microsaccades counteract visual fading during fixation, Neuron 49(2):297–305（検索結果で要旨を確認: 消える前にマイクロサッカードの頻度・大きさが下がり、また見える前に上がる。Troxler 1804 の再発見の記述）。
- 推定・注意: 「脳が消す」はやさしい言い方。くわしいしくみ（網膜の慣れか脳か）は研究中 → 画面に小さく「しくみはまだ研究中」。消えない人もいる（画面の大きさ・距離による）。
- コメント欄の問い（任意）: 何秒で消えた？
