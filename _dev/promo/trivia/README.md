### 出す前に決めること（試作で見つかったもの）
- extreme-1: 題名の深さを「8,400 m より下」と「8,200 m」のどちらにそろえるか（画面は両方を別の線で出している）。
- evolution-3: 「6500万年前の恐竜のふん」と「絶滅は6600万年前」が並ぶ → 「白亜紀の終わり」と言いかえるか。「草の化石は5500万年前から」→「はっきりした草の化石は」にするか。
- air-flow-2: 計算どおりなら朝の CO₂ は 2,233 ppm、字幕は「約2300」。
- railgun-3: 「戦闘機のパイロットは 9G くらい」の出どころがまだ。見つからなければその場面を削る。railgun-2 の「第一次世界大戦のころ」→ 出願は1919年（大戦の直後）。
- metamorphosis-2: 字幕の「決まった順に死ぬ」を「消える」にするか。
- 15秒ループ（型G）は、締めの画面（しし屋の目印）でループが切れる。ループの型を選ぶなら、目印を最初だけにするか決める。
