### sail-wind-1  型H  「追い風だけで、風より速く走れる？」　◎おすすめ
- 題名: 【うんちく】真後ろの風だけで、風の2.8倍の速さで走った乗り物 ／ EN: Did you know? A wind-powered cart once went dead downwind at 2.8× the wind speed
- 尺: 40秒　しゃべり: (2) VOICEVOX　へぇ度: ★5
- フック（0〜1.5秒の画面）: 背中から矢印の風。「真後ろの風だけで、風より速く走れる？ ①ムリ ②できる」
- 台本:

| 秒 | 画面 | しゃべり／字幕 |
|---|---|---|
| 0–3 | 2択 | 真後ろからの風だけで、風より速く走れる？ |
| 3–5 | カウントダウン | （考える時間） |
| 5–10 | 帆の絵が風に押される。速さが風に近づくと押す力が 0 に（アプリの「押されるだけの帆」） | ふつうはムリ。帆が風に押されて進むなら、風と同じ速さになった瞬間、押す風がなくなる。 |
| 10–14 | 答え「② できた」 | でも、できた乗り物がある。 |
| 14–20 | 線画: 3輪の車の上に大きなプロペラ。車輪 → チェーン → プロペラ | 帆のかわりにプロペラ。走ると車輪がプロペラを回して、プロペラが空気を後ろへ押す。 |
| 20–27 | 地面に対して速い・空気に対しては … の2つの矢印 | 風より速くなっても、地面はいつも後ろへ流れている。地面から力をもらって、空気をけって進む。 |
| 27–34 | 数字「風 16 km/h → 車 45 km/h（2.8倍）」「2010年7月 アメリカの干上がった湖」 | 2010年、風速 16 km/h の追い風で、時速 45 km。風の 2.8 倍。陸の帆走の協会が記録と認めた。 |
| 34–40 | 「当時、物理の専門家どうしでも『ありえない』と大論争」 | 専門家どうしでも大論争になった。答えは、エネルギーの出どころは、風と地面の速さの差。 |

- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: 風 10 mph（16 km/h、ゆっくりの自転車）で 27.7 mph（45 km/h、原付の制限速度より速い）。比 2.8。
- 絵の作り方: アプリの録画（押されるだけの帆で、真後ろの風は風速をこえない場面）／Canvas の線画（プロペラの車、車輪とプロペラのチェーン、地面と空気の速さの矢印）。車の写真・動画は使わない。
- 出どころ:
  - NALSA（北米陸上帆走協会）"Downwind" の記録ページ https://v1.nalsa.org/DownWind.html （WebFetch で確認: 2010-07-02、まっすぐ風下へ、持続した 10 mph の風で 27.7 mph、比「ほぼ 2.8」。別の記録として El Mirage の干上がった湖でプロペラ式 51.4 mph）
  - 同じ協会の申請書: https://v1.nalsa.org/BlackBirdDDWSR/NALSA%20Submision%20report.pdf （検索結果の要約で確認: 比 2.8 と最高 51.4 mph を申請）
- 推定・注意:
  - 乗り物の名前（Blackbird）と作った人の名前は出さなくてよい（選手ではないが、写真は使わない）。出どころには書く。
  - 「論争」: 当時、ある物理学者が「突風のせいで一時的にこえただけ」と反論した記録がある（ScienceAlert の記事、検索結果の要約）。画面は「大論争になった」までにして、だれが勝ったとは言わない。
  - 2.8 は持続した風での比（突風ではない）、と協会のページ。
- コメント欄の問い（任意）: 「なぜ地面から力をもらえるのか、説明できる？」

### sail-wind-2  型A  「追い風がいちばん速い、はウソ」
- 題名: 【うんちく】ヨットがいちばん速いのは追い風じゃない ／ EN: Did you know? A sailboat is slowest with the wind right behind it
- 尺: 30秒　しゃべり: (2)　へぇ度: ★4
- フック（0〜1.5秒の画面）: 真後ろから風を受けるヨットに × 「いちばんおそい」
- 台本:

| 秒 | 画面 | しゃべり／字幕 |
|---|---|---|
| 0–2 | × | ヨットは、追い風がいちばんおそい。 |
| 2–8 | アプリの録画: 同じ 4 ノットの風、真後ろ → 船は風の 0.58 倍 | 弱い風で、真後ろから受けると、船は風の6割の速さ。 |
| 8–14 | かじを切って真横の風 → 1.26 倍 | 同じ風を真横から受けると、風の 1.26 倍。風より速い。2倍以上ちがう。 |
| 14–21 | 帆のまわりの空気の流れ（アプリの断面）。帆の裏側に「引っぱる力」の矢印 | 横の風では、帆は押されるのではなく、飛行機の翼のように空気の流れで前へ引っぱられる。 |
| 21–26 | 船の下のキールが横流れをおさえる矢印 | 横へ流されそうな力は、船の底の板（キール）が水でおさえて、前へ進む力だけが残る。 |
| 26–30 | 真後ろ → 真横の速さの棒グラフ | 追い風は、押されるだけ。だから、いちばんおそい。 |

- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: 同じ 4 ノット（時速 7 km、早歩きくらい）の風で、真後ろ 0.58 倍 ／ 真横 1.26 倍（2.2 倍のちがい）。
- 絵の作り方: アプリの録画（4 kt、真後ろ 180° と真横 88°、見かけの風の矢印・速さの表示を入れて）。
- 出どころ:
  - Python-VPP（M. Lauber、MIT ライセンス）の results.json、YD-41（主帆＋ジブ／スピネーカーの速いほう）。ORC（国際的なレースの規則の団体）の帆の係数と船体抵抗の式（アプリの PLAN.md・DEVNOTES.md にある表。アプリの `tools/verify.js` で Python 版と一致を確認済み）
- 推定・注意:
  - 数字は1つの船（YD-41、全長 12 m ほどのヨット）の計算。船によってちがう、と画面に小さく「計算: ある12mのヨット」。
  - 強い風（20 kt）では真横 0.57・真後ろ 0.49 と差が小さい → 「弱い風で」と言う。
  - 「風より速い」は真横の弱い風のとき。いつもではない。
- コメント欄の問い（任意）: 「じゃあ、向かい風にはどうやって進む？」

### sail-wind-3  型G  「風下へ走るのに、向かい風」
- 題名: 【うんちく】速いヨットは、追い風でも顔に向かい風 ／ EN: Did you know? The fastest sailboats feel a headwind even when sailing downwind
- 尺: 20秒　しゃべり: (1) 字幕だけ　へぇ度: ★4
- フック（0〜1.5秒の画面）: 上から見た図。風は後ろから（青い矢印）、船の上の旗は前から（赤い矢印）。
- 台本:

| 秒 | 画面 | しゃべり／字幕 |
|---|---|---|
| 0–2 | 青と赤の矢印 | 後ろから風がふいているのに、船の上は向かい風。 |
| 2–7 | 風の3倍で走る船（上から）。風の矢印から船の速さを引くと、矢印が前へ回る（アプリの見かけの風の表示） | 風の3倍の速さで走る船では、自分が作る風のほうが強い。 |
| 7–12 | 「風下へ 140° でも、感じる風は前から 16°」 | 風下へ向かっていても、感じる風は、ほとんど正面から。 |
| 12–16 | 帆はいつも、ぴんと引きこまれたまま | だから速い船は、追い風でも帆を引きこんだまま走る。 |
| 16–20 | 最初の図にもどる | 後ろから風がふいているのに…（最初へ） |

- いちばんの「へぇ」の数字と、ふだんのものとのくらべ: 風の3倍で、風から 140° の向きへ走ると、感じる風は前から 16°、強さは本当の風の 2.3 倍。風下へ進む速さ（風の向きの成分）も風の 2.3 倍。
- 絵の作り方: アプリの録画（世界に固定した上からの図、見かけの風の矢印）＋Canvas で矢印の引き算。
- 出どころ:
  - 風の3倍: SailGP の公式ガイド "Beginner's guide to the F50 foiling catamaran" https://mediahub.sailgp.com/news/24/beginners-guide-f50-foiling-catamaran/ （WebFetch で確認: 「風の3倍をこえる速さ」、記録 103.93 km/h）
  - 見かけの風の向き: ベクトルの引き算（下の計算）
- 推定・注意: 140° で風の3倍が出るかは船・風による。台本では「風の3倍で走る船なら」と仮定として言う。SailGP のチーム名・選手名は出さない。
- コメント欄の問い（任意）: なし

#### 計算（sail-wind-3）
- 船の向きを x、本当の風は船の向きから測って 140° の方から吹く。風の速さ W = 1、船の速さ V = 3。
- 風の速度（吹いていく向き）: −(cos140°, sin140°) = (0.766, −0.643)
- 見かけの風 = 風 − 船 = (0.766 − 3, −0.643) = (−2.234, −0.643)。大きさ √(2.234² + 0.643²) = 2.32
- 吹いてくる向き: atan(0.643 / 2.234) = 16.1°（船の正面から）
- 風下へ進む速さ: −V cos140° = 3 × 0.766 = 2.30（風の 2.3 倍）
- 参考: 風の2倍・135° なら 前から 28.7°、強さ 1.47 倍。
