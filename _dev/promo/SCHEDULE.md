### う1 の台本の案（ブラックホールの見え方、約35秒）
角度は台本の setup でアプリの `__bh.pickAt` で測って字幕に入れる（10° 単位で「約」。縦長・カメラ 47.6 M で測ると 上の帯 約50°・下の帯 約60°・影のふちの細い輪 約220°。DEVNOTES の 41°・100° は横長の画面で測った値）。文字は穴の上の空き、光の道すじの図は下に置いた（帯を隠さない）。
| 秒 | 画面（アプリ） | 字幕 |
|---|---|---|
| 0〜3 | 映画の角度。上と下に帯のある姿 | ブラックホールの上にある輪、何だと思う？ |
| 3〜12 | 上の帯をクリック → 光の道すじの図（横から） | 答え: **真後ろ**の円盤。光が上を回りこんで届いている（約50°曲がる） |
| 12〜20 | 下の帯をクリック | 下の帯も真後ろの円盤。しかも円盤の**裏の面**（約60°曲がる） |
| 20〜28 | 影のふちの細い輪をクリック（図は「穴の近く」） | 影のふちの細い輪は手前の円盤の裏。光が穴のまわりを約220°まわって届く |
| 28〜35 | カメラを少し上へ（85° → 62°）、形が変わる | 角度を変えて自分で確かめられます |
出どころ: James, von Tunzelmann, Franklin, Thorne（2015、映画「インターステラー」のブラックホールの論文）・Bardeen, Press, Teukolsky（1972）。アプリの画面の出どころと同じ。映画の名前は説明のために出すだけ（映画の画像・音は使わない）。
