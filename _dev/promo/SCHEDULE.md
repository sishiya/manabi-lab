# 紹介動画の公開順（案、2026-10-10）

1日1アプリ。説明動画 20:00 → ショート 20:05（README・メモリの方針）。1日目は 46億年（ユーザーが決めた）。
日付は始める日が決まったら右の列に入れる。予約は `youtube-upload.ps1 -Schedule`（字幕を送らないので割り当てを食わない）。

## 並べ方の決まり
1. **同じジャンルを連日にしない**（入口の分類: 地球と宇宙・からだ・いきもの・物理）。いきものが4本あるので、いきものを1日おきに入れて、あいだを他でうめる。
2. **サムネイルの色味が似たものを連日にしない**。色味は入口のサムネイル（`assets/thumbs/`、説明動画のサムネイルと同じ）で分けた:
   - 紺の暗い画面: 量子・電波・進化の箱庭
   - ピンク・赤: 体内ダイブ・免疫
   - 灰色: 神の視点マップ（ビルの写真）・カビ（白い壁）
   - 明るい: いきもの（夕方の空）・空気の流れ（水色の間取り）
   - そのほか: 46億年（緑と青の地形）・ブラックホール（黒と金）・さなぎ（暗い地に水色と黄の模式図）
3. **中身が似ているものを近づけない**: 電波と空気の流れ（どちらも「見える部屋」の間取り）、46億年と進化の箱庭（進化）、免疫とカビ（微生物）、量子と電波（紺の物理）。
4. **見て強いもの・録画ずみのものを前に**: 1〜3日目は録画ずみの3本（ブラックホールは見た目がいちばん強い）。そのあいだに残り9本を録れる。録画に1時間ほどかかる神の視点マップは後ろ（10日目）。
