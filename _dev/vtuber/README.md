# しし屋 VTuber 試作

しし屋のアイコン（`_dev/sns-icon/a-lion-glasses.svg`）をパーツに分けて、Canvas 2D で動かす。1ファイル（`index.html`）。

## 動かし方

- `apps` のサーバー（http://localhost:8765/_dev/vtuber/）で開く。カメラ・マイクは https か localhost でないと動かない。
- **おまかせ**: 首ふり・まばたき・ときどき口パク（カメラなしで見た目を確かめる用）。
- **カメラ**: MediaPipe Face Landmarker（`@mediapipe/tasks-vision@0.10.14`、jsDelivr から。型は Google の storage から）で顔の向き・まばたき・口・笑顔を読む。映像はパソコンの中だけで使う。まっすぐ見て「いまの顔を正面にする」。
- **マイク**: 声の大きさで口を動かす（顔は自動でゆらし、しゃべっている間は少しうなずく）。静かなときと大きな声を覚えて自動で合わせる。札に声の目盛りと感度。
- **リアル**: カメラの表情の値 52 種類（blendshapes）を細かく使う別の描き方（`drawReal`）。眉（アイコンにはない）・視線・目を細める／見ひらく・片側だけ笑う・口をすぼめる／横に引く・ほおをふくらます・鼻のしわ。首の向きで、顔に貼りついたもの（目・メガネ・口）が奥行きに合わせてずれて細くなる。追う速さもほぼそのまま。右下に読みとった顔の点（映像は出さない）。
  - 値の Left／Right がどちらの目かは、片目を閉じたときに顔の点の目の開き方と見くらべて自動で決める（`swapLR`）。動きは鏡と同じ向き。
  - カメラなしの確認: `?clean&pose=1`〜`4`（ウインク笑顔・おどろき・横目でチュー・しかめっ面）。
- キー: `1`〜`4` 表情（ふつう・にっこり・びっくり・ねむい）、`5` メガネがキラーン、`H` 札を隠す。

## 配信や録画で使う

- OBS の「ブラウザ」ソースに `http://localhost:8765/_dev/vtuber/index.html?clean&bg=clear`（札なし・透明）。カメラを使うときは、OBS 側でカメラの許可が要るので、ふつうのブラウザで開いて「ウィンドウキャプチャ」＋ `?bg=green` をクロマキーで抜くほうが簡単。
- URL の後ろ: `?clean`（札なし）、`?bg=green`／`?bg=clear`、`?ex=1`（表情）。

## しくみ

- 奥から: たてがみ（ばねで遅れてゆれる）→ 耳（ときどきぴくっ）→ 顔 → ほっぺ → 目 → 鼻と口 → メガネ。首を振ると奥のパーツほど少なく・手前ほど多くずらして、立体っぽく見せる（`P(d)`）。
- 白衣は「まなびラボ」から。中のシャツはメガネと同じ紺。
