### 1. 見た目・言葉・置き場所の行ったり来たり（いちばん多い）

**例**
- 果ての滝の箱庭: 観察帳 → 巻物（v033）→ 箱庭の博物誌（v036）→ 天命の書板（v037）→ 観察帳にもどす（v038）。泉の印は v058 から v066 まで6版いじって、最後に「v058 の案にもどす」。
- 歴史係: 題名を 歴史係 → 守り人（v060）→ 時守（v061）→ 歴史係にもどす（v063）が同じ日。回答ボタンの場所を3版続けて動かす（v046〜v048）。上の帯を5版（v053〜v057）。綴じるキーを H → G。
- 系統樹: はじめの画面を 3D（v012）→ 2D（v018）。ガイドを切りかえ式にしてから固定（v016）。

**どう直したか**: うまくいったのは、**案をアプリの中で切りかえられるようにして一度に見くらべた**とき（歴史係 v003-looks の見た目3案 → v005 で決定、果ての滝 v002 の画風3つ、ボクセルの細かさを「試験」の切りかえで出した v010・v013、VTuber の服の見くらべページ）。1案ずつ直してコミットすると、くらべる相手がもう画面にない。

**ルールにしたこと**: 同じ所（見た目・言葉・名前・置き場所・音）を**2回直したら、3回目は案を2〜3個並べて選んでもらう**（RULES 6章、あそびラボ RULES 6章）。

**ブログの切り口**: 「AI と作ると "作る" はタダになり、"選ぶ" が仕事になる」。版が 90 まで増えた2日間の中身を、何が残って何が戻ったかで分ける。

### 2. スマホでくずれる（あとから詰める）

**例**: 体内ダイブ v003o（表示物が重なる）、変化球 v012〜v013（はみ出し・名札）、果ての滝 v021〜v023（色）、恐竜かけっこ牧場 v005（画面を分けなおし）、英語の画面のはみ出し点検（10/16）。

**どう直したか**: 10/12 に「スマホを最初から設計に入れる」を基本ルールに（見比べたい図は上に固定、ほかはスクロール。幅 375px で毎回）。あそびラボは 10/17 に画面の区割り（まん中は遊び場・手元のふちに道具・右に決める行動）を基本ルールに。

**気づき**: ルールにしたあとに作ったアプリ（メトロノーム・タイピングする手）は、スマホの直しのコミットがほとんどない。**ルールはあとから効く**。

### 3. 正確さ・出どころ（「本当のことだけ」）

**例**
- 10/07 に全アプリの「おもな出どころ」を画面に出す一斉作業。確かめられない数値は「目安」と書きなおした（ネコの暗さ、満月の明るさなど）。
- 二重スリットの「2つの山になる」の誤りを直す（quantum v001j）。S状結腸→直腸を「括約筋」から「せまい曲がり角」へ（解剖で見つかっていない）。
- ハエの目の六角形のふち: 見やすさのための線なのに、本当にそう見えるかのようにサムネイルに出しかけた → 「※ 目印」と凡例に書く（10/16）。コウモリのこだまも同じ。
- 確かめられない出どころを外す（脱毛・ピアノ）。DOI は Crossref で確かめる（ファージ）。

**ルールにしたこと**: 見やすさのために足した目印（本物には無い線・色・光）は、画面の凡例に「目印」と書く。サムネイル・動画でも同じ（RULES 9章）。

**ブログの切り口**: 「シミュレーションの "演出" はどこまで許されるか」。記録・推定・演出を画面で分けるやり方。

### 4. 権利・収益化の後始末

**例**: 非営利だけ可のデータ（EOX の衛星写真・Open-Meteo）を外し、古い版 17 個ごと消した（god-view、10/10・10/12）。ピアノの運指の出どころ（CC BY-NC-SA）を外して答え合わせを 664/704 → 533/559 に。タイピングのサンプル文は権利を確かめて「雨ニモマケズ」に。

**気づき**: 「あとで収益化するかもしれない」を最初に決めておけば、外す作業はいらなかった。いまはルール（非営利だけの素材を使わない）と `check-content.ps1` で入口で止めている。

### 5. 小さな数の事故（NaN・あふれ・届かないイベント）

| 症状 | 原因 | 直し方 |
|---|---|---|
| ファージが出ない（phage v005） | 最初のコマの経過時間がマイナス → 位置が NaN | dt を 0〜0.05 秒にはさむ（new-app.ps1 のひな形にも入れた） |
| 断面が消える（脱毛） | ドラッグ移動で拡大率が空 → NaN | こわれた表示は全体表示にもどす |
| 滝にピンクの粒（果ての滝 v047） | 色が 255 をこえた | 色は 0〜255 にはさむ |
| ホイールで拡大できない（系統樹 v008） | Windows の拡大率で量が小数になり、トラックパッドとまちがえた | 判定を量の大きさでなく種類で |
| WASD が押しっぱなし（いきもの） | 右クリックのメニュー・タブ切りかえで keyup が来ない | 窓がはずれたら全部はなす |
| 表示されないことがある（phage v004） | 隠れたタブで絵の大きさが 0 | 見えたときに測りなおす |
| 消したはずの設定が残る（脱毛） | `hidden` が `.row{display:flex}` に負けた | `[hidden]{display:none!important}` をいつも入れる |

**ルールにしたこと**: この表を「こわれにくさの確かめ」として RULES-more 6章に。ひな形（new-app.ps1）に `[hidden]` の1行を足した。

### 6. ブラウザの違い

- iPhone の Safari だけ地面の色がくずれる（果ての滝 v022・v023）: シェーダーの入れ子の `mix` と同じ名前の `const` が原因。書き直して色は同じのまま直った。
- doctype のない `index.html`（Artifact 時代の名残）は Pages で互換モード → 入口へ移すたびに配置のずれを直していた（ファージは 608 要素を比べた）。
- 公開版で古い CSS・JS が読まれる → あそびラボでは `?v=<番号>` をルールに。まなびラボは脱毛のしくみで同じことが起きた。

**ルールにしたこと**: まなびラボにも `?v=<番号>`（RULES 8.1）。シェーダーの書き方の注意を RULES-more 6章に。

### 9. 運用（動画・YouTube・記事）

YouTube の処理が止まる・API の1日の上限・BGM で音量が 14 dB ちがう・チャプターは最初が 10 秒以上・サムネイルを3回作りなおし・Zenn の24時間の上限。どれも1回目でつまずいて、2回目には道具（`youtube-upload.ps1 -Verify`・`check-loudness.ps1`・`make-short-thumbs.ps1`）とルール（8.4〜8.7）にした。

### 10. 文書の太りすぎ・並行セッション

- RULES.md 41KB → 22KB、PLAN-9apps 69KB → 13KB、god-view の DEVNOTES 68KB → 36KB（10/12）。毎回読む文書が太るとトークンが増える → `upkeep.mjs` が毎週測る。
- 並行セッションが同じ共有ファイル（入口・保管庫・README）を直していて、別のセッションのコミットに変更がまざった（10/12）。あそびラボはルールあり → **まなびラボの RULES 10章にも「自分の行だけコミット」**。

### ほかよりうまくできていること（記事の柱になりそう）

1. **物理を曲げないで、検査を数字にする**: ピアノの運指の答え合わせ 88% → 97%、タイピングの検査（関節の限界 8.1 → 3.7%）、メトロノームの `tools/verify.js`、手の太さを産総研の寸法データに合わせる。「見た目がおかしい」を測れる形にしてから直す。
2. **自動プレイのダイジェスト**: ゲームをクリアまで自動で遊ばせて、章ごとの日数とエラーを見る。手ざわりは人、大枠は機械。
3. **トークンを使いすぎないリポジトリ**: CLAUDE.md は地図だけ・DEVNOTES の「別セッションで続けるとき」・ファイル構成の表・800行/60KB で分ける・`.ignore`・毎週の `upkeep.mjs`。
4. **公開前チェック2段＋フック**: 機械で調べる（付加情報・秘密・外への通信）と、内容を調べる（医療の言い切り・商標・素材の条件）。push はチャットで頼まれたときだけ通すフック。
5. **本当のことだけのサムネイル・ネタバレ厳禁**: 目を引くより、動画とアプリで出している数字だけ。

### もっとよくできそうなこと

- **選ぶ回数を減らす**: 見くらべを先に出す（6章のルール）。2日で 90 版は、くらべる道具があれば半分で済んだはず。
- **企画書の段階で手ざわりを決める**（4章のルール）。作り変え5回のうち、何回かは防げた。
- **こわれにくさの表をひな形に寄せる**: dt と `[hidden]` は入れた。キーをはなす・隠れたタブの大きさも、次に作るアプリで型にする。
- **英語は最初から `L()` で書く**: 入口へ移すたびに英語対応のコミットが1本ずつある（24件）。保管庫の段階から `L('日本語','English')` の形で書いておけば、移すときは訳だけで済む。

### このふりかえりで足したルール

- RULES 4章: 企画書に「見る人・遊ぶ人の手がすること」と「時間の見せ方」を書き、作る前に確かめる。
- RULES 6章（あそびラボ RULES 6章も）: 同じ所を2回直したら、3回目は案を並べて選んでもらう。

- RULES 9章: 見やすさの目印は凡例に「目印」と書く（サムネイル・動画も）。
- RULES 10章: 並行セッションがあるので、共有ファイルは自分の行だけコミット。
- `new-app.ps1` のひな形に `[hidden]{display:none!important}`。
