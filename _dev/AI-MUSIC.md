# 楽曲生成 AI（Suno ほか）を使うとしたら

2026-10-17 に調べたメモ。**まだ使っていない**（いまの BGM はすべてコードで合成した音。`_dev/promo/README.md`）。規約はよく変わるので、使う前に必ず本文を読みなおすこと。ここは判断の材料で、法律の助言ではない。

## 1. 規約の要点（2026-10-17 時点）

### Suno（規約 2026-08-10 更新、2026-09-03 から有効）
- **無料プラン**: 個人・非営利の用途だけ。あとから有料にしても、無料のときに作った曲はさかのぼって商用にならない。
- **有料（Pro・Premier）**: Suno が持つ権利を利用者にゆずる。ただし「著作権が生じるとは保証しない」「第三者の権利を侵害しないとは保証しない」と書いてある。
- **商用に使えるのは、正規の方法でダウンロードした曲だけ**。ダウンロードは月ごとの上限あり（Warner との和解 2025-11 のあと）。録音・ストリームの抜き取りは禁止。
- ダウンロードした曲の商用の権利は、解約したあとも続く。
- リミックス（他人の曲をもとにしたもの）は、どのプランでも非営利だけ。
- 表示（クレジット）の義務はない。ただし**透かし・メタデータを消して出どころを隠すのは禁止**。Suno の側から「Suno で作った」と公表することもある。
- 出力を**ほかの AI の学習に使う・Suno と競う製品を作るのは禁止**。
- 同じ曲・似た曲がほかの利用者にも出ることがある（ユニークでない）。
- 利用者が Suno を補償する（訴えられたら利用者の責任）。Suno の責任の上限は、過去6か月に払った額か 100 ドルの大きいほう。
- Universal・Sony との裁判はまだ続いている（2026-06 の報道）。

### Udio
- Universal との和解（2025-10-29）から、**全プランでダウンロードできない**（2026-09 時点でも）。外に持ち出せないので、サイトにも動画にも使えない。

### ElevenLabs（Eleven Music、規約 2026-10-09 更新）
- 無料: ダウンロードできない・表示が必要。Starter: 配信サービスへの配信は不可。Creator・Pro: 配信も可、表示不要。
- **映画・テレビ・ラジオ・「スタジオのゲーム」は Enterprise 以外どのプランでも不可**。インディーのゲーム（売上 50 万ドル未満など）は可。
- 権利は利用者に残る。プロンプトにアーティスト名・曲名・歌詞を入れるのは禁止。

### Stable Audio 3（自分の PC で動かす。2026-10-19 から使っている）
- 重みが公開されたモデル（medium）を、Audio Studio MCP（KANA さん作、MIT）でこの PC の RTX 5070 で動かす。クラウドに何も送らない・料金なし。
- **Stability AI Community License**（本文を 2026-10-19 に読んだ）: 作った音は使った人のもの（IV(c)(iii)）。商用も可、ただし本人と関連会社の年の売上が 100万ドルをこえたら終わる（III）。「Powered by Stability AI」の表示はモデルや派生物を配るときだけで、作った音には要らない（IV(a)）。作った音を別の生成 AI の土台モデルの学習に使うのは禁止（IV(b)）。透かしの義務はない。
- 学習データはすべて許諾ずみと会社は言っている。
- しし屋のサウンドライブラリはこれで作る → `_dev/sounds/README.md`（使い方のきまりもそこ）。

### そのほか（公式の本文までは読めていない。使うなら要確認）
- **Stable Audio（クラウド版・Large）**: 有料は商用の許諾、無料は個人・非営利。
- **Google Lyria（Gemini）**: 透かし SynthID が必ず入る。ふつうの Gemini の規約。「表現の道具で、プロの音楽制作向けではない」という位置づけ。
- **Mubert・SOUNDRAW・AIVA**: どれも商用は有料プラン。Mubert は Content ID への登録を禁止。

## 2. まなびラボ・あそびラボで使うときの心配

1. **ライセンスの食いちがい（いちばん大きい）**: このリポジトリの中身は CC BY-NC 4.0（README「ライセンス」）。AI の曲をリポジトリに置くと、他人に CC BY-NC で配るように見える。でも、その曲に著作権があるかが分からない（下の 3）うえ、Suno の規約は他人の改変・学習利用を止めたい内容。→ 置くなら **README に「AI で作った音は CC BY-NC の対象外」と書いて除く**必要がある。
2. **公開リポジトリ＝誰でもファイルを持ち出せる**: GitHub Pages の mp3 は誰でもダウンロードでき、他の AI の学習に使われても止められない。Suno の「学習に使わせない」と、こちらの手の届く範囲がずれる。
3. **著作権がつかないかもしれない**: 文化庁「AIと著作権に関する考え方」（2024）では、AI が自律的に作ったものは著作物ではない。人の創作的寄与（詳しい指示・手での編曲や修正）がある部分だけ。プロンプトだけの曲は、他人にまねされても守れない可能性が高い。
4. **既存の曲に似る危険**: 学習元の曲に似たフレーズが出ると、YouTube の Content ID で申し立てを受けたり、侵害と言われたりする。責任は利用者（補償の条項）。音を聞いて似ていないかを毎回確かめる手間が増える。
5. **無料プランは使えない**: しし屋は収益化の可能性がある（メモ「NC の出どころを使わない」の方針）。YouTube の収益化も商用。→ Suno なら有料プランで、ダウンロードした曲だけ。
6. **YouTube の表示**: 曲だけなら「改変・合成されたコンテンツ」の表示はたぶん必須ではないが、付けても損はない（ラベルで収益は減らないと YouTube は言っている）。AI の曲ばかりの量産チャンネルに見えると収益化の審査で不利。
7. **「出どころは画面に」（RULES 9章）**: 使うなら、どの AI・どのプランで作ったかを画面の出どころと動画の概要欄に書く。透かしは消さない。
8. **学びのサイトとしての見え方**: 「測られた値だけ」「物理を曲げない」を売りにしているので、AI の曲を使うと、それを好まない人の目には印象が下がるかもしれない。AI の曲だと隠さず書くのが前提。
9. **規約が変わる・サービスが止まる**: Udio は和解の日にいきなりダウンロードを止めた。音の元データ（どのプロンプト・いつ・どのプラン・規約の版）を残しておかないと、あとで権利を説明できない。

## 3. できること・できないこと（Suno の有料プランを使う場合）

| | できる？ | メモ |
|---|---|---|
| 紹介動画（ショート・説明動画）の BGM | ○ | 有料・ダウンロードした曲。概要欄に「BGM: Suno で作成」。Content ID の申し立てに備えて記録を残す |
| アプリの中で鳴らす BGM（Pages に mp3 を置く） | △ | 規約上は商用利用の範囲だが、上の 1・2（CC BY-NC との食いちがい・持ち出し）を README で手当てしてから |
| あそびラボのゲームの BGM | △ | 同上。ElevenLabs なら売上の小さいインディーのゲームは可と明記 |
| 無料プランで作った曲を使う | × | 個人・非営利だけ。あとから有料にしても戻らない |
| 曲を素材集として配る・売る | × | ElevenLabs は明記で禁止。Suno も競う製品にあたるおそれ |
| 曲を自分の曲として Content ID に登録する | × | 著作権が不確か・他人と同じ曲が出うる。Mubert は明記で禁止 |
| 透かし・メタデータを消す | × | Suno は明記で禁止 |
| 曲を AI の学習データにする（自分で・他人に） | × | Suno は明記で禁止 |
| 実在のアーティスト風・歌詞の流用 | × | ElevenLabs は明記で禁止。どの道具でも侵害のもと |
| Udio の曲を使う | × | ダウンロード不可 |

## 4. いまのおすすめ

- **いまのまま（コードで合成した BGM）がいちばん安全**。権利がはっきりしていて、CC BY-NC とも食いちがわない。
- 使うとしたら、まず **紹介動画の BGM だけ**（リポジトリに mp3 を入れない）で試すのが小さく始められる。
- アプリの中で使うなら、その前に: ① README のライセンスに AI の音の除外を足す ② 画面の出どころに書く ③ 記録（道具・プラン・日付・プロンプト・規約の版・ダウンロードの記録）を `_dev/promo/` か各アプリの DEVNOTES に残す ④ 聞いて既存曲に似ていないか確かめる。
- 実際に使うと決めたら、この文書と RULES 9章にルールとして足す。
- **2026-10-19 追記**: Suno より先に、自分の PC で動く Stable Audio 3 を使いはじめた（規約がゆるく、記録が自動で残る）。まず紹介動画と作業用から。アプリに入れる前の手当ては上と同じ。
