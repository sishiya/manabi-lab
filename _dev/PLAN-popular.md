# 企画書: 入口に「よく遊ばれている」を出す

2026-10-17〜。入口（`index.html`）に来た人が、どれから開くか選びやすくするため。

## 見る人の手がすること・時間の見せ方
- 見る人は**ながめるだけ**。カードの印を見る／並び順のボタンで「人気順」を選ぶ。新しい操作は増やさない。
- 時間: 「直近4週間」の1つだけ。グラフや推移は出さない。

## 決めたこと
- **数は出さない。順位と印だけ。** 立ち上げの時期は数が小さく、かえってさびしく見えるため。`assets/popular.json` にも順位だけを書く（数は今どおり `_dev/tools/out/` だけ。Git に入れない）。
- **測る値**: アプリのページ（`/manabi-lab/<id>/`）の**エンゲージメントのあったセッション数**（GA4 の `engagedSessions`。開いてすぐ閉じた分は数えない）。
- **新しいアプリを不利にしない**: 4週間より新しいアプリは、公開してからの日数で割った「1日あたり」で比べる。「新作」の印は今までどおり残す（新作が先、人気はそのあと）。
- **少なすぎるときは出さない**: 1位でも 4週間で 30 セッションに届かないあいだは、印もボタンも出さない。
- **古くなったら出さない**: `popular.json` が 3週間より古ければ出さない（更新を忘れても、古い順位を見せ続けない）。
- **根拠を画面に**: 印か並び順の近くに小さく「直近4週間に、よく遊ばれた順（Google アナリティクスで集計）」。英語も L() で。
- 対象は**入口のアプリだけ**（保管庫は今回は入れない）。

## データの取り方（もう半分ある）
- GA4 を読むしくみは `youtube-upload.ps1 -Ga`（読むだけの許可、トークンは秘密のフォルダ）と `weekly-report.ps1` にある。サービスアカウントは使わない。
- 新しく `_dev/tools/popular.ps1`: 上の許可で `pagePath` ごとの `engagedSessions` を読み、APPS の id に合わせて順位を出し、`assets/popular.json` に書く。
  ```json
  {"from":"2026-09-19","to":"2026-10-16","rank":["phage","pitch-physics","eye-optics"]}
  ```
- 週のふり返り（`weekly-report.ps1`）のあとに回す → commit。公開に出るのは、ユーザーが push を頼んだとき（RULES 10章）。

## ユーザーにしてもらうこと（Claude はできない・しない）
1. GA4 のプロパティ ID（数字）を `_dev/tools/analytics.local.txt` に1行で書く（GA の 管理 → プロパティの詳細）。
2. `youtube-upload.ps1 -Ga -Auth` で読む許可を出す（GA を持っている Google アカウントで）。
3. （おすすめ）自分の見た分を数えないように、GA の 管理 → データストリーム → タグ設定 → 内部トラフィックの定義 に自宅の IP を足し、データフィルタを「有効」にする。設定の変更なのでユーザーが行う。

## 出し方の案（段階Bで入口の中で切りかえて見くらべる。`?pop=a|b|c`）
- **A 印だけ**: 上位3本のカードに小さな「人気」の印（右上。左上は「新作」「更新」）。並び順は今のまま。
- **B 並び順だけ**: 並び順のボタンに「人気順」を足す（分野ごと・新着順・更新順・人気順）。印はなし。
- **C 両方**: B に加えて、上位3本に A の印。
- おすすめは C。ふだんの並びは変えずに目印が付き、見たい人は人気順にもできる。

## 段階
- **A データ**: `popular.ps1` を作り、手元で `popular.json` が出るところまで。ユーザーの 1・2 が済んでから動かせる。それまではテスト用の json で進める。
  - **済み（2026-10-17）**: `youtube-upload.ps1 -Ga -Popular`（pagePath × date ごとの engagedSessions）と `popular.ps1`。テスト用の数で、launcher.html・保管庫・入口の一覧のページを数えないこと、入口に出る前の日の分を外すこと、少ないときは空になることを確かめた。**本物の GA ではまだ動かしていない**（プロパティ ID と許可がまだ）。pagePath と engagedSessions の組み合わせを GA が受けつけるかは、そのとき確かめる。
  - 入口に出た日は APPS の `created` を使う。`created` より前に入口へ出ていたアプリはない前提。
- **B 見せ方**: `index.html` に 3案を `?pop=` で切りかえられるように入れる。幅 375px・暗い色でも確認。ユーザーが1つ選ぶ。
- **C 仕上げ**: 選ばなかった案を消す。`_dev/tools/README.md` に道具を1行、週のふり返りの手順に「popular.ps1 → commit」を足す。

## やらないこと
- 数（人数・回数）を画面や Git に出す。
- アプリの中に順位を出す。
- 見た人ごとの記録（いいね・星など）。サーバーがなく、正直に数えられないため。
