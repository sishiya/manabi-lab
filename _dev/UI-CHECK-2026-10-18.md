# PC・スマホの操作の点検（2026-10-18）

ユーザーの頼み: 過去のアプリそれぞれ、PC とスマホのどちらでも問題なく使えるか、操作しづらい・見づらいところはないか。

## やり方
- ローカルのサーバー apps-2（http://localhost:8766/。プレビューの道具は 8767 と言ったが、実際に聞いているのは 8766）。8765 は別のプロセスが使用中だった。
- PC: アプリ内ブラウザのふだんの幅。スマホ: 375×812（resize_window の mobile。タッチ端末としてふるまう）。
- 見るところ: 横にはみ出さないか／図と結果が上に固定されているか（RULES 9章）／ボタンが小さすぎないか（目安 32px 以上）／文字が切れていないか／重なり／コンソールのエラー。
- この段階では直さず、記録だけ（直すかどうかはユーザーと決める）。

## 結果（アプリごと）

## まとめ（直すならこの順）
1. スマホで図が上に固定されていない（RULES 9章に反する）: **illusions（作品ページ。測るスライダーと図が同時に見えない）**・quantum・immune-battle・metamorphosis・ga-creatures・mold-growth・muscle-growth。
2. 重なって押せない・読めない:
   - evolution（スマホ）: 「排出」の選択欄が「地球のようすと祖先」ボタンをかくす（#side の bottom:150px が #dock の高さ 229px より低い）。
   - metamorphosis（スマホ）: 題「終齢幼虫（…」に「透かして見る」ボタンがかぶる。
   - pitch-physics（PC 1280 幅）: 「フォーシーム（ドラッグで動かせる）」の札が「打者の目」ボタンにかぶる。
3. 小さすぎて押しにくい: immune-battle のズーム −・＋（幅 15〜17px）と小窓のたたむボタン（17×16）。多くのアプリの切りかえボタンが高さ 20px（black-hole・typing-hand・piano-hand・ferrofluid の視点、black-hole の横から／上から）。
4. スマホなのにキーボード・マウスの説明: body-dive・blood-dive・urinary-dive（「W を押し続けると」・ボタンのキー名）、piano-hand（[ ] キー）、tiny-earth（ホイール）、brain-response（「右の」刺激の場所）。
5. 読み込み中の表示がない: god-view（6〜10 秒まっ黒）。 → **2026-10-18 直した**（Cesium.js を本文の後ろへ＋「地球を読みこんでいます…」。god-view/DEVNOTES の履歴）。
6. 小さなこと: 図の下の説明が2行で「…」（black-hole・wifi-wave・air-flow・brain-response・ferrofluid）、ラベルの切れ（phage の時間のバー、extreme の目もり）、ラベル同士の重なり（metamorphosis の器官、muscle-growth のグラフ、air-flow の札）。
