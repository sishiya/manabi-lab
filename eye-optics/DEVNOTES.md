## しくみ
- 座標は mm、z は角膜の頂点から奥へ、y は上。断面の1平面だけ。面は円すい曲線（sag の式）、交点はニュートン法、屈折はスネルの法則のベクトル形。
- 目の模型: Navarro 1985。角膜 R 7.72（k −0.26）/6.50、厚み 0.55、n 1.376／房水 1.3374／水晶体 n 1.42、前 R 10.2（k −3.1316）、後 R −6.0（k −1）、厚み 4.0／硝子体 1.336。調節 A（D）の式: 前房 3.05−0.05 ln(A+1)、前 R 10.2−1.75 ln(A+1)、後 R −6+0.2294 ln(A+1)、厚み 4+0.1 ln(A+1)、n 1.42+9e−5(10A+A²)。k は変えない。値は MathWorks の目の模型の例（Navarro の表を引用）と、式を引用した論文で照合した。
- 近軸の焦点で計算した目の長さは 24.0040 mm で、Navarro の値（24.00）と一致した（模型の入れまちがいがない確認）。`OPT.L0` は「ひとみ 3 mm で遠くがいちばんくっきりする長さ」23.924 mm にしている（球面収差で近軸の焦点より手前がくっきり）。
- 虹彩は水晶体の前面の 0.6 mm 手前。明るさ→見かけのひとみの直径（Crawford 1936、Watson & Yellott 2012 の書き方）→ 平行光をその高さで入れて虹彩の面での高さ＝あなの半径。
- 網膜は半径 12 mm の球（中心 L−12）。ぼけ: 扇の光線の網膜での高さを、ひとみの面での |高さ| で重みづけした二乗平均（円いひとみ全体の近似）→ 円板の直径 = 2√2 × rms。
- 調節は「網膜のぼけ最小」を 0〜最大（Hofstetter 平均 18.5−0.3×年齢）の中で黄金分割で探す。表示の調節 A は水晶体の式の A（目の屈折力の変化とほぼ同じだが同じではない）。
- 目の屈折: 角膜の位置のうすいレンズで遠くがいちばんくっきりする度。dL=+1 mm で −2.66 D、+2 mm で約 −5.1 D、−1 mm で +2.9 D。
- メガネ: 角膜の 12 mm 手前のうすいレンズ。遠く用＝遠くのぼけ最小の度、近く用＝40 cm を調節の半分でぼけ最小の度（遠く用より弱くしない）。どちらも 0.25 D きざみ、ひとみ 3 mm で決める。
- 見え方: 視力表の高さを 100 分（角度）として、ぼけの円の半径/2 を CSS の blur(σ) に。ランドルト環は外径 5/V 分・すきま 1/V 分。「ぼやける」の目安は ぼけの円 2 分。
- 目の外の距離は対数で縮めて描く（70 mm〜6 m、その先は「遠く」）。目の外の光線は物の印から引いた絵で、目の中だけが計算どおり。
- 時間（段階B）: `S.At`（調節のねらい）・`S.stopRt`（ひとみのねらい）は条件が変わるとすぐ変わる。いまの値 `S.A`・`S.stopR` は `dynStep` が追う: ねらいの変化を遅れの箱に入れ、遅れ（調節 0.30 s・ひとみ 0.2 s）のあとに効かせる → 指数関数で近づく。調節の時定数 τ ＝ 動く量 ÷ ピーク速度（近くへ 1.58×量＋3.42 D/s、遠くへ 1.4355×はじめの調節＋1.1345 D/s。Bharadwaj & Schor 2006 の PMC1578507 本文で確認）。ねらいが 0.005 D 以上変わるたびに τ を決め直す（ドラッグ中は小さな段の連続）。ひとみは縮む τ 0.35 s・開く τ 6 s（Mathôt 2018 の経過に合わせた推定）。結果: 5 m→30 cm で 0.3 s 動かず、約 1 s でくっきり。夜道へ 2.9→6.4 mm を約 20 s、明るくすると 0.2 s 後に約 1 s で 3 mm。
- 記録（`TL.rec`）はシミュレーションの時刻で 4 ms ごと・40 秒分。ふりかえりは記録の1コマ（距離・調節・ねらい・ひとみ・条件）を `applySnap` で目にのせ、いまの状態は `TL.live` にとっておく（そのあいだ時間は止まる）。ボタン・ドラッグ・案内の切りかえはふりかえりをぬけてから。
- 速さ `S.speed`（1/10・1/4・1・4）はシミュレーションの時間だけ変える（`step` で dt × speed）。案内の `go` の時刻もシミュレーションの時刻。
- 乱視（段階C）: `buildEye(..., cyl)` で角膜の前の面の曲率に cyl/((1.376−1)×1000) を足す（1.5 D → 半径 7.72→7.49 mm）。縦の断面は `cv`、横の断面は `ch`。トーリック面の主経線の断面にある光線は面の対称性でその平面に留まるので、2D の計算のまま正しい（斜めの光線＝skew ray は計算しない）。調節は縦横のぼけの二乗平均が最小の所（最小錯乱円）。メガネは縦横で別々に `farGlasses`/`nearGlasses`（円柱レンズ）。屈折は縦 −1.54 D・横 0（1.5 D の角膜乱視）、遠く用は縦 −1.50・横 0。直乱視（縦が強い）では縦にのびたぼけ（縦 14.3 分・横 2.3 分）→ 線の表で縦の線がくっきり。
- 乱視（段階E で一般化）: 強さ `astigP` と強い向き `astigAx`（横から反時計回り ang: 縦 90・横 0・斜め／45・斜め＼135）。強い向きの断面 cyl=astigP、弱い向き cyl=0。ぼけは強い向き `diamS`・弱い向き `diamW`、見え方はその向き ang にのびるだ円。斜めは表を回して（canvas の rotate(90°+ang)）長い向きを縦にそろえてから縦横のぼかし → 回しもどす（点の像で、45° なら右上・左下にのびることを確かめた）。
- 暗順応（段階D）: しきい値（log10 cd/m²）を錐体 `S.cone`・桿体 `S.rod` で持つ（`darkStep`）。暗くなると 錐体は頭打ち −1.4 へ時定数 1.5 分、桿体は 0.23 log/分（30歳から1年 0.001 ずつおそく。Patryas: 45歳以上 0.19）、rodAbs −4.6 の上 0.6 は 0.05 log/分。明るい所の桿体の高さ `rodLight(L)` = 1.2＋1.03 log L（推定。晴れ 3000 → 4.8 で切りかわり 6.5 分、部屋 100 → 3.3 で錐体の段なし＝Hecht の弱い光のあと）。明るくなると数秒（3 s）で上がる。晴れ→夜道（0.001）: 約13分まで見えない、30分で −4.59（測定 −4.40±0.44）。`darkSee`: 明るさが錐体＋0.3 を上回れば cone、桿体を上回れば rod、ほかは none。見え方の明るさは 余裕/1.5 log（目安）、rod はまん中 直径 75 分を平らに（Curcio の 1.25°）・σ 3 分を足す（視力 0.16、Shlaer）。
- 残像（段階F）: 図は変わらず目も動かないので、場所ごとの順応は c(x)·α(t)。dα/dt = (s − α)/τ（s: 残像の表で「図を見つめる」なら 1、ほかは 0）、τ 7 s（Zaidi ほか 2012 の神経節細胞 5〜12 s、Kelly & Martinez-Uriegas 1993 の 4〜8 s の中の推定）。見える錐体コントラスト: 見つめる c·(1 − kα)、白い面 −kα·c（k 0.42 = Zaidi の図4a の傾き。推定）。灰色 128 の地／白 236 で LMS に戻して sRGB へ。15 秒で α 0.88、白へ変えて 0.5 s で強さ 34%、15 秒で 4%、30 秒で消える。α は記録に入るので、ふりかえりで残像の途中にも戻れる。見え方の表のタブ「残像」（`S.chart='after'`）、図の上の `#afterBtn`（白い面へ／図を見つめる）。ぼかし（光学）はかけない（ピントは合っている前提）。
- 残像のしくみの図（ユーザー「残像のメカニズムも図でわかるように」）: 残像の表のとき、draw.js の `drawAll` が拡大鏡の代わりに `drawAfterMech` を描く（パソコンは右下・見え方の欄の下に入る高さ、網膜へ線。狭い画面は図いっぱい）。棒の値は after.js と同じ s・kα・s−kα（その図形の色を +、反対の色を −）、見える色は `spotSeen`（after.js と同じ式）。残像の表の `#chartLab` をさわると `pickSpot` でいちばん近い図形を選ぶ（表に点線の輪）。残像の表では `#swap` を隠す。
- 見え方のぼかしは CSS の blur ではなく JS の箱ぼかし3回（縦横別。乱視のため）。σ の値が 0.01 px 変わったときだけ描き直す。

## 英語対応（2026-10-12、入口へ移すときに）
- 言語の窓口（`var LANG=` の行）は wifi-wave からコピー。HTML は `lang="ja"`／`lang="en"` を並べる（「このアプリについて」は `#about`／`#about-en` の2つ）。JS の文はすべて `L('日本語', 'English')`（scene.js の条件・説明 `PARTS`・案内 `TOUR`（text は関数）、ui・view・timeline・draw・main の文字）。題名・aria-label は main.js の起動のところ。JP／EN のボタン `#langsw` は見出しの右。
- timeline.js の `tlDraw` の配置の変数を `L` → `Ly` にした（`L()` を隠すため）。
- Bash の heredoc で JS にバックスラッシュ2つを書くと1つになって文法エラー → Edit で直した（RULES 6章）。
- 英語の文が長く、スマホで見え方の見出しがはみ出した（幅 388px）→ `#view` の2列目を `minmax(0,1fr)`、見出しの em を折り返す。
- 確かめ方: `?lang=en` で14段・説明・グラフ・乱視の各設定・ふりかえりを通し、画面と canvas の日本語（全角記号も）がゼロ・エラーなし。`?lang=ja` で14段の状態の文が前と同じ。互換モードと標準モードで全239要素の位置が一致（1200px・375px）。

## ハマったところ
- Bash の heredoc で `cat > file` の後ろに何も渡さないと止まる（標準入力待ち）。Node での確認は一時ファイルに書いてから `node` で。
- 近軸の焦点で調節・正視を決めると、球面収差のため遠くでもぼけが 28 µm と大きく出た → 「ぼけ最小」で決めるように直した。
- 狭い画面で数字・見え方を図の上に重ねると読めない → 719px 以下は並べる（図 236px、見え方と数字は横に2つ）。図を `#cvwrap` で包んだので、説明の吹き出しの位置は `getBoundingClientRect` の差で出す（offsetLeft は 0 になる）。
- 「見る先」のボタンが図から遠いとスマホで見比べられない → 図に「⇄ 近く／遠くを見る」ボタン（`#swap`）を重ねた。
- スマホで固定（sticky）するとき、`#pin` の親が `#stage` のままだと #stage をこえた所で固定がはずれる → 719px 以下は `#stage{display:contents}` で #pin の親を #app（ページ全体）にした。説明の吹き出しは `tip.offsetParent` を基準に。
- `.grp{display:flex}` が `hidden` 属性に勝って行が消えない → `#controls .grp[hidden]{display:none}`。
- 暗順応を入れたら、案内9段目（晴れ→夜道でひとみが開く）は「暗くて見えない」になる（正しい）→ 案内の文をそれに合わせた。

## 確認のしかた（変更のたびに）
1. `powershell -NoProfile -ExecutionPolicy Bypass -File _dev/tools/smoke.ps1 -Apps eye-optics`（例外・読み込みの失敗・外への通信）
2. 開いて `__eyopErr` が空。最初の画面: 3 m・25歳・ふつうで「くっきり見える」、ぼけ 4 µm ほど、調節 0.2 D ほど。
