## ねらい
- **海の波は、風が少しずつ育てたもの**。風が吹いた時間（と距離）で、波は高く・長く・速くなる。それを研究の式（観測から作られた成長の式）で計算し、ひとつの海で見せる。
- **波は形だけが進む**。波は遠くまで進むのに、浮かべたブイや葉っぱはほとんどその場で回るだけ。寄ると、水の粒が円をえがき、深くなるほど小さくなるのが見える。
- 「きれいな海」で終わらせない: 見えている海が全部、風速・時間と式から出ていることを、数字とグラフでいつでも確かめられる。

## 形（2026-10-20 ユーザーに確かめた）
- **見る人の手**:
  - 風の速さを決める（いつでも変えられる。0〜25 m/s）。
  - 海をタップしてものを浮かべる（ブイ・葉っぱ・ボトル。いくつでも、好きな場所に）。浮かべたものは、その場の水の動きのとおりに上下・前後する。
  - 浮かべたものをタップすると、そこへ寄る（海 → 波1つの断面 → 水の粒の円）。
  - **カメラを回す**（2026-10-20 ユーザー「カメラも回せるようにしたい」）: ドラッグで海のまわりを回る・見下ろす角度、ホイール／2本指で近づく・はなれる。カメラは波の中に入らない（波の高さに合わせて持ち上げる）。
- **時間の見せ方**: タイムスライダー1本 =「風が吹きはじめてからの時間」（5分〜72 時間。風速 20 m/s で発達しきるのに約70時間かかるため72時間に。はじめの数時間が見やすいよう目盛りは平方根）。▶ で進む（速さ: 1秒で1分／10分／1時間）。どの時間でも、波そのものはふつうの速さで動き続ける（スライダーは「海の育ち具合」、画面の波は「いまの1秒」）。
- **案内**: 図の上の「つぎへ」1つで6段くらい（1段＝見るもの1つ・光る枠・図の下に1〜2行）。例: ①凪の海 → ②風が吹くとさざ波 → ③何時間かで波が長く・高く → ④グラフの山が長い波の側へ → ⑤ブイを浮かべる → ⑥寄ると水が回っている。
- **スマホ**: 海と、ひとこと・いまの数字（波の高さ・周期・波長）は上に固定。スペクトルのグラフ・つまみ・くわしくは下へスクロール（375px で確認）。

## 段階A（風が波を育てる）— 2026-10-20 v002-stageA でできた
1. 海の計算 `js/ocean.js`（試作4の FFT 海を分けて写す）: 3枚の海面（640 m・80 m・10 m）、深い海の分散 ω² = gk、波の分布 JONSWAP＋向きの広がり Mitsuyasu。
2. 成長の計算 `js/growth.js`（CEM の式。2026-10-20 本文で確かめた）:
   - 摩擦速度 u* = √C_D・U10、C_D = 0.001(1.1 + 0.035 U10)
   - 時間 → 同じ育ち方をする吹送距離 gX/u*² = 5.23×10⁻³ (gt/u*)^{3/2}（II-2-38）
   - gHm0/u*² = 4.13×10⁻² (gX/u*²)^{1/2}、gTp/u* = 0.651 (gX/u*²)^{1/3}（II-2-36）
   - 発達しきった海: gHm0/u*² = 211.5、gTp/u* = 239.8（II-2-37）で止まる
   - 分布の形は JONSWAP（γ 3.3）を Hm0 と Tp に合わせる。向きの広がりは cos^{2s}(θ/2)、s = s_max (f/fp)^5（山より低い周波数）／s_max (f/fp)^{-2.5}（高い周波数）、s_max = 10（風の波。Goda & Suzuki 1975）
   - **風速を途中で変える**: 風の記録（いつから何 m/s）をタイムラインに残す。区間ごとに「いまの波の高さになるには、新しい風で何時間吹けばよいか」（同じ高さの時間）に置きかえて続きを計算する（SPM・CEM のふつうのやり方）。風を弱めても、この版では波は小さくならない（本当はゆっくりうねりになって出ていく。段階C）。
3. 画面: 海（上に固定）、タイムスライダー、風速、いまの数字（有義波高・ピーク周期・波長・波の速さ）、スペクトルのグラフ（いまの山と、発達しきった海の山を点線で）、案内、「このアプリについて」（出どころ・推定・簡単にしたところ）。
4. 検証 `tools/verify.js`: CEM の値・時間の逆算・分布の面積（すべて OK）。
5. 照り返しのにじみ: Cox & Munk (1954) の海面の傾き σ² = 0.003 + 5.12×10⁻³ U から、描いている波の分を引いた残り（2026-10-20 足した）。

## 段階B（水は進まない）— 2026-10-20 v004-stageB でできた（流される分は Kenyon 1969 の式で足した。断面は別の1列の波）
1. 浮かべるもの `js/floats.js`: タップした場所の水の粒の動き（海面の横と上下の変位）を、GPU の結果から読んで動かす。ゆっくり前へ流される分（ストークスドリフト）を足すかは、式を確かめてから。
2. 寄る（意味のあるズーム）: 海 → 波1つの横断面（ブイの真下の水の柱）→ 水の粒の円。深くなるほど円が小さくなる（線形の波で e^{kz}）。波長の半分の深さでほとんど動かない。
3. 断面では、水の粒に色をつけて追える（1つの粒だけ光らせて円を見せる）。

## 段階C以降（案）
- **地球全体から寄る**（2026-10-20 ユーザー「他のアプリも参考に、地球全体が見える規模から自由に拡大して見れるようにしたい」）: 神の視点マップ（god-view）・ちいさな地球（tiny-earth）のように、地球 → 大洋 → 嵐の下の海 → 足元の波まで、ひと続きに寄る。大きいときは「どこで風が吹き、どこへうねりが出ていくか」、寄ると今の FFT の海。別の段階（D）として、作る前に形をユーザーと決める。
- **津波**（2026-10-20 ユーザー「津波のシミュレーションとかね（これはセンシティブなので慎重に考える）」）: 風の波と津波のちがい（波長・深さで決まる速さ √(gh)・海の底まで動く）を計算で見せる。**作る前に必ずユーザーと話す**。考えておくこと:

  - 「どれだけ危ないか」をまちがえて小さく見せない（数十 cm でも人は立てない、などは確かな出どころだけ）。避難の判断に使わないことを画面に書き、気象庁などの公式の情報へリンク。
  - 震源の動き・海底の地形のデータの出どころとライセンス（商用不可のものは使わない）。
- 風がやんだあと: 風の波が「うねり」になって遠くへ出ていく（長い波ほど先に。遠くの嵐から届くうねりの順番＝案3 の話につながる）。
- 風力階級（ビューフォート）の表と並べる。
- 浅い海へ来ると波が高くなって砕ける。
- 英語対応（入口へ移すとき）。

## 段階C（2026-10-21 ユーザー「Cから進めて」。形はユーザーが選んだ）
1. 風力階級: 数字の横に「風力 N・海のようす」、たたむ欄に気象庁の表と計算の波の高さ — v007-beaufort でできた。
2. 浅い海で砕ける: 紺の線の断面で、いまの海の波（高さ・周期）が遠浅の浜へ進む。浅くなると遅く・短く・高くなり（線形の波のエネルギーの流れ）、水深の約 0.8 倍の高さで砕ける。浜の坂の急さを変えられる。
3. うねり: 新しい場面「遠くの嵐から届く」。何千 km 先の嵐で育った波が、日にちのスライダーで届く。長い波ほど先に着き、周期がだんだん短くなる（波の道すじ＝群速度で、分布は道すじにそって保たれる）。距離・嵐の強さを変えられる。海は今の 3D、別に紺の線の地図。

## 簡単にするところ（画面にも書く）
- 深い海だけ（底の影響なし）。風は一様でずっと同じ向き。
- 波どうしのやりとり・砕ける波のエネルギーの抜け方は計算せず、成長の式（観測の当てはめ）で分布を決める。
- 泡は「波の面が横に押しつぶされた所」の目安（推定のしきい値）。
- 空の色は1回散乱だけ。水平線近くの空は 2° の空で代用（試作4と同じ）。
