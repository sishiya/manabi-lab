## しくみ

### 場所（`world.js`）
- z（m）: + が空、− が海の深さ。z = 0 は海面（地上）。魚だけは z = 0 を水の中として扱う（絵も海の中）。
- 空: U.S. Standard Atmosphere 1976 の層の式（86km まで）。86km より上は表（100km 3.2e-2 Pa … 400km 1.45e-6 Pa）を対数で補間。86km より上は気温を出さない。エベレスト山頂の実測（33.7kPa）は標準大気（31.4kPa）より高いことを人の説明に書いた。
- 海の圧力: Saunders (1981) の深さ→圧力の式（z = (1−c1)p − c2p²、緯度 11.35°N）を逆に解く。水深10m で 1.99 気圧、1,000m で 100.5、海溝の底で約1,113気圧。v1 の「密度一定」（約1,084気圧）から直した。
- 水温はマリアナ海溝の近くの外洋の目安（表面27℃、1,000m 4℃、底 2.4℃）。明るさ exp(−0.023×深さ)（200m で 1%）。
- 吸う空気の酸素分圧 = 0.2095 ×（気圧 − 体温の水蒸気 6.27kPa）。海面で 19.9kPa。
- 水が沸く温度: Wagner–Pruss の飽和蒸気圧の式を二分法で逆に解く。611.657Pa（三重点）未満は「液体でいられない」、22.064MPa（臨界圧、約2,200m）以上は「沸かない（超臨界）」。
- ものさしの縮尺 `AXIS`: 400→100km、100→20km、20→0km、0→300m（√で広げる）、300→10,920m の5区間。

### モノのモデル（`things.js`）
- 閉じこめた気体の体積 = (1/気圧) × (T/288.15K) × Z(気圧)。Z は 0℃の窒素の測定値（1,000気圧で約1.94）。宇宙では 15℃ のまま。
- 人（そのまま）: 空は SpO2 の目安・意識を保てる時間（FAA AC 61-107B の表。45,000ft 9〜15秒、50,000ft 6〜9秒まで）・高山病の段階。体温37℃の水が沸く高さ（約19km）より上と宇宙は「約10秒（資料により6〜15秒）」。海は素潜り（肺 6L がボイルの法則で縮む。残気量 1.5L より小さいと `squeeze` で胸が押しこまれる絵。214m の記録）。体全体にかかる力（1.8m²）も書く。
- 人（空気ボンベ）: 空は酸素100%のマスク（`altForPO2()` で空気なら何mと同じか）。海はスクーバの空気（酸素分圧 1.4・1.6 気圧、窒素酔い 30m〜、90m より深いと「きわめて危険」）。服は高さ・気温でダウン、海ではウェットスーツ。
- 風船: 体積 2.8 倍で割れる（推定。約9,600m）。体積 0.04 より小さいと、ゴムがたるんでしわの中に空気の玉が残る絵（海溝の底で中の空気は直径 3.0cm）。
- 空のペットボトル（500mL・ふたをした）: 水の中では中の空気の体積までへこむ（下限 5%）。水深10m で 261mL、海溝の底で 0.89mL。戻すと形は戻り、折れじわ `crease` が残る。空・宇宙では中の1気圧が押すだけ。
- ピンポン球: 中と外の差が 3.5 気圧（水深約36m）でへこむ（推定。うすい殻の座屈の計算 約13気圧に、形のゆがみで弱くなる分を見こんだ）。へこんだ後は中の空気の体積まで（下限 0.03）、戻しても 0.82 のまま。
- 発泡スチロールのカップ: 体積の 95% が泡、6気圧（約50m）より深いと泡の空気が押し縮められる。戻したあとの大きさ = いちばん縮んだ大きさ^0.8（海溝の底 3.8cm → 戻して 4.6cm）。
- ポテトチップスの袋: 窒素、袋の最大は 1.6 倍。中と外の差が 0.25 気圧で口が開く（推定。約11,100m）。水の中でしぼむとチップスの形が浮き出る絵。
- マシュマロ: 泡 6割、泡が 3 倍で破れる（約10,100m）。破れた後は戻すと 0.55 倍のしわしわ。
- コップの水（20℃）: 気圧が 2.3kPa より低い（約26km より上）と沸く。三重点より低いと凍る。海では Tait の式で縮む（海溝の底で約4%）。
- 魚: すむ深さ `range`。うきぶくろのある魚は、範囲の端の圧力 ÷ いまの圧力 でふくらみ、4倍以上で「胃が口から」。アコウダイは目も飛び出す（`eyes`）。8,200m より深いと TMAO の限界の説で「すめない」。陸・宇宙では息ができない。クロマグロは 0〜550m（大西洋の仲間は 1,000m 超えの記録）、アコウダイ 300〜600m、シンカイクサウオ 6,000〜8,100m。
- クマムシ（乾眠）: どこでも平気（宇宙10日・約6,000気圧の記録）。
- `mem`: いちばん高い・深い所、割れた場所 `burstZ`・`popZ`・`buckleZ`、カップの `cupMin`、ボトルの `crease`、水の `boiled`。モノを選び直す・「新しいものにとりかえる」と消え、地上から今の場所まで運び直す（途中で割れるものは割れる）。

### 絵（`draw.js`）
- モノは実寸（m）で描く。`objFrame()` で `pm = 2R / ref`（R は画面の大きさから）。右下のスケールは 1・2・5 の切りのよい長さ。人・カップなどは足もと、魚とクマムシは中央が原点。
- 海の中の色: 水が光を吸う強さ `KW` = 赤 0.40・緑 0.07・青 0.025 /m（澄んだ外洋の目安）。モノの色には、上から届く深さ d と見ている距離 1.5m の分の吸収を、いちばん残る色を1にして 0.35 乗（目の慣れ）したものをかける。明るさは青の届き方の 0.4 乗。150〜260m で潜水艇のライトに切りかえ（ライトは見る距離 1.5m の吸収だけ）。
- 空: 天頂と地平線の色の表 `SKY_TAB`。地平線の見下ろす角度 `acos(R/(R+h))` から丸みを出す。9km より上は地球（海と雲）と大気のうすい層。星は 60km より上で少しだけ（写真では日なたの地球と星はふつう同時に写らないため控えめ）。
- 点滅は入れない（生き物の光は小さな点がゆっくり明るくなって消える、泡は小さく流れるだけ）。

## ハマったところ
- 移動を1コマ分まとめてモデルに渡すと、ドラッグで一気に宇宙へ行ったとき「割れた場所 400km」になる。`passThrough()` でものさしの 0.0005 刻みに途中を通す（割れた場所は 100m 単位の「約」で表示）。
- Browser ペインが裏だと rAF が止まり、`innerWidth` が 0 になる。画面の大きさが小さすぎると `arcTo` に負の半径が入って止まった（`rr()` で 0 以上にした）。確かめるときは `resize_window` で大きさを決める。
- sed で JS を書きかえたら改行が消えて、コメントの後ろにコードがつながった（RULES 6 のとおり、複数行は Edit で）。
- 海の色を物理どおり（目の慣れなし）にすると、水深5m で赤い魚が真っ青になって不自然だった。0.35 乗の慣れを入れた。

1. 読み込み直後にエラーなし（`__ex.err` が undefined）。開いたときは風船・海面。
2. 全部のモノを順に運ぶ: `for (const k of THINGS.map(t=>t.key)) { __ex.setThing(k); for (const z of [0,3776,8849,19500,400000,0,-10,-40,-214,-1000,-10920,0]) __ex.go(z,true); }` → `__ex.err` が undefined。
3. 目安（変えていなければ）: 風船は約9,600m で割れ、エベレストで体積 2.58 倍、海溝の底で中の空気の玉 3.0cm。ペットボトルは水深10m で 261mL、海溝の底で 0.89mL、戻すと「形が戻った（しわは残る）」。ピンポン球は 30m で「今にもへこみそう」、約36m でへこみ、戻して 0.82。カップは海溝の底で 3.8cm、戻して 4.6cm。素潜り 300m で肺 0.19L。アコウダイは海面でうきぶくろ 30.8 倍。`envAt(-10920).atm` ≈ 1113、`envAt(-10).atm` ≈ 1.99。
4. 見た目（`resize_window` 1280×760 で）: 水深5m で赤い魚が茶色がかって見え、250m より深い所は黒い背景にライト。宇宙（400km）で地球の丸みと大気の層。エベレストで雪の頂上と雲海。
5. ものさしの目印の名前を押すとそこへ運ぶ（`__ex.S.zTarget` が変わる）。帯のドラッグ・下のスライダーでも動く。「押す力の矢印」で矢印が消える。
6. 幅 375px（縦長）で絵が上に貼りつき、スライダーが1行、横スクロールなし（scrollWidth = 375）。素潜りの肺の小窓と光の注記が場所の文字に重ならない。
7. 点滅なし。
8. 入口に載せる変更をしたら、doctype なし（互換モード）と doctype あり（標準モード）で全要素の位置を比べる。
