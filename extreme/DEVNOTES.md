# 極限の世界に置いてみたら 開発メモ

最終更新: 2026-10-06

宇宙（400km）からマリアナ海溝の底（10,920m）までを1本のものさしにして、モノ・生き物を運び、どうなるかを見るアプリ。企画は `PLAN.md`（`../IDEAS.md` のストック2から）。Canvas 2D、css/js に分割。

## 別セッションで続けるとき（まずここ）
- **いまの状態**: 最新は v1（`versions/v001-first`、段階A）。入口「まなびラボ」の「物理」に載せた（サムネイル `thumbs/extreme.jpg`）。GitHub Pages には push で公開される（push はユーザー）。Artifact には公開していない。
- **次にやること**: ユーザーの感想しだい。次の段階は `PLAN.md` の段階B（時間をかけて置く: 減圧症・高所順応、砂漠と寒さ、宇宙に長くいるとき）。
- **読む順**: `../RULES.md` → このファイル → 下の「ファイル構成」で関係するファイルだけ。モノを足す・直すなら `js/things.js` だけ（絵は `js/draw.js` の `drawThing()` の表に足す）。
- **動かし方**: ユーザーはルートの `start.bat`。Claude は `.claude/launch.json` の `apps`〜`apps-4`（8765〜8768）のどれか空いているもので `http://localhost:<port>/extreme/`。
- **デバッグ用**: `window.__ex` — `S`（`z` いまの高さ m、`zTarget`、`key`、`mem` モノの記憶）、`setThing(key)`、`go(z, true)`（一気に運ぶ。途中も通す）、`goTo(z)` と `advance(秒)`（Browser ペインが裏だと rAF が止まるので、これで進める）、`state()`、`envAt(z)`、`err`（例外。`window.__exErr`）。
- **区切りごとに**: ① `versions/v0NN-名前/` に index.html・css・js を丸ごとコピー ② `launcher.html` にカード・表 ③ 下の「状態」 ④ 「確認のしかた」を通す ⑤ 公開前チェック → コミット（push はユーザー）。中身を変えたら入口 `../index.html` のカードの更新日も。
- **ユーザーの好み**: 正確さ重視（記録／計算／推定を書き分ける）。ちょっと危ない・意外なモノが選べると楽しい。子どもにも読める日本語。

## しくみ

### 場所（`world.js`）
- z（m）: + が空、− が海の深さ。z = 0 は海面（地上）。魚だけは z = 0 を水の中として扱う。
- 空: U.S. Standard Atmosphere 1976 の層の式（86km まで）。86km より上は表（100km 3.2e-2 Pa … 400km 1.45e-6 Pa）を対数で補間。86km より上は気温を出さない。
- 海: P = 101325 + 1025×9.80×深さ（密度一定。海溝の底で約1,084気圧、実測の約1,086 bar に近い）。水温はマリアナ海溝の近くの外洋の目安（表面27℃、1,000m 4℃、底 2.4℃）。明るさ exp(−0.023×深さ)（200m で 1%）。
- 吸う空気の酸素分圧 = 0.2095 ×（気圧 − 体温の水蒸気 6.27kPa）。海面で 19.9kPa。
- 水が沸く温度: Wagner–Pruss の飽和蒸気圧の式を二分法で逆に解く。611.657Pa（三重点）未満は「液体でいられない」、22.064MPa（臨界圧、約2,200m）以上は「沸かない」。
- ものさしの縮尺 `AXIS`: 400→100km、100→20km、20→0km、0→300m（√で広げる）、300→10,920m の5区間。

### モノのモデル（`things.js`）
- 閉じこめた気体の体積 = (1/気圧) × (T/288.15K) × Z(気圧)。Z は 0℃の窒素の測定値（1,000気圧で約1.94）。宇宙では 15℃ のまま。
- 人（そのまま）: 空は SpO2 の目安・意識を保てる時間（FAA の表）・高山病の段階。気圧で体温37℃の水が沸く高さ（アームストロング限界、約19km）より上と宇宙は「約9〜12秒で意識を失う」。海は素潜り（肺 6L がボイルの法則で縮む。214m の記録）。
- 人（空気ボンベ）: 空は酸素100%のマスク（`altForPO2()` で空気なら何mと同じか）。海はスクーバの空気（酸素分圧 1.4・1.6 気圧、窒素酔い 30m〜、空気の限界 90m）。
- 風船: 体積 2.8 倍で割れる（推定。約9,600m）。体積が 0.33³ より小さいとゴムがたるんだ絵。
- 発泡スチロールのカップ: 体積の 95% が泡、6気圧（約50m）より深いと泡の空気が押し縮められる。戻したあとの大きさ = いちばん縮んだ大きさ^0.8（実例の「半分くらい」に合わせた推定）。
- ポテトチップスの袋: 窒素、袋の最大は 1.6 倍。中と外の差が 0.25 気圧で破れる（推定。約11,100m。エベレストでは「今にも破れそう」）。
- マシュマロ: 泡 6割、泡が 3 倍で破れる（約10,100m）。破れた後は戻すと 0.55 倍のしわしわ。
- コップの水（20℃）: 気圧が 20℃の蒸気圧 2.3kPa より低い（約25km より上）と沸く。三重点より低いと凍る。海では Tait の式で縮む（海溝の底で約4%）。
- 魚: すむ深さ `range`。うきぶくろのある魚は、範囲の端の圧力 ÷ いまの圧力 でふくらみ、4倍以上で「胃が口から」。8,200m より深いと TMAO の限界の説で「すめない」。陸・宇宙では息ができない。
- クマムシ（乾眠）: どこでも平気（宇宙10日・6,000気圧の記録）。
- `mem`: いちばん高い・深い所、割れた場所 `burstZ`・`popZ`、カップの `cupMin`、水の `boiled`。モノを選び直す・「新しいものにとりかえる」と消え、地上から今の場所まで運び直す（途中で割れるものは割れる）。

## ハマったところ
- 移動を1コマ分まとめてモデルに渡すと、ドラッグで一気に宇宙へ行ったとき「割れた場所 400km」になる。`passThrough()` でものさしの 0.0005 刻みに途中を通す（割れた場所は 100m 単位の「約」で表示）。
- Browser ペインが裏だと rAF が止まる。確認は `__ex.go()` と `__ex.advance()`。

## 確認のしかた（変更のたびに）
1. 読み込み直後にエラーなし（`__ex.err` が undefined）。開いたときは風船・海面。
2. 全部のモノを順に運ぶ: `for (const k of THINGS.map(t=>t.key)) { __ex.setThing(k); for (const z of [0,3776,8849,19500,400000,0,-10,-40,-214,-1000,-10920,0]) { const r=__ex.go(z,true); console.log(k,z,r.st.lvl,r.st.verdict); } }` → エラーなし。
3. 目安（変えていなければ）: 風船は約9,600m で割れ、エベレストで体積 2.58 倍。袋は約11,100m で破れる。マシュマロは約10,100m で泡が破れ、地上で 0.55 倍。カップは海溝の底で 3.8cm、地上に戻して 4.6cm。人（そのまま）は富士山で酸素 60%・SpO2 86%、エベレストで 26%。キンメダイは水深10m でうきぶくろ 10.5 倍。水は富士山で 87℃、エベレストで 70℃ で沸く。
4. ものさしの目印の名前を押すとそこへ運ぶ（`__ex.S.zTarget` が変わる）。帯のドラッグ・下のスライダーでも動く。
5. 幅 375px（縦長）で絵が上に貼りつき、横スクロールなし（scrollWidth = 375）。
6. 点滅なし（生き物の光は小さな点がゆっくり明るくなって消えるだけ。水の泡も小さい）。
7. 入口に載せる変更をしたら、doctype なし（互換モード）と doctype あり（標準モード）で全要素の位置を比べる。
