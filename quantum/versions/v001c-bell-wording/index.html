実験 1 · 波と粒子

二重スリット

粒子を1個ずつ、2本のすき間（スリット）に向けて飛ばす。1個ずつ点で当たるのに、たくさん集めるとしま模様ができる。どちらを通ったか調べると、しま模様は消える。

装置を横から見たところ。青い明暗は「粒子が見つかる確率」の広がり。
上: スクリーンを正面から見たところ（1点＝粒子1個）。下: 当たった数のグラフ。当たった数 0

装置

スリット
干渉あり干渉なし（2本を足しただけ）

やってみよう

  1. そのまま待つ。点はばらばらに当たるが、数百個たまるとしま模様が見えてくる。急ぐなら「1000個まとめて」。
  2. 「通り道を調べる」をオンにする。スクリーンが消えて、今度はしまのない2つの山になる。
  3. スリットを片方だけにする。しまは出ない。2本あいていて、しかも通り道が分からないときだけ、しまが出る。
  4. 波長を長くする、間隔をせまくする。しまの間隔が広がる。

なにが起きている？

粒子がどこで見つかるかは、波（確率の波）で決まる。この波は2本のスリットを同時に通り、向こう側で重なる。山と山が重なる所には当たりやすく、山と谷が打ち消し合う所にはほとんど当たらない。

検出器でどちらを通ったか確かめると、波は片方のスリットから出たものだけになり、打ち消し合いが起きない。見るだけで結果が変わる。

それでも当たるときはいつも1点。波のように広がり、粒のように見つかる。これが量子のいちばん基本の性質。

電子を1個ずつ飛ばして、しまが育っていく様子を撮影した実験がある（1989年、日立製作所の外村彰らのグループ）。

測るまでは「手前にいる」と「向こうにいる」が重なった状態。測った瞬間に、どちらか一方に決まる。

身近な例: 太陽の中で水素がくっつく核融合、USBメモリの書き込み、原子を1個ずつ見る走査トンネル顕微鏡、ウランなどのα崩壊。

実験 3 · 測ると状態が変わる

3枚の偏光板

向きを直角にした2枚の偏光板は、光をまったく通さない。ところがその間に、斜めの偏光板をもう1枚入れると、光が通るようになる。じゃまを増やしたのに通る。

やってみよう

  1. A と C が直交（0° と 90°）。届く光子は 0。
  2. B を入れる（45°）。届くようになる。理論では 1/8 = 12.5%。
  3. B を 0° や 90° にすると、また 0 になる。
  4. A だけにすると 50%。最初の光の偏光はばらばらなので、半分が通る。

なにが起きている？

光子1個が偏光板を通るかどうかは確率で決まる。偏光の向きと板の向きの差が θ なら、通る確率は cos²θ。光子は割れないので、通るか消えるかのどちらか。

大事なのは、通り抜けた光子の偏光が板の向きに作り直されること。45° の板を通った光子は、もう 0° の記憶をもっていない。だから 90° の板も半分の確率で通れる。1/2 × 1/2 × 1/2 = 1/8。

偏光板を通すことは、偏光の「測定」にあたる。測ると状態が変わる、という量子の性質がそのまま見える。

やってみよう

  1. 2人の角度を同じにする。結果は毎回そろう。でも＋か−かは毎回ばらばら。
  2. 角度の差を 22.5°、45°、67.5°、90° と変えて、グラフに点を集める。
  3. しくみを「隠れた変数」にして同じことをする。差 0° と 45° と 90° では量子と同じ割合になるが、その間では青い線から外れる。
  4. ベルテストを実行。S が 2 を超えるかどうかで、2つのしくみを見分けられる。

なにが起きている？

もつれた2個の光子は、それぞれの偏光が決まっていない。アリスが測った瞬間に、ボブの光子の状態もそれに合わせて決まる。角度の差が θ なら、結果がそろう確率は cos²θ。

「生まれたときに、どの角度ならどう答えるかを決めて持っていく」仕組みでも、角度が同じなら必ずそろう。違いが出るのは角度をずらしたとき。このアプリの「隠れた変数」はその仕組みの一例で、そろい方は直線になる。決め方を工夫すれば別の形にもできるが、どう工夫しても量子の曲線を全部は再現できないことが証明されている。ベルの不等式（S ≤ 2）は、その限界を1つの数字で表したもの。

ただし、アリスの結果だけを見るといつも半々でランダム。ボブの角度を変えてもアリスの側は何も変わらないので、もつれを使って光より速く合図を送ることはできない。

実際の実験で S ＞ 2 を確かめたアスペ、クラウザー、ツァイリンガーは 2022年のノーベル物理学賞を受けた。

実験 5 · 両方は決まらない

不確定性原理

粒子の位置をきっちり決めるほど、運動量（どちら向きにどれだけの勢いで進むか）がぼやける。逆も同じ。測り方が下手だからではなく、波であることから来る性質。

白い線が ħ/2。どう動かしても、この線より左には行けない。

波の形

やってみよう

  1. 「位置の広がり」を小さくする。左はとがるが、右の運動量は横に広がる。
  2. 逆に大きくする。右がとがり、左が広がる。かけ算 Δx·Δp は 0.5 のまま。
  3. 「形のくずれ」を上げる。かけ算は 0.5 より大きくなる。小さくする方向には動かせない。
  4. 「位置を測る」。位置は1点に決まり、その代わり運動量の分布が一気に広がる。続けて「運動量を測る」と、今度は位置が広がる。

なにが起きている？

運動量は波の細かさ（波長）で決まる。1か所にぎゅっと集まった波を作るには、いろいろな波長の波をたくさん重ねる必要がある。だから位置をしぼるほど、運動量はいろいろな値が混ざる。

1種類の波長だけの波は、どこまでも同じ形で続く。運動量はきっちり決まるが、位置はまったく決まらない。

この関係は Δx·Δp ≥ ħ/2（ħ はプランク定数を 2π で割ったもの）。この画面では ħ = 1 の単位で描いている。

二重スリットでスリットを細くすると、通り抜けた後の広がりが大きくなるのも同じ理由。

計算はすべてこのページの中で行っている。数値は ħ = 1、質量 = 1 の単位。
