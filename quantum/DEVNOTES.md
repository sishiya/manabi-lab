## 実験ごとのしくみ

| タブ | 計算 |
|---|---|
| 二重スリット | スリット幅 a（初期 1.5、0.8〜6）を24点のホイヘンス波源に分け、距離 L=60 のスクリーン上の複素振幅を足す。検出器なし＝|ψ1+ψ2|²、あり＝|ψ1|²+|ψ2|²（どちらのスリットかを先に選ぶ）。確率の波の絵は 150×100 の格子で同じ計算（列ごとに正規化）。当たった点はオフスクリーンの canvas に足していく。 |
| トンネル効果 | 1次元シュレーディンガー方程式を Visscher 法（実部・虚部を交互に更新）で解く。N=2000、dx=0.25、dt=0.02、1フレーム80ステップ。両端40単位は吸収層で、吸収した確率は左右別に足して割合に含める。壁の端のマスは重なった分の高さにする（これをしないと薄い壁で理論値から大きくずれた）。t>420 で自動停止。 |
| 3枚の偏光板 | 光子ごとに偏光角をランダムに持たせ、板で cos²θ の確率で通過し、通ったら板の角度に置き換える。 |
| 量子もつれ | 量子: アリスは半々、ボブは確率 cos²(a−b) で一致。隠れた変数: 角度 λ を共有し、各自 sign(cos 2(角度−λ))。CHSH は (0,22.5)(0,67.5)(45,22.5)(45,67.5) で S = E1 − E2 + E3 + E4（各2万組、誤差は √Σ(1−E²)/N）。 |
| 不確定性原理 | ガウス波束（チャープ c つき）を解析式で描く。Δp = √(1+c²)/(2σ)。測定で位置なら σ→0.3、運動量なら σ→3.2 へなめらかに移る。 |

## 確認のしかた（変更のたびに）

コンソールエラーがなく（`__qx.err` が空）、次の値になること。ペインが非表示でも step を直接呼べば確かめられる。

```js
const E=__qx.EXPS.tunnel; E.T.E=0.6; E.T.w=1.25; E.fireNew();
while(E.T.running) E.step();  E.parts()   // 通り抜け ≈ 0.338（理論 34.0%）
```

- トンネル: (E, 厚さ) = (0.6, 3) → 約1.9%（理論1.8%）、(1.2, 1.25) → 約64%（理論65.5%）、(0.4, 0.75) → 約53%（理論53.3%）。
- 偏光板: 0°・45°・90° の3枚で約12.5%。
- ベルテスト: 量子 S ≈ 2.83、隠れた変数 S ≈ 2.0。
- 不確定性: どの設定でも Δx·Δp ≥ 0.500。
- 英語（`?lang=en`）: `../I18N.md` 2.4 のコンソールで5つのタブ（測る・ベルテスト・1000個まとめても）を通し、画面とキャンバスに日本語が残っていない。上の値は日本語のときと同じ。右上の JP／EN で読み直せる（タブは `#` と `qlab-tab` で保たれる）。
