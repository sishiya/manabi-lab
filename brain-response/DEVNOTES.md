# 刺激が脳に届くまで 開発メモ

最終更新: 2026-10-08

目・耳・皮膚に刺激があると、脳のどこが・何ミリ秒後に反応するかを、研究で測られた時刻と場所に合わせて再生するアプリ。ヒト・サル（マカク）・ラットを切り替えられる。病気・特性は、ヒトで違いが測られたものだけ。企画は `PLAN.md`（ユーザーの依頼と、確かめた出どころの一覧）。Canvas 2D、ライブラリなし。

## 別セッションで続けるとき（まずここ）
- **いまの状態**: v1（`versions/v001-first`。段階A）。入口・アーカイブにはまだ載せていない（ユーザーが決める）。Artifact にも公開していない。
- **次にやること**: ユーザーの感想しだい。段階B（におい・味、刺激の強さ、MMN）は `PLAN.md`。入口かアーカイブに載せるなら RULES 8.1（ファビコンはあり、GA の1行・サムネイル・互換モードの確認が必要）。
- **読む順**: `../RULES.md` → このファイル → 下の「ファイル構成」で関係するファイルだけ。
- **動かし方**: `.claude/launch.json` の空いているサーバーで `http://localhost:<port>/brain-response/`（2026-10-08 は `apps-5`＝8769 を使った）。
- **デバッグ用**: `window.__br` — `S`（状態）、`fire(autoplay?)`（いまの種・刺激・場所・病気で作り直す）、`step(秒)`（Browser ペインが裏で rAF が止まっていても進める）、`seek(ms)`（その時刻の絵にする）、`set({sp, stim, cond})`、`render()`。例外は `window.__brErr`。全部の組み合わせを回す確かめ方は下の「確認のしかた」1。
- **区切りごとに**: ① `versions/v0NN-名前/` に index.html・css・js を丸ごとコピー ② `launcher.html` にカード・表 ③ 下の「状態」 ④ 「確認のしかた」を通す ⑤ 公開前チェック → コミット（push はユーザー）。
- **ユーザーの好み**: **想像で埋めない**（「想像によるところが多いのであれば無しでいい」）。確かめた数値だけ。測られていないものは「データなし」と書いて作らない。正確さ重視で、出どころを画面に。
- **新しい数値を足すとき**: PubMed の要旨（E-utilities: `https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=pubmed&id=<PMID>&rettype=abstract&retmode=text`）か、Europe PMC の本文（`https://www.ebi.ac.uk/europepmc/webservices/rest/<PMCID>/fullTextXML`）で数値を確かめてから。出版社のページ（journals.physiology.org など）は 403 で読めないことが多い。確かめたら `SRC` と `PLAN.md` の出どころに足す。

## しくみ

### 1. 駅（station）
1回の刺激は「駅」の並び。駅 = { 部位 `reg`（なければ体の外の通り道 `way`）, 左右 `side`, 時刻 `t`（範囲なら `t1`〜`t2`）, 根拠 `ev`, 出どころ `src`, 強さ `gain`（負は「下がる」＝青）, どこから来たか `from`, 地図の位置 `hot` }。両側に届くものは `both()` で L・R の2つを作る（id の最後が L/R）。
- 根拠: **measured** 論文の数値／**range** 論文の範囲／**order** 順番だけ確か（時刻は前後のあいだに置いた）／**place** 場所だけ（時刻なし。再生では道すじの順に光らせる）。画面の印と、時間の帯の線の形（実線・帯・長い点線・短い点線＋「?」）で区別。
- 病気・特性で変わった駅は `cond: true`（ピンク）。典型は `S.base` として同じ場所・刺激で作り、時間の帯に点線の縦線、波のグラフに点線で重ねる。

### 2. 時間
- 横軸は `tAxis(t) = log(1 + t/TAU) / log(1 + tmax/TAU)`。`TAU` は最初の駅の時刻 × 0.8（1〜40 ms）。`tmax` は最後の時刻 × 1.35（150 ms 以上）。
- 再生は横軸の上を一定の速さで進む（ゆっくり 7 秒、とてもゆっくり 16 秒）。つまり最初の数ミリ秒はとても引きのばされる。
- 光り方 `activation`: 駅の時刻から立ち上がり（横軸で 0.045 で最大）、その後 0.3 まで下がって残る（形は模式）。

### 3. 数値（すべて `model.js` の note と `PLAN.md` に出どころ）
| 種・刺激 | 駅と時刻 |
|---|---|
| ヒト・光 | V1 56 ms（Foxe & Simpson 2002 のはじまり）、前頭 80 ms。LGN・頭頂・腹側は順番だけ。波は N75・P100・N135（ISCEV） |
| ヒト・顔 | V1 56 → N170 172 ms（右 1、左 0.6。Bentin 1996） |
| ヒト・音 | I 1.49・III 3.66・V 5.59 ms（聴性脳幹反応）、一次聴覚野 30 ms、外側 50〜75 ms、M100 100 ms |
| ヒト・触る | 手首: N9・N13・P14・N20、足首: P40（Cruccu 2008 の名前の数字）。顔は場所だけ。点字は Sadato 1996（見える人は視覚野が下がる、目の見えない人は働く。時刻なし） |
| ヒト・熱い痛み | 弁蓋 150 ms より前、島・前帯状 200〜400 ms（N2–P2）、C 線維 806・1033 ms |
| ヒト・カチッ2回 | P50 を 50 ms と 550 ms。2回目の高さ 0.35（典型）／0.75（統合失調症）は**模式** |
| サル・光 | LGN-M 33、LGN-P 50（M+17）、V1 65、MT・FEF 73、V4 104 ms（Schmolesky 1998）。V2・V3 は順番だけ。顔パッチは場所だけ |
| サル・音・触る | 場所だけ |
| ラット・光 | LGN 25〜40、V1 30〜60 ms（Kara 1993） |
| ラット・ひげ | たる4層 8 ms（Brecht & Sakmann 2002）、2・3層は 2〜3 ms あと |
| ラット・音 | 扁桃体外側核 15 ms より速い（Quirk 1995）。ほかは順番だけ |

病気・特性: 多発性硬化症＝光・顔の目から先にスライダーの遅れ（0〜50 ms、はじめ 30。遅れの大きさは人によるので選ばせる）。自閉スペクトラム＝右の M100 +11 ms。線維筋痛症＝痛みの部位の強さ ×1.6（模式）。恐怖条件づけ（ラット）＝扁桃体の強さ 0.25 → 1（模式）。

### 4. 脳の図
- 半球ごとの座標 u（0 前〜1 後ろ）, v（0 上〜1 下）。左半球は画面の左で前が左、右半球は鏡写し（頭の後ろから見て本を開いた形）。後頭葉が真ん中で向かい合う。感覚器は下の真ん中（後ろから見た体）。
- 奥の部位（視床・島・扁桃体・内側の部位・下面）は点線の丸。大脳は半透明。
- 地図: V1 は視野の中心ほど後ろ（ヒトは後頭極、サルは月状溝のすぐ後ろ）、上の視野は下側。体の地図は `strip` の上（足）から下（顔）。ヒトの聴覚野は高い音で光る点が2つ（鏡写しの地図、低い音の境を共有）。ラットの聴覚野は高い音が前。

## ハマったところ
- 図を 1000 幅で描いて縮めて表示するので、文字が 6px くらいになった → 表示の幅から `VK` を出して、文字と札の大きさを掛ける。時間の帯と波のグラフは CSS の幅そのもので描く。
- 時間の帯が行の数だけ高くなり、脳の図が小さくなった → 左右で同じ部位は1行にまとめた（強い側を実線、弱い側をうすく）。
- 光った部位の札がすべて残ると重なって読めない → 立ち上がり〜山のあいだだけ札を出す。

## 確認のしかた（変更のたびに）
1. 開いて `__brErr` がないこと。コンソールで全部の組み合わせ（3種 × 6刺激 × 病気・特性 × 触る場所）を `fire(false)` → `S.p=0.8; render()` で回してエラーがないこと（2026-10-08 は 54 通り）。
2. ヒト・光: 左の視野をクリック → 両目から視交叉 → 右の脳だけ光る。中心と端で V1 の点が前後に動く。時間の帯で V1 56・前頭 80。
3. ヒト・音: 左耳 → 左の脳幹 → 両側。高い音で聴覚野の点が2つ。波で I・III・V・Pa・N1。
4. ヒト・触る: 手首で N20（20 ms）、足首で P40。点字＋「早くから目が見えない人」で視覚野がピンク、典型では青（下がる）。
5. 熱い痛み: 2回の波（0.2〜0.4 秒と 1 秒）。線維筋痛症で点線の典型と重なる。
6. サル・光で V1 65 → V4 104、ラット・ひげで 8 ms。ラットの顔・痛みはボタンが薄く、押すと理由が出る。
7. 病気・特性を選ぶと、合う刺激に切り替わり、典型が点線で重なる。多発性硬化症のスライダーで遅れが変わる。
8. スマホ（375×812）: 横にはみ出さない、種・刺激のボタンが1行ずつ、刺激の場所を押すと図までスクロール。

## 残っている課題
- サルの音・触覚の時刻、ラットの音・足の時刻は確かめていない（場所と順番だけ）。原典で確かめられたら `ev` を上げる。
- ヒトの LGN・腹側の流れなど「順番だけ」の駅は、脳の中の電極の研究（てんかんの手術前の記録など）で時刻を確かめられるかもしれない。
- 脳の形は手で描いた模式。ラットの脳は横から見た形がやや丸い。
