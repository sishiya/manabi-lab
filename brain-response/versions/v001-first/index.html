      しくみと本当の話

      反対側の脳が受け取る

      体の左側の感覚（左手・左足・左の視野）は、途中で交差して右の脳へ届きます。目は少し特別で、左右の目それぞれの「左の視野」の部分が右の脳へ行きます（視交叉で、鼻側の網膜からの線維だけが交差する）。音は脳幹で左右両方へ分かれます。痛みは、両側の弁蓋・島と前帯状皮質が受け取ります。

      脳の中の地図

      感覚の場所は、脳の中でも並び方を保っています。体の地図（中心溝のうしろ。足がいちばん上、手と顔は広い）、視野の地図（V1。視野の中心ほど後頭葉の後ろで、広い面積を使う）、音の高さの地図（聴覚野）。ラットでは、ひげ1本ごとに脳の「たる」が1つあります。

      なぜ時刻がちがうのか

      道の長さと、途中で乗りかえる細胞の数・電線（神経線維）の太さで決まります。耳は脳幹までが近く、太い線維なので数ミリ秒。目は網膜の中で何段も処理するので、大脳までに 50〜60 ms かかります。熱い痛みには、細い有髄の Aδ 線維（速い）と、髄鞘のない C 線維（遅い）の2種類があり、2回にわけて届きます。ラットはサル・ヒトより脳が小さく、道が短いので速い。

      根拠の印について

      研究の値 論文に書かれた数値そのもの。研究の幅 論文が範囲で示したもの。順番だけ どの順に反応するかは研究のとおりで、時刻は前後の値のあいだに置いたおよその値。場所だけ 反応する場所はわかっているが、時刻を確かめられなかったもの（再生では道すじの順に光らせている）。

      ヒトは頭の表面の波（脳波・脳磁図）と、手術の前に脳に入れた電極の記録。サルとラットは、脳に入れた電極で1つ1つの神経細胞を記録したもの（多くは麻酔の下）。測り方がちがうので、種どうしの時刻は目安として比べてください。

      簡単にしたところ

      脳の形と部位の場所は模式図です（3つの種の脳は、同じ大きさに描いています）。光り方の強さ・長さは模式で、研究の値は反応のはじまりの時刻と場所です。刺激の強さ、注意、眠気、年齢で時刻は変わりますが、ここでは研究の平均的な値を使っています。光は短いフラッシュ（ヒトの V1 は 56 ms のはじまり、P100 はパターン反転の検査の値）として扱い、測り方のちがいはまとめています。

      入れていないもの

      確かめた数値がないものは作っていません: サル・ラットの痛み、ラットの顔、サルの音と触覚の時刻（場所だけ）、においと味（道すじは知られているが、時刻を確かめていない）。病気・特性も、ヒトで違いが測られた5つと、ラットの恐怖条件づけだけです。
