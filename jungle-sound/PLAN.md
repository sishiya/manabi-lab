## ねらい
アマゾンの熱帯雨林の音を、本物の録音を重ねて鳴らす。聞こえている音の1つ1つについて
**「だれの声か、どこまでわかっているか」** を画面で区別して見せる。
「森の音」の多くは、名前のわかる鳥やサルではなく **名前のない虫の声** だ、という意外さが見どころ。

## 確かさを2本の軸で書く
| | 音のもと: 本物の録音（その種） | 本物の録音（だれか分けられていない森の音） | 測った数から計算 |
|---|---|---|---|
| **① 種までわかる** | 録音の種名が専門家・iNaturalist の確認つき | — | （使わない） |
| **② なかままで** | なかまの別の種の録音（「なかまの例」と書く） | —（帯で切る案はやめた。批判役2回目の2） | 研究の帯・時刻から作る（「計算で作った」と書く） |
| **③ わからない** | — | 森の録音のうち、①② に分けられない残り | 作らない |
| 生き物でない音 | 雨・川・葉ずれの録音 | | 足りなければ計算 |

- **いちばん大事なうそをつかないこと**: 録音は場所も年もばらばら。**「ひとつの場所で同時に録った音ではない」** を画面の目立つ所に書き、カードごとに**録った場所（地図の点）・年・録った人・ライセンス**を出す。アマゾンの外で録ったもの（例: ホエザルはコロンビア北部）は、そうはっきり書く。
- 「③ を消すと、どれだけ静かになるか」を主役の体験に。③ は**だれの声か分けられていない本物の森の録音**そのもの（想像で作った音ではない）。
- 1,714 などの数は「型の注釈の合計で、種の数ではない」と書く（DATA.md 1）。

## 本物の音との聞きくらべ（ユーザーの指示）
- アプリの中に **「本物の森の録音（1か所でそのまま録ったもの）」⇔「このアプリで重ねた森」** の切りかえを置く。同じスペクトログラムで並べて、ちがいが見える。
- 作るときの確かめ: scikit-maad（BSD-3、手元だけ）で、本物と重ねたものの高さごとの音の量・時刻ごとの変化をくらべ、数でずれを出す。区切りごとに批判役にも聞かせて（数と図で）指摘をもらう。
- 本物の基準は Sonoteca Uirapuru（CC0、アマゾナス州アナビリャナス）ほか。夜・夜明けの基準の録音は、まだ探している。

## 音の作り方（比べた結果。RULES 6章）
| 案 | 判定 |
|---|---|
| A. 本物の録音を重ねる（CC0／BY／BY-SA だけ） | **中心**。本物らしさがいちばん高い。種名・場所・録った人がたどれる |
| B. Web Audio でその場で合成（虫＝パルス列など） | **録音のないところだけ**（例: キリギリスのなかまの帯）。「計算で作った」と書く。手本: SynSing（Tanner ほか 2020）、Farnell『Designing Sound』。WaveSongs は GPL なので使わない |
| C. 音を作る AI（Stable Audio 3） | 使わない（中で何が鳴っているか説明できない） |

**重ねるときに足すもの**（批判役 3）: 何十匹の重なり（同じ録音の時間をずらし、数を研究の数にそろえる）・距離（高い音ほど遠くで弱く。ISO 9613-1＋葉）・森の残響（ConvolverNode）・左右の位置（PannerNode）。同時に鳴らす数に上限（スマホの電池）。画面を離れたら止める（`assets/power.js`）。鳴らしはじめは画面を1回押す。
**超音波**: 録音の多くは 44.1〜48 kHz で、22 kHz より上は入っていない。キリギリスの超音波は図に「録れていない・聞こえない」と書く。

## 画面
**上に固定**
- **声のカード**（①はシルエットか写真、②は「なかまの形の例」、③は形のない「？」）。鳴いている間カードが**光る**。カードの下に録った場所と年。
- スペクトログラム（実際に鳴っている音から計算）。カードを押すと、その声の帯が強く見える。
- 「いま鳴っている声 N のうち、種まで n・なかままで m・分からない（森の録音）」。
**下にスクロール**
- 声ごとの **ON／OFF**（カードを押す。OFF はうすく）、**この声だけ聞く**、**全部もどす**、確かさごとにまとめて ON／OFF。
- 24時間のスライダー（時刻を変えたら音は徐々に切りかえる）。**本物の録音と聞きくらべ** の切りかえ。雨・音量・出どころ。
**スマホ**: 上にカード（横スクロール）と小さいスペクトログラム、下に操作。

**写真・シルエット**: PhyloPic（CC0・CC BY のものだけ）、Wikimedia Commons・iNaturalist（CC0／BY／BY-SA）。撮った人とライセンスを画面に。画像も音も `jungle-sound/` の中に小さくして置く（外から毎回読まない）。

## 段階
- **段階0（いま）**: DATA.md。残り: 夜・夜明けの本物の基準の録音、種ごとの鳴く時刻の出どころ、写真、Xeno-canto の録音ごとのライセンス（ユーザーがブラウザで確認）。**録音のダウンロードはユーザーの OK のあと**。
- **段階A**: **夜の1時刻だけ**。① 数種（カエル・タチヨタカ・コオロギのなかま）＋③ 森の録音。カードの ON／OFF・ソロ・ハイライト・「③ を消す」・**本物との聞きくらべ**。ユーザーに聞いてもらい、批判役の指摘で直す。
- **段階B**: 24時間（夜明けの合唱・昼のセミ・夕方）。声を増やす。雨・川。
- **段階C**（あとで相談）: 森の断面で耳の位置を指で動かす。ほかの森とくらべる。

## やらないこと
- 非営利のみ（NC）・改変禁止（ND）の録音や写真を使う。
- わからない声に、想像で種の名前や姿を付ける。
- 場所のちがう録音を、同じ場所の音のように見せる。
- 「リラックス効果」のような根拠の弱い効能を書く。

## 批判役の指摘と決めたこと
**1回目（2026-11-14、全部その場の計算の案に対して）**: ③ の音の形の決め方（→2本の軸の表）／ソノタイプの数の使い方（→型≠種・1時間ごとの数）／合成だけでは森らしくない（→重なり・距離・残響・左右）／段階A をしぼる（→夜の1時刻）／見るだけにならない（→カードの ON／OFF・ソロ・「③ を消す」）／超音波とスマホのスピーカー／画面を1回押す・徐々に切りかえ・名前は「熱帯雨林」。すべて反映。
**2回目（2026-11-14、録音を中心にした案に対して）**。すべて反映。上の本文より、ここが優先:
1. 場所の寄せ集め（大）→ **地域を1つにしぼる**。夜の録音が見つかった地域に合わせて決める（候補: エクアドルのアマゾン＝虫・カエルがそろう／アナビリャナス＝土台の録音がある）。① は**その地域にいる出どころがある種だけ**（例: シロスズドリはアマゾン川の北だけ）。
2. 土台と ON／OFF（大）→ 土台は **① の声が入っていない区間を目と耳で選ぶ**。入っていればカードに「土台にもいる」。「③ を消す」は**「分けていない森の録音を消す」**と書く。② は別に録った録音か計算だけ。① の録音も**きれいな区間だけ切り出し、加工（ローカットなど）を書く**。
3. 本物に近いの測り方（大）→ 基準は**土台と別の録音、同じ地域・時刻で2〜3本**。比べる: 1 kHz ごとの平均の音の量・帯ごとのパルスの速さと1分の鳴く回数・scikit-maad の指数（ACI・ADI・AEI・NDSI・H）・帯ごとの音のある時間の割合。合格は**基準どうしのばらつきの範囲に入る**こと。**どちらか伏せた聞きくらべ（ABX）**もユーザーに。
4. ライセンス（大）→ README と LICENSE-CONTENT に「ほかの人の音・画像はそれぞれ元のライセンス」の例外。BY-SA を加工したものは BY-SA で。何を変えたかを書く。紹介動画に BY-SA の音を入れるときの扱いは、動画を作る前に決める。録音ごとのライセンスは**確かめた日とページの控え**を DATA.md に。DORSA の利用条件も読む。
5. 段階A の止まり所（中）→ 段階0 で先に集める: **同じ地域の夜の録音（土台1本＋基準2本）**・種がその地域にいる出どころ・鳴く時刻の出どころ・きれいな区間の一覧。
**3回目（2026-11-14、第一弾の重ね方と測り方に対して）**。くわしくは DEVNOTES の「しくみ」。
1. 重ね方（大）→ 土台は1か所・1日から時刻の順に。鳥は本物の鳴いた時刻の並びを写す。同じ切り出しをくり返さない。高さで切る版と切らない版を数でくらべて選ぶ。
2. 数のくらべ方（大）→ 本物を21区間に増やし、位置（%）で見る。わざと悪く作った重ね方でも測る。L10・L90・鳴きはじめの数・ADI・AEI を足す。圧縮して戻した音で測る。機械で見分ける試しと、もっと多くの場所・日の基準は次に。
3. 聞きくらべ（大）→ 重ねた森を3本。大きさをそろえ、0.3 秒で出入り。20回でまとめて結果、15回以上で「聞き分けられる」。本物どうしの組を混ぜるのは次に。
4. 画面の文（中）→ 回数の言い方・土台に入りうる音・高さで切った影響・置けなかった種の数・Viruá は別の場所、を直した。

6. 細かいこと（小）→ 超音波は録音ごとに書き分ける（826473 は 96 kHz で 48 kHz まで入っている）。カードの光は**実際に鳴っている音の大きさ**で決める（決め打ちの時間表にしない）。
