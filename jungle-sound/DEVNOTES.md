- 読む順: PLAN.md（批判役の指摘の欄が優先）→ DATA.md → このファイルの「ファイル構成」→ 関係するファイルだけ。

- 音を作りなおす: 下の「しくみ」の手順。録音（1本約110MB）は Git に入れない。
- 区切りごとの手順: 「確認のしかた」と smoke.ps1 → 「状態」に1行 → launcher.html の表 → 公開前チェック → commit（節目の版だけ versions/ へコピーしてカードに。RULES 3章）。
- ユーザーの好み: 目的は**本物らしさ**（機械で作ることではない）。使える本物の録音は使う（CC0／BY／BY-SA だけ）。本物と聞きくらべ、批判役の指摘で磨く。

**v007（2026-11-14 ユーザー）** — 「『選んだ声: ほげほげ』のパネルはいらない。高さが変わって鬱陶しい。下に名前と次へ進むボタンはある。繰り返す必要はない」:

- 一覧の「▶|」は、その声へ飛んで帯と一覧に白い縁を付けるだけ（行は開かない＝高さが変わらない）。行を押したときだけ開く（`List.select(code, open)`）。
- 上に固定した所の「だけ・+20 dB」と「〜へ移動しました」は、**高さの決まった1行** `.pin-line`（18px、はみ出しは「…」）にまとめた。押しても固定した所の高さは変わらない（スマホで ▶|・だけ を押して 0 px を確かめた）。
- 「くわしい見方」などの開閉（`.more`）の下に余白 12px。
- **高さが変わる表示は作らない**（このアプリの決まり）: 出たり消えたりする文は、場所を先にとっておく。

**v003 で変えたこと（下の v002 の説明より優先）**
- ユーザーの聞きくらべ（v002）: 20回中19回当たり。違和感の主は**つなぎ目**（図でも耳でも分かる）。20回はしんどい → **10回・9回以上で「聞き分けられる」**に。
- 土台 `bed_fill`: BED（PER_020）の**連続した3分**（W0〜）。その中の鳥の注釈の箱（時間 ±0.15 秒・高さ ×1/1.15〜1.15）を、±90 秒の範囲で同じ高さに鳥の箱が少ない時刻の STFT（位相ごと）で塗りつぶす（はしは 4 コマ・3 本でなめらかに）。つなぎ目なし。
- 鳥 `cut(mode='sub')`: 前後 1 秒のまわりの音の中央値をスペクトル減算（2 倍の余裕）で引き、箱の高さ ×1/1.3〜1.3 だけ残し、3×3 でならす。虫の音が二重にならない。
- 機械の聞き分け `machine`: 15 秒ずつの数（全体の大きさはのぞき、L10−L90 は残す）でロジスティック回帰。3分ごと（同じ3分の本物は 15 秒ごと）に分けて交差検証、両クラスの正解率の平均。
- くらべる本物: 機械が**場所ちがいの本物どうしでも 100%、同じ場所でも時刻ちがい（5:15〜21 と 5:30〜39）で 81%** 見分けた（夜明けの虫の合唱は数分で変わる）。だから**土台のもとの同じ3分（塗る前）**を本物にした。虫の音が同じなので、手がかりは鳥の入れ方と塗りつぶしの跡だけ。聞きくらべの ref1 もこの3分（同じ位置の 15 秒）。
- 結果（同じ3分の本物との機械の聞き分け）: 第一弾 99%／塗りつぶし＋鳥そのまま 99%／＋高さで切る 67%／**＋まわりの音を引く 65%（採用）**。鳥の切り出しの中の虫の音（二重）が大きな手がかりだった。1〜4 kHz の鳴きはじめも本物の範囲に入った（第一弾は 0%）。全体の大きさは本物の 5〜10% と静かめ（鳥を塗りつぶした分）。
- 次: 65% → 50% に近づける。批判役5回目: **まず機械が何で見分けているかを切り分ける** — 「塗っただけ（塗ったあと本物の鳥を元の時刻にそのまま戻す）」と「切って戻した（同じ鳥をまわりの音を引いた切り出しにして元の時刻に戻す）」を作って正解率をくらべ、ロジスティック回帰の重みの大きい数も出す。鳥の時刻の並べ方はそのあと。本物の区間を増やす（同じ場所のほかの3分にも塗る→重ねるをして、その本物とくらべる）。65% は本物が 12 個なので ±15% ほどぶれ、鳥の入れ方をこの 12 個で選んだので甘い。言えるのは「鳥の入れかえのばれにくさ」まで（画面に書いた）。

**v002 の説明**
- 録音はすべて Hopping, Kahl & Klinck 2022（Zenodo 7079124、CC BY 4.0）。ペルー Inkaterra Reserva Amazonica の7か所×3日、5:00〜6:00、32 kHz モノラル、鳥だけに注釈（132種＋「????」＝種のわからない鳥、計 16,482 個）。**ひとつの保護区の録音だけ**を使うので、場所の寄せ集めにならない（批判役2回目の1）。
- くらべる時間: 録音の 1500〜1680 秒（5時25分ごろ）の3分。
- 使い分け（場所も日もかぶらない）: 土台と鳥 = PER_015（S01・1/31）・PER_020（S08・1/31）・PER_005（S06・1/16）・PER_012（S06・1/20）。本物の基準 = PER_002（S02・1/16）・PER_010（S04・1/20）・PER_018（S05・1/31）。
- 土台: **PER_015（1か所・1日）だけ**から、鳥の注釈のない区間（前後 0.4 秒をあける、1 秒以上）を、まねる時刻に近いものから3分ぶん選び、**時刻の順に**つなぐ（0.25 秒の重ねつなぎ）。つなぎ目の数は画面に出す。
- 鳥: 種ごとに、ほかの録音（TRAIN の1本、時刻を前後10分の中でずらす）で**本物が鳴いた時刻の並び**を写し、そこへ同じ種の切り出しをはめる（続けて歌うまとまり・回数が本物どおりになる）。切り出すのは、ほかの注釈と重ならない（前後 0.2 秒）15 秒以下の注釈だけ。同じ切り出しは、その種の切り出しを一周使い切るまでくり返さない。音量は録れたまま。注釈の高さの箱だけ残す版（1/1.2〜1.2 倍）と、切らない版の両方を作り、数で良いほうを使う（`band_filter`）。並びを写す録音の選び方を変えて3本（mix1〜3）。
- 数（tools/build_mix.py の `metrics`。**AAC 64 kbps に圧縮して戻した音で**測る）: 全体の大きさ・L10・L90、1 kHz ごとの音の量の割合と音のある時間の割合（16帯）、帯ごとの鳴きはじめの数（3帯）、ACI（Pieretti 2011）、H（Sueur 2008）、NDSI（Kasten 2012。ここでは 1〜2 kHz と 2〜8 kHz）、ADI・AEI（Villanueva-Rivera 2011）。
- 本物の基準は REF 3本 × 15:00〜36:00 の3分 7区間 = 21区間。重ねた森が21区間の中のどの位置（パーセンタイル）に来るかを出し、5〜95% なら ○。
- 物差しの確かめ: わざと悪く作った重ね方（鳥なし・鳥を2倍・鳥の時刻をでたらめ）も同じに測り、本物の外に出るかを見る。
- 聞きくらべ: 重ねた森3本×本物3本から、15秒・同じ位置。2つの大きさをそろえ（`loud` の1秒ごとの dB から）、0.3 秒で出入り。20回たまってから結果。20回中15回以上（二項分布で偶然なら約2%）で「聞き分けられる」。
- 第一弾の結果（2026-11-14）: 43個の数のうち、本物21区間の5〜95%に入ったのは 重ねた森 37・34・37、基準に入れていない本物4本 30・30・28・30。悪い作り方もほとんど入る＝**物差しが甘い**。土台（S01・S06・S08 を試して S08）と高さで切らない版は、同じ基準の数で選んだので有利に出ている。1〜4 kHz の鳴きはじめの数はどの重ねた森も 0%、L10 は高め。
