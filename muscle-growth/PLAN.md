# 筋肉が育つまで 企画書

最終更新: 2026-10-06

## 何を作るか
筋トレをすると、筋肉はどう傷つき、どう治り、どう大きくなるのか。条件（やり方・重さ・セット数・週の回数・経験・年齢・たんぱく質・睡眠）を選んで、**数週間の時間を動かしながら**、筋線維の中（ミクロの断面）と体の中の数値（グラフ）で確かめる。

- もとになったアイデア: `IDEAS.md` の 7。作り方は「免疫のたたかい」（数のモデル＋ミクロの図＋グラフ）と同じ。
- 見せたい「意外な点」
  1. **「傷ついて治ると大きくなる」は半分は誤解**。はじめのころ作られた材料の多くは修理に回り、筋肉はほとんど太くならない（Damas ほか 2016）。主な合図は筋肉が引っぱられる力（機械的張力）。
  2. **筋肉痛は運動の直後ではなく1〜3日後**に強くなる。同じ運動を2回目にやると軽くなる（繰り返し効果）。筋肉痛の強さと、筋肉の育ち方は比例しない。
  3. **はじめの数週間に力が伸びるのは、おもに神経のなれ**。筋肉が太くなるのはそのあと。最初の太さの増加の一部は「むくみ」。
  4. **軽い重さでも限界近くまでやれば**、筋肉は重い重さとほぼ同じように大きくなる（力の伸びは重いほうが大きい）。軽くても限界から遠いところで止めると、ほとんど育たない。
  5. 週あたりの量が同じなら、回数（頻度）の差は小さい。量は増やすほど効くが、だんだん頭打ち。
  6. やめても、筋肉はすぐには落ちない。

## 画面
- 左上: **筋線維の中**（大きな図）
  - 縦の断面: 筋原線維のしま模様（サルコメア、Z線）。運動のあとは Z線が乱れる（損傷）、すき間に水（むくみ）、好中球 → マクロファージ、衛星細胞が目を覚まして増え、核を渡す。
  - 横の断面: 筋原線維の数が増えて線維が太くなる。はじめの太さを点線で。核の数。
  - 「実際の大きさ／変化を強調」の切りかえ（実際の変化は数％で目では分かりにくい）。
- 下: **グラフ**（1週間／全期間の切りかえ）
  - 上の段: 筋たんぱく質の合成と分解（その時刻の速さ）、筋肉痛、傷の量
  - 下の段: 筋肉の量（％）、見た目の太さ（むくみ込み）、力（％）。前の条件を薄い線で残して比べる。
  - 筋トレした時刻と食事の印。
- 右: 条件、いま起きていること、結果（12週後）、よくある誤解、まだ分かっていないこと、このアプリについて。
- 時間の帯: 再生（6時間／1日／1週間 が1秒）、スライダー。

## モデル（数のモデル、1時間きざみ）
- 期間: 筋トレ12週 ＋ 休み6週 = 18週。トレーニングは夕方18時。食事は 8時・12時半・19時半。
- 変数: 合成のうながし `A`（運動のあと、初心者は約48時間、慣れると約24時間）、食事 `fed`、合成 `MPS`、分解 `MPB`、傷 `D`、繰り返し効果 `P`、好中球・マクロファージ、筋肉痛、むくみ、筋肉の量 `M`、神経のなれ `Nr`、核の数、慣れ `Tr`。
- 合成と分解の差のうち、傷に応じた割合（`D/(D+K)`）は修理に回り、残りが筋肉の量になる。
- 数値の出どころと「確か／推定」は DEVNOTES に書く。合わせる目安（いずれも研究のおおよその値）:
  - 初心者・70%で10回×3セット・週3回・12週 → 筋肉の断面積 +8〜10%、力 +25〜35%
  - はじめての運動の筋肉痛は 24〜72 時間で最大、5〜7日で消える。下ろす動作を重くすると力が数日 30〜50% 落ちる。2回目は大きく軽くなる。
  - 初心者の筋たんぱく質合成は運動後 48 時間ほど高い。慣れた人では 24〜36 時間で戻る。
  - 軽い重さで限界まで ≒ 重い重さ（筋肉の量）。たんぱく質が少ないと少し減る、睡眠不足で 15〜20% 減る、高齢では 3割ほど少ない（推定）。

## 段階
- **段階A（この版）**: モデル、筋線維の図（縦と横の断面）、グラフ、条件、いま起きていること、誤解、注意書き。
- 段階B: 体の小窓（腕の力こぶ）、休んだあと再開（マッスルメモリー）、比べる表（いくつかの条件を並べる）。
- 段階C: 太もも（スクワット）、有酸素運動との組み合わせ、女性・男性の差の説明。

## やらないこと
- 個人に合わせた運動のすすめ（医療・健康の判断には使えないと書く）。
- 薬（ステロイドなど）の話。
