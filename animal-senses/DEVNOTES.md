# いきものの感じる世界 開発メモ

最終更新: 2026-10-04

同じ庭を、生き物（と道具）を切り替えて一人称で見る。人に感じられない感覚（紫外線・熱・こだま・速い時間・偏光・近赤外線）を「置き換えて」見せる。企画は `PLAN.md`。体内ダイブ系・電波の見える部屋とはエンジンが別（Three.js r128 を cdnjs から、シェーダは自前）。

## しくみ

- **頂点の属性**（`paint()`）: `aCol` 人の目の色（線形 RGB）、`aP` = (紫外線の反射率, 昼の温度, 夜の温度, 発光)、`aA` = 可視光・紫外線・熱の不透明度、`aX` = (こだまの強さの係数 `b`, 近赤外線の反射率 `nir`（なければ色から推定）, なめらかで偏光する面 `pol`)。
- **パス**（`SCENE_FS` の `uMode`）: 0 可視光、1 紫外線、2 熱（温度/60）、3 こだま（距離/40 と、面の向きで決まる返り方 × `b`）、4 近赤外線（太陽＋カメラの赤外線ライト。ライトは距離の2乗で弱まる）、5 偏光（なめらかな面はフレネルの式で反射光の偏光度、空はレイリー散乱の式）。空の可視光パスは alpha 0（複眼で空かどうかを知るため）。
- **合成**（`COMP_FS`）: 人間（夜は桿体）、カラス（紫外線を紫で重ねる）、マムシ（熱を320マス幅でぼかして重ねる）、コウモリ（下記）、シャコ（白黒＋横帯の中だけ色相を12段にまとめた色＋紫外線→紫、帯は `scan` で上下。偏光は緑のしま）、イヌ・ネコ（2色型 Viénot 1999 の式、ぼかし、ネコは夜に明るく・にじむ）、サーモ（5〜40℃ を色に）、近赤外線（白黒）。`uSplit` で左半分を人間に。
- **複眼**（`CUBE_FS`）: カメラ位置で 256px のキューブマップを描き、画面の横を 336°（いつも画面の幅いっぱい）、縦を最大176°として方位・仰角に直す。それを六角形の格子（`uHex` 度）に分け、六角形の中心の方向を1回だけ読む（ミップマップで個眼の受け入れ角ぶんぼかす）。ミツバチは紫外線のキューブも描いて「緑→赤・青→緑・紫外線→青」。空の偏光は太陽からの角度で強さ＋輪。
- **時間の流れ**（`clocks`）: 世界の時間 `S.t` は `dt × 時間の倍率` で進む。自分の移動は実時間（速い感覚＝反応する時間がある、という見せ方）。蛍光灯（50Hz → 100回/秒）は、画面上で30回/秒以下になる倍率のときだけちらつかせる（60fps では速いちらつきは正しく描けないため）。**光過敏性発作への配慮（v5）**: 画面上では毎秒2〜25回と、発作の起きやすい範囲（3〜30回）に入る。だから「灯りのちらつきを見る」（`S.flicker`、最初は切）を入れたときだけ、明るさを85〜100%でゆらす（本物は約50%まで下がる）。`prefers-reduced-motion` のときは選べない（`REDUCED_MOTION`）。v4 のゆれ方だと、ハエの「玄関の灯り」で画面の約9%が相対輝度0.1以上変わっていた → v5 は0%。
- **ハエたたき**（`swatterStep`、世界時間）: 待つ2.2秒 → ハエがテーブルの近くなら位置をねらって振りかぶり0.7秒 → 0.11秒で振り下ろし → 当たり判定（水平12cm・高さ±9cm）→ 戻る。ハエのときだけ動く。
- **コウモリ**: 鳴いた時刻を6個まで `SX.calls` に持つ。各画素で `age − 2d/343` が0以上になったら（こだまが返ったら）明るくし、`tau`=0.12秒で薄れる。声の波面が当たっている所（`d ≈ 343·age`）は青い線。前方ほど強い（`beam`）、空気で弱まる。ガが前方にいると鳴く間隔が 0.1 → 0.05 → 0.012秒（フィーディングバズ）。ガに20cmまで近づくと捕まえ、4秒後に戻る。
- **こだまの音**: 30ms の下降 FM（8→2.5kHz＝実際の 80→25kHz を10倍に伸ばした音）を、`W.echoObjs`（物ごとの外接球）の距離・向き・大きさから遅れと音量を決めて最大24個鳴らす。0.45秒に1回まで。チェックを入れたとき（ユーザーの操作）に AudioContext を作る。
- **弱視・ロービジョン**（`lowv()`、`uSense` 9）: `rtVis` を半分の大きさで横・縦にガウスぼかしした `rtB1` を使う。ぼやけ: 視力 V は約 30·V サイクル/度まで見分けられるとして σ ≈ 0.9/(30V) 度（`lvSigma()`）。中心暗点: 画面中心（比べる表示のときは右半分の中心）から半径 R° をぼかし・灰色に、まわりをゆがませる。視野狭窄: 半径 R° より外を暗く、夜はさらに暗く（夜盲）。白内障: かすみ（ぼかしと混ぜる）・黄ばみ・散乱光でコントラスト低下・明るい所のまぶしさ。
- **近視・遠視・乱視・老眼**（`refr()`、`uSense` 10）: こだま用の距離パス（mode 3）を `rtX` に描き、画素ごとに「必要な度数 = 1/距離 + 遠視の度数（近視はマイナス）」。0未満なら近視のずれ、調節力 A を超えた分が遠視・老眼のずれ。ぼやけの円の直径 = 瞳の直径 × ずれ（ラジアン）、瞳は昼3mm・夜6.5mm。28点の円盤で集める（最大半径22px）。調節力は Hofstetter の最小値 15 − 0.25×年齢（近視のときは8D）。乱視は距離に関係なく一方向に 瞳×円柱度数 の長さでぶらす。眼鏡をかけるとぼかさない。
- **色覚の多様性**（`cvd()`、`uSense` 11）: Machado ら（2009）の重さ1.0の行列（線形 RGB、GLSL では列優先で書いている）。「強さ」はふつうとの間を線形に混ぜた目安（異常3色覚）。1色覚は桿体寄りの重みで白黒＋ぼかし＋昼のまぶしさ。
- **夜の明かり**（`NIGHTS`、`curTime()`）: 夜のときだけ 灯りあり／満月／星明かり／まっくら。月明かりと空の明るさを `L` 倍（満月=1、星明かり 0.004、まっくら 0.0004）、灯りの on/off、星（`uStars`、空の球に固定の明るさの点）。目が暗さに慣れる上限 `DARK_GAIN`（満月の何倍暗くまで補えるか: 人100・ネコ600・イヌ300・カラス15 など）で露出を `min(1/L, G)` 倍し、足りない分は暗くなり、ざらつき `uGrain`（明るさに掛かるゆらぎ）が増える。熱・こだま・カメラの赤外線ライトは関係ない。比べる表示の左半分（人間）は `uExpH`（人の上限）で描く。
- **手に持つ本**（`buildBook(cam)`）: カメラの子に付けた文庫本（35cm 先・少し下）。文字は約4mmの黒い棒で行を作る。`low` と `refr` のときだけ表示。カメラをシーンに入れている（`R.scene.add(R.cam)`）。
- **軽くするため**: 動かない不透明な物は `bakeStatic()` で1つのメッシュにまとめる（描画呼び出しが数百 → 数十）。動く物は `W.dyn` に登録する（ネズミ・ガ・ネコの尾・庭の人・ハエたたき）。物を足すときは、動くなら `W.dyn.add()` を忘れない。
- **温度の値**（推定・演出用の目安）: 人の肌 34℃、服 28〜31℃、ネズミの毛 29.5〜31.5℃・鼻と耳 34℃、ネコの毛 27.5〜32℃、昼に温まった石 41℃→夜 21℃、コンクリート 38→19.5℃、芝生 27→13.5℃、窓ガラス 18.5℃（夜）。
- **紫外線の値**（目安）: ヒマワリ・ルドベキアの花びらは根もと 0.03 → 先 0.58、白い花 0.06、ブルーベリーの粉 0.5、白い壁 0.05、魚 0.45。**近赤外線**: 葉・芝生 0.55〜0.6、水 0.02、ジーンズ 0.7、カラス 0.1、ネコの目 7（タペタムの再帰反射の代わり）。

## ハマったところ
- 一時停止（ループで `step` を呼ばない）にすると Browser ペインのスクリーンショットが真っ黒・タイムアウトになる。`S.paused` は「時間 dt を 0 にして描画は続ける」にした。
- 起動直後、キャンバスの大きさが決まる前に描くと熱のぼかし用のサイズが未定義で落ちた（`R.thSize` に初期値）。
- 半透明の膜を両面で描くと、深度を書かないので裏面が表の上に描かれ、紫外線で隠れるはずの袋の中身の形が浮き出た → 半透明は表面だけ。
- GLSL で関数名とローカル変数名が同じ（`cat`）だと危ないので `catV` `dogV` にした。
- Browser ペインで `resize_window` の大きさを変えると、スクリーンショットでは縮小されて小さく写る（内容は正しい）。
