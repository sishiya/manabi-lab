# いきものの感じる世界 開発メモ

最終更新: 2026-10-04

同じ庭を、生き物を切り替えて一人称で見る。人に感じられない感覚（紫外線・熱・こだま・速い時間）を「置き換えて」見せる。企画は `PLAN.md`。体内ダイブ系・電波の見える部屋とはエンジンが別（Three.js r128 を cdnjs から、シェーダは自前）。

## しくみ

- **頂点の属性**（`world.js` の `paint()`）: `aCol` 人の目の色（線形 RGB）、`aP` = (紫外線の反射率, 昼の表面温度, 夜の表面温度, 発光)、`aA` = 可視光・紫外線・熱の赤外線それぞれの不透明度。材料は `M` と各関数の中で `{ c, uv, t:[昼,夜], e, a:[可視,紫外,熱], j:色ムラ }`。
- **パス**（`render.js`）: 同じ場面を `uMode` を変えて描く。0 = 可視光（太陽・空と地面の環境光・玄関灯・部屋の灯り。半精度浮動小数点）、1 = 紫外線（反射率 × 紫外線の光。空は紫外線で明るい）、2 = 熱（温度/60 を 320 マス幅の小さい画面に → 横・縦のガウスぼかし）。空は別の球（`SKY_FS`）で、熱では「冷たい空」。
- **合成**（`COMP_FS`）: `uSense` 0 人間（夜は桿体: 色をうすく・少しぼかし・ざらつき）、1 カラス（彩度を少し上げ、紫外線を紫 `tint` で重ねる／紫外線だけの白黒）、2 マムシ（目の像は黄と青の2色・ぼかし・暗め、熱は気温との差 `uAmbT`（昼26℃・夜16.5℃）を 0〜16℃ で色に。冷たいものはうっすら青）。`uSplit` で左半分を人間に。
- **半透明**: 黄色いゴミ袋は紫外線の不透明度 1（中身が隠れる）、ふつうの袋は 0.4。窓ガラスは熱の不透明度 1（向こうの人の熱が見えない）。半透明の素材は表側だけ描く（両面にすると裏面が表の上に描かれて中身の形が浮き出た）。
- **温度の値**（推定・演出用の目安）: 人の肌 34℃、服 28〜31℃、ネズミの毛 29.5〜31.5℃・鼻と耳 34℃、ネコの毛 27.5〜32℃、昼に温まった石 41℃→夜 21℃、コンクリート 38→19.5℃、芝生 27→13.5℃（夜は放射冷却で気温より低い）、窓ガラス 18.5℃（夜）。
- **紫外線の値**（演出用の目安）: ヒマワリ・ルドベキアの花びらは根もと 0.03 → 先 0.58（的の模様）、白い花 0.06、ブルーベリーの粉 0.5、白い壁（酸化チタンの塗料は紫外線を吸う）0.05、魚 0.45。

## 確認のしかた（変更のたびに）

コンソールエラーがなく（`__as.err` が空）、次のようになること。

1. 3つの時刻 × 3つの生き物で、すべての見どころへ移動・W で前進してもエラーなし:
   ```js
   for (const t of ['day','dusk','night']) { __as.setTime(t); for (const a of ['human','crow','snake']) { __as.setAnimal(a); for (const p of ANIMALS[a].pois) { __as.goto(p); __as.frame(60); } } } __as.err
   ```
2. カラス・昼・「ゴミ袋」・紫外線だけ: 白い袋は中身が見え、黄色い袋は暗く一様（中身が見えない）。
3. カラス・昼・「ヒマワリ」: 花びらの先が紫、根もとと中心は暗い。「ブルーベリー」で実が紫。比べる表示で左が人間。
4. マムシ・夜・「ネズミ」（`__as.S.t=0` にしてから行くとネズミが正面で止まっている）: ネズミがオレンジに光る。「窓の中の人」: 人は目の像には映るが熱では光らない（ガラスがうっすら）。
5. 人間・夜: 色がうすい灰色、玄関灯の近くが白飛びしすぎない。
6. スマホ幅（375×812）: 上が3D、下がパネル、横スクロールなし、移動ボタンが出る。

## ハマったところ
- 一時停止（ループで `step` を呼ばない）にすると Browser ペインのスクリーンショットが真っ黒・タイムアウトになる。`S.paused` は「時間 dt を 0 にして描画は続ける」にした。
- 起動直後、キャンバスの大きさが決まる前に描くと熱のぼかし用のサイズが未定義で落ちた（`R.thSize` に初期値）。
