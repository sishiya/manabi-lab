# いきものの感じる世界 企画書

最終更新: 2026-10-04

## きっかけ

公開した「電波の見える部屋」へのコメント:「題材を音波に変えて『コウモリシミュレーター』みたいなゲームにして、マルチで笑える要素を入れれば流行りそう」。
「電波の見える部屋」はシミュレーターとしてそのまま残し、**人間には感じられない感覚・見え方を体験するアプリ**を別に作る。ゲーム・マルチ要素は後の段階で考える。

## 何を作るか

- **同じ1つの庭**（家の壁・窓・玄関灯、花壇、ブルーベリー、ゴミ置き場、池、石、ネズミ・ネコ・カエル・人・ガ）を、生き物を切り替えて**同じ場所から**見る。違いがいちばん分かるのは「同じものが別の感覚でどう見えるか」なので、舞台は共通にする。
- 一人称の3D（Three.js r128、cdnjs）。ドラッグで見回し、キー／画面のボタンで移動。飛べる生き物は上下にも動ける。
- **左右に分けて人間と比べる**表示（画面の左半分が人間の目、右半分がその生き物）。
- 生き物ごとに「見どころ」ボタン（その感覚で面白い場所へ移動）と、感覚の説明カード。
- 説明は **確か／推定／演出** を区別して書く（RULES 9章）。人に見えないもの（紫外線・熱・音の反射）は必ず何かに「置き換えて」見せるので、何を何に置き換えたかを画面にも書く。
- 時刻: 昼・夕方・夜。熱の温度や光の強さが変わる。

## しくみ（概要）

- 物体ごと（頂点ごと）に「人の目の色」「紫外線の反射」「表面温度（昼・夜）」「透け具合（可視光・紫外線・熱の赤外線で別々）」を持たせる。
- 同じ場面を**感覚ごとのパス**で描き分け（可視光／紫外線／熱／距離と向き）、最後に生き物ごとの合成シェーダで1枚にする。
  - 例: 黄色いゴミ袋は可視光では透けるが紫外線では透けない。窓ガラスは可視光は通すが熱の赤外線は通さない。

## 段階

| 段階 | 内容 |
|---|---|
| **A** | 舞台（庭）・操作・時刻・比べる表示。**人間**（夜は色が薄くなる）、**カラス**（4色型。紫外線を紫に置き換えて重ねる／紫外線だけの白黒）、**ヘビ（マムシ）**（ピット器官の熱の像をぼかして目の像に重ねる）。 |
| B | **ハエ**: 複眼（六角形のモザイク、ほぼ全周の視野、粗い解像度）と時間（ちらつきを感じる速さが人の数倍 → スローモーションで見せる。蛍光灯のちらつき、迫るハエたたき）。 |
| C | **コウモリ**: 暗闇で超音波を出し、こだまが返ってきた所だけが浮かび上がる（音の殻が広がる様子をスローで）。こだまを10倍に引きのばして耳で聞く（研究でも使う「時間伸長」）。飛ぶガを見つけて捕まえる。 |
| B2 | 追加（ユーザーの希望）: **ミツバチ**（紫外線・青・緑の3色＝赤が見えない。研究で使う「ずらした色」で表示、空の偏光の輪）、**シャコ**（12種類以上の色センサーだが近い色の見分けは苦手 → 横帯だけ色を大まかな仲間に分け、帯が上下に走査。偏光）、**イヌ**（2色型・視力が低い。赤いボールが芝生に紛れる）、**ネコ**（夜に強い・2色型・ぼやける）。道具として **サーモグラフィ**（熱をくっきり・温度の色）、**近赤外線カメラ**（葉が白く光る、水が黒い、夜は赤外線ライトでネコの目が光る）。 |
| B4 | **色覚の多様性**（1型・2型・3型・1色覚）、**夜の明かり**（灯り・満月・星明かり・まっくら。目が慣れる上限で、見える生き物と見えない生き物の差）、生き物をカテゴリ別に並べ、ヒトの見え方は一番後ろ。 |
| B3 | ヒトの見え方のちがい: **弱視・ロービジョン**（ぼやけ・中心暗点・視野狭窄・白内障。医学の「弱視」と福祉の「弱視」のちがいも説明）、**近視・遠視・乱視・老眼**（距離ごとにピントのずれを計算。手に持った本と遠くを比べる、眼鏡）。見え方は人によってちがうので「一例」と明記する。 |
| D | 仕上げ: スマホ対応の調整、「このアプリについて」（出典・置き換えのルール）、公開。出典は 2026-10-07（v5e）に画面へ載せた。 |
| E 以降（案） | ほかの生き物（ミツバチの偏光と紫外線、イヌの2色型の色覚、ネコの暗視、サメの電気感覚、渡り鳥の磁気感覚、ゾウの低い音、魚の側線、ホシバナモグラ）。ゲーム: コウモリでガを捕る、ハエたたきをよける、ヘビで暗闇のネズミを探す。マルチ: 感覚の違う2人（例: 音だけのコウモリと熱だけのヘビ）が言葉で伝え合って協力する（「見ざる言わざる聞かざる」系）。 |

## 案のメモ

- 映画のキャラクター（エイリアン・プレデターなど）は名前・姿・画面の見た目が著作物・商標なので使わない。「熱で見る」こと自体はサーモグラフィやヘビと同じなので、やるなら**オリジナルの架空の宇宙人**（例:「電波が見える宇宙人」＝電波の見える部屋とつなぐ、「X線が見える」「磁場が見える」）として、演出だと明記する。

## やらないこと（いまは）

- 本物の物理シミュレーション（音波の波動計算など）。コウモリは「距離の画像からこだまの時刻を出す」近似にする（電波アプリとは役割を分ける）。
- 写実的なモデル。形は単純な立体の組み合わせ（ローポリ）で、感覚の違いが見えることを優先する。
- 当たり判定（壁や物を通り抜けられる）。庭の外には出られない程度にする。
