# 企画書：ヒトへの46億年

作成: 2026-10-03

## 1. ひとことで

ひとつの場所を空から見下ろし続ける「定点観測」のアプリ。タイムスライダーを動かすと、太陽系ができる前のちりの円盤から、マグマの海、海の誕生、微生物の時代、全球凍結、生き物の上陸、恐竜、哺乳類、そしてヒトが現れて街ができる現代までが、切れ目なくつながって変わっていく。

## 2. ねらい

- **時間の長さを体で感じる。** 46億年のうち人類はほんの最後。目盛りを「出来事ごと」と「実際の長さ」で切り替えられるようにして、その差を見せる。
- **ヒトの祖先を追う。** どの時代にも「このとき、あなたの祖先はこれ」を示す。細胞 → 魚 → 四肢動物 → 単弓類 → 哺乳類 → 霊長類 → 人類。
- **環境と生き物はセットで変わる。** 空の色・海の色・氷・陸の形・植物・動物を、同じ時刻の値から一度に決める。

## 3. 舞台

- 見ている場所は「いまのアフリカ東部、大地溝帯の湖のほとりになる場所」。ここを選んだのは、人類の化石と石器がいちばん多く見つかっている地域だから（トゥルカナ湖では330万年前の最古の石器、トゥルカナ・ボーイなど）。
- 古い時代はこの場所の地殻がたどった姿を代表として描く（大陸移動の正確な再現はしない）。地球規模の出来事（全球凍結、大量絶滅、隕石衝突）は空や色で表す。
- オルドビス紀末や石炭紀〜ペルム紀前期の氷河は、当時アフリカが南極近くにあったので実際に氷を描く。
- 地形の大きな流れ：マグマの海 → 火山島だけの海 → 海岸（西が海、東が陸）→ 新生代に台地へ隆起 → 大地溝帯が割れて湖ができる → 湖畔の村 → 現代の街と鉄道。
- 生き物は見やすいように大きめに描く（縮尺は誇張）。

## 4. 画面

```
┌───────────────────────────────────────────────────┐
│ 時代（累代›代›紀）          環境：酸素・CO2・気温   │
│ 約3億5900万年前              1日の長さ・太陽・月    │
│ 地球カレンダー 11月28日       ─────────────          │
│ 出来事の見出しと説明          あなたの祖先           │
│                                                     │
│          （鳥の目で見下ろす3Dのフィールド）         │
│                                                     │
│ [⏮][▶][⏭] 速さ  目盛り[出来事ごと|実際の長さ]       │
│ ▓冥王代▓太古代▓▓原生代▓▓▓顕生代（古・中・新）▓     │
│ ━━━━━━━━━━━━━━━━━━━━━━━━━●━━━━  出来事の目印        │
└───────────────────────────────────────────────────┘
```

- ドラッグで視点を回す、ホイール／ピンチで寄る、右ドラッグ（2本指）で平行移動。
- スライダーには地質年代の色帯と出来事の目印。目印をクリックするとその時代へなめらかに移る。
- 再生ボタンで時間が流れる。大きな出来事の前後では自動でゆっくりになる。
- 「いま見えているもの」の一覧。押すとその生き物に名前ラベルが出る。

## 5. 時間の扱い

- 内部の時刻は「何年前か」（A 年）。表示は「38億年前」「31万5000年前」、1万2000年前より新しいときは「紀元前3000年」「西暦1901年」。
- スライダー位置 → A の変換は2通り。
  - **出来事ごと**（初期設定）: 区切りの年代に目盛り位置を割り当て、その間を対数で補間。どの時代にもほどよい幅がある。
  - **実際の長さ**: 均等。人類の時代は右端の1ピクセル未満になる。
- 環境の値は、キーフレーム表を log(A) で補間する。だからどの目盛りでも切れ目なく変わる。
- 地球カレンダー（46億年を1年にしたら何月何日何時か）も出す。

## 6. 中身（v1 の範囲）

### 環境
空の色（宇宙の闇 → 赤黒い → メタンのオレンジのもや → 大酸化イベントで青）、海の色（鉄で緑がかる → 青）、雲、霧、太陽の明るさ（70% → 100%）、氷（ヒューロニアン、全球凍結、オルドビス紀末、石炭紀〜ペルム紀）、溶岩の光、火山、隕石、K-Pg 衝突の閃光と灰、ペルム紀末の火山性のもや、更新世の湖の水位の上下、現代の都市化。

数値: 酸素濃度、CO2、平均気温、1日の長さ、太陽の明るさ、月までの距離（いずれも推定値で、推定であることを明記）。

### 生き物（約50種類）
- 海: ストロマトライト、藻類、カルニア、ディッキンソニア、三葉虫、アノマロカリス、初期の脊椎動物、オウムガイの仲間、ウミサソリ、甲冑魚、サメ、魚、肉鰭類、アンモナイト、魚竜、首長竜、モササウルス、初期のクジラ
- 陸の植物: コケ、クックソニア、シダ、アルカエオプテリス、リンボク、木生シダ、針葉樹、ソテツ、広葉樹、ヤシ、イネ科の草、アカシア
- 陸の動物: 初期の四肢動物、メガネウラ、ディメトロドン、ゴルゴノプス、リストロサウルス、キノドン類、初期の哺乳類、小型の獣脚類、竜脚類、大型の獣脚類、ケントロサウルス、鳥脚類、翼竜、鳥、ガストルニス、初期の霊長類、プロコンスル、ゾウ、レイヨウ、キリン、カバ、ワニ、ライオン
- 人類: 初期の人類（サヘラントロプス・アルディピテクス）、アウストラロピテクス、パラントロプス、ホモ・ハビリス、ホモ・エレクトス、ホモ・ハイデルベルゲンシス、ホモ・サピエンス
- 人の営み: たき火、小屋、牛、畑、丸木舟、鉄道、道路、車、建物、飛行機

それぞれ「いつからいつまで」「すみか（海・浅瀬・陸・水辺・空）」「数」を持ち、時刻に応じて増えたり減ったりする。植物はすみかに合う場所から少しずつ広がる。動物は群れで歩き回る。

### 出来事（約55件）
太陽系の誕生から現在まで。見出しと2〜3文の説明。年代は国際年代層序表（2023年版）と主要な発見に合わせる。諸説あるものは「諸説あり」と書く。

### 祖先
各時代の「あなたの祖先（に近い仲間）」を右上に表示し、画面にいればその1体に印をつける。

## 7. 作り方

- 1ファイルの HTML（Three.js r128 を cdnjs から）。体内ダイブシリーズと同じ書き方（doctype なし、Artifact で公開）。
- 地形: 高さを決める層（大きな起伏・細かい起伏・海岸の傾き・火山・クレーター・地溝）を最初に計算しておき、時刻ごとに重みを変えて合成。色も頂点ごとに計算。
- 水: 地形と同じ格子で深さを計算し、浅いほど明るく透ける。氷になると白く不透明に。
- 生き物: 種類ごとに InstancedMesh。形は箱・円柱・球の組み合わせで作る（頂点色）。
- 影あり（太陽光の平行光源）。
