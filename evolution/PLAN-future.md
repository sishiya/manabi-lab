# 企画書 2：未来とIF（「ヒトへの46億年」の次の段階）

作成: 2026-10-03

## 1. 結論

できる。ただし、いまのアプリのデータからは「因果」は取り出せない。そこで、因果を**しくみのモデル**として書き、いまの年表（キーフレーム）はそのモデルの**答え合わせ用の隠しデータ**にする。モデルが過去を再現できれば、同じモデルを未来へ進めた絵や、プレイヤーが手を入れたIFの世界にも根拠が持てる。

## 2. なぜ「差分から割り出す」だけでは足りないか

- いまの値（酸素・CO2・気温・氷・植生など）は、文献から手で置いた約50の点を補間したもの。点と点の差は「何が変わったか」は教えてくれるが、「なぜ」は入っていない。
- 例: 7億年前に気温が −40℃ に落ちたのは、表の上ではただの数値の変化。実際には「大陸が赤道に集まる → 風化が進んで CO2 が減る → 氷が増えて日光を反射 → さらに冷える（暴走）」という連鎖がある。
- 点が50ほどでは、統計的に因果を推定するには少なすぎる。しかも地球史は一度きりなので、比べる対照実験がない。

→ 因果は、地球科学ですでにわかっている**しくみ**から組み立てるのが確実。

## 3. 地球システムの小さなモデル

ゲームで毎フレーム動かせる軽さの「箱モデル」。状態量と、それを動かすしくみ。

| 状態量 | 主に動かすしくみ |
|---|---|
| 太陽の明るさ | 時間とともに増える（46億年で約1.4倍） |
| 大気の CO2 | 火山が出す ／ 岩石の風化が吸う（暖かいほど速い＝**天然のサーモスタット**）／ 生物が埋もれて固定する ／ 人間が燃やす |
| 気温 | 太陽 ＋ 温室効果（CO2・メタン）− 反射（氷・雲） |
| 氷の量 | 気温が下がると増え、増えると反射で冷える（**氷のアルベド・フィードバック**。行き過ぎると全球凍結） |
| 酸素 | 光合成でつくる ／ 鉄や火山ガスが消費（消費を上回ると大酸化イベント） |
| 海面・陸の割合 | 氷の量、大陸の配置（超大陸の周期 約4〜5億年） |
| 生態系 | 生き物のグループ（微生物・海の動物・陸の植物・陸の動物・人間）ごとの「多様さ」。環境が急に変わると減り（大量絶滅）、時間をかけて回復・多様化する |
| 人間 | 人口・エネルギー・排出。シナリオ（IPCC の SSP など）か、プレイヤーの選択で動く |

**答え合わせ**: モデルを46億年前から動かし、いまの年表（全球凍結の時期、大酸化、石炭紀の酸素、K-Pg 後の回復、現代の CO2 など）と比べる。合わないところは係数を調整し、どこまで合うかを画面で見せる（「モデル」と「記録」の2本の線）。

## 4. 未来

モデルを進めるだけだと遠い未来ほど不確かになるので、文献の予測をいくつかの「錨」として重ねる。

| いつ | 何が起きる（研究の予測） |
|---|---|
| 〜2100年 | 排出シナリオしだいで +1.5〜4℃ 前後（IPCC AR6） |
| 〜1万年 | 海面上昇が続く。グリーンランド・南極の氷が減る |
| 〜10万年 | 人間が出した CO2 の大半が風化で吸収されるまで続く。次の氷期は大きく遅れる |
| 〜2.5億年後 | 大陸が再び集まり、次の超大陸（パンゲア・ウルティマなど）。内陸は哺乳類にとって暑すぎる可能性 |
| 〜6億〜10億年後 | 太陽が明るくなり、風化が進みすぎて CO2 が減る → 多くの植物が光合成できなくなる |
| 〜10億〜15億年後 | 海が蒸発し始める |
| 〜50億年後 | 太陽が赤色巨星になる |

画面では、タイムスライダーの「現在」の右側に「未来（予測）」の区間を足す。色や表示で、記録と予測をはっきり分ける。

## 5. IF（プレイヤーが手を入れる）

- 例: 「小天体が地球をそれる」「火山活動を10倍に」「大陸を極に集める」「酸素を出す生物が現れない」「産業革命が起きない／2倍の排出」。
- 手を入れた時点からモデルを走らせ直し、記録の世界と並べて見られるようにする（左右分割、または「本来の世界」に戻すボタン）。
- **生き物の扱い**: 進化は偶然に大きく左右されるので、「どの種が現れるか」は予測できない。そこで、いるかどうかを決めるのは「生き物のグループ」と「生態系の空き（大きな草食、木の上、海の捕食者など）」にする。空いた席を、そのグループの部品で組み立てた**想像の生き物**が埋める。例えば恐竜が絶滅しなければ、哺乳類は小さいままで、大きな草食の席は恐竜が持ち続ける。
- 画面には、根拠の強さを常に表示する。「記録」「モデル」「想像」の3段階。

## 6. ゲームにするなら

- **ねらいを与える型**: 「人類が現れる世界を作れ」「全球凍結を一度も起こさずに複雑な生命を」「人類が1万年続く未来を」。
- **介入の数を制限する型**: 手を入れられるのは3回まで。どこで使うかを考えさせる。
- **観察型**: ねらいはなく、IFを試して世界の分かれ方を見る（図鑑のように、出会った世界と生き物を集める）。
