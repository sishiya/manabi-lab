# 錯覚の美術館 企画書

最終更新: 2026-10-05

## きっかけ

ユーザーの希望:「世界各国の有名どころだったりマイナーなだまし絵とか、人間の認知特性をついた不思議な体験ができるアプリを作りたい。長さが同じなのに違うように見えるとか、中心をみていると周囲の点が見えなくなるとか、最初ノイズを聞いて意味のある音にきこえないがテキストをインプットしてから再度きくと意味のある言葉にきこえるとか、そういうの。」

## 何を作るか

- **美術館の形**: 入口（ホーム）に部屋（分類）ごとの展示カードが並ぶ。カードを選ぶと展示室。
- **展示室の流れ**: ① 見る（やり方の指示つき）→ ② たしかめる（答え合わせ・自分で測る・条件を変える）→ ③ なぜ？（しくみ。**確かなこと／有力な説／まだ分からない**を分けて書く）。
- **見つけた人・国・年**を各展示に書く（「世界各国」の希望）。有名なものと、あまり知られていないもの（最近の「錯覚コンテスト」の受賞作の原理など）をまぜる。
- **自分で測る**: 長さ・大きさの錯視は、比べる図形を自分で調節して「同じに見える」所を決めると、自分の目がどれだけだまされたか（%）が出る。研究で知られている目安も並べる（目安と明記）。
- **条件を変える**: スライダーで錯視が強くなる・消える条件を探せる（例: カフェウォールのすき間を黒にすると消える）。
- 絵はすべて**プログラムで描く**（Canvas 2D。必要なら3Dに Three.js）。有名な作品の画像をそのまま写さない（原理は自由に使えるが、作品の絵には著作権がある）。原理のもとになった人の名前は書く。
- 音の展示は Web Audio でその場で作る。声が必要なもの（ノイズの中から言葉が聞こえる）は、使ってよい声で作った音を加工して入れる（下の「音声の出どころ」）。

## 段階

| 段階 | 内容 |
|---|---|
| **A** | 美術館の土台（ホーム・展示室・前後の移動・測る仕組み・このアプリについて）と、ユーザーの例を中心に10展示: ミュラー・リヤー、エビングハウス、ポンゾ（測る）／トロクスラー、運動誘発盲、ライラック・チェイサー（消える）／チェッカーシャドウ、ヘルマン・きらめき格子、カフェウォール／カニッツァ、周辺ドリフト。 |
| **B** | 音の部屋: ノイズの中のことば（ユーザーの例。下の「音声の出どころ」を決めてから）、シェパード音、ミッシング・ファンダメンタル。 |
| C | ふたつに見える・答えを見たら戻れない: ネッカー、ルビンの壺、回るシルエット、二値画像。 |

| F | 仕上げ: スマホ、サムネイル・入口（まなびラボ）に載せる、公開。 |

## 音声の出どころ（段階Bの前に決める）

「ノイズの中のことば」には元になる声が要る。実在の人の声は使わない（RULES 7章）。候補:
1. Windows の音声合成（日本語の声が入っている）で作って加工する。手軽だが、合成音声を公開物に入れてよいかの条件を確かめる必要がある。
2. ライセンスがはっきりした音声合成（Open JTalk と HTS の声「mei」など、CC BY 系）で作る。表記が要る。
3. 声の特徴（フォルマント）を自分で並べて正弦波音声を作る。権利の心配はないが、聞き取れる質にできるかは試してみないと分からない。

## やらないこと（いまは）

- 有名作品の画像をそのまま載せる（著作権）。
- 実在の人の顔・声の素材。
- 画面の広い範囲の速い点滅（RULES 9章）。点滅を使う展示は小さい範囲・ゆっくりにして、ボタンで始める。
- 目の病気の判断。注意書きを出す。
