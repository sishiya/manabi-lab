## 展示の書き方（defEx の項目）
- `id` `room` `title` `en` `who` `where` `year`（数なら「年」がつく。文字列ならそのまま）`lead` `bg`（ステージの枠の色にも使う）
- `steps`: やってみようの文（配列）
- `controls`: `{type:'range', id, label, min, max, step, val, fmt}` ／ `{type:'toggle', id, label, val}` ／ `{type:'choice', id, label, opts:[[値,表示]], val}` ／ `{type:'timer', id, start, lap}`（見つめはじめてから「消えた！」までの秒）。値は `st[id]` に入る。
- `init(st)`: 状態の初期値。サムネイルもこの状態で描く。
- `draw(g, S, t, st)`: 1辺 S（CSS px）の正方形に描く。`t` は展示を開いてからの秒。`g.canvas.width / S` で画素の倍率が分かる。
- `anim(st)`: true の間だけ毎フレーム描く（そうでないときは操作したときだけ）。
- `measure`: `{q, label, min, max, step, start(st), result(st)→{big, text, typ}}`。スライダーは `st.adj`。`start` で毎回ランダムな位置から始める（アンカーを避ける）。「同じに見えた」で `st.reveal = true`（補助線）。
- `tap(x, y, st, ctx)`: 0〜1 の座標。返した文字をステージの下に4秒出す。
- `why`: `[['sure'|'theory'|'open', 文]]`（確か／説／未解明）、`facts`: こぼれ話。

## しくみ・数値のメモ
- **チェッカーシャドウ**: 明マス 205、暗マス 123、影の中心は ×0.6（205×0.6＝123）。A（0,2）は影の外の暗マス、B（3,2）は影の芯（`CORE` 0.85 以内）の明マス。どちらも RGB(123,123,123) になることを画素で確かめた（2026-10-06）。影の範囲を広げると A のとなりまで暗くなって錯覚が弱まるので注意。
- **測る**の結果 = `(1/adj − 1)×100`（比べる側を何倍にしたら同じに見えたか）。研究の値は「目安」として幅で書いた（図の形で大きく変わるため）。
- **点滅**: ライラック・チェイサーはボタンで始める。1つの円はキャンバスの約1.5%、1つの円が消えるのは 1周（12個 ÷ 速さ）に1回＝最大 1回/秒なので RULES 9章の基準より十分小さい。運動誘発盲の見つめる点は、元の実験と違って点滅させていない。
- **周辺ドリフト**: 黒→濃い色→白→薄い色（幅 0.32・0.18・0.32・0.18）。「並びを変える」は 黒→白→濃い→薄い。北岡さんの作品の絵は写していない（原理だけ）。

## ハマったところ
- 展示室を開いた直後は `#stageWrap` の幅がまだ 0 のことがあり、ステージが最小の 200px になった → ResizeObserver で測り直す。
- Browser ペインのスクリーンショットが時間切れになることがある。ほかの会話のサーバー（8766）には届かないので、自分で `apps` を起動する。

## 確認のしかた（変更のたびに）
1. 入口: 部屋ごとにカードとサムネイルが出る。コンソールに例外がない（`window.__ilErr` が undefined）。
2. 全展示を `#id` で開き、絵が出る・ステージがパネルの横いっぱいの大きさになる。
3. 測る（ミュラー・リヤー・エビングハウス・ポンゾ）: 「同じに見えた」で結果と赤い補助線、「もう一回」で消えて始めの長さが変わる。
4. チェッカー: A と B をタップすると、どちらも RGB(123, 123, 123)。「帯でつなぐ」「まわりを隠す」。
5. トロクスラー: 「見つめはじめる」→「消えた！」で秒が出る。ライラック: 「動かす」で1つずつ消える。運動誘発盲: 「模様を止める」。
6. スマホ幅（375px）で横にはみ出さない（`document.documentElement.scrollWidth` = 375）。
