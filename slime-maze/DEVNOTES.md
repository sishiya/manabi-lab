## しくみ
- 迷路: 12×9 マス。深さ優先で掘ったあと、残った壁の 12% をぬいて道を何通りにも。左上と右下のいちばん短い道が1本だけの迷路を種を進めて探す（`makeGood`。同じ長さの道が2本あると、μ=1 ではどちらも残りうるため。批判役の指摘）。
- モデル（Tero・小林・中垣 2007、式 (5)(6)、無次元）: Q = D/L (p_i − p_j)、入口から I0=1 が入り出口から出る、dD/dt = |Q| − D（μ=1）。半陰的に D ← (D + δt|Q|)/(1+δt)、δt = 0.05。はじめの D は [0.5, 1.0] の一様乱数。辺の長さ L = 1。
- 圧力は、入口と管でつながった節だけで、出口を 0 に固定して前処理（対角）つき共役勾配法で解く（論文は ICCG）。前の答えから始める。
- D は式どおり 0 にしない（下限 FLOOR = 1e-9 は行列のため）。だから道をふさぐと、細く残った管がまた太る（批判役の指摘で「消えたら生えない」をやめた）。壁で閉じた通路は D = 0、ひらいた通路は D = FLOOR から。
- 管の絵: 太さ ∝ D^(1/4)（D は半径の4乗に比例）。D が 1e-2 より細いと薄くしはじめ、1e-4 で見えない（`Draw.alpha`）。
- 「管の長さ」= Σ D·L / I0。μ=1 で落ち着くと最短の道の長さになる（最短の道の D → 1）。「いちばん短い道だけが残りました」は、落ち着いて（太さの変わる速さの最大 < 3e-4）、管の長さと最短の長さの差が 0.5 未満のとき。
- 往復流: 1.5秒ごとに入口と出口を入れかえる（`s.swap`）。|Q| は変わらないので太さの変わり方は同じ（Tero 2007 の「その瞬間、一方のエサが入口」）。粒の速さ = 流量 ÷ 断面（D^(1/2)）。
- 時間はすべて本物の時間（時間 h）。速さボタンで「1秒＝10分」「1秒＝1時間」（`SPEEDS`）。止めるのは「止める」を押したときだけで、落ち着いても動きつづける（2026-11-22 ユーザー「常に再生しつづけるように」）。画面を離れれば rAF をブラウザが止める。
- はじめ: エサは1つ（左上）、粘菌は迷路のまん中のかけら1つ（2026-11-22 ユーザーの希望。実験はあちこちにかけらを置いた → 画面の「簡単にしたところ」に書いた）。迷路が埋まったら「空いたマスを押して、エサをもう1つ置いてみましょう」。エサは2つまで。
- 伸びる（`grow`）: 粘菌がいるマスから、開いた通路を連続して伸びる。速さ 2 cm/時（Patino-Ramirez ほか 2019「1時間に数センチ」から選んだ値）、1マス 5 mm（仮定）→ 4マス/時。通路ごとに ±25% のばらつき（演出）。両はしから伸びた長さ fa + fb が 1 で管になり、はじめの D は [0.5, 1.0]。まん中から迷路が埋まるまで約4〜5時間。エサの方向は知らない（走化性なし）。壁をひらくと、となりに粘菌がいればまた伸びて入る。
- 管の太り・やせはエサが2つとも粘菌にふれてから（`flowing`）。モデルの時間 1 = 1時間（Tero 2007「管は数時間でこわれ作り直される」から決めた仮定）。エサを足してから落ち着くまで、多くの迷路で約20〜60時間（tools/verify.js）。
- 先端の見た目: 伸びかけの管＋先端の扇のようなぼんやりした縁（放射状のグラデーション）＋着いたばかりのマスの膜（約1時間で消える）。どれも演出。2026-11-22 ユーザー「伸びていくところがデジタルすぎる」→ 1マスずつ現れる形をやめて、本物の速さで連続して伸びる形にした。
- 「いちばん短い道だけが残りました」: 落ち着いて（太さの変わる速さの最大 < 1e-3 /時）、管の長さと最短の長さの差が 0.5 未満。
