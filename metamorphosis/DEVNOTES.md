## しくみ

### 座標と体の形
- 単位は mm、x は頭→しっぽ（頭が左）、y は上が背中。
- どの時期の体も**同じ15本の節の境目**で表す: s = 0 頭の先、1 頭｜前胸、2 前胸｜中胸、3 中胸｜後胸、4 後胸｜腹1、5〜13 腹1〜9の終わり、14 しっぽの先。各境目に X（位置）・D（背側の半分の高さ）・V（腹側）・Y（背骨の高さ）。
- 器官は (s, v)（v = +1 背の表面、−1 腹の表面）で置く。体の形が変わると器官もいっしょに動く。幼虫と成虫で形が違う器官は、幼虫用 L と成虫用 A の点を持ち、器官ごとの進み具合（`gutM` など）で混ぜる。
- 外側の形 `outerKey`: 幼虫 → （ワンダリングで）前蛹 → （脱皮の数時間で）蛹 → 羽化で成虫（腹がふくらんだ ADULT_WET から、翅をのばす間に ADULT へ）。
- 器官用の形 `innerKey`: 蛹の間だけ PUPA → PHARATE（蛹の中の成虫の体。成虫の形をやや大きくし、背側へ1.1mm 上げた）へ 1.5〜7日で寄っていく。翅・脚・触角・口吻のケースは蛹の皮の下にあるので外側の形 `S.O` に置く。
- 大きさ: 終齢幼虫 48.5mm、蛹 28.5mm、成虫の体 25mm、前翅 44mm（蛹の中では 15mm、翅原基は 0.4〜1.8mm）。

### 時間
- t は蛹になってからの日数（−3〜11.5）。羽化 t = 10。スライダーは区分ごとの一次式（−3〜10 が78%、羽化〜30分が9%、〜3時間が6%、〜1.5日が7%）。グラフの横軸も同じ。
- 時期の割りふりの出どころ（目安）: 蛹約10日＝ナミアゲハ夏型・25℃前後。器官ごとの時期はタバコスズメガ・カイコ・ヒメアカタテハ・ショウジョウバエの研究をあてはめた。羽化から翅がのびきるまで約20分、乾くまで1〜2時間。腹の節の間の筋肉は羽化後約1日で壊れる（タバコスズメガ）。
- ホルモンは量の形だけ（0〜1）。エクジソン: 食べるのをやめる小さな山（−2.4）、前蛹の山（−0.95）、蛹の大きな山（1〜8.6、ピーク3.4〜5.2）。幼若ホルモン: 終齢の初めでほぼ0、前蛹に小さな山、成虫で再び出る（推定）。遺伝子: *Kr-h1* は幼若ホルモンに合わせる、*broad* は −2.6〜1.8、*E93* は −0.4 から上がる。

### 描き方
- 壊れる器官 `breakingTube()`: 管を一定間隔の点に分け、点ごとに乱数でずらした進み具合 f で「つながっている → 3つのかけら（アポトーシス小体）→ 消える」。かけらは `S.debris` に入り、血球（`hemocytes()`、最大70個）がそこに集まる。すべて t と実時間 `clock` だけで決まるので、スライダーを戻しても同じ絵になる（粒の状態は持たない）。
- 中腸の内側の層は、かけらが腸の真ん中へ寄ってかたまり（イエローボディ）になり、3〜8日で腸の後ろへ、羽化後30〜50分で蛹便として出る。
- 翅: 終齢までは胸の中の小さなふくろ（翅原基）。−1.2〜−0.1 日で裏返って蛹の翅の形へ。翅の座標は (u, w)（u は前のふち、w はうしろへ負）で、`g.transform` でまるごと置く。蛹では付け根が胸の横の高い所、前のふちが腹側へ斜めに下りる（体の横に寝る）。後ろ翅は蛹では `hf = 0.5` に縮めて前翅の下に隠す。羽化で背の上へ回し（`mir` を −1→1 にして裏返す）、3〜22分で 15→44mm に広げ、しわ（`crumple`）を消す。
- 翅の色の順: 組織（2日まで）→ 鱗粉の細胞の列（2〜5.5日）→ 白 → 黄（6.3〜7.6日）→ 黒（7.4〜9日）→ 青・オレンジの点（8.2〜9.2日）。黒が最後なのはタテハチョウなどの研究から。アゲハでの順は推定。模様は簡単にしたもの（演出）。
- カメラ: その時間に描くもの全部の外枠に合わせる（t だけで決まるのでなめらか）。透かして見る成虫は体に寄せ、翅の上は画面の外へ出す（`sceneBox` の `wk`）。ものさしは 1・2・5・10・20・50mm から画面上 90px に近いもの。
- 名前のラベルは、いま変化している器官（`busy`）を先に置き、重なるものは省く。

## 確認のしかた（変更のたびに）
1. コンソールにエラーがない。`__mm.err` が undefined。
2. 全時間を通してエラーなし（両方の見かたで）:
   `for (const see of [true,false]) { __mm.VIEW.see=see; for(let i=0;i<=400;i++){ __mm.setT(uToT(i/400)); if(__mm.err) throw __mm.err; } } __mm.VIEW.see=true`
3. 透かして見る: t = −2.8（幼虫。腸に葉、黄色の脂肪体、胸に翅原基）、−0.5（前蛹。絹糸腺・筋肉がかけらになり血球が集まる。翅が体の横に出てくる）、1（蛹。中腸の内側の層がかたまりに）、5.5（飛ぶ筋肉・複眼・成虫の皮の点線）、9（翅に黒い模様）、10.004（羽化。翅はしわで小さい）、10.03（翅が広がり、体に寄った画面）、11（蛹便のしずく、腹の節の間の筋肉が消える）。翅が蛹の背中から飛び出していないこと。
4. 外から見る: 幼虫（緑・目玉もよう・腹脚）、蛹 4日（緑のまま）、9.8日（黒っぽく翅が透ける）、成虫（翅を立てたチョウ）。
5. 器官をタップ／一覧を押す → 説明カード。× と Esc で閉じる。
6. グラフを押す・ドラッグ → 時間が移る。再生（`frame(60)` で t が進む）。
7. スマホ（375×812）: 縦に積まれ、時間の帯が2段、ものさしが帯に隠れない。

## ハマったところ
- `-x ** 2` は JS では構文エラー（`-(x ** 2)` と書く）。1つのファイルが読めないと、あとのファイルが次々に「未定義」で止まる。
- `mixHex()` の結果（`rgb(...)`）をもう一度 `mixHex()` に入れると色が NaN になり、塗りが前の色（黒）のままになった。`hexRgb()` が `rgb()` も読めるようにした。
- 翅を「付け根から腹側へ」の向きで置くと、翅の本体（前のふちのうしろ側）が背中から飛び出す。付け根を胸の横の高い所にして、前のふちを腹側へ斜めに下ろす向きにした。
