## しくみ

### 座標と体の形
- 単位は「模型の単位」（1 = `UNIT_MM` = 1.85 mm）。ものさしは mm に直して描く。v1 の器官の大きさをそのまま使えるようにするため（タバコスズメガは v1 のアゲハのほぼ 1.85 倍）。
- 実物の大きさ（目安）: 終齢幼虫 約90mm（49単位）、蛹 約52mm（28.4単位）、成虫の体 約48mm（26.2単位）、前翅 約50mm（27単位、蛹の中では 14単位）。
- どの時期の体も**同じ15本の節の境目**で表す: s = 0 頭の先、1 頭｜前胸、2 前胸｜中胸、3 中胸｜後胸、4 後胸｜腹1、5〜13 腹1〜9の終わり、14 しっぽの先。各境目に X・D（背側の半分の高さ）・V（腹側）・Y（背骨の高さ）。
- 器官は (s, v)（v = +1 背の表面、−1 腹の表面）で置く。幼虫用 L と成虫用 A の点を持つ器官は、器官ごとの進み具合（`gutM` など）で混ぜる。
- 外側の形 `outerKey`: 幼虫 → （W0〜土にもぐるまでに）前蛹 → （脱皮で）蛹 → 羽化で成虫（ADULT_WET から翅を広げる間に ADULT へ）。器官用の形 `innerKey`: 蛹の間だけ PUPA → PHARATE（蛹の中の成虫の体）へ、アポリシス（P2）から P9 にかけて寄っていく。翅・脚・触角・口吻のケースは蛹の皮の下にあるので外側の形 `S.O` に置く。

### 時間（`TL` が全部）
- t は蛹になった日（P0）からの日数。W0（ワンダリング）= −4、羽化 = 18（研究室で 18〜20日。18日目の夜という Truman・Schwartz の記述に合わせた）。スライダーは −6〜18 が76%、羽化〜15分（殻から出て土から出る）が8%、〜100分が7%、〜6時間が3%、〜1.5日が6%。
- `TL` の各行に sure（タバコスズメガで日付つきで分かっている）／est（目安）を書いた。説明文の札もそれに合わせる。主な数値の出どころは PLAN.md の「主な出どころ」。
- ホルモンは量の形だけ（0〜1）。エクジソン: コミットメントの小山（−5.2）、前蛹の山（W1〜P0）、成虫の山（P2.5 から上がり P7〜9 で最大、P10 で急に下がり P14 で低い）。幼若ホルモン: 終齢の初めにほぼ0、前蛹に小山、成虫で再び（推定）。遺伝子: *Kr-h1* は幼若ホルモンに合わせる、*broad* はコミットメントから P2 ごろまで、*E93* は前蛹の終わりから。

### 描き方
- 壊れる器官 `breakingTube()`: 管を点に分け、点ごとに乱数でずらした進み具合で「つながっている → 3つのかけら → 消える」。かけらは `S.debris` に入り、血球が集まる。すべて t と実時間 `clock` だけで決まるので、スライダーを戻しても同じ絵になる。
- 中腸の内側の層 → かたまり（イエローボディ）→ P9〜16 で腸の後ろへ → P14〜18 で直腸の袋がふくらむ → 羽化後 80〜105分に蛹便として出る（出す時刻は目安）。
- 翅: 終齢までは胸の中の小さなふくろ。`EVERT`（−1.6〜−0.1）で裏返って蛹の翅の形へ。(u, w) 座標（u は前のふち、w はうしろへ負）を `g.transform` で置く。蛹では付け根が胸の横の高い所、前のふちが腹側へ斜めに下りる。**羽化後は蛹のときと同じ向き・場所のまま 15〜70分で 14→27単位に広げ**、70〜85分に付け根で回して屋根の形にたたむ（`mir` を −1→1。「約80分で広げ終えて付け根で回す」という観察に合わせた）。外から見た蛹にも翅のケースを翅の輪かくそのもので描くので、蛹のどこが翅になるかが分かる（2026-10-06 ユーザーの指摘「翅が何もないところから現れる」への対応）。
- 翅の色: 組織 → 鱗粉の細胞の列（P3〜5）→ 白 → 灰褐色（P12.5〜15.5）→ 線と点（P14.5〜16.8）。色の日は目安。模様は簡単にしたもの。
- 羽化（`TL.emerge` 0〜8分、`TL.dig` 8〜14分）: 外側の形は PHARATE（蛹の中にいた成虫）から始まり、ADULT_WET に変わりながら `EMERGE_DX` だけ前へ動く（器官の形 `innerKey` は羽化の前後とも PHARATE なので切れ目がない）。翅・脚・触角・口吻は `S.Oe`（`appendKey`: 蛹 → はい出る成虫）に置くので、蛹のときの位置から連続して動く。殻 `pupalCase()` は蛹の皮の絵（`pupaSkin` を、羽化直前の蛹の形で）を、頭側（s < 3.3）のふたと後ろの筒に切り分け、ふたを腹側の付け根で回して開く。殻と土の部屋は 8〜14分で消える（成虫が地上へ出る）。外から見るでは殻を成虫の上に描く（筒の中の部分は隠れる）。透かして見るでは薄く後ろに。2026-10-06 ユーザーの指摘「蛹と羽化の切りかえが唐突」への対応。
- 割って見る（`drawCutOpen()`）: 縦に割ったとき人の目にどう見えるか。器官は同じ模式図の形を本物に近い色（`CUR.cut` のとき `C()` が `REAL[id]()` を返す）で別のキャンバスに描き、体の輪かくで切り抜き、①どろっとした中身 `goo()`（クリーム色のかたまり、蛹の初めほど多い `soup()`）②体液のにごり `murk()`（体液の色を重ねる。蛹の初めほど濃い）③つや `gloss()` ④つぶつぶの質感 `grainPattern()` を重ね、少しぼかして本画面へ。体の外に出る部分（幼虫の腹脚・角、成虫の脚・触角・口吻・翅）は切り抜かずに描く。皮の切り口は太い線。血球・成長のきらめき・名前のラベルは出さない（押せば説明カードは出る）。根拠と札は `REAL_NOTE`（どろっとした中身・体液の緑・気管の銀白・神経の白・脂肪体のクリーム色は確か、ほかの色は目安、質感は演出）。2026-10-06 ユーザーの希望「外から見るの亜種、人間の目からどう見えるか。質感を出してもいい」。
- カメラ: その時間に描くもの全部の外枠に合わせる（t だけで決まる）。ものさしは 1・2・5・10・20・50mm から画面上 90px に近いもの。
- 名前のラベルは、いま変化している器官（`busy`）を先に置き、重なるものは省く。

## 確認のしかた（変更のたびに）
1. コンソールにエラーがない。`__mm.err` が undefined。
2. 全時間を3つの見かたで通してエラーなし:
   `for (const m of ['in','cut','out']) { __mm.VIEW.mode=m; for(let i=0;i<=300;i++){ __mm.setT(uToT(i/300)); if(__mm.err) throw __mm.err; } } __mm.VIEW.mode='in'`
3. 透かして見る: t = −5（幼虫。腸に葉、脂肪体、胸に翅原基、角）、−2（前蛹・土の中の部屋。唾液腺・腸の内側がかけらに）、1.5（筋肉が壊れ血球が集まる、口吻のケースの輪）、8（飛ぶ筋肉・空気の袋・成虫の皮の点線）、16（翅が灰色に）、18 + 20分（翅は蛹のときの場所で小さくしわ）、18 + 60分（同じ向きで大きく）、18.5（屋根の形にたたむ、蛹便）、19.3（腹の節の間の筋肉が消える）。翅が蛹の背中から飛び出していないこと。
4. 割って見る: 幼虫で体液が緑・腸が緑・気管が白、−1〜4日はクリーム色のかたまりでにごってどろっと見える、15日は翅や筋肉の形が見える、成虫は脚・触角が切り抜かれずに出る。名前のラベルは出ず、押すと説明。右のパネルに「割って見ると」。
5. 外から見る: 幼虫（緑、白い斜めの線7本、赤い先の角）、ワンダリングで暗くなり背中に赤っぽい線、蛹（緑→茶色、持ち手、翅のケースの輪かく）、羽化 0〜8分で殻の頭側のふたが開いて成虫が前へはい出る（殻は残り、8〜14分で土の部屋ごと消える）、そのあと翅のケースと同じ場所で翅が広がる、成虫（灰褐色の屋根形の翅）。
6. 器官をタップ／一覧を押す → 説明カード。× と Esc で閉じる。グラフを押す・ドラッグ → 時間が移る。
7. スマホ（375×812）: 縦に積まれ、時間の帯が2段、ものさしが帯に隠れない。
8. 入口に載せているので、push 前に Pages の互換モード（doctype なし）でも同じに見えるか（RULES 8.1）。

## ハマったところ
- `-x ** 2` は JS では構文エラー（`-(x ** 2)` と書く）。1つのファイルが読めないと、あとのファイルが次々に「未定義」で止まる。
- `mixHex()` の結果（`rgb(...)`）をもう一度 `mixHex()` に入れると NaN になった。`hexRgb()` が `rgb()` も読めるようにした。
- 翅を「付け根から腹側へ」の向きで置くと、翅の本体が背中から飛び出す。付け根を胸の横の高い所にして、前のふちを腹側へ斜めに下ろした。
- 羽化直後に翅を一気に成虫の向きへ回すと、外から見て「何もない所から翅が現れる」ように見えた（ユーザーの指摘）。蛹の向きのまま広げてから回すようにした。
