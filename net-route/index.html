    • 「図」の線の長さは本物と合っていません（線の数字が長さ）。「地球儀」は本当の緯度経度に置き、線は大円（いちばん短い道）で描いています。四角は重ならないよう少しずらしています。
    このアプリについて

    学習用に簡単にした計算のモデルです。ブラウザからは本物の経路を測れない（traceroute が打てない）ので、あなたの回線を測っているわけではありません。

    計算していること

    • 光ファイバーの中の光の速さ＝真空の光の速さ ÷ 屈折率 1.4675（光の包みが進む速さを決める値・1310nm）＝ 約20万km/秒（1km で約4.9マイクロ秒）。WiFi は空気中なので真空とほぼ同じ。
    • 線の長さ: 陸揚げ局などの緯度経度からいちばん短い道（大円距離）を出し、本物のケーブルは曲がっているので海は 1.1 倍・陸は 1.3 倍にした（推定）。家からプロバイダ・まちの中の長さは仮定。
    • 中継ごとに、送り出す時間（大きさ ÷ 回線の速さ）と処理の時間（0.02ミリ秒・推定）。WiFi は順番待ち（平均2ミリ秒・推定）。混ませた中継は平均30ミリ秒待ち、8%が捨てられる（推定・演出に近い）。
    • 流れ: 名前引き（DNS。プロバイダが答えを覚えている前提。返事が5秒来なければもう1回、それでもだめならあきらめる＝glibc の初めの値）→ TCP のあいさつ → TLS 1.3 のかぎ → ページをください → ページ（60KB を 1460 バイトずつ・42個）。
    • 送る数は最初10個、「受けとったよ」が1つ返るたびに1つ増やす（スロースタート）。返事が来ないと待って送り直し、送る数を1にもどす。待ち時間は最初1秒、往復を測ったら往復の3倍（下限0.2秒）で、時間切れのたびに2倍にのばす。

    遊びについて

    • サーバーを置く: 置いた所から、いちばん近い2つの中継へ「いちばん短い道×1.2」の仮のケーブルでつなぎます（推定。本物のケーブルの地図ではありません）。
    • 月・火星のサーバーは仮のものです。長野（佐久のあたり）の大きなアンテナから電波で送ります（真空の光の速さ）。
    • 距離は、月は平均 38万4400km。火星は 2003年の大接近 5576万km と、いちばん遠いとき 約4億100万km。
    • 火星は往復が127秒をこえるので、ふつうの TCP はあいさつの途中であきらめます。本物の宇宙の通信は、返事を待たずに預けて運ぶしくみ（DTN）を使います。ping はあきらめる決まりがないので、往復ぶん待てば返事が来ます。
    • 静止衛星: 赤道の上 3万5786km。家のアンテナと地上の局（ここでは IX においた）から衛星までのまっすぐの距離を計算しました。低い軌道の衛星: 上空 約550km、ななめに約700km（推定）。どちらも電波が進む時間だけで、衛星の中の順番待ちなどは入れていません。
    • 伝書鳩: RFC 1149（1990年4月1日のじょうだんの決まり）。2001年にノルウェーのベルゲンで、本当に鳩で ping を送った試験がありました。
    • その試験では9つ送って4つ返り、往復の平均は約87分（約5km・手わたしの時間こみ）。ここでは片道をその半分、なくなる割合を片道 33% にしました。
    • 鳩では名前引きが10秒であきらめるので、ページは開けません。ping は返ってくることがあります。
    • 本当にあった切断: 道とケーブルは例です。2006年の台湾沖の地震は「ルソン海峡を通る2本」を切り、のこった予備の道（釜山まわりの陸の道・例）は混む（推定）ことにしました。2022年のトンガは、外へつながる1本だけのケーブル（827km）を切ります。

    簡単にしたところ

    • 道と陸揚げ局は例です（本物のケーブルの地図を写したものではありません）。地球儀では線を大円で描いていますが、本物の海底ケーブルは海の深さや地形をよけて曲がっています。家・プロバイダの位置は図のための仮の場所です。
    • 本物の道は、会社どうしの約束（BGP）で決まり、いちばん早い道とは限りません。ここでは各中継が「いまいちばん早い道」を選び、ケーブルが切れるとすぐ組み直します。本物は組み直しに数十秒〜数分かかることもあります。
    • 「受けとったよ」は1つずつ返し、送り直しは時間切れのときだけにしました（本物はもっと工夫があります）。あいさつ（SYN）は6回送り直して返事がなければ、約127秒であきらめます（Linux の初めの値）。待ち時間の下限は、RFC の1秒ではなく Linux と同じ0.2秒にしました。
    • ページは HTML 1つ（60KB の例）だけ。本物のページは画像やスクリプトなど何十ものファイルを読みます。サーバーがページを作る時間・暗号の計算・光回線の上りの順番待ちなどは入れていないので、本物はもっとかかります。
    • 最近は、あいさつと暗号を1往復にまとめる HTTP/3（QUIC）や、2回目からの近道（つなぎっぱなし・TLS の再開）があり、いつも4〜5往復かかるわけではありません。ここは基本の形だけです。

    おもな出どころ

    • 光ファイバーの屈折率 1.4675（長い距離用のシングルモード光ファイバー・1310nm）: Chaudhry, Yanikomeroglu (2020) Free Space Optics for Next-Generation Satellite Networks（arXiv）。海底ケーブルでよく使う 1550nm でもほぼ同じ（ちがいは 0.1% より小さい）。
    • TCP: RFC 9293（あいさつ）、RFC 6928（最初に送る数 10）、RFC 5681（スロースタート）、RFC 6298（送り直しの待ち時間）
    • TLS 1.3: RFC 8446。DNS: RFC 1034・RFC 1035
    • 道の組み直しに時間がかかること: Labovitz, Ahuja, Bose, Jahanian (2000) Delayed Internet Routing Convergence（ACM SIGCOMM）
    • 伝書鳩: RFC 1149（Waitzman 1990）。ベルゲンの試験（2001年4月28日）: Bergen Linux User Group と、そのときの ping の結果の記録
    • あいさつの送り直しの回数: Linux の tcp(7) の tcp_syn_retries（初めの値 6・約127秒）。名前引き: resolv.conf(5) の timeout（5秒）・attempts（2回）
    • 2006年の台湾沖の地震: Submarine Networks（8つのケーブル・18か所）、RIPE 54 の発表「Quaking」（ルソン海峡を両方の道が通っていた）
    • 2022年のトンガ: AP・Reuters の報道（827km のケーブルのうち約90km を取りかえ、約5週間後に復旧）
    • 月までの平均の距離 38万4400km、火星のいちばん近いとき（2003年）5576万km・いちばん遠いとき 約4億100万km: NASA。静止衛星の高さ 3万5786km
    • 地球儀の海岸線: Natural Earth 1:50m（パブリックドメイン）を間引いて使っています。
