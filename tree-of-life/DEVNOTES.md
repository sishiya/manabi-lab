## しくみ
- **上のほう**（約650のまとまり）: COL の最新版（API `dataset/3LR`）の界〜綱を全部集める → Open Tree の `tnrs/match_names` で同じ学名を探す → `tree_of_life/induced_subtree` で枝分かれの形 → Open Tree で見つからないものは COL の親の下へ。
  - COL の門のすぐ下に属などがならぶもの（所属のはっきりしない属。子嚢菌門に約2千）は入れず、しるし 1（開いたら COL から読む）。
  - COL の Animalia = Open Tree の Metazoa、Plantae = Archaeplastida（`ALIAS`。Archaeplastida は合成系統樹で分かれていて使えなかった）。
  - COL だけのまとまりで子の一部が別の場所へ行ったもの（植物界・細菌の門など）は「（一部）」、種の数は残りの合計。
  - 名前のないふしで子が1つのものはまとめる。'h2007-2' のような Open Tree の作業用の名前・'Craniata (subphylum in Deuterostomia)' のかっこは消す。種が0のまとまり（COL の枠だけ）は入れない。
- **綱より下**: 開いたときに `tree/{id}/children`（100件ずつ、残りは「あと N 件」）。種の数の多い順。和名は Wikidata SPARQL（P225 = 学名）で80件ずつ。
- **検索**: 日本語 → Wikidata `wbsearchentities`（学名 P225 のある項目だけ）→ COL で学名ぴったり。ローマ字 → COL `nameusage/suggest`。選ぶと `classification` で道すじを取り、木にある祖先から下を順に読んで開く（1ページ目にいないときはその1つだけ足す）。
- **重ならないように**（v010）: 開いたふしの名前は2段ごと枝の上に持ち上げるので、子が1つなど少ないと1つ上の行の名前にかかっていた（ゾウ目を開くと海牛目に重なる）。配置で、名前の上はしが1つ上の行の名前の下はし（≒ その枝を置きはじめた高さ − 行の高さ + 24）より上になるときは、その枝ごと下へずらす。788 の名前を開いて重なり 0 を確かめた。
- **描き方**: 葉を上から1行（34px）、親は子の真ん中。名前は2段（1段め: 札＋和名、2段め: 小さめの学名と種の数。和名がなければ1段めが学名）で、幅は2段のうち長いほう。名前のあるふしは名前の幅だけ右へ（開いていれば2段ごと枝の上）。名前のないふしは小さな点で、いつも開いている。点の大きさは種の数の log。色は段（界・門・綱・目・科・属・種・枝）。
- **枝とアニメ**（2026-10-15 v003）: 枝は分かれ目から子へのベジェ曲線、太さは種の数の log（`branchW`）。見た目の位置 ax/ay/ajx は決めた位置 x/y/jx へ指数で近づく（`step`、時定数 約0.09秒）。新しく見えたふしは親の分かれ目から出てきて、うすい所から濃くなる。閉じると子は `leaving` に入り、0.3秒で親へ加速しながら吸いこまれ（t³）、着いたら親の点が小さく弾む（`pulse`）。開いたときも小さく弾む（`pop`）。押した名前は動かさず、まわりは今の見た目の場所から新しい場所へすべる（main.js の `stay` が `V.shift` とカメラを同じだけずらす）。
- **名前の下じき**（v004）: えらんだ・指している・子を吸いこみ中のふしは、名前の下に不透明の下じき（`SEL_BG`・`HOV_BG`・`PAPER`）。吸いこまれる子と枝はふしより先に描くので、親の名前の裏へまわる。背景は無地（下じきの紙の色と合わせるため、CSS のぼかしはやめた）。
- **はじめの画面**（v004・v005）: `startView`（main.js）。哺乳類の祖先を開き、哺乳類 → 獣亜綱 → 真獣下綱を COL から開いて目をならべる。哺乳類から下の囲み（`V.bbox`）が入るなら真ん中に（右のつまみの分をのぞく）、入らなければ（スマホ）真獣下綱を左はしに。たては囲みの真ん中。
- **全体**（v005）: いま開いている枝がぜんぶ入る大きさ（読めないほど小さくてもよい。形を見わたすため。最小 0.05 倍）で真ん中に。
- **大きさのつまみ**: たての range（`writing-mode: vertical-lr; direction: rtl` で上が大きい）。0.05〜3 倍を対数で。ホイール・ピンチ・全体で変わったら描くたびにつまみも合わせる（`V.onDraw`）。さわるまでは大きさが変わってもここへ置きなおす（`replace`）。詳細は哺乳類（写真つき）。
- **シルエット**（v006, critters.js）: 見えていて閉じている名前（開いた枝の先）の右に、PhyloPic の絵を最大 14。絵はそのまとまり → なければ近い祖先（6段まで）。API は `nodes?build=&filter_name=` で名前（names は部分の並びの並び）をさがし、代表の絵が NC なら `images?filter_clade=&filter_license_nc=false`。絵は墨の色に染めた小さな canvas にしておく（`crossOrigin` は付けない: images.phylopic.org は CORS なしで、描くだけならいらない）。動き方は祖先の名前で決める演出（`KIND`: 飛ぶ・泳ぐ・くねる・はねる・ゆれる（植物・キノコは歩かない）・ただよう・歩く）。名前の右 64 の中だけを動くので文字にかからない。出るときはその場でぽこっ（easeBack）、見えなくなると祖先の点へ t³ で吸いこまれる。0.35 倍より小さいときと、`prefers-reduced-motion` のとき（動かない）に配慮。？のポップアップで止められる。作者・条件は詳細の下に。
- **どこで分かれた？**（v006, compare.js）: 1つめは詳細の「くらべる」、2つめは押す・検索。共通の祖先 = 2つの祖先の列が最初に重なるふし。くらべている間は `V.only`（2本の道すじと根もとまで）で、ほかの枝は親へ吸いこまれ、行の間を 1.7 倍に。金の光が葉から祖先へ 1.3 秒でのぼり、着いたら金の輪。読める大きさ（0.75 倍以上）で合わさるところを左に。詳細の上に、2本の道すじを2列で。ほかを押す・検索するとやめてふつうにもどる。帯の「例: ヒト×シイタケ」ですぐためせる（オピストコンタで分かれる）。
- **すぐ下のなかま**（v007, ui.js `kidsHTML`）: 詳細に、名前のある子を40までチップで（押すとそこへ）。まだ読んでいなければ「すぐ下のなかまを読む」。子の和名が届いたら出しなおす（`sig`）。
- **リンク**（v007, main.js `fromHash`・`setHash`）: アドレスの # に `t=<COL id>`／`n=<学名>`（COL id のないまとまり）／`c=<id>,<id>`（どこで分かれた？。n がまざるときは `&k=tn` など）。さわったあとだけ書きかえる（はじめの画面では書かない）。開いたときに # があれば、はじめの画面のかわりにそこへ。詳細の「リンク」でコピー。
- **ホイール**（v007・v008）: たてのホイールは拡大・縮小。横の量がまざるとき（トラックパッドの2本指）だけ動かす。ピンチ（ctrlKey）は拡大、Shift は横へ。v007 の「量が 50 以上の整数ならマウス」は、Windows の表示の拡大率で量が小数（83.33 など）になってホイールで拡大できなくなったのでやめた（ハマったところ）。
- **たくさん開いたときの負荷**（v009, view.js）: 1,889 ふしで測って直した（当たり判定 17→0.1ms、全体の描画 23→0.4ms、アニメ1コマ 21→0.7ms、配置 18→2.8ms）。
  - 名前の部品（`labelParts`）はふしごとにおぼえる（数字の区切り toLocaleString が重かった。中身が変わったら作りなおす）。
  - 描くのは画面の中だけ（x・y とも）。0.3 倍より小さいと名前を描かず点だけ、0.12 倍より小さいと点も描かない（形を見わたすとき）。
  - 止まっている枝は太さごとに Path2D にまとめて1回で描く。アニメ中（うすい）枝だけ1本ずつ。
  - アニメは動いているふし（`active`）だけ毎コマ計算。閉じたときの吸いこみは画面の中のものだけ（最大 300）。
  - 当たり判定といきものは、さっき名前を描いたふし（`V.drawn`）だけ見る。見えているかは `V.isVis`（Set）。
  - 確かめ方: `for (const n of T.nodes) n.open = true` ＋いくつかの綱・目を `T.loadKids` で読んでから、`V.layout()`・`V.draw()`・`V.hit()` を時間を測ってくり返す。
- **3D**（v011, view3d.js）: 根もとを手前、枝分かれの先を奥（z = 段 `n.lv` × 130。名前のある段で1、名前のない分かれ目は 0.35）、2D のたての並び（`n.ay`）を左右に、地面（y=0）に寝かせる。カメラは見る点のまわりを回る（yaw・pitch・dist）。自前の透視投影（Canvas 2D）。枝はベジェを10点に分けて投影。遠いほどうすく（霧）。名前はいつもこちらを向く札で、手前・えらんだものを優先して重なるものは省く。字は 9px より小さくしない（うんと遠いものは出さない）。V.draw は 3D のとき `V.draw3d`（= V3.draw）に任せる（アニメやいきもののコマ送りはそのまま使える）。
  - ルートを方眼に固定（v013）: 左右の位置は `n.ay - T.root.ay`（カメラの行き先は `n.y - T.root.y`）。2D の行の位置そのままだと、枝を開くたびに木全体が方眼の上をすべって見えた。いまは開いた枝のぶん行が増えるので、ほかの枝は1行ほどずれるだけ。方眼のはしは 240 ごと・奥行きは5段ごとにそろえる。
  - はじめから 3D（v012。`set3d(true)` を最初に、はじめの画面の `place` で `V3.frame(mam, 0)`。`frame(n, 0)` は時間 0 で 0÷0 にならないよう、すぐ置く）。
  - 操作（v012・v014）: マウスは右ドラッグか Shift＋左で回す、左ドラッグか中ボタンで平行移動（2D とそろえた）。指は1本で平行移動、2本指を左右に動かすと回す・上下に動かすと近づく（ピンチでも）。ホイール・つまみで近づく（つまみは 3D のときカメラの近さ）。押すと開く・閉じる。
  - 開いたときのカメラ（v012, `glideTo`）: 子の並ぶ少し手前を見る（0.85 段先から）。開いたふし（親）の点が画面の中（下のはしに残る）でなければ、0.6・0.35… と手前にもどして決める。3D に入るときは `frame`（えらんでいるふしの先の枝が入るように）。
  - 名前（v012）: 字は 9px 以上。遠い（10.5px 未満）ものは名前（1段め）だけの小さな札。置き場所は点の右 → 上 → 下（ずらしたら細い線で点とつなぐ）、少しの重なりは許す。名前を出すものは遠くてもうすくしすぎない（0.6 以上）。いきものは、ほかの名前にかぶるところには出さない。
  - ガイド（見比べ用、localStorage に好みを）: 方眼の地面（段ごとの線、5段ごとに数字）・地層の帯（5段ごとの色の帯。1段ずつの板に分けて描くので手前がカメラのうしろでも欠けない）・ゲート（5段ごとに門）・なし。奥行きは枝分かれの段で、年代の目盛りではないと画面に書いた。
  - いきもの: 3D では名前の札の右に（`C.draw3d`、押せる `C.hit3`）。
- **2D と 3D をつなぐ**（v015, view3d.js）: 2D の見え方 = 真上（pitch 1.56）から yaw −90° で見たところ。奥行きは `B`（真上に近いほど 1）で、段ごとの並び（lv×130）から 2D の並び（ax − ルートの ax）へなめらかにうつる（3D で真上まで回しても 2D の並びにつながる）。ボタンで 3D→2D: 真上まで起き上がってから（`morphTo2D`）2D の絵へ（`toTop2D` で 2D のカメラを合わせる）。2D→3D: 2D のカメラから真上の 3D のカメラを作り（`fromTop2D`）、ななめへ倒れこむ（`morphTo3D`）。合わせる基準は画面の真ん中に近いふし（遠いルートで合わせると、少しななめな分のずれが真ん中で大きくなった）。起き上がる間は、見る点の近くのふしが同じ所に写るよう見る点を追いかける（`tween` の `follow`）。入れかわりのずれは 1〜2px。3D の字の大きさ = 遠近の倍率 × 14px（真上で 2D の拡大と同じ）、9〜22px。
  - 前後（v015）: 3D の名前は 下じき → 点 → 名前 の順に描く（近づくと点が下じきに隠れていた）。
- **2D の方眼**（v014, view.js `drawGrid`）: 1マス 34（葉1行）、5マスごとに少し濃く。原点はルートの見た目の位置（枝を開いても方眼はすべらない）。小さく見えているときは5マスごとだけ。ガイドは 2D も 3D も「方眼・なし」の二択（v015。地層・ゲートのボタンは外した。view3d.js に描き方は残してある）。はじめは方眼（覚えておく名前を `tol-guide2` に変えて、それまでに試したガイドが残らないように）。
- **まだ先がある枝**（v011）: 閉じていて開けるまとまりは、2D では名前の右へ、3D では奥へ、うっすら線をのばす（2D ではシルエットがこの線の上を歩く）。
- **詳細の欄**（v011・v012・v015。PC は上のつまみを出さず左のふちだけ、つまみに「広げる」の文字は出さない）: スマホは下から出る板（はじめ 200px、`--sheet-h`）、PC は右の欄（はじめ 320px、`--side-w`）。つまみ `#grip`（PC は左のふち `#edge` も）を押すと広げる・縮める（スマホ 72%・PC 460px）、ドラッグで好きな大きさに（`dragSize`。ドラッグ中はアニメなし）。スマホで板が高いとき（45% より上）は大きさのつまみをかくす。いちばん上はまなびラボの入口のカードと同じ「左に小さな図・右に名前と説明」、図は押すと大きく（`#lightbox`、作者・条件つき）。写真がないときはシルエットを図のかわりに。リンクのボタンは図と説明の下、押しても文字を変えず（幅が変わって回りこむのがいやとユーザー）、知らせは樹形図の下に。
- **ふしぎ旅**（v006〜v009）: ランダムに枝を下って種まで連れていく機能。2026-10-15 ユーザーの指示でいったん外した（もどすときは v009-perf のコミットの main.js `trip`）。
- **図**（2026-10-15 v003）: Wikidata の P18（写真）→ なければ英語版 Wikipedia の記事の代表の図（`pageimages`、pilicense=free）→ Commons の `imageinfo` で作者・条件を読み、CC0・パブリックドメイン・CC BY・CC BY-SA だけ出す（NC・ND・GFDL だけ・不明は出さない）。人とチンパンジーなどの写真は出さない（`NO_IMAGE`）、ファイル名・説明・カテゴリに裸・性器・交尾・死体などの語があるものも出さない（RULES 9）。作者の HTML は DOMParser で文字だけにする。
- 押す: 選ぶ＋閉じていれば開く・選んでいて開いていれば閉じる。押した名前が画面の同じ場所に残るように cam を合わせ、子が右の外なら左へ寄せる（`reach`）。

## ハマったところ
- Open Tree の induced_subtree は、合成系統樹にない ott_id があると 400 と `unknown` の一覧を返す → のぞいてやりなおす（`pruned_ott_id` がほとんど。所属のはっきりしない属）。
- 最初は CSS が効く前で canvas の大きさが 0 → `ResizeObserver` で、だれも動かしていない間は全体を入れなおす。押した・検索したあとは入れなおさない（`touched`）。
- 和名があとから届くので、詳細の欄を出しなおす（`UI.refresh`）。あとから届く説明・リンクは、出しなおしたら古いほうを捨てる（`token`）。
- Browser ペインがかくれている間は canvas の大きさが 0 になり、ResizeObserver も requestAnimationFrame も止まる → 描く前に `measure()`、アニメは `__trofli.V.tick()` で1コマずつ進めて確かめる・`settle()` で一気に。
- 検索で Wikidata の1件目が亜属・別名（「シマウマ」→ Hippotigris）のことがある → COL で別名なら受け入れられた名前（ウマ属）へ。
- Browser ペインの mobile の表示は 1.25 倍に縮めて映すので、JS で作った PointerEvent の座標がずれる（本物の指では問題なし）。確かめるときは `__trofli.press(学名)`。
