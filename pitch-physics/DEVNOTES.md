## しくみ
- 座標は PITCHf/x・Statcast と同じ: 原点 ホームの先、x 捕手から見て右（一塁側）、y 投手の方、z 上。止めるのはホームの前の端 y = 17 インチ。
- 運動方程式 m a = mg + 抗力 + マグヌス力 + 縫い目の力 を RK4・1 ms。
  - 抗力 ½ρA C_D v²、C_D = 0.3008 + 0.0292 × rpm/1000（全部の回転数）。
  - マグヌス力 ½ρA C_L v²、向き ω⊥ × v̂（ω⊥ = 進む向きに直角な成分）。C_L = 1.120 S /(0.583 + 2.333 S)、S = r|ω⊥|/v。係数は Nathan の軌道計算機（pybbda の calculator.py・parameters.py で式の形を確認。2026-10-12）。
  - ナックル: 縫い目の力 ½ρA C_K v²、C_K = ck0 sin 4θ、θ = θ0 + |ω| t。ck0 = 0.5 mg /(½ρA v65²) = 0.328（Watts & Sawyer「65 mph で最大が重さの約半分」）。向きは 回転軸 × v̂。
- 回転の入力: `dir` = 捕手から見た「手前の面が動く向き」の時計の角度。ω⊥ = v̂ × d とすると ω⊥ × v̂ = d なので、マグヌス力の向きは手前の面が動く向きと同じ（ボールのドラッグで決められる）。`eff` = 使える回転の割合（残りは v̂ 向きのジャイロ回転）。回転軸の時計 = dir + 270°。
- ω は飛ぶ間一定（減衰なし・軸も空間で固定）。そのため純粋なジャイロ回転でも、落ちて進む向きが変わると少し曲げる回転になる（ジャイロボールの変化 4 cm ほど）。
- ねらい（`aim`）: 全部の力を入れた道すじがゾーンのまん中（x 0, z 0.765）を通るよう、上下・左右の角度を8回まで直す。角度のつまみを動かすと自動のねらいは切れる。
- 変化量 = 重力と抗力だけの道すじ（同じ放し方・同じ C_D）とのホームでの差（Statcast の考え方）。
- ナックル10球: 縫い目の向き ±20°・回転数 0〜2倍・回転軸の向き ±90°（決まった乱数 seed 7。幅はこのアプリの仮定）。
- 図: 横から・上からは高さ・左右を広げて表示（倍率を図に書く）。捕手の目線は目 (0, −0.85, 0.80) から +y を見る透視で、大きさは本物どおり。力の矢印は 26 px/N。
- 縫い目の絵: a cos t + b cos 3t … の曲線（a 0.75, b 0.25、単位球の上）。曲線の z 軸を回転軸にそろえ、軸のまわりに |ω| t（ナックルは θ0 も）回す。向きは目安。

- 左投げ（`mirrorP`）: 捕手から見て鏡うつし（x0・hAng の符号、dir → 360−dir、axisDeg → 180−axisDeg）。プリセットは右投げの値を入れて、左投げならすぐ鏡うつし。「腕の側」は右投げで −x。
- 3D: three の座標 X = x、Y = z、Z = −y（`T3`）。描くのは2層: 背景（stadium.js の野球場）をレンダーターゲットに描いて半分の大きさでガウスのぼかし3回 → 画面に貼る → 深さを消して手前の層（view3d.js）をくっきり描く。被写界深度の「それらしさ」で、本当の焦点の計算ではない。
  - 道すじの管の太さはカメラから道すじのまん中までの距離 × 0.0011（fov で補正）。35% 以上かわると作りなおす。いまの時刻までは `setDrawRange` で描く範囲をしぼる。
  - 力の矢印はカメラからの距離に比例した長さ（画面の上でだいたい同じ大きさ）。「ボールの後ろ」では矢印と輪を出さない。
  - カメラ: 投手の後ろ（テレビの中堅カメラふうの望遠 fov 17°。左投げは X を逆）・ボールの後ろ（0.9 m 後ろ・0.18 m 上から進む向きを見る）・捕手の後ろ・横から（三塁側）・上から。ドラッグで回す・ホイールで寄る（ボールの後ろ以外）。
  - 野球場は実在のものではない（両翼 100 m・中堅 122 m のフェンス、7段のスタンド、照明塔6本、スコアボード）。
- 断面（flow.js）: 断面 = 進む向き v̂ と横向きの力（マグヌス力＋縫い目の力の v̂ に直角な成分）の向き n̂ をふくむ面。図の右 = −v̂（空気の流れ）、図の上 = n̂。横向きの力の係数 c = |F⊥| /(½ρAv²)。はく離の位置 = 105° ± ずれ、ずれ = min(1, c/0.25) × 22°（目安）。伴流の曲がり = −0.9 × ずれ。前側はポテンシャル流（円柱＋循環。循環は回転があってマグヌス力があるときだけ、上の面の速さ / v に比例・±0.6 まで）。赤い点 = 縫い目の曲線が断面を横切る所。

- 段階C: `airDensity(tC, elev, pHpa, rh)` は Nathan の計算機と同じ式（pybbda parameters.py）。20 ℃・海面・1013.25 hPa・50% で 1.1994。`PHY.env = {rho, wind}` を `launch` が st にうつし、`forces` は vr = v − wind で抗力・マグヌス力・S を計算。`STD_ENV` で放したときを `S.ghostStd`（水色の線）。断面（flow.js）も vr を使う。
- 投手の例: `presetP` は `arsenal(S.pitcher)` の球種と、その投手の release を使う。左投げなら鏡うつし。投手を選ぶと、その投手の利き腕（hand）にする。
- 重ねて見る: `recompute` で、いまの球種以外を `S.multi`（色は PCOL）。ねらいは「それぞれゾーンのまん中」か「いまの球と同じ向き（vAng・hAng を同じに）」。時間のつまみの終わりは `tEnd()`（重ねた球・10球のいちばん遅い到着）。
- 3D のボール: `makeBall` = 球 + 合わせ目の細い管 + 108 の V 字の縫い目（InstancedMesh 216 本）を体の座標で作り、`orientBall` で毎コマ回す（回転軸に曲線の軸をそろえて軸のまわりに回す。2D の baseSeam・rotAxis と同じ向き）。

- 段階D: SSW = マグヌス力に直角な向きの力。2S は腕の側（st.arm = x0 の符号）、4S はグラブの側。係数 = 表（Nathan 2023 の図 7・8 から読み取った、使える回転の割合 → y = 50 ft からの横の変化 インチ）× `PHY.ssw.perInch`。perInch は `calibSSW`（150 km/h のツーシームで、y = 50 ft からの変化が表どおりになるよう、一定の力として時間の2乗で直す）で 0.0130。速さを変えても横の変化はほぼ同じ。st.eff は放したときの使える回転の割合。
- 2つの縫い目のナックル: `PHY.k2s`（Morrissey 図 3-24 を 10° ごとに目で読んだ。重さに対する比、70 mph）→ `k2sAt(θ)` で係数（ρ 1.20 の ½ρAv² で割る）。lift は 回転軸 × v̂ の向き、lat は回転軸の向き。
- ねらい方 `S.aimMode`: plain（重力と抵抗だけの道すじでまん中＝初めの値）・line（放す点からまん中へまっすぐ）・fit（全部の力でまん中）・manual。重ねた球種も同じねらい方（manual のときは plain）。ずれは「まん中から」（`missText`）。
- 腕の角度 `S.arm`: `releaseFor(arm)`（ARM_TABLE の目安）で放す位置、回転の向きは 投手の例の arm からの差だけ回す（右投げ +、左投げ −）。`setArm` はいまの球を動かす。人形は `buildPitcher` が放す位置・腕の角度から肩・腰・ひざを組み立てる（計算には使わない）。「ボールの後ろ」のカメラでは出さない。
- 土: `dirtCanvas` は芝色のまだら（うすい大きなぼかしの円 70 個）と細かい粒（ごくうすい）、ふち 10% で透明へ。ホームの円は直径 26 ft、中心はホームのまん中。白線は幅 3 in を絵に描く（1536 px で 1 px ≈ 5 mm）。マウンドは LatheGeometry（上は平ら・まわりはなめらか）に上から見た位置で絵を貼る。

- 段階E: 決める最後の時刻 tDecide = tPlate − (swingMs + delayMs)/1000（初め 150 + 150 ms）。目で追えなくなる tTrack = 目から見た角速度 |r × v|/|r|² が 70°/秒をこえる最初の時刻。ずれ = 同じ時刻の「回転の力なし」の道すじとの距離。重ねた球種のはなれは、目から見た向きの角度（同じ時刻の距離にすると、遅い球が道のりの手前にいるぶんまで入ってしまうため）。打者の目は右打者 (−0.80, 0.35, 1.50)、左打者は x を逆に。3D の打者の目のカメラは tTrack まではボールを向き、あとは止める。

- 段階F: `PHY.fx = {decay, buoy, added, coriolis}`（opt.fx で上書き）。回転の減り exp(−λ v0air t / r)（道のりを v0air·t で近似）を ω と C_D の回転数にかける。浮力 ρVg を力に、付加質量 ½ρV を質量に足す（opt.air のときだけ）。コリオリ −2Ω×v、Ω = Ω0(−cosφ sinA, cosφ cosA, sinφ)（A = 67.5° 東北東、φ = 緯度）。`PHY.clModel` で C_L の式（nathan / sawicki）。`recompute` で、それぞれを切りかえたときのホームでの差（`S.fine` mm）と、C_L の式を変えたときの差（`S.clAlt` cm）を出す。

- 段階G: 3D は2つのシーン。`V3.world`（stadium の野球場＋field の土・マウンド＋投手の人形。影も）を `makeDof`（stadium.js）で描く: 色と奥行き（DepthTexture）→ 半分の大きさで弱いぼかし（1回）と強いぼかし（3回）→ 画素ごとに coc = aperture × max((fNear−z)/z, (z−fFar)/z) で 鋭い・弱い・強い を混ぜる。fNear〜fFar は カメラから「ホーム」と「投手板」までの距離の −3〜+4 m（ボールの後ろのカメラは 0.3 m から）。aperture = 0.30 / tan(fov/2)（上限 8）。そのあと world の奥行きだけを書き（MeshDepthMaterial colorWrite false）、`V3.fg`（ゾーン・道すじ・ボール・矢印・印。いつもくっきり）を描く。輪（Sprite）は fov で大きさを直す（望遠でふくらむため）。
- カメラ: catcher = 捕手の目 (0, 0.95, 1.0)（three の座標。ホームの後ろ 1.0 m・高さ 0.95 m）→ (0, 1.15, −18)、fov 50（初期値。投手のほうを見たまま）。high（ホームの後ろ（高め））= (0, 2.4, 6.5) → (0, 0.9, −9)、fov 32。pitcher（投手の後ろ）= (1.1, 2.6, −24.5) → (0, 1.0, −4)、fov 30（左投げは x を逆）。どれも見やすさで決めたオリジナル（2026-10-12 ユーザー: MLB に合わせなくてよい）。pitcher = (−2.6, 7.5, −125) → ホーム、fov 3.2（センターの望遠。左投げは x を逆）。初期値は catcher。
- 投手の人形（pitcher3d.js）: `initPitcher` で部品（LatheGeometry の手足・胴、帽子・つば・グラブ・靴、関節の球）を一度だけ作り、`posePitcher(P, arm, t)` で毎コマ関節を置く。放す瞬間の姿勢 → 投げ終わり（t = 0.35 秒）をなめらかに補間、ひじ・ひざは `ik2`。world の太陽が影を落とす（マウンドのまわり ±5 m）。
