    神の視点マップ

    本物の地形・航空写真・地図を読み込んで、地球全体から家1軒までを見わたすアプリです。いずれは宇宙の果てから素粒子まで、ホイールひとつで行き来できるようにします。

    操作

    • ホイール／ピンチ: 寄る・引く
    • 左ドラッグ: 動かす　右ドラッグ・Ctrl＋ドラッグ／2本指: 傾ける・回す
    • クリック: その地点の住所と標高（日本のみ）

    印の意味

    実データ 公開されているデータをそのまま表示　推定 データから計算したもの　演出 それらしく作ったもの（本物ではない）

    注意

    地図・写真・標高は公開データで、撮影や測量の時期によって今の様子と違うことがあります。日本の外の地形は粗く、海の深さは表示していません（海面を 0m にしています）。
    地図や写真の画像、地名検索・住所・標高は、それぞれの提供元のサーバーから直接読み込みます（見ている場所の座標が提供元に送られます）。

    使っているもの

    • CesiumJS（Apache License 2.0）
    • 地理院タイル（標準地図・淡色地図・写真・色別標高図・陰影起伏図・標高タイル）、地理院の地名検索・逆ジオコーダー・標高 API（国土地理院）
    • Nominatim（OpenStreetMap の地名検索）
    • Sentinel-2 cloudless 2016（EOX IT Services GmbH、CC BY 4.0、Contains modified Copernicus Sentinel data 2016）
    • OpenStreetMap（© OpenStreetMap contributors、ODbL）
    • Terrain Tiles（AWS Open Data。SRTM・GMTED・ETOPO1 などから作成）
    地球を表示できませんでした。WebGL が使えるブラウザで開いてください。
