- **次にやること**: ユーザーと相談（v011・v012 はまだ push していない。push で公開）。ちぎるの候補: 空気の流れこみ、湯気が冷えて雨になる（数時間〜）、粒を増やす（GPU）、岩の固さ（小さなかけら）、何度もちぎる。地図の候補:「災害の想定」層（PLATEAU の浸水想定）、地図 ⇔ ミクロの入れかえで地面と手のひらをつなぐ演出、OSM の建物の組み立てを Web Worker に（軽量化）、交差点で曲がる車、ミクロの層を増やす（ウイルス・脳の神経など）。
- **読む順**: `../RULES.md` → このメモ → `PLAN.md`（全体の構想と段階）→ 下の「ファイル構成」で関係するファイルだけ。
- **動かし方**: ユーザーはいちばん上のフォルダの `start.bat` をダブルクリック（サーバーがなければ空いているポートで起動して、まなびラボを開く。`start.bat god-view` ならこのアプリを直接）。2026-10-06 に god-view/start.bat から移した（v010b）。Claude は `.claude/launch.json` の `apps`。**file:// では動かない**（Cesium の Worker が CDN から読めない。開くと案内だけ出す）。
- **デバッグ用**: `window.__gv`（`width()` 画面の幅 m、`state()`、`terrain()` 標高タイルの読み込み数、`goto(lon,lat,h)`、`home()`、`run(n,dt)` 描画を n 回進める）。例外は `window.__gvErr`。ちぎる: `GV._tear`（`frame` 最新のこま・`ready`・`torn`・`opt`・`worker`・`render()` 1 枚描く・`hit(x,y)`・`cam(yaw,pitch,dist)`）。Worker の中の例外は `__gvErr` に入らないので、`GV.TearSim` を `js/tear-sim.js` からページに読み込んで同じ計算を手元で回すと調べやすい（「地球をちぎる」の章）。
  - **Browser ペインが非表示だと描画ループが止まる** → `await __gv.run(60,120)` で進めてからスクリーンショット。スクリーンショットが「timed out」になったら、もう一度撮ると撮れることが多い。
- **区切りごとの手順**: `versions/<番号-名前>/` に index.html・css・js を丸ごとコピー → `launcher.html` にカード → このメモの「状態」 → 「確認のしかた」を通しで → 公開前チェック（RULES 7章）→ コミット（push はユーザー）。
- **ユーザーの好み・決まったこと**: 名前は「神の視点マップ」。最初は日本全体。地球を先に厚く。**API キーなしでできることから**。キーが要る段階になったら作業の前に知らせる（使うなら無料、できれば回数無制限のもの）。正確さ重視、実データ／推定／演出を区別して表示。

## ハマったところ

- Browser ペインが非表示 → Cesium の描画ループが止まり、地球が黒いまま・タイルも読まれない。`__gv.run()` で手動描画。
- 非表示のペインでは読み込み時の `innerWidth` が 0 になることがある → 層のパネルの初期表示は「幅が 0 より大きく 800 未満のときだけ閉じる」。
- 地理院の地名検索は住所専用で「東京タワー」→「…東」のような結果になる → Nominatim を併用。
- index.html をダブルクリック（file://）すると「Refused to cross-origin redirects of the top-level worker script」で地球が出ない → ルートの start.bat から開く。

28. 地球をちぎる: 宇宙へ出て地球が大きく見えているとき右下に「✋ 地球をちぎる」（太陽系まで引くと消える）。このとき裏で組み立てが始まる（宇宙で 15 秒ほど待ってから押すと、すぐ「つまんで…」）。すぐ押すと「組み立てています… %」のあいだも粒の地球が見えていて（まっ黒にならない）、そのあと写真の色の粒の地球と、海の上に小さな青い粒。表面のすき間に橙の点が見えない。
29. 地球をつまんで外へ引く（試験では `GV._tear.render()` と合成の pointer イベント）→ 「ぶちっ！」、穴のふちが橙に光る。「ちぎってから」の時間・穴の深さ（2000 km なら はじめ 1000〜1500 km → 10 分ほどで 0 km）・流れの速さ（秒速 3〜7 km）・熱くなった所（+2000〜5000℃）。速さが 10 km/s・熱が 1 万℃ を大きく超えたら手か運び方がおかしい。
30. 「遠くへ運ぶ」でかけらが画面の右下（スマホは地球の下）へ。かけらの上の水が白く凍る。穴のまわりに水色の水、熱い所から白い湯気。説明の欄に「穴に流れこんだ海の水」「湯気になった水」（km³ と海の %）。海の約半分が白（沸騰）になっていたら hotS の判定がおかしい。
31. 見え方: 温度（埋まった所が黄色く熱い）・層（マントル・外核・内核）・溶け（外核が青、穴の下とかけらが橙）。断面で中が見え、穴が切り口に入る。
32. 「その場で落とす」→ かけらが落ちてぶつかる。1000・3000 km も試す。「もとに戻す」で時間 0・穴なしに戻り、もう一度つまめる。「← 宇宙へ」と ⌂ で戻れる。スマホ幅で地球が画面に収まり、パネルと重ならない。

33. 英語（`?lang=en`）: 地図（層のパネルを全部入れる・東京駅で地点をクリック）、宇宙（ホイールで宇宙の果てまで。星・銀河の名前）、ミクロ（3 本の道を `GV._micro.L` で 0〜−36）、地球をちぎる（パネル・ちぎったあとの説明の欄）で、画面に日本語が残らない（`../I18N.md` 2.4 の式。地図の下の出典の欄 `.cesium-widget-credits` は除く）。JP／EN ボタンで読み直し、`localStorage['manabi-lang']` が変わる。日本語（`?lang=ja`）は前の版と同じ（v012c では、題名・属性・層のパネル・目盛り・このアプリについて・地点の情報・状況の文・ものさし・長さの書き方・電車とバスの説明を v012b と比べて一致）。

## 英語対応（v012c、2026-10-10。`../I18N.md`）
- 言語は開いたときに決まる（`?lang=` → `localStorage['manabi-lang']` → ブラウザ）。`index.html` の `<head>` の `var LANG=` の行と `L(ja, en)`。JP／EN ボタンは上のバーの ? の左（`#langsw`）。
- HTML の文は `lang="ja"`／`lang="en"`（「このアプリについて」は `<div lang="ja">` と `<div lang="en">` の2つ）。属性（title・aria-label・placeholder）と題名は ui.js のはじめで入れる。
- JS の文は、その場で `L('日本語', 'English')`。ものさし `GV.RULERS` と目盛りの帯 `GV.BANDS` は scale.js で英語の表を同じ順に上書き。長さの書き方（光年）と大きな数は英語だと million・billion。
- **英語にしないもの**（I18N.md の決まり）: 地図の下の出典の欄のうち提供元の指定の文言（地理院タイルの出典、都営交通の「東京都交通局・公共交通オープンデータセンター」、PLATEAU の名前）、データの中の地名（PLATEAU の市区町村名 `data/plateau-bldg.js`、都営の駅・バス停・路線名 `data/toei.js`、建物の用途など PLATEAU の属性の値、OSM の名前）。アプリが書いた前置き（「建物: 」「地震: 」など）と説明は英語にした。
- 住所と検索（Nominatim）は `accept-language=${LANG}`。英語のときは日本の住所も `display_name`（英語の地名）をそのまま出す。標高の出どころ（`1m（レーザ）` など）は英語だと laser／photogrammetry に置きかえ。
- 地下のデータの名前は `data/plateau-under.js` の `name_en`。新しく足すときは `name_en` も書く。
- **`L` という名前の変数を変えた**: micro.js と space.js の大きさ `L`（ファイル全体で使う）→ `Lw`（`GV._micro.L` の名前はそのまま）、ui.js `updateScale` → `Lsc`・`onLife` → `ls`、underground.js の管の層 → `ly`、life.js の TLE の行 → `tl`、tear.js のつまむ長さ → `dl`。
- 宇宙のヒント `#space-hint` は、読み込み中の文を出したあと `innerHTML` で戻す（`textContent` だと日本語と英語の両方の文がつながって出た）。

## 残っている課題

- 日本の外を地図にしたとき、文字が小さめ（OSM タイルを3D の地球に貼るため）。
- 地理院の写真は引いたとき（level 6 未満）は出さず、EOX の写真に統一している。境目で色が変わる。
- 海底地形なし。夜の街の明かり（NASA Black Marble）は段階C。
- ホイールで寄る速さは Cesium の初期設定のまま。宇宙・ミクロとつなぐとき（段階F・G）に、スケール値 L を直接動かす方式に変える。
