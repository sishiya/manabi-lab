# 企画書：神の視点マップ

作成: 2026-10-05

## 1. ひとことで

ホイールひとつで、宇宙の果てから地球、街、家、人、細胞、原子、素粒子まで、切れ目なく寄ったり引いたりできるアプリ。
地球の部分は**本物の地形・航空写真・建物・交通のデータ**を読み込み、その上に人・車・動物を（演出として）歩かせて、「神さまの目で現実の世界をながめる」体験にする。

イメージ: Google マップ／Google Earth ＋ シティーズ：スカイライン ＋ 映画「パワーズ・オブ・テン」。

## 2. ねらい

- **大きさの感覚を体で知る。** 10⁻³⁵m（プランク長）から 10²⁶m（観測できる宇宙）まで、約60桁を1本のホイールでつなぐ。いまの大きさを「家1軒分」「日本列島くらい」「太陽系くらい」などの身近なものさしで常に示す。
- **本物のデータで世界を見る。** 地形・写真・建物の高さ・線路・地震・雲などは、公開されている実データを読む。
- **見えないものを見る。** 地下の管、電車の流れ、昼と夜の境目、人の多さなど、ふだん見えない層を重ねたり外したりできる。
- **このフォルダの他のアプリの入口になる。** 人に寄れば「体内ダイブ」「免疫のたたかい」、部屋に寄れば「電波の見える部屋」、原子の先は「量子の実験室」、時間を巻き戻せば「ヒトへの46億年」へつながる。

## 3. 正直さのルール（このアプリでいちばん大事）

画面に出すものすべてに、次の3つのどれかの印をつける（RULES 9章「記録・推定・想像を区別」）。

| 印 | 意味 | 例 |
|---|---|---|
| **実データ** | 公開データをそのまま表示（取得日時・出典つき） | 地形、航空写真、建物の形と高さ、地震、雲の衛星画像 |
| **推定** | 実データから計算したもの | 時刻表から計算した電車の位置、昼夜の境目、惑星の位置 |
| **演出** | それらしく作ったもの（本物ではない） | 歩いている人・車・動物、データのない場所の水道管、細胞や原子の見た目 |

- 実在の個人を追跡・特定できるものは**作らない**（人は統計から生成した架空の人。顔も名前もない）。
- リアルタイムの交通情報は、無料で鍵（API キー）なしに使えるものが限られる。使えないものは「推定」「演出」と明記して代わりにする。

## 4. スケールの構成（ホイールの道のり）

内部では「いまの画面の幅が何メートルか」を **log10(m)** の1つの数（スケール値 L）で持つ。ホイール1目盛りで L を約0.05〜0.1 動かす（指数的に寄る）。L によって担当する「世界（ステージ）」が切り替わり、境目では前後の世界を重ねてフェードする。

| L（10^L m） | 世界 | 中身 | データ |
|---|---|---|---|
| 26〜21 | 宇宙の大規模構造 | 銀河のあみの目、局所銀河群 | 演出（観測をもとにした分布） |
| 21〜17 | 天の川銀河 | 渦巻きの腕、太陽の位置 | 推定 |
| 17〜13 | 近くの恒星 | 明るい星の実際の位置と色 | 実データ（星表を同梱） |
| 13〜8 | 太陽系 | 惑星・月の実際の位置、軌道 | 推定（天文計算） |
| 8〜5 | 地球全体 | 昼夜、雲、人工衛星・ISS、地震 | 実データ／推定 |
| 5〜1 | 地形と街 | 地図・航空写真・地形・建物・線路 | 実データ |
| 1〜−1 | 地上（人の目の高さ） | 人・車・動物・木（演出）、地下の管 | 演出／一部実データ |
| −1〜−5 | 生き物のからだ | 皮膚・細胞・細菌 | 演出（→体内ダイブ・免疫のたたかいへ） |
| −5〜−10 | 分子・原子 | DNA、水分子、原子 | 演出 |
| −10〜−15 | 原子核 | 陽子・中性子 | 演出（→量子の実験室へ） |
| −15〜−35 | 素粒子とその先 | クォーク、プランク長（「ここから先は分からない」） | 想像と明記 |

- 寄る場所は画面の真ん中（またはマウスの位置）。地上より下では「いま寄っているもの」（人・葉っぱ・水たまりなど）を選んでから寄る。
- 数字の精度の問題（60桁は1つの座標系に入らない）は、**世界ごとに原点と単位を持ち直す**ことで避ける（ステージ切り替え）。

## 5. 地球の部分（このアプリの中心）

### 5.1 地図の層（重ねたり外したりできる）

| 層 | 内容 | データの候補（鍵なし・無料） | 状態 |
|---|---|---|---|
| 地図 | 道・地名・川 | 地理院タイル（日本）、OpenFreeMap／OpenStreetMap（世界） | 実データ |
| 航空写真 | 写真 | 地理院タイルのシームレス写真（日本）、Sentinel-2 雲なし画像・NASA GIBS（世界） | 実データ |
| 地形 | 起伏・高さの強調 | 地理院の標高タイル（日本・細かい）、AWS Terrain Tiles（世界） | 実データ |
| 建物 | 立体の建物 | PLATEAU（日本の都市・形が正確）、OpenFreeMap の建物の高さ（世界） | 実データ |
| ワイヤフレーム | 地形と建物を線で | 上の層の表示を切り替え | — |
| 鉄道・バス | 動く電車・バス | GTFS（時刻表）から位置を計算。リアルタイムは鍵が要るので後で検討 | 推定 |
| 交通の流れ | 道路の混み具合 | 公開のリアルタイムデータは少ない。まずは時間帯から演出 | 演出（実データが見つかれば差し替え） |
| 地下 | 水道管・下水・ガス・地下鉄 | PLATEAU の地下埋設物モデル（一部の都市）、自治体のオープンデータ。ほかは道路に沿った模式 | 実データ／演出 |
| 地球の今 | 昼夜、雲、地震、ISS・人工衛星 | 天文計算、NASA GIBS、USGS の地震情報、CelesTrak の軌道要素 | 実データ／推定 |
| 人口・土地 | 人の多さ、森・田・街 | 国勢調査の地域メッシュ（e-Stat）、土地被覆データ | 実データ（人や動物の配置に使う） |

※ それぞれ**利用条件（出典の書き方・使ってよい量・CORS）**を段階0で確かめてから使う。条件は DEVNOTES に表で残す。

### 5.2 地上の人・車・動物（シティーズ：スカイラインのように）

- 十分寄ったら（L < 2.5 くらい）、見えている範囲だけに人・車・自転車・動物を生成する。
- 人の数は人口メッシュと時間帯（昼はオフィス街、夜は住宅地）から、歩く道は OSM の歩道・道路から、車は道路の種類から、動物は土地の種類（森ならシカ・タヌキ、水辺なら鳥、街ならカラス・ネコ）から決める。
- 全員**架空**で「演出」の印。クリックすると「この人は統計から作った架空の人です」と出す。
- 電車・バスは時刻表どおりに動く（推定）。

### 5.3 操作

- ホイール／ピンチ: 寄る・引く（L を動かす）。ドラッグ: 移動。右ドラッグ（2本指）: 傾ける・回す。
- 地名で探す、緯度経度へ飛ぶ、ブックマーク（よく見る場所）。
- 時刻を動かす（昼夜・電車・人の量が変わる）。
- 左に層のパネル、右に「いま見ているもの」の説明、下にスケールの目盛り（10⁻³⁵ … 10²⁶ の帯と、いまの位置）。

## 6. 作り方（技術）

- **地球の部分は既製のエンジンを使う**のがよい（世界中の地図タイルを読み、寄ると細かくなる処理を自作すると何か月もかかるため）。候補:
  - **CesiumJS**（Apache-2.0）: 3D の地球が前提。地形、3D Tiles（PLATEAU がそのまま読める）、時刻で動くもの、太陽・月・星空を持つ。宇宙側へ引くのと相性がよい。有料の Cesium ion は使わない（鍵が要るため）。
  - **MapLibre GL JS**（BSD-3）: 地図らしい見た目と軽さ。v5 から地球儀表示と地形、建物の立体あり。PLATEAU は deck.gl を足して読む。
  - → 段階0で両方を小さく試し、決める。いまの第一候補は **CesiumJS**。
- **宇宙とミクロの部分は Three.js**（このフォルダのいつもの道具）。地球のエンジンと Three.js の切り替え・重ね合わせを「スケール管理」（scale.js）がまとめる。
- 天体の位置は astronomy-engine（MIT）、人工衛星は satellite.js（MIT）などを検討。
- 最初から css／js に分割する（大きくなるのが確実なので）。

```
god-view/
  PLAN.md  DEVNOTES.md  index.html  launcher.html
  css/main.css
  js/scale.js        スケール値 L、ステージの切り替え・フェード、ものさし
  js/earth/*.js      地球のエンジン、層（地図・写真・建物・地下・交通…）
  js/agents.js       人・車・動物（演出）
  js/space.js        太陽系・恒星・銀河・宇宙（Three.js）
  js/micro.js        細胞・分子・原子・素粒子（Three.js）
  js/ui.js           パネル、検索、説明、出典の表示
  data/              同梱する小さなデータ（星表・GTFS の一部など）
  versions/<番号-名前>/
```

## 7. 大きな心配ごと（段階0で最初に確かめる）

1. **Artifact から外のデータが読めるか。** これまでのアプリは外のデータを読んでいない。Artifact のページは外部への通信が制限されている可能性が高い。読めなければ公開先を考え直す（例: ローカルだけで使う、GitHub Pages など別の場所に置く）。→ **GitHub Pages に決定**（2026-10-05）。
2. **CORS。** ブラウザから直接読めるデータか（サーバーを用意しない前提）。読めないもの（多くのリアルタイム交通 API など）は同梱データか演出で代わりにする。
3. **API キー。** キーが要るサービス（公共交通オープンデータセンターなど）は、公開するページにキーを書けない（RULES 7章）。使うなら別の仕組みが必要なので後回し。
4. **利用条件と量。** OSM の公式タイルは大量の利用が禁止。出典の表示も必須。各データの条件を表にしてから使う。
5. **重さ。** スマホでも動くように、地上の人や車は見えている範囲だけ・数を上限つきで。

## 8. 進め方と節目

| 段階 | 内容 | 終わりの目安 |
|---|---|---|
| **0 実現性の確認** | Artifact で外のタイルが読めるかの小さな試作、CesiumJS と MapLibre の比較、各データの CORS・利用条件の表 | エンジンと公開先が決まる |
| **A 地球の地図** | 地球全体から家1軒までホイールで寄れる。地図／航空写真／地形の切り替え、高さの強調、地名検索、出典表示 | v1（最初の公開） |

| **D 動く街** | 時刻表から電車・バス、人・車・動物の演出（シティーズ風） | |
| **E 地下** | 水道管・下水・地下鉄（実データのある都市から） | |
| **F 宇宙へ** | 地球 → 月 → 太陽系 → 恒星 → 銀河 → 宇宙の大規模構造（Three.js、つなぎ目のフェード） | |

- 各段階は版（v001, v002…）に分け、`versions/` にバックアップ、節目は `launcher.html` へ（RULES 3章）。
- 段階ごとに DEVNOTES を更新し、次の段階は新しいセッションで始める（RULES 11章）。

## 9. やらないこと

- 実在の個人の位置・顔・名前を出すこと、個人を追うこと。
- 鍵や個人の情報をファイルに書くこと。
- 利用条件を確かめていないデータを使うこと。
- 地図エンジンを一から自作すること（地球の部分は既製のものに任せ、宇宙とミクロに力を使う）。

## 10. 決まったこと（2026-10-05）

1. 名前は **「神の視点マップ」**。
2. **公開は GitHub Pages**（リポジトリ manabi-lab を Public にして、main のルートを配信）。Artifact は使わない（外のデータが読めない可能性が高いため）。
3. 最初に見せる場所は **日本全体**。
4. **地球を先**に作る（段階 A〜E → F・G）。
5. **まずは API キーなしでできることから。** キーが要る段階になったら、作業の前にユーザーに知らせる。使うなら無料（できれば回数無制限）のものを選ぶ。
