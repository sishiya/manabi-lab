## パラメータの点検（2026-10-12 公開の前に。ユーザー「嘘がないか厳重に」）
- 原文・データで確かめた値: 周期（Seago & Ebling 1985 の要旨・NCT03945383 の文）、男女ののびる速さの比 1.22（太ももだけ）、皮ふの散乱 a=46.0・b=1.421（Jacques 2013 Table 2）、真皮の B 0.2%・S 39%・W 65%（同 Table 3 の Choudhury 2010 の行）、メラニンの式 6.6×10¹¹ λ^−3.33・下地の式・メラノソームの割合の幅・表皮 60 µm（OMLC skinoptics）、ヘモグロビン・水の表（OMLC）、深さと光の式の形（Jacques 2010）、Henriques の A・Ea（よく使われる式 exp(226.78−75000/T) と合う。Ea は 0.7% の丸めの差）、ケノン ストロング2 35 J・7.7 J/cm²・4.5 cm²・ストロング 1.5×3.0 cm（比較サイト。公式ではない）。
- 直したもの: すねの値の「もとは Richards & Meharg の表とされる」（登録の文になかった）を外した。のびる速さの出どころにしていた Myers & Hamilton 1951 は数値を原文で確かめられない（PubMed に要旨なし・解説サイトの引用だった）→ 出どころから外し、のびる速さは推定と明記。毛球の深さ「2.5〜4 mm とされる」・密度「60 本/cm² とされる」はクリニックのページの値 → 推定と明記。ケノンの面積「4.9 cm²」は確かめられない → 4.5 cm² に（Lv10 7.4 → 7.7 J/cm²）。照射口はスーパープレミアム（2 cm）とストロング2 の強さを組み合わせていた → ストロングの 1.5 cm にそろえた。推定の値は「このアプリについて」に全部並べた。

## しくみ
- 時間は日。スライダーは −7〜365 日（手入れは 0 日目から）。きざみ `SIM.dt`=0.25 日で決まった格子の上だけを進むので、`Runner` を続きから進めても 0 から計算しても同じ結果（再生中は続きから。日をもどすと作りなおす）。
- 0 日目より前に 500 日回して周期をばらばらにした状態（`startState`、部位ごとに1回だけ作って複製）。毛穴ごとに別の乱数（`mulberry32`）なので、手入れをしない毛穴は3列で同じ。
- 毛穴1つ: 期 `ph`（A 成長・C 退行・T 休止・R 抜いたあと待つ・X 作れない＝段階B）、毛球の深さ `bulb`、毛 `hairs[]`（`L`＝根もとから先までの長さ、`club`＝棍毛、`blunt`＝剃った切り口）。先の高さ = L − 根もとの深さ（`tipH`）。
  - 成長期: 毛球が 1.1 → 3.0 mm へ 10 日でおりる（推定）、毛は v mm/日でのびる。退行期 14 日で毛球が 1.1 mm へ上がる。休止期: 棍毛は止まる。次の成長期が始まると古い棍毛は 0〜25 日で落ちる（推定）。
  - 剃る: 表面から出た分を切る（`blunt`）。毛穴は変えない。休止期の毛は切ったまま止まる → 剃った次の日に見える毛は成長期の割合ぶんだけ。
  - 抜く: 表面から 0.5 mm 以上出ている毛を取る。いま育っている毛（休止期なら棍毛）が取れたら期 R（平均7日・ばらつき 0.5 の対数正規。推定）→ 新しい成長期。
- 周期の値は3種（`SITES`）。すねの値（成長期 16 週・休止期 24 週）は臨床試験の計画 NCT03945383 の文。太ももの値は Seago & Ebling 1985 の測定（PubMed 4015973 の要旨で確認）。のびる速さ: 太もも 0.13〜0.25 mm/日（Myers & Hamilton 1951、総説の引用）→ 0.2、男女比 1.22（Seago）。
- 光の列: 段階A では光の日の前日に剃るだけ（0 日目は同じ日に剃ってから）。予定は NCT03945383 の「2週ごと4回→4週ごと」。
- 分かりやすさ（2026-10-12 ユーザー「毛根の伸び縮みがうそっぽい・再生で何が起きているか分からない」）: 原因は ①再生が速すぎ（1秒で1か月 → 図の15個のどれかが毎秒4〜5回形を変える）②縮む・のびるが等速で 0.3〜0.5 秒のカクッとした動き ③いまの期が図に書いていない ④手入れの日が一瞬で通り過ぎる ⑤「どれだけ毛深いか」が小さな数字だけ。対策: 最初の速さ 1秒で1週（速さは時間の行に）、のび縮みを smoothstep、毛穴ごとの札（`drawTag`）、手入れの日は再生を 1.3 秒止めて字幕（`nextEvent`・`S.hold`・`L.today`）、列ごとに「上から見た肌」の帯（`drawSurface`。60本・線＝出ている毛・点＝切り口）。
- 図: 表面の上 1.6 mm・下 3.6 mm。毛穴は 30° 傾ける（`TILT`）。深さはたての深さ（モデルの値）で、軸にそった長さは深さ÷cos。寸法は実寸の比（`UM`）。表面から上の毛は毛穴の向きで出て、肌にそって寝ていく弧。狭い列（スマホ）では深い端が少しはみ出すのを許して2〜3個描く。
- 光（段階B、`light.js`）:
  - 光: 600〜1100 nm を 25 nm ごと、平らな強さ（推定）。面の強さ F0 = レベル×0.77 J/cm²（Lv10 ≈ 7.7、ストロング2 の 35 J ÷ 4.5 cm²。比較サイトの値）。光る長さ 5 ms（推定）。
  - 肌の中: μs' = 46(λ/500)^−1.421（Jacques 2013 Table 2 の皮ふ）、真皮の μa = 下地(1−W) + 水 W + 血液 B（B 0.2%・S 39%・W 65%、Choudhury 2010＝Jacques Table 3）。φ(z) = F0·T_epi·k·e^(−z/δ)、δ = 1/√(3μa(μa+μs'))、Rd ≈ exp(−8/√(3(1+μs'/μa)))·T_epi²、k = 1+7.4Rd・表面 1+6.8Rd（Jacques 2010 の文の値から直線で）。800 nm で δ ≈ 3.6 mm、1 mm の深さで F0 の約4倍。
  - 毛・毛母: μa = fh·μa_mel、μa_mel = 6.6×10¹¹ λ^−3.33（OMLC）。fh は黒 0.10・茶 0.05・うすい 0.015（**推定。結果をいちばん左右する**）。毛母は毛乳頭をとり囲む輪（半径 0.05〜0.1 mm）、毛乳頭へは半分の色。成長期のはじめ（5〜12 日目）は色がない（毛母が色を作るのは毛球ができてから）。退行期 0.4 倍、休止期は毛球に色なし。バルジは毛（半径 35 µm）からの熱、休止期は根もとに色がないので 0.3 倍。
  - 熱: 円柱（輪）の熱の式を q=1 で1回解いて記録し（`unitResponse`）、q をかける。Ω = ∫A·exp(−Ea/RT)dt（Henriques 1947: A 3.1×10⁹⁸/s・Ea 6.28×10⁵ J/mol）、いたむ確率 1−e^−Ω。
  - 起きること（`applyFlash`）: 毛母がいたむ → 毛は伸びなくなり 7〜21 日で押し出されて落ちる（押し出されるあいだ伸びて見える）、毛穴は退行期 → 休止期。毛乳頭がいたむ → 次の毛 0.6 倍の細さ（0.3 未満で作れない）。バルジがいたむ → 次の成長期が来ない（X）。
  - 表皮: 60 µm の層の1次元の熱の式（表面は断熱、下へ逃げる）。冷やす 22°C／冷やさない 32°C から（推定）。Ω≥1 で「やけど」、0.1〜1 で「熱い」と表示。
  - 剃らない: 表面に寝た毛が光をさえぎる（60本/cm² 相当の長さ×太さ×吸う割合）。表面の毛の温度も出す。
  - 結果のめやす（すね・明るい肌・黒い毛）: Lv10 で成長期の毛母は 85°C・全部いたむ、Lv5 は 60°C でほぼ効かない、茶色の毛は Lv10 でも効かない。バルジは 40°C 程度でいたまない → **このモデルではケノンは毛穴をこわさず、生えかわりのたびに毛を落とす**。中ほどの肌の Lv10 で表皮 65°C（冷やさないと 75°C で「やけど」）。

- 毛の作られ方（2026-10-12 ユーザー「毛根あたりが伸びる様子は本当？」で直した）: 成長期のはじめ `GEO.descend`（10日、推定）は毛穴の下の部分が下へのびて毛球ができるだけで、毛はまだない。毛球ができてから毛を作り、下から押し上げる（`stepF` で `f.t >= GEO.descend` から `L` がふえる）。前は毛球が下りるのと同時に毛がのびて、毛が下へのびるように見えていた。
- 毛先: 新しく作られた毛は先がとがる（0.6 mm、見た目の目安）。剃った毛だけ平ら。前は先の細り方を毛の長さの割合で描いていて、短い新しい毛が平らに見えていた。
- 白髪（`AGING`・`pigAt`）: 毛穴ごとに「色の幹細胞が毛球へ届かなくなる年齢」`gAge`（平均＝白髪の出やすさ 52/62/72歳、ばらつき ±10歳、別の乱数）を持つ。成長期が始まるとき `pig = (gAge − 年齢)/3` を 0〜1 に切ったものがその周期の毛の色（1 色あり・0 白・あいだは灰色）。年齢は `f.age`（0日目に `S.age`）。図: 黄色の点＝色の幹細胞（ふだんバルジ、成長期は毛球へ）、白髪の毛穴は灰色の点がバルジに取り残される（Sun 2023 マウス）。光: 毛母・毛の吸収に `pig` をかける → 白い毛は熱くならない。人の数値は Panhard 2012（50歳で半分以上白い人 6〜23%）に合う程度の推定。

## ハマったところ
- `hidden` をつけても見えていた（2026-10-12）: `.row` などに `display:flex` があると hidden が効かない。css に `[hidden]{display:none !important}`、白髪の設定は remove() で取り除く。
- 白髪を外したのに「残っている」（2026-10-12）: ブラウザが古い JS を覚えていた可能性。index.html の css・js に `?v=…` をつけた（いま 011）。**js・css を直したら番号を上げる**。
- カミソリが変な所へワープする（2026-10-12）: なぞり終えたあと、刃が「なぞり始めた所」へ戻ってもう一度すべるアニメを再生していた。→ 後からの再生はやめ、なぞっている途中で刃が毛穴の出口を通った瞬間に切る（`razorPass`。ひとなぞりの手入れは同じ `g` で、↶ でまとめて取り消す）。
- しらべる でクリックすると画面が消えた（2026-10-12）: ドラッグ移動の始まりで、全体表示（`S.view` が null）を `Object.assign({}, null)` で写していたので z が空 → NaN。`curView()` から写し、4px 動くまでは動かさない。`layout` はこわれた view を全体表示にもどす。
- Browser ペインが隠れていると canvas の大きさが 0 → `ellipse` の負の半径で例外。`drawScene`・`drawGraph` は小さすぎるときは描かない。
- ほかのチャットのサーバーが 5 つ立っていて `preview_start {name}` ができない → `preview_start {url: http://localhost:8765/hair-removal/}` で開く。
- `_dev/tools/thumb.html` に new-app.ps1 が SETUP を足せなかった（ほかのセッションの変更が入っている）。サムネイルを撮るときに手で足す。
