## しくみ

- **計算**: 床に垂直な電場 Ez の2次元波動方程式 `∂²E/∂t² = (1/με)∇²E − (σ/ε)∂E/∂t` を陽解法で解く（TM モードなので Ez だけで厳密）。1マス `DX=0.75cm`、1280×800マス（9.6m×6m）、クーラン数 `KC=0.5` → 1ステップ `DT=12.5ps`。
- **GPU**: 状態テクスチャ RGBA32F を2枚でピンポン。`r=u(n)`, `g=u(n-1)`, `b=u² の指数移動平均（BETA=1/256）`。`EXT_color_buffer_float` が必須。材料は R8 テクスチャの ID（0 空気〜7 水・人体）で、シェーダは uniform 配列 `uK2[id]`（= KC²/εr、金属は −1 で Ez=0）と `uA[id]`（= σ·DT/2ε）を引く。
- **吸収境界**: 外周40マスのスポンジ（減衰係数を3乗で増やす）。`uStrip=1` のときは左右だけ（1次元テスト用）。
- **波源**: 点（ルーター）か、x=一定の線（平面波。「比べっこ」「すき間」）。開始時に2周期かけて立ち上げる。
- **dBm 換算**: 起動時に 320×320 の空の場で自由空間の `C = 平均(u²)·r` を測る（`CAL`）。受信 = `20dBm − FSPL_3D(d) + 10log10(平均u²·r / C)`。つまり2次元の「1/r」の広がりを3次元の自由空間損失に置き換え、壁・反射・干渉の分だけをシミュレーションから取る。平面波のときは基準の通路（何もなし／板なし）との差を出す。
- **材料の値**: ITU-R P.2040 の εr・σ（`MATS` の `er,c,d`）。表示する「壁1枚で −X dB」は `slabDb()`（垂直入射の板の透過を複素数で解析計算）。
- **格子の補正 `eff`**: 0.75cm 格子では 5GHz のガラス内が1波長3マスしかなく、そのままだとガラス −14dB・コンクリート −59dB と過大になる。そこで材料ごと・周波数ごとに、1次元テスト `__ww.stripDb(f,id,er,sig)` で「解析値と同じ透過損失になる εr・σ」を二分法で求め、`eff:[[2.4GHzのer,σ],[5GHzのer,σ]]` に固定した。材料を足すとき・厚さを変えるときは作り直すこと（コンソールで数秒）。
- **画面**: 表示シェーダ1枚。波モードは `u / sqrt(2C/r)`（距離補正あり）を tanh で色に。強さモードは u² 平均を λ/2 の円内16点でならしてから dBm → 色。アンテナ本数の境目（−55/−67/−75/−85）に線。上に 2D キャンバス（部屋名・ルーター・スマホ・通路の値・作図プレビュー・縮尺）。
- **スマホ**: 17×17マスの平均を `readPixels` で読む。通路のプローブは 200×40マス（1.5m）平均（通路内のモードのうなりで数dBぶれるため）。電波が届くまで（距離/KC×1.25+700ステップ）は「待っています」。

## 確認のしかた

ビューが隠れているとアニメーションが止まるので、コンソールで `__ww.advance(n)`（nステップ進めて描画・読み取り）を使う。GPU なら 4500 ステップは一瞬。

1. 読み込み直後にエラーなし（`window.__wwErr` が空）。`__ww.CAL` に 2.4/5 の `C`・`L` が入る。
2. 「壁の比べっこ」で 4500 ステップ後、通路の値が解析値（ツールボタンの数字）と ±1.5dB 程度。目安（2.4GHz / 5GHz）: ガラス −3.9/−3.0、石こうボード −3.3/−1.8、木 −1.2/−1.9、レンガ −4.0/−3.7、コンクリート −14/−23、金属は「届かない」。
3. 「すき間の実験」: 4cm が 2.4GHz で約 −30dB、5GHz で約 −14dB。2cm は両方とも届かない。
4. 2LDK: スマホ（LDK窓際）が 2.4GHz で約 −48dBm、「壁がなければ −38dBm」。ルーターをドラッグで動かせる、材料を選んでドラッグで壁が描ける、元に戻すが効く。
5. 幅 360px（縦長）でパネルが下に回り、地図（#stage）が上に貼りついたままパネルだけスクロールする。横スクロールが出ない。地図の幅が560px未満だと `small` になり、部屋名・通路の値・ルーター・スマホの表示が小さく1行になる。ヒントは2行で省略、タップで全文。
6. 横向きスマホ（`orientation:landscape` かつ高さ560px以下。780×360・640×360・932×430 で確認）は PC と同じ左右2列で、右パネルは290px。ページ自体はスクロールせず（scrollHeight = 画面の高さ）、右パネルだけがスクロールし、地図は左に出たまま。縦長（`max-width:860px` かつ portrait）だけが1列＋地図を上に固定。
7. 点滅（光過敏性発作）: 波の表示は、1点ごとに見ると毎秒8〜29回明るさが入れかわる（細かいしまが流れるため）。ただし 32px 四方で平均すると、相対輝度が0.1以上変わる点滅が毎秒3回を超える所は画面の0〜6%だけ（2.4/5GHz × 1コマ2〜16ステップ、v4b で測定。どれも最大は 1コマ8ステップ・2.4GHz の 5.9%）。WCAG の基準（視野10°の25%＝1024×768 の画面の約11%）より下。色・コントラスト・速さの選択肢を変えたら測り直す（`animal-senses/DEVNOTES.md` の測り方と同じく、`#gl` を縮小して2D キャンバスに描き、相対輝度を比べる）。
※ v3 から index.html の先頭に viewport メタ（`width=device-width,initial-scale=1,viewport-fit=cover`）を入れたので、ローカルでもそのままモバイル確認できる。`viewport-fit=cover` はノッチ端の `env(safe-area-inset-*)` を効かせるために残すこと。
