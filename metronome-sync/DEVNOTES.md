## しくみ
- 座標: 板 x、振り子 θi（重心の側が右へふれると +）。T = ½Mtot ẋ² + Σ(S ẋ θ̇i cosθi + ½Ii θ̇i²)、V = −Σ S g cosθi。
  - Ii θ̈i + S cosθi ẍ + S g sinθi = Ii fi、 Mtot ẍ + Σ S(cosθi θ̈i − sinθi θ̇i²) = −c ẋ。θ̈i を消して ẍ を1つの式で（O(N)・厳密）。
- 値（Pantaleone 2002 II.B）: メトロノーム 94 g、板 58 g、104 往復/分、最大のふれ約 45°（θ0 = 0.39）、x0 = m r/(M+2m) = 0.088 cm → S = m r = 2.165e-4 kg·m、β = 0.011、μ = 0.010。
  - ω0 は、ふれはば A = 2θ0 で 104 往復/分になるように ω0 = ωpen/(1 − A²/16) = 11.32 rad/s。I = S g/ω0²。シミュレーションの1台は 43.7°・105.0 往復/分（vdp）。
  - 論文の m は「メトロノーム」の質量として使われている。ここでは Mtot = 板 + N×94 g（＋足したおもり）、振り子は S と I だけで表す（振り子だけの質量は論文にない）。
- 押し方: vdp = 論文の式 fi = −μω0[(θ/θ0)² − 1]θ̇。kick = −γθ̇ + K·窓(|θ|<0.1)·sign(θ̇)（なめらかにしてある）。γ = μω0（ふれはばの落ちつく速さを vdp とそろえる）、K は1往復のエネルギーのつり合いから（推定）。
- ばらつき: 台ごとに ω を (1 + spread·d/2)、d は −1〜1 を入れかえた並び（`detune`）。I を変える（S はそのまま）。
- 刻み 0.5 ms の RK4。保存則（μ=0, c=0）: 60 秒でエネルギー 6e-12（比）、運動量 1e-14。2 ms でも 6e-9。
- 板の動きは 10 倍で描く（`XMAG`。本物は 1 mm ほど）。缶は板の半分の速さで転がる。棒は上へ、重心は支点の下（点線）。
- 位相 = atan2(−θ̇/ω0i, θ)（表示の目安。ふれが大きいと少し波打つ）。

| 板の摩擦 c=3〜8 | 行ったり来たり（止まらない。ふれはばも左右でちがう） | c=3 で 6°、c=8 で 0〜33° | — |
| 5台 ばらつき1% | 45秒で r>0.95 | 30秒で r>0.99 | 7台で同じ向き |

## ハマったところ
- ぬれた床で逆向き: 速さに比例する摩擦では、c を大きく（板がほとんど動かないくらい: c/(Mω) ≈ 10）しないと逆向きにならず、ばらつき 0.1% でもずれていく。中くらいの c では止まらない状態。論文の実験とどこまで同じかは決めきれない（押し方の形・床の摩擦の形しだい）→ 画面に正直に書いた。
- 「そろえて」をまったく同じ角度にすると、対称のまま永遠にずれない（不安定な状態にのったまま）。0.03 rad ずつずらしてある。
