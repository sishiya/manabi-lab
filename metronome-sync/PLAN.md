# メトロノームがそろうまで 企画書

作成 2026-10-17

## ユーザーの依頼
「結合振子の同期ってコンピュータで正確に再現できる？できそうならアプリつくって。正確な物理シミュレーションが必要かも」（2026-10-17）

## 答え（できるかどうか）
- **できる**。動く板にのせたメトロノームは、板1つ＋振り子 N 本の「自由度 N+1 の運動方程式」で書ける。これは小さな式なので、近似なし（角度は sin・cos のまま、小さい振れの近似なし）に、誤差を確かめながら数値で解ける（RK4、刻み 0.5 ms。摩擦と駆動を切るとエネルギーと運動量が保たれるかで誤差を測る）。
- 正確さを決めるのは計算ではなく**モデルの中身**: メトロノームのぜんまい（脱進機）が振り子を押すしかたと、板の転がりの摩擦。ここは論文が実験に合わせて決めた式と値（Pantaleone 2002 の van der Pol 型の項 μ=0.010）を使い、「実験に合わせて決めた推定」と画面に書く。
- そろうこと・そろう向き（同じ向き／逆向き）・そろうまでの時間（数十秒）は再現できる。何秒後のどの瞬間にどの角度か、までは、実物の初めの状態と摩擦が分からないので合わせられない（実験でも毎回少しちがう）。

## ねらい
- ばらばらに動かし始めたメトロノームが、板が少しゆれるだけで、ひとりでに同じリズムにそろうのを見る。
- 「なぜそろうのか」: 板のゆれが振り子どうしをつなぐ。板をおさえるとつながりが切れ、そろわない。
- 条件で結果が変わる: 床をぬらす（板の動きに摩擦）と逆向きでそろう（Huygens の時計と同じ）。板を重くするとそろうのが遅い。台数をふやしても、そろう。

## 形
- 1つの板の上に、メトロノームを横一列（2〜10台）。横から見た図。
- 上に固定: 板とメトロノームの図＋「位相の円」（各メトロノームが円の上の点。そろうと1か所に集まる）。
- 下にスクロール: 時間のグラフ（となりとの位相のずれ、Pantaleone の図2と同じ見方）、操作、説明。
- いつでもマウス・指で: メトロノームをさわると振り子を押す（ずらす）。「板をおさえる」をおしているあいだ板が止まる。
- カチカチの音（振り子がまん中を通るとき。はじめは音なし、ボタンで）。
- 画面の「つぎへ」1つで: ①2台を逆向きから → そろう ②板をおさえる → そろわない ③床をぬらす → 逆向きでそろう ④板を重く → 遅い ⑤5台ばらばら → そろう。

## 段階A（この版）
- 物理: 板＋N 本の振り子のラグランジュの運動方程式（近似なし）を、毎ステップ (N+1) 元の連立を解いて RK4。脱進機と振り子の摩擦は Pantaleone の van der Pol 項。板の摩擦（ぬれた床）は板の速さに比例する力。
- 値: Pantaleone 2002（Wittner Super-Mini-Taktell 94 g、板 58 g、208 拍/分＝104 往復/分、ふれはば約 45°→θ0=0.39 rad、x0=0.088 cm、β=0.011、μ=0.010）。
- 検証: 摩擦と駆動を切ったときのエネルギー・運動量の保存（デバッグの窓口で測る）。2台を逆向きから始めて数十秒で同じ向きにそろう（論文の図2）、ぬれた床で逆向き。
- 画面・つぎへ・出どころ・スマホ。

## 段階B以降（案）
- テンポ（おもりの位置）を変える。論文ではおもりを外した 315 拍/分で、同じ向き・逆向きの両方が見られた。
- 板どうしをばねでつなぐ（キメラ状態、Martens ほか 2013。確かめてから）。
- 脱進機を「まん中で押す」力積の形にして、van der Pol と比べる。ぜんまいがほどけていく。

## 簡単にするところ（画面にも書く）
- 脱進機（ぜんまいが押すしくみ）と振り子の空気の抵抗を、まとめて van der Pol 型の1つの項にしている（論文が実験に合わせて決めた式）。
- 空き缶の重さ・回転は入れない（論文も同じ）。板は横にだけ動く。
- 床の摩擦（ぬれた床）は速さに比例するとし、大きさは推定。
- 音は振り子がまん中を通る瞬間に鳴らしている（実物のカチの瞬間とは少しちがう）。
