## しくみ
- つまみ → `partialsOf`（成分の一覧 {f, a, g, s}。s は合成の枠: 1つ目の音 0〜15・2つ目 16〜31・キーキー 32〜37。枠を固定しているので、2つ目をつけ外ししても高さが飛ばない）。
- 聞こえる音と計算は同じ一覧から。ゆらし（AM）は合成では掛け算、計算では両わきの成分（まん中 1−m/2、両わき m/4）に分けて数える。
- 大きさ: 成分ごとに dB SPL（想定の大きさ × 振幅の割合）→ ISO 226:2003 の式を逆に解いて phon → Bark 帯ごとに強さを足して sone の合計。マスキングなし。
- 鋭さ: 0.11·Σ N'·g(z)·z / N、g は 16 Bark まで 1、上は 0.066·e^(0.171z)（Zwicker）。
- 粗さ: 成分の組ごとに Sethares の式 min(a)·(e^(−3.51 s Δf) − e^(−5.75 s Δf))、s = 0.24/(0.0207 f + 18.96)。振幅はいちばん強い成分を 1 とした比、全体の大きさで 2^((L−60)/20) 倍。1 kHz・60 dB・70 Hz・100% の AM を 1 asper にそろえる（`ROUGH_REF`）。
- 快さ: P = e^(−0.7R)·e^(−1.08S)·(1.24 − e^(−2.43T))·e^(−(0.023N)²)、地図の横 = log10(P/0.25)/0.65（±1 で切る）。
- 興奮: tanh(0.45·log2(N/4) + 0.5·(S − 1) + 0.6·R + テンポ)、テンポ = 0.6·tanh((bpm − 90)/40)（拍なしは 0）。
- 音程のある音のパワーを tone²、ノイズを noise² にそろえてから、全体を想定の大きさに合わせる。
- ノイズ: `NOISE` の密度の式（白 1・ピンク 1/f・雨 1/f×HP1k²×LP9k・波 1/f²×LP700×HP40・風 1/f×BP450 Q1.5）を 1/3 オクターブの帯の成分（g=2）にして耳のモデルへ。粗さには数えない。合成は同じ形のフィルタで、強さは 20 秒の平均で測って合わせる（種類を変えたら 1 秒空回しで初めの値）。波のうねり・雨つぶ・風のさまよい・拍・ゆらぎは計算に入れない。
- 音らしさ T = 音程のある成分の sone ÷ ぜんぶの sone。
- 内わけ（`analyze` の `why`）: 快さは log10 の各項 ÷ 0.65（音らしさは T=1 のときとの差）、興奮は tanh の中の各項。`UI.whyText` が大きい順に3つ。
- 地図でつくる: cost = 推定と目標の距離² + 0.015·Σ(なぞりはじめからの動き)²。動かすのは高さ・明るさ・大きさ（68 dB まで）・キーキー・ゆらし・拍・音程（2つ目がオンのとき）・自然の音の量と音の量（自然の音を選んでいるとき）。拍は「なし」から 108（興奮へ）か 45 拍/分（落ち着きへ）に飛ぶ。なぞる間は毎コマ2回、はなして 0.6 秒つづけ、距離 0.12 より遠ければ「届きません」。
- BGM: 和音（半音の数）を `P.chord` に入れると、1〜3つ目の音を枠 0・16・32 から鳴らす（キーキーは 48〜）。開いた配置 Ⅰ[0,7,16]・Ⅳ[−7,9,12]・Ⅴ[−5,11,14]・Ⅵm[−3,4,12]。和音の切りかえは worklet の xfade（高さの変わる枠をいったん消してから次の高さで鳴らす。すべらせない）。進めるのは setInterval（隠れたタブでも進む）。BGM のときだけ、タブを隠しても止めない。

## ハマったところ・確かめられなかったこと
- **快さの式の係数**（0.7・1.08・1.24・2.43・0.023）は、記憶にある Zwicker & Fastl の式の形。2026-10-20 にウェブで原典（Aures 1985・Fastl & Zwicker 9章）の係数を確かめられなかった。画面には「Aures の考え方にならった式、係数はこのアプリの推定」と書いた。原典を確かめられたら直す。
- Sethares の式は2つの純音の不協和の曲線なので、AM の粗さがいちばん大きくなる速さが本物（約 70 Hz）より低く出る（1 kHz で約 36 Hz）。画面にも書いた。
- 粗さの重みに sone の平方根を使うと、弱い倍音の両わきの成分まで強く数えて、ほぼ sin の AM が 2.6 asper になった → Sethares どおり振幅の比にした。
- 大きさ 0 のキャンバス（最初のコマ・隠れたタブ）で `ellipse` の半径が負になって例外 → `Draw.all` で小さいときは描かない。ループは先に requestAnimationFrame を呼ぶ。
- Halpern ほか 1986: いちばん高い帯を消しても黒板の音のいやさは減らなかった（「高い音ほどいや」ではない）。ツアー③は Kumar ほか 2008 の 2,500〜5,500 Hz と書く。

- ノイズだけにすると T=0 で、快さの式の (1.24 − e^(−2.43T)) が約 1/5 になり、さらに広い帯の音は sone が大きく鋭さも出るので、雨・ザーは快さ −1 近くに出る（波＋少しの音で −0.2 ほど）。式をいじって自然の音を快にすることはしなかった（係数も原典で確かめていないので、合わせにいくと作り話になる）。かわりに、耳のモデルは「何の音か」を知らないことと、Alvarsson ほか 2010 を画面に書き、「じぶんの感じ方」とくらべる形にした。

- BGM の和音を近い形（Ⅰ[0,4,7] など）で 196 Hz に置くと、3度の音どうしがうなって粗さ 0.6〜1.2、地図のまん中に来た → 開いた配置で粗さ 0.1〜0.5、「ゆったり」側に（Plomp と Levelt どおり。低い音で近い音程を避けるのは和声のふつうのやり方）。
- 探す処理: 正則化の項を動かすつまみ以外でも足していて NaN → 比べる式がいつも false で何も動かなかった。拍は 0（なし）から少し動かしても 30 未満で 0 に戻るので、飛ばす値を入れた。
