## しくみ（2026-10-25 に計算と合わせて書き直し、批判役のデバッグで直した）
- **信号**（ntsc.js `decodeFrame(pic, link, frame, dotW)`）: 1ドット＝8点÷dotW（ドットの速さの倍率。用意した絵と「画面の一部」の自分の画像は 1、「画面まるごと」は 横/256）。1行の点の数 N≈8W/dotW（「画面の一部」の横 512 ドットで 4096 点 → 出力 2048 点）。位相 = (点 + 4×行 + 8×コマ) mod 12（NESdev の一例。2コマで交互）。色の波は理想の正弦波（`setSquare` で四角い波にもでき、verify.js で差は 1 割まで）。YIQ は FCC の式（Wikipedia「YIQ」で確かめた。一次資料は読めていない）。
  - こし器はガウスを箱3回で近似。−3dB の点が帯域になるよう σf＝0.1325（verify.js で 1/√2）。
  - ビデオ端子: 色副搬送波をかけて ±1.0MHz（推定）のこし器 → それを戻して信号から引いたのが明るさ（トラップ）。色はその候補をさらに 0.6MHz（推定）。アンテナ線は 0.5MHz＋ノイズ 0.06。S端子: 明るさ 4.2、色 I・Q とも 1.0MHz（推定。放送の 1.3／0.4 は送る側の値）。
  - 出力は横 N/2 点の RGBA8（E'、`out.w`）。「目に見える平均」は2コマを光の量（ガンマ 2.4。ガンマを切っても 2.4）で平均して E' に戻す。
- **大きさ**（main.js `geom`）: 「画面まるごと」だけ、縦 241〜480 行は 480本（rowH＝0.5）・dotW＝横/256・縦横比 (8/7)÷dotW÷rowH（NESdev「Overscan」の 240×4/3÷280。320 幅で 0.914）。それ以外は rowH 1・dotW 1・8/7。自分の画像は縦 480・横 512 ドットまで（こえたら平均でまとめる）。
- **画面**（crt-gl.js）: 長さはぜんぶ 240本の1行を 1 とする。ビームのたて σ＝0.15〜0.40 行（明るさの平方根）÷rowH、横 σ＝0.24〜0.55（256 ドットの1ドット単位）×uDotW、9点で欠けるすそは erf で割って光を保つ。たて3点の平均（z＜6）。1行 1.5〜2.3 ピクセルで帯をならす。光のにじみ: 光の量の RGBA16F ミップ（3・5段＋log2(1/rowH)、横 n 点で丸く）を 12% まぜる（光る点と頭打ちの前なので、一様な面は変わらない。拡張がなければ E'）。光る点: 1組が 3.5 ピクセル以上なら本物の大きさ（1ピクセルに 4×2 点の平均）、未満なら画面の3ピクセルに合わせたしま（HUD に粗さの倍率）。明暗は 75%、平均を保つ。0.8 から頭打ち → 白は光の量で液晶の約45%（測った値 0.44）。ガンマ 2.4 → 表示 1/2.2。ふくらみは Lottes の 0.031/0.041。
- 光る点の組: 家庭のテレビ 1.5組／行、モニター 2.6組（どちらも出どころのない推定）。シャドウマスクは六角形（となり 1/√3 組・行 1/2 組）。

## ハマったところ
- 全体表示の倍率が半端だと走査線のすきまがモアレになる → 全体は「1ドット＝整数のデバイスピクセル」にそろえ（15% より小さくなるときは半端のまま）、＋−ボタンも整数へ。さらにブラウン管の側は 1行が 6 ピクセル未満のとき、1ピクセルの中のたてに3点とって平均。1行 2.3 ピクセル未満は帯をならす（HUD も同じ境目）。光る点は案 C で、細かすぎるときは画面の3ピクセルに合わせる。
- 自分の画像をいつも「画面まるごと」として、テレビの横はばに合わせたら、写真をならべた縦長の画像が2倍に横長になった → ふつうは「画面の一部」（ドット1つずつを当時のドットとして）、「画面まるごと」は選んだときだけ。
- 批判役のデバッグ（2026-10-25）で直したもの: ブルームを頭打ちのあとにまぜていて白い面が 15% 明るくなった、画像より大きい k で 0×0、ビデオ端子の明るさが 1.6MHz でぼけすぎ（→トラップ）、S端子の帯域、寄った倍率が画面の大きさの変化で消える、480本の絵のブルームが半分、ガンマを切ったときのずれ、横の広がりの光が 3% 欠ける、テクスチャ 2048 点をこえる（→横 512 まで）。
- ダブルタップを「300ms 以内の2回の指の接触」で見ていたら、ピンチのあとの移動が全体表示に戻った → 動かさずに短くたたいた2回だけ数える。
- 上に固定した画面の下に、フォーカスやページ内の移動でボタンが隠れた → `scroll-padding-top` に固定部分の高さ（横向き2列のときは 0）。
- 自分の画像の拡大の倍率を、3点おきに調べていたので 2倍の絵を 3倍とまちがえた・なめらかなグラデーションを 8倍とまちがえた → 点をばらまき、「四角の中は同じ色・さかい目では変わる」の両方を見る。
- GLSL ES の `flat` は予約語（変数名にするとシェーダーが通らず「WebGL2 が使えない」の文になる）。
- 白黒の1ドットじまのにせの色は、行ごとに色相が 120° 回るので面の平均では灰色。確かめは点ごとの色のこさで。
- Browser ペインが隠れているとスクリーンショットが古いままのことがある（もう一度撮る）。
