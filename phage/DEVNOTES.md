## しくみ
- **時間**: スライダーの位置 u（0〜1）を区間に分ける（区間の長さ＝ふつうの速さでの秒数: 近づく7・くっつく6・刺さる9・DNA が入る6・細菌の中55・破れて出る7）。区間ごとに本当の時間の書き方がちがう（ミリ秒・はっきりしない・分）。もしもで区間が変わる（受け手なし: くっつけないで終わる、糖のない T4: 細菌の中は3分で切られて終わる、もう1つ来る: 破裂が60分）。
- **細菌の中は時刻だけから決まる**: 頭は 9分から毎分12個のペース（25分以降は少しずつ減る）で `born` を決め、つめはじめ `fs`・つめおわり `fe`（毎秒 350〜2000 の速さでヘッドフル）を前もって作る。T4 の DNA は `1 + 14×(分−5)` 本ぶん（目安）からつめた分を引いた数だけ輪を描く（40本まで）。流れる点は種類ごとに決まった間かくで生まれ、決まった時間（0.5〜0.6分）で行き先へ。
- **寄るほど細かく**: 拡大率 s（px/nm）で描き分ける。s<1.1 は点や線、1.1〜はリボソーム（約20nm）・RNA ポリメラーゼ（約15nm）・コピーの機械、1.5〜は DNA を二重らせんで、4〜は塩基対の段、6〜は T4 の DNA のブドウ糖、5〜は分子の名前。頭としっぽは s<0.9 で `drawPhageBody`、それ以上で `T4D`（殻の六角形・23段のさや・脚）。見えている範囲だけ描く。
- **着陸**: 降りる場所は細菌の上面 x=−380（`SITE`）。③の「刺さる」と同じ時刻表（0〜18秒: 星形・短い脚・さやが1段ずつ・リゾチーム・DNA）を、刺さる区間・DNA が入る区間に割りあてる。
- **解説**: 描くたびに `V.hit({c|seg|box|test, info|infoAt})` で場所を登録し、マウスの下を上から順に調べる。いちばん下に細胞の外側の層（深さで 外膜・ペリプラズム・細胞壁・内膜・細胞質 を決める）。スマホはタップ。
- **おまかせカメラ**: 見どころ（`Story.events()` の `cam`）が切りかわるたびにそこへ寄る（ゆっくり。位置は画面の上の距離で近づけるので、人のからだ → 分子のように大きく寄っても目的の場所が外に残らない）。細かいところは `zoom` でルーペに出し、本図は引いたまま。ルーペは本図の枠のすぐ横（右、入らなければ左。上の切りかえ・右の拡大ボタン・左下のカードを避ける）に出し、本図より1.8倍以上大きくできないときは出さない。シークバーを動かすとおまかせにもどり、動かしている間はカメラを速く（`View.camK` 4。人のからだの区間は 2.2、ふだん 1.1）。見どころが変わった直後の約3秒は再生を遅く（0.3倍から）。ホイール・ドラッグ・ピンチで自分で動かすと止まり、図の上のまん中の「自分で動かす」が光る。「おまかせカメラ」でもどる。動ける範囲は原点から「横はばの半分＋1.6µm」まで。自分で動かすときは、さらにいまの見どころの場所から ±max(横はば, 2.2µm)×0.8 まで、引けるのは見どころの横はばの3倍まで（`View.setBounds`）。人のからだの区間（6秒）は見どころの直後も遅くしない。
- **奥行き**: 細菌の中は立体を平面に重ねるので、頭（`h.z`）・リボソーム・DNA の輪（1つめと3つに1つが手前）・流れる点のうち手前の約3割だけくっきり描いて説明を出し、奥は薄い背景（説明なし）。数は減らさない。
- **組み立て**: born〜+0.35分 内膜の上で殻（gp23 の6個組が入口の側から1つずつ、次に付くものは外から寄ってくる）、〜fs 足場が切られて殻が離れる、fs〜fe DNA をつめる（はじめに殻がふくらむ 0.88→1）・その間しっぽは別の場所で 基盤（くさび）→ 管 → さや1段ずつ → ふた、fe〜+0.25 首ができてしっぽがふらふら寄ってはまる、〜+0.6 長い脚が1本ずつ。
- **はじめと終わり**: 人のからだ（約1.7m）→ 大腸 → かべ → 粘液 → たくさんの大腸菌（64個、模式）。大腸のかべの内側（`Macro.SURF`）の上の粘液の外側の層に原点。破れたら、まわりの細菌へうつる（REACH 5.2µm 以内に距離に応じて0.5〜3分で。潜伏期は物語の細菌と同じ）。
- **破れる**: burst 0〜0.22 で棒の形がくずれてふくらむ（`swollen`）、そのあと上面の x=300 が破れて中身が出て、膜は8つのかけら（`frag`）に。ぬけがらはささった場所（`siteAnchor`）といっしょに動いて薄れ、次々にうつる区間では描かない。出たファージの位置は `burstPos(h, k)` で、次々にうつる区間はその k=1 の位置から続ける。大きく見えるときは小さな形、引くと点（`phageMark`）。中身が薄れるとき、`drawInside` の中は `baseA`（はじめの濃さ）を基準にする（1 にもどすと中身が残って見えた）。
- **本物に近い見た目**: `.viewWrap.real` の CSS の filter で色を抜き、つぶつぶを重ねる（毎コマの計算はしない）。札を消し、細胞の中の模様を3倍ぎっしり、DNA を本当の太さ（約2nm）に。
- **軽さ**: 解像度は最大1.5倍。止まっていて時刻とカメラが同じなら描き直さない（`View.sig()`）。引いて見るときは殻の六角形の並びを描かない。奥の頭は簡単な絵で。

## ハマったところ
- 行の途中に `// 注釈` を足すと、その行の後ろのコードまで注釈になる（中心の位置の計算が消えて、絵がずれた）。注釈は別の行に書く。
- 隠れている canvas は大きさ0になる。拡大率を計算するところは 0.01 以上にし、ResizeObserver で見えたときに測り直す。
- 最初のコマは requestAnimationFrame の時刻が前に取った時刻より前のことがあり、dt がマイナスになる（√ が NaN）。dt は 0〜0.05 に収める。
- smoke.ps1 は開くだけなので、見どころを順に押す・いろいろな時刻と拡大率で描く、は headless の Chrome で別に確かめる。

## 確認のしかた（変更のたびに）
1. `powershell -NoProfile -ExecutionPolicy Bypass -File _dev/tools/smoke.ps1 -Apps phage -Lang ja`（`-Port` は使っているサーバーに合わせる）
2. 見どころを上から順に押す → その時間・その場所へ寄る（20個）。`__phErr` が空。
3. いろいろな時刻と拡大率で描く: 人のからだ（横3.6m）・大腸（36cm）・かべ（5mm）・粘液（340µm）・たくさんの細菌（40µm）・近づく（全体）・くっつく（横はば300nm）・刺さる（190nm）・DNA が入る（500nm）・3分のリボソーム（140nm）・4分の細菌の DNA と酵素（60nm）・7分のコピーの機械（70nm）・12分の頭へ DNA をつめる（420nm）・20分（500nm）・破れて出る（ふくらむ 0.1・破れたあと 0.6）・次々にうつる（34µm）。「見た目: 本物に近い」でも1枚。1コマの時間をはかる（ソフトウェア描画で 10ms 以下が目安）。
4. マウスを乗せると解説: 水・外膜・細胞壁・内膜・細胞質・リボソーム・脚・頭・さや など。
5. もしも 4つ（ふつう・受け手なし・糖のない T4・もう1つ来る）で最後まで再生できる。
6. スマホの幅（390px）で横にはみ出さない（`scrollWidth` が 390）。
7. 自分で動かす → 上のまん中の切りかえが「自分で動かす」に光る → 「おまかせカメラ」で今の見どころへもどる。遠くへドラッグ・大きく引いても、見どころのまわりで止まる。
8. 最後まで再生したあと、シークバーを行ったり来たりする → おまかせにもどり、その時刻の場所・ルーペになる（エラーなし）。
