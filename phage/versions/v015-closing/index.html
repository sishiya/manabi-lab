見どころ（押すと、その時間・その場所へ）

    もしも

    ぎもん

    ファージはどこから来るの？

    細菌のいるところなら、どこにでもいる（水・土・下水・人や動物の腸の中）。T4 のような大腸菌のファージは、下水や便から見つかる。食べ物や水といっしょに口から入ることもある。研究の値

    1つだけ？ たくさんいるの？

    たくさんいる。人の大腸の中身1gに、ウイルスは約1億〜100億個いて、そのほとんどがファージ（Shkoporov と Hill 2019）。種類もとても多い。このアプリでは、そのうちの1つを追いかけている。目安

    1つのファージから、どれだけ増えるの？

    細菌1つの中で約20〜25分のうちに100〜150個。出てきたファージがまた別の細菌にとりつくので、1回ごとに何十〜百倍になる（ねずみ算）。目安

    部品は、だれが組み立てているの？

    運ぶ係や組み立てる係はいない。部品は熱でふらふらとでたらめに動き（ブラウン運動）、正しい相手に正しい向きでぶつかったときだけくっつく（自己集合）。殻のたんぱくを折りたたむ gp31、長い脚を付けるのを助けるひげ（フィブリチン）など、手伝うたんぱくはある。研究の値

    人にもうつるの？

    うつらない。ファージがとりつけるのは、脚がつかめる印（受け手）を持つ細菌だけ。T4 がとりつくのは大腸菌の一部の株で、人の細胞には入れない。研究の値

    大腸菌はぜんぶやられちゃうの？

    いいえ。受け手（OmpC など）を変えた大腸菌は生き残る（「もしも: 受け手のない細菌」）。細菌は制限酵素などの守りも持つ。腸の中では、細菌とファージがずっといっしょにいつづける。研究の値

    ファージは生きているの？

    自分では増えられず、栄養からエネルギーも作らない。細菌の中に入ったときだけ、細菌の材料と工場を使って増える。生き物と呼ぶかどうかは、人によって考えが分かれる。

    大きさの見え方は本当？

    細菌（約2µm）・ファージ（約0.2µm）・膜の厚さ・リボソーム（約20nm）・べん毛（太さ約20nm）は本当の大きさに合わせている。ただし DNA の長さ（T4 は約57µm、細菌は約1.6mm。どちらも細菌よりずっと長く、ぎゅっと折りたたまれている）、リボソームの数（本当は数万個）は、見やすさのために大きく減らして描いている。

    細菌の中の数（いまの時刻）

    図の中の流れる点1つは、たくさんの分子の代わり（模式）。細菌は立体なので、奥にあるもの（約7割）は薄く背景として描き、マウスを乗せて説明が出るのは手前のものだけ。数は減らしていない。

    このアプリについて

    バクテリオファージ（ファージ）は、細菌にとりつくウイルス。ここでは、研究でいちばん調べられてきた T4 ファージと大腸菌を使う。T4 は頭が 120×86nm、しっぽと合わせて約 200nm。大腸菌（約 2µm）の10分の1ほどの大きさ。

    見かた: 下のスライダーで時間を動かす（▶で再生）。ホイール・ピンチで拡大、ドラッグで移動。マウスを乗せる（スマホはタップ）と、そこにあるものの説明が出る。細菌全体（約2µm）から、たんぱく質が見える大きさ（横はば約20nm）まで寄れて、寄るほど細かく描く。「見どころ」を押すと、その時間・その場所へ寄る。

    文の右の印: 研究の値 研究で測られたこと・確かなこと　目安 時刻や数の目安・推定　模式 見せ方のための形

    くっつく・刺さる・DNA が入る

    • 6本の長い脚（長い尾繊維、約145nm）の先が、細菌の表面の決まった印（受け手）にくっつく。大腸菌 K-12 では外膜のたんぱく質 OmpC。研究の値
    • 3本以上の脚がくっつくと、基盤が六角形（直径約52nm）から星形（約61nm）に変わり、短い脚が約100°まわって LPS の内側の糖にしっかりくっつく。研究の値
    • しっぽのさや（gp18 が6個×23段）が基盤の側から1段ずつ縮み（92.5→42nm、1段のねじれは17.2°）、中の管が約345°回りながら押し出されて外膜を突きぬける。針のリゾチームが細胞壁に穴をあけ、DNA が入る。研究の値
    • 受け手をなくした変異の大腸菌（OmpC がなく、LPS の糖の鎖も短い）には付けない（もしも）。研究の値

    細菌の中（37℃・栄養のある液での目安）

    • 1分で細菌自身のたんぱく質がほとんど作られなくなる。研究の値 T4 の EndoII（CCGC を切る）・EndoIV（シトシンの DNA を切る）が細菌の DNA をこわし、T4 の DNA の材料にする（このアプリでは2〜10分）。目安
    • T4 は細菌の RNA ポリメラーゼを最後まで使い、Alt・AsiA・MotA・gp55・gp33・gp45 を付けかえて、早期 → 中期 → 後期の遺伝子を読ませる。研究の値
    • 約5分で T4 の DNA のコピー（gp41・gp43・gp45・gp44/62・gp61・gp32 など。毎秒約400〜500塩基）、約9分から頭・しっぽ・脚の部品。目安
    • 頭: 入口 gp20 のまわりに足場（gp22・gp21）と殻（gp23 約930〜960個・頂点 gp24）→ モーター gp17 が DNA をつめる（平均 毎秒約700塩基対、最大約2000、1つ約4〜5分）→ ゲノムの1.02倍で切る。研究の値
    • しっぽは頭と別に組み立てられ（基盤 → 管 → さや → ふた）、DNA のつまった頭に付く。長い脚が最後。研究の値
    • 最初の完成品は約12〜15分、約22〜25分で破裂し、100〜150個が出てくる。目安
    • ホリン（t）が決まった時刻に内膜に穴をあけ、リゾチーム（e）が細胞壁を切って破れる。研究の値
    • もしも: 約4分すぎに来た別のファージの DNA は中に入れない（重感染排除）。5分すぎに別のファージが来ると、破裂が大きくおくれる（溶菌阻止）。DNA にブドウ糖の目印がない変異の T4 は、大腸菌の制限酵素に切られる。研究の値

    人のからだから・次々にうつる

    • はじめは人のからだ（身長約1.7m）から、おなかの大腸 → 大腸のかべ（粘膜・陰窩・粘膜下層・筋肉）→ 粘液 → 大腸菌（約2µm）へ寄っていく。人の体の細菌は約40兆個で、ほとんどが大腸にいる（Sender ら 2016）。目安
    • 大腸の粘液は2層で、内側の層には細菌がほとんど入れず、外側の層に細菌がすむ（Johansson ら 2008）。大腸の中身1gにウイルスは約1億〜100億個、ほとんどがファージ（Shkoporov と Hill 2019）。研究の値
    • 組み立て: 頭は内膜の上で、入口 gp20 → 足場 gp22・gp21 → 殻 gp23（入口の側から付いていく）。はさみ gp21 が足場を切ると空の殻が離れ、DNA をつめはじめると殻がふくらみ、Hoc・Soc が付く。つめおわると首（gp13・gp14）が付き、別に組み立てたしっぽ（基盤 → 管 → さや → ふた）がはまり、最後に長い脚が付く。部品は運ばれるのではなく、熱でふらふら動いてぶつかったときにくっつく（自己集合）。研究の値
    • 破れて出る: ホリンが内膜に穴をあけ、リゾチームが細胞壁を切ると、細菌は棒の形を保てなくなり、スパニンが外膜を破って中身がいっせいに出る（Kongari ら 2018 などのスパニンの研究）。細菌は死に、膜はちぎれたかけらになる。研究の値
    • 次々にうつる: 出てきたファージが近くの細菌にとりつき、同じことがくり返される。どの細菌にいつうつるか、広がる速さ、まわりの細菌の位置・泳ぎ方は模式。「ファージ 約○個」は（破れた細菌の数）×（物語の細菌から出た数）の目安。模式

    簡単にしているところ

    • 立体を横から見た平面の図にしている。6本の脚は奥行きを色の濃さで表す。
    • スライダーの区間ごとに時間の進み方がちがう（近づく・くっつくはミリ秒、細菌の中は分）。区間の名前と本当の時間を出している。模式
    • 近づくときのゆれ（ブラウン運動）・脚がくっつく時刻は演出。ファージを半径約75nm の球とみなすと、拡散係数は約3µm²/秒（ストークス・アインシュタインの式）。目安
    • さやが縮む速さ、DNA が入るのにかかる時間は、T4 でははっきり測られていない。管がどこまで入るかも模式。模式
    • 細菌の中の分子（リボソーム・RNA ポリメラーゼ・コピーの機械・酵素）の数・置き場所・色は模式。大きさはおおよそ本当に合わせた（リボソーム約20nm、RNA ポリメラーゼ約15nm、DNA の太さ約2nm）。たんぱく質は丸や四角で描き、本当の原子の形ではない。模式
    • 流れる点は、1つがたくさんの分子の代わり。どこからどこへ流れるかは本当の順番どおりだが、点の数と動きは模式。「頭の殻 gp23 約○個」は、1つの頭に約960個（Rao と Black 2010）×作りはじめた頭の数で計算している。T4 の DNA の本数は、頭につめる数に足りるように決めた目安。模式
    • 頭が作られる速さは「最初の完成が約12〜15分・破裂までに100〜150個」に合うように決めた。溶菌阻止で破裂がどれだけおくれるかは条件で大きく変わる（数十分〜数時間）。アプリでは約60分にした。模式
    • DNA の長さは大きく短くしている（T4 の DNA は約57µm、細菌の DNA は約1.6mm で、どちらも細菌の長さ約2µm よりずっと長く、ぎゅっと折りたたまれている）。リボソームの数も本当（数万個）よりずっと少ない。大きさ（太さ・直径）は本当に合わせている。模式
    • べん毛（太さ約20nm、長さ5〜10µm。Turner ら 2000）・線毛（太さ約7nm、体じゅうにほぼ均等に生える）の本数と向きは模式。寄ったときは薄く描く。模式
    • DNA を入れおわったファージ（ぬけがら）はもう感染できず、細菌の表面にささったまま残る。細菌が破れると、ささっていた膜のかけらといっしょに流される。研究の値
    • 細菌の中は立体を平面に重ねて描いているので、頭どうしが重なって見える。破れるときの形のくずれ方・かけらの数は模式。模式
    • 「見た目: 本物に近い」: 本物のファージや細菌は光の波長より小さく、色はない。電子顕微鏡の写真のように色を抜き、名前の札を消し、細胞の中をぎっしりにした見え方。形と大きさは「わかりやすい」と同じ。模式
    • 学習用に簡単にしています。医療や実験の判断には使えません。
