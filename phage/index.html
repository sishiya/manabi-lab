        ルーペ

        このアプリについて

        バクテリオファージ（ファージ）は、細菌にとりつくウイルス。ここでは、研究でいちばん調べられてきた T4 ファージと大腸菌を使う。T4 は頭が 120×86nm、しっぽと合わせて約 200nm。大腸菌（約 2µm）の10分の1ほどの大きさ。

        文の右の印: 研究の値 研究で測られたこと・確かなこと　目安 時刻や数の目安・推定　模式 見せ方のための形

        ① 着陸させる

        • 6本の長い脚（長い尾繊維、約145nm）の先が、細菌の表面の決まった印（受け手）にくっつく。大腸菌 K-12 では外膜のたんぱく質 OmpC、OmpC を持たない大腸菌 B では LPS（外膜の表面の糖の鎖）のブドウ糖。研究の値
        • 3本以上の脚がくっつくと、基盤が六角形から星形に変わり、短い脚が LPS の内側の糖にしっかりくっつく。研究の値
        • しっぽのさやが 92.5nm から 42nm に縮み（23段の輪が基盤の側から順に縮む）、中の管が外膜を突きぬける。管の先の酵素が細胞壁に穴をあけ、DNA が入る。研究の値
        • 受け手をなくした変異の大腸菌（OmpC がなく、LPS の糖の鎖も短い）や、外膜のない枯草菌には付けない。研究の値

        ② 細菌の中（37℃・栄養のある液での目安）

        • 1分で細菌自身のたんぱく質がほとんど作られなくなる。研究の値 細菌の DNA はこわされ、T4 の DNA の材料になる（このアプリでは2〜10分）。目安
        • 約5分で T4 の DNA のコピー、約9分から頭・しっぽ・脚の部品。目安
        • 頭の殻に DNA をつめるモーターは、平均 毎秒約700塩基対（最大約2000）。研究の値 1つの頭（約17万4千塩基対）で約4分の計算。
        • 最初の完成品は約12〜15分、約22〜25分で破裂し、100〜150個が出てくる。目安
        • 約4分すぎに来た別のファージの DNA は中に入れない（重感染排除）。5分すぎに別のファージが来ると、破裂が大きくおくれる（溶菌阻止）。研究の値
        • T4 の DNA は、シトシンのかわりにブドウ糖のついたヒドロキシメチルシトシンを使い、細菌の多くの制限酵素に切られない。ブドウ糖のない変異の T4 は、大腸菌の制限酵素（K-12 では McrBC）に切られる。研究の値

        ③ 寄って見る（たんぱく質が見える大きさ）

        • 形: 頭の殻 gp23 約930〜960個・頂点 gp24（12の頂点のうち11）・入口 gp20（12個）・飾り Hoc 155個／Soc 870個、さや gp18 138個（6個×23段）、管 gp19 約140個、短い脚 gp12 18個、長い脚 6本、中に DNA（ゲノムの1.02倍）と内部たんぱく約1000個。研究の値
        • 刺さる: 基盤は直径約52nm の六角形から約61nm の星形に。さやは基盤の側から縮み、1段のねじれは 17.2°、管は約345°回りながら押し出される。研究の値
        • こわす: T4 の EndoII は CCGC を、EndoIV はシトシンを含む DNA を切り、hmC の T4 の DNA は切らない。遺伝子56の酵素が C の材料をこわし、遺伝子42の酵素が hmC の材料を作る。研究の値
        • 読みかえ: T4 は細菌の RNA ポリメラーゼを最後まで使い、Alt・AsiA・MotA・gp55・gp33・gp45 を付けかえて、早期 → 中期 → 後期の遺伝子を読ませる。研究の値
        • コピー: gp43・gp45・gp44/62・gp41・gp61・gp32 などの7つのたんぱくで分かれ目が進む。体の中では毎秒約400〜500塩基。組みかえでつながった長い DNA（コンカテマー）になる。研究の値
        • 頭: 入口 → 足場（gp22・gp21 が 576:72）→ 殻 → はさみ gp21 → ふくらむ（約15%）→ モーター gp17（最大 毎秒約2000塩基対・約60pN、1つ約5分）→ 1.02倍で切る。研究の値
        • しっぽ: くさびは gp10 → gp7 → gp8 → gp6 → gp53 → gp25 の順（gp11 はいつでも）。管 → さや → ふた gp3・gp15 → 頭と合体 → 長い脚が最後。研究の値
        • 破って出る: ホリン（t）の穴でリゾチーム（e）が細胞壁に届く。rI がホリンをおさえると破裂がおくれる。研究の値

        簡単にしているところ

        • 立体を横から見た平面の図にしている。ファージは画面の面の中でだけ回る。6本の脚は奥行きを色の濃さで表す。
        • 着陸は本当の 1万分の1 の速さ。ゆれの大きさは、ファージを半径約75nm の球とみなした見積もり（拡散係数 約3µm²/秒、回転 約400rad²/秒。ストークス・アインシュタインの式）。目安
        • 光ピンセットにつままれた細長いものは、光の向き（縦）にそろいやすい。アプリではそれを簡単な力で表している。模式
        • 脚がくっつく・はなれる速さは演出（測られた値ではない）。模式
        • DNA が入るのにかかる時間は、T4 でははっきり測られていないので、早回しで見せる。管がどこまで入るか、内膜がどう引きよせられるかも模式。模式
        • 細菌の中の部品の数・置き場所・色は模式。頭が作られる速さは「最初の完成が約12〜15分・破裂までに100〜150個」に合うように決めた。模式
        • 溶菌阻止で破裂がどれだけおくれるかは条件で大きく変わる（数十分〜数時間）。アプリでは約60分で破裂させ、作る速さも少しずつ落とした。模式
        • ③ の絵の形・色・置き場所は模式。たんぱく質は丸や四角で描き、本当の原子の形ではない。DNA の文字の間は見やすく広げている（本当は1文字 0.34nm）。模式
        • ③「読みかえ」の読まれやすさ・RNA の数、「コピー」で部品が欠けたときの速さ、「破って出る」のホリンの数は模式（そろったときの毎秒400〜500塩基だけが測られた値）。模式
        • ③「こわす」の細菌の制限酵素は、何種類かあるものを1つにまとめている。模式
        • ③ の時間（DNA のつめこみ・コピー・さやが縮む速さ）は早回し・ゆっくりにしている。模式
        • 学習用に簡単にしています。医療や実験の判断には使えません。
