# 細菌にとりつくウイルス 企画書

作成 2026-10-11

## ユーザーの依頼

`IDEAS.md` の 16「バクテリオファージ」。月着陸船のような形の T4 ファージが細菌に降り、注射器のように DNA を入れ、細菌の中で増えて破って出てくる。2026-10-11 に「バクテリオファージつくって！」「できたらいつも通り保管庫へ」。

## ねらい

- ウイルスが**自分では動けない・増えられない**こと、それでも決まった印（受け手）を探して刺さり、細菌の工場をまるごと乗っとることを、**自分の手で運んで**確かめる。
- 研究で測られた大きさ（nm）と時間（分）で見る。測られていないところは「測られていない」と書く（想像で埋めない）。

## 形

Canvas 2D。3つのタブ。

1. **着陸させる**（横から見た細菌の表面。1万分の1の速さ）
   - ファージは泳げない。**光ピンセット**（実験で本当に使う、レーザーで小さなものをつまむ道具）でつまんで運び、はなすとブラウン運動でゆれて回る。
   - 6本の長い脚（長い尾繊維、約145nm）の先が細菌の表面の**受け手**にふれると、くっついたり離れたりする。**3本以上が同時にくっつく**と、根もとの板（基盤）が六角形から星形に変わり、短い脚がくいこんで動けなくなる（後戻りできない）。
   - しっぽのさやが **92.5nm → 42nm** に縮み（Leiman ら 2010）、中の管が外膜を突きぬける。管の先の酵素が細胞壁（ペプチドグリカン）に穴をあけ、DNA（168,903 塩基対、のばすと約57µm＝ファージの約300倍）が流れこむ。頭は空っぽの「ぬけがら（ゴースト）」になる。
   - 細菌を選べる: 大腸菌 K-12（受け手は OmpC）／大腸菌 B（OmpC がなく、LPS の糖で付く）／受け手をなくした変異の大腸菌（OmpC がなく LPS の糖も短い。付けない）／枯草菌（外膜がなく壁が厚い。付けない）。
   - 小窓に細菌の全体（約2µm）と、いまの場所。
2. **細菌の中**（細菌をまるごと。0〜約25分を早回し）
   - 1分: 細菌のたんぱく質づくりが止まる → 細菌の DNA がこわされ材料になる → 約5分で T4 の DNA のコピーが始まる → 約9分から頭・しっぽ・脚の部品 → 頭に DNA をつめるモーター（毎秒約700塩基対、最大約2000）→ 約12〜15分で最初の完成品 → 穴あけのたんぱく（ホリン）が内膜にたまり、約22〜25分で溶菌酵素とともに破裂、100〜150個が出てくる。
   - さわれること: ルーペ（さわった部品の説明）、速さ、**あとからもう1つファージを来させる**（5分すぎなら破裂がおくれる＝溶菌阻止。2つめの DNA は入れない＝重感染排除）、**糖のない T4（変異）にする**（DNA の目印がないので、大腸菌 K-12 の制限酵素 McrBC に切られて失敗する）。
   - 起きたことの記録（時刻つき）。
3. **このアプリについて**（しくみ・簡単にしたところ・おもな出どころ・使っているもの）

## 段階B「③ 寄って見る」（2026-10-11 にユーザーから）

ユーザーの依頼: 「段階Bも作って！」「インフルエンザウイルスのアプリ（`immune-battle/`）よりもっと寄ったスケールで、バクテリオファージの形や、細胞にとりついて具体的に何をするのか、どうやって増殖するのかに強くフィーチャーして」。
→ 前の案の段階B（シャーレ）は引いた見え方なので、段階Cへ回す。段階Bは**たんぱく質1つずつが見える大きさ（数nm〜300nm）**の8つの場面。どの場面も、ボタンを押すだけで眺めるのではなく、**自分で付ける・切る・はめる・押しこむ**。

1. **形**: T4 を大きく。ばらす・中を見る。部品をさわると名前（遺伝子の番号 gp）・数・役目。頭の殻 gp23（約930〜960）、頂点 gp24（5×11）、入口 gp20（12）、飾り Hoc 155・Soc 870、首、ひげ（フィブリチン 6本）、さや gp18（138＝6×23段）、管 gp19（約140）、基盤（くさび6つ×7種類＋中心）、針 gp5・gp27、長い脚 gp34〜37、短い脚 gp12（3本ずつ×6）。中に DNA 171kb と内部たんぱく約1000個。
2. **刺さる**: 基盤のまわり（約200nm）。脚を1本ずつ OmpC にくっつける → 3本で基盤が六角形（52nm）から星形（61nm）、短い脚が約100°まわって LPS へ → さやが基盤の側から1段ずつ縮み（1段 17.2° ねじれ）、管が回りながら押し出される → 針が外膜を破り、リゾチームが細胞壁を切る → DNA と Alt・内部たんぱくが入る。
3. **こわす**: 細菌の DNA（シトシン C）と T4 の DNA（ブドウ糖つきのヒドロキシメチルシトシン hmC）。酵素を選んで当てる: EndoII（CCGC で切る）・EndoIV（C の DNA を切る）・細菌の制限酵素 → 細菌の DNA だけ切れる。切れはしは材料になる。
4. **読みかえ**: 細菌の RNA ポリメラーゼに T4 のたんぱくを付けかえる（Alt → AsiA＋MotA → gp55＋gp33＋gp45）と、読まれる遺伝子が「細菌 → T4 の早期 → 中期 → 後期」と切りかわる。
5. **コピー**: 分かれ目（フォーク）に部品を集める（gp41 ヘリカーゼ・gp61 プライマーゼ・gp32・gp45 と gp44/62・gp43 ポリメラーゼ）。そろうと毎秒約400〜500塩基で進む。コピーは組みかえでつながって長い鎖（コンカテマー）になる。
6. **頭をつくる**: 入口 gp20 → 足場 gp22（576）・gp21（72）→ 殻 → はさみ gp21 で足場を切る → ふくらむ（約15%、中は約2倍）→ モーター gp17 を**押しつづけて** DNA をつめる（最大 毎秒約2000、力 約60pN）→ ゲノムの1.02倍で切る → 飾り。
7. **しっぽをつくる**: くさびを順番どおりに組む（gp10 → gp7 → gp8 → gp6 → gp53 → gp25、gp11 はいつでも。順番がちがうと付かない）→ 6つで輪 → 中心 → 管 → さや → ふた gp3・gp15 → 頭と合体 → 長い脚（最後）。
8. **破って出る**: ホリン（t）が内膜にたまり、決まった時刻にいっせいに穴 → 待っていたリゾチーム（e）が細胞壁を切る → 破れる。外にファージがまだいると rI がホリンを止める（溶菌阻止）。

①②からも、関係する場面へ「寄って見る」で飛べる。

## 段階C以降（案）

- **C. シャーレの箱庭**: 細菌の芝生にファージを落として溶菌斑（プラーク）が広がる。受け手を変えた耐性菌が出て増える、ファージ側も変わる（軍拡競争）。CRISPR を持つ細菌（Barrangou ら 2007）、抗 CRISPR（Bondy-Denomy ら 2013）。
- **D. λ（ラムダ）ファージ**: すぐ増えるか、細菌の DNA に入って眠る（溶原化）かを、同時に入った数（Zeng ら 2010）と細菌の調子で決める。
- **E. 人とのかかわり**: ファージセラピー（ジョージアのエリアヴァ研究所、1923〜）、海のファージ（海のウイルスは約10の30乗、Suttle 2007）。

## やらないこと

- ヒトの病気のウイルスの増やし方・扱い方（このアプリは大腸菌のファージだけ）。
- 点数・クリア（ゲームにしない。着陸は「付けるか・付けないか」を見るためのもの）。

## 簡単にするところ（画面にも書く）

- 立体を横から見た平面にしている（6本の脚は奥行きを色の濃さで）。
- 着陸の速さは1万分の1。ブラウン運動の大きさは、ファージを半径約75nmの球とみなした見積もり（拡散係数 約3µm²/秒、回転 約400rad²/秒。ストークス・アインシュタインの式）。
- 脚がくっつく・はなれる速さは演出（測られた値ではない）。
- DNA が入るのにかかる時間は、T4 ではっきり測られていないので早回しで見せる（λ では試験管で約10秒、細胞では数分の例）。
- 細菌の中の時刻は 37℃・栄養のある液での目安。条件で変わる。部品の数・位置は模式。
- 溶菌阻止で破裂がどれだけおくれるかは条件で大きく変わる（数十分〜数時間）。アプリでは約60分で破裂させる。
