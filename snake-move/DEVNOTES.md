## 実物との見比べ（v004。2026-10-18「動きがうそっぽい。実物と見比べて、計算がまちがっていないか確かめて」）

## 枝をわたる（2026-11-03。ユーザー「石のあいだを廃止して、棒の上を歩く系のタブを」）
- 調べ（Astley & Jayne 2007・Jayne & Herrmann 2011）: PLAN の「枝をわたる」。水平ではどの太さでもアコーディオン、全員が渡れた、腹の静止摩擦 0.28、止まった区間はしばしば胴の 0.25 倍より長い。
- 枝にそった動き: tree.js に `horiz`（つかむ所 `gripH` 30 cm・ループにした所の長さの割合 `cLoop` 0.6・巻かない・ループで枝をはさむ締めつけ `sqN = safety·need`。どれも推定）。はじめ木登りと同じ 11 cm のつかみ＋締めつけなしで試したら、④で前のつかみが支えきれず体がすべり、すべっている所はまわりの向きにおさえが効かず、5.7 cm 以上の枝で回り落ちた（実物と合わない）→ つかみを長く・はさむ に。
- 枝のまわり（branch.js）: θ = ヘビが決める形（つかむ所は S 字のループ1つ、頭がわから先にできる。まん中は折りたたみの小さなゆれ。片がわだけ は |θ|）。回す力 τ = Σ w R sin(θ+φ)（R = 体のまん中の半径）。押す力 N = 重さの分（cos に比例、たての合計 = 体重。推定）＋はさむ分。おさえる力の上限 = Σ(止まっている所) 0.28·N·(D/2)·√(1 − (枝にそって使っている分/上限)²)。こえたら回る（I = m(R² + d²/8)、動摩擦 0.25 をすべる向きのまわり成分で）。100° こえたら「横へ回り落ちた」で止めて3秒後に最初から。
- 批判役（できたあと）で直した所: 片がわだけの説明（細い枝で回りやすいのは、おさえる摩擦の腕＝枝の半径が小さいから。回す力の腕はむしろ太い枝のほうが長い）、動摩擦で回る向きが反対になるコマ（0 をまたいだら止める）、「逆さま」→「横へ回り落ちた」、窓は「尾のほうから見る」、摩擦の出どころのちがいを画面の推定に。
- 批判役（計画のとき）で直した所: 摩擦の腕を枝の表面の半径に（体のまん中の半径だと細い枝で 2.3 倍大きすぎ）、木登りの締めつけをそのまま借りない、動いている所の動摩擦をすべる向きで、体の太さの分の I。
- 結果（verify branch）: 左右交互＋はさむ → 1.6〜21 cm のどれでも落ちない（回す力 上限の最大 6〜54%、細いほど大きい）。片がわだけ → 1.6〜4.1 cm は 0.2〜0.3 秒で回り落ちる、5.7 cm は横に倒れて止まる、8.9 cm 以上は落ちない。はさまない → どの太さでも2〜7秒で回り落ちる（その前に体が後ろへすべる）。速さ 秒速 3.1 cm（太さで変わらない ✕）。刻み 0.002〜0.008 秒で同じ。
- 図: 横から 35° 見下ろす（`EL`。左右のループが見える）。「上から」ボタン（`#bView`）で真上から（EL 90°。ループの形がそのまま）。タブの順は 地面をうねる・横ばい・まっすぐ・枝をわたる・木を登る（2026-11-03 ユーザー）。枝のうしろの所はうすい点線。右上の窓は枝の切り口・体の断面（止まっている所は緑）・重心・回す力の弧の矢印・上限の何%の棒。せまい画面では窓は上、枝は下。

- 石のつりあい: 押す力の組の総当たり → 小さな線形計画（2段階の単体法 `lp`）。石の押す力 N ≥ 0 のほかに、10 区切りごとの「横の摩擦」（体が道から少しずれる、すべる向きのずれ 20° まで＝上限 μ横 ν sin20°。推定）を、重み3倍で使える。これがないと、体を道にぴったり固定した計算が「3つの石の回す力」でつりあわず、ばらばらの石で8割止まった。実際に使うのは平均 ほぼ 0%・最大 15%（上限に対して）。BETA 15° だと「どの向きも同じ」で10とおり中1つ止まった。

## しくみ
### 地面（js/ground.js）
- 体は長さ L の線を 80 個に区切る（i = 0 が尾）。曲がり κ(s,t) = (α/L) cos kπ(s/L + t/τ)、α 12・k 3.6・τ 2 s（形は Hu 2009 の実物の測定に合わせた。式の形は同論文）。s を尾から測ると、波は頭から尾へ流れる。
- 体の中から見た形（重心が原点・接線の向きの平均が 0）を κ を積分して作り、時間で差分して形の変わる速さを出す。世界での速さ = 重心の速さ (U,V) ＋ 回る速さ W × r ＋ 形の速さ。
- 摩擦（1 m あたり）: f = −ν [μt (û·n̂) n̂ + μf|b (û·t̂) t̂]（Hu 2009 の式 2）。û は速さの向き（|v| に 1e-5 m/s を足して割る）。ν は地面を押す重さ。
- 未知数 (U,V,W) は「摩擦＋坂の重さ − 勢い（m dU/dt、後退オイラー）＝ 0、回す力も同じ」をニュートン法（数値ヤコビアン・1回の動きを 0.2 におさえる）で解く。勢いを入れたのは、急な坂ですべり落ちるときに静止の解がなくなるため（勢いは重心と回転だけ）。
- 持ち上げ: ν ∝ max(0, 1 − (κ/κmax)²) を体重に合わせて正規化（推定。Hu は「曲がり 0 の所に重さ」とだけ書いている）。
- 坂: +x が上り。重さ ρg sinφ を −x へ、ν は cosφ 倍。「坂でウロコを立てる」は Hu の坂の計算の値（μf 0.3・μt 0.54・μb 0.39）。
### 木（js/tree.js）
- 体を幹にそった上下だけの線にし、90 個に区切る。区切りは 尾 7 cm・下のつかみ ℓg・まん中 ℓm・上のつかみ ℓg・頭 7 cm。ℓg = min(幹のまわり π(D+d), grip 11 cm)（11 cm は 4.1 cm 登れる・5.7 cm 登れないに合わせた推定。Savidge 2021「まわりくらいの長さ」はそのままは使っていない）。まん中は最低 5 cm。巻く角度が 180° 以下なら締めつけ 0（推定。Astley & Jayne 2007 は「180° より多いほうが強い」とだけ言い、5.7 cm でも 180° より多く巻いていた → 落ちる理由は実物と合わない。2026-11-03 監査）。
- 各区切りの「たての長さの割合」c: まっすぐ 1、巻く w で 1 − w(1 − cw)（らせんのピッチ 2d、cw ≈ 0.14〜0.25）、折りたたむ f で 1 − f(1 − 0.7)。高さ z_i = Z + ζ_i、ζ は尾から c を積み上げたもの。
- 順番（1回 4 秒、`PH`）: ①下でつかんでまん中をのばす ②上を巻いて（7割）締める（3割） ③下をゆるめて（3割）ほどく（7割） ④まん中をちぢめる ⑤下を巻いて締める ⑥上をゆるめてほどく。'wrong' は②③を入れかえ（下を先に放す）。
- 押す力 n_i = 締めつけ × sqN（巻いた所）＋ ρg cosθ（傾いた幹の上にのる重さ）。sqN = 余裕 × 必要（重さの坂の分＋ほかがすべる摩擦を、つかみ1か所の静止摩擦で支える分）。
- 尾の先の速さ V を、m (Vc − Vc0)/dt + m g sinθ = Σ 摩擦 で二分法で解く（Vc = V + ζ̇ の平均 = 重心の速さ）。摩擦は動いていれば −μk n・sign(v)、止まっていれば静止の範囲（前 μs,f n 〜 後ろ μs,b n）。止まれる速さ V = −ζ̇_i に寄せて、そこで静止の範囲に入れば止まる。
- 地面（Z = 0）より下へは行かない。落ちたら3秒後に下からやり直し、2.6 m まで登っても下から。

### 石のあいだ（js/stones.js。2026-11-03 に消した。コードは Git の 217215d まで）
- 道 y = A sin 2πx/λ（λ 0.12 m = 0.4 L、A 0.03 m = 0.1 L。Hu 2009 の実測）を弧の長さで引ける表にし、体の80区切りを頭の弧の位置 S から並べる。S は 1周期に1波長ぶんの道の長さだけ進む（秒速 8.8 cm）。
- 地面の摩擦は体にそって後ろ向き μf ν。石は体の中心線から RB + RS（0.6 + 0.8 cm）の所にあるものがふれている（±3 mm）。押す向きは石から体へ。
- 未知数は石ごとの押す力 N ≥ 0。力 x・y と回す力の3式。合計 ΣN が最小になる組（線形計画の頂点 = 3つまで）を、1・2・3個の組を全部ためして探す（最小二乗でぴったり・N ≥ 0 のもの）。なければ止める（U = 0）。
- 既定の石は、曲がりの外がわの頂上の 0.08 波長手前（ahead）。頂上ちょうど（ahead 0）だと押す向きが真横で止まる。
### まっすぐ（js/rect.js）
- 皮の区切り i の位相 φ = (t/τ + 2 s/L) mod 1。φ < duty のあいだ皮は背骨に対して −c（c = 1回の歩幅 4.5 cm / τ 3 s。いまの値）で動く → 背骨が c で進めば地面に止まる。残りは 1 − cos の山で取りもどす（平均 0）。
- 背骨の速さ V を、勢い m(V + ū̇ − Vc0)/dt と摩擦（動けば −μf w・+μb w、止まれば範囲）のつりあいで二分法（木と同じ）。止まれる条件は μb·duty ≥ μf·(1 − duty)（布 44%・板 50%）。
### 横ばい（js/ground.js の gait 'side'）
- 地面の計算そのままで、重さの配り方 ν を「上下の波」で決める: ν ∝ max(0, cos(kπ(s/L + t/τ) + δ) − cos(π·contact))。k 4（体に2波、2か所でふれる）、δ 1.51 rad、contact 0.3、α 18、τ 2 s。地面は「どの向きも同じ 0.15」。
- 地面に残る跡は、ふれている区切りの位置を τ/40 ごとに点で残す（mode-ground.js）。

### 横ばい（立体。js/side3d.js。v005-side3d）
- 形: 位相 w = 2πs/(λL) + 2πt/τ（λ 0.5）。'arch'（既定）: w の 1周のうち contact（40%）は左右の向き ψ = 0・上下の向き φ = 0（まっすぐ地面に置く）、残りは q = 0〜1 で ψ = Ah(1 − cos 2πq)/2（片がわへふくらむ）・φ = Av sin 2πq（上がって下がる）。Ah 2.2・Av 1.0（跡 33°・止まる所 44% に合わせた）。'wave'（くらべる用）は ψ・φ をなめらかな波の曲がりの積分で。
- ψ・φ の平均を引いてから、接線 (cos ψ cos φ, sin ψ cos φ, sin φ) を積み上げて立体の線にし、重心を原点へ。（はじめ φ の平均を引き忘れて、体が坂のように持ち上がり高さ 20 cm 以上になった）
- 地面: めりこみ（−z）× k の力。k は「平らに置いたらめりこみ sink」（砂 0.004 m → ふれた所が約 1.2 cm めりこむ = Marvi の 1.4 ± 1.3 cm）。高さ z0 と傾き a・b を、重さ・2つの傾きのつりあい（3式）で、ふれる所の集合をくり返して決める。
- 地面にそった動き: 摩擦はどの向きも同じなので、つりあい = すべりの仕事率 Σ μn|v| が最小。くり返し重みつき最小二乗（重み μn/√(|v|² + (2e-4)²)）＋勢い（前の速さへ引きもどす項）で解く。**ニュートン法だと止まりかけの所で解けず（ok false）、すべりが 46% と出ていた**（`kinCheck` で「止められる動き」がある＝すべり 3% と分かって気づいた）。
- ground.js（平面の版）も、ニュートン法が解けないときは同じくり返しで解くようにした（横ばいで 4 割のコマが解けていなかった。結果のすべり 10% は変わらなかった＝平面の計算そのものの限界）。

## ハマったところ
- 地面: 慣性なしの「つりあいだけ」だと、急な坂（重さが摩擦の上限をこえる）で解がなくなりニュートン法が発散した → 重心と回転に勢いを入れ、後退オイラーで解く形に。持ち上げのときの速さも 0.149 → 0.200 に変わった（浮かせ方で摩擦が急に変わるので、勢いが効く）。
- 速さを「体の向き TH への成分」で測ると、うねりで TH がゆれて小さく出た → 1周期の移動距離（坂では +x 成分）に。
- 木: はじめ勢いを「尾の先の速さ V」で入れていた → 下をほどく（尾の先が 0.5 m/s で下がる）ときに大きな見かけの力が出て、上のつかみがすべった。重心の速さで入れて直った。
- 木: 巻いている途中から締めると、動く所の摩擦を止まっている所が引きずり、支える摩擦が上限の 9割まで使われた → 巻き終わってから締める・ゆるめてからほどく順に。
- 木の幹の太さの初期値は 2 cm（スライダー・mode-tree.js の `TP.D`・tree.js の `D` をそろえる。2026-11-02 に 4 → 2）。
- 石: 石を曲がりの頂上に置くと押す向きが真横で、前へ押せず止まった → 頂上の少し手前（体が進んでくる側の斜面）に。体のタップの範囲が広いと、体のすぐ横に石を置けなかった → 体の太さ＋2 mm だけに。
- 横ばい: α 5 くらいだと跡の角度が 74° になり論文（33°）と合わない → α 18。波のずれ 0 でも α 18 では少し進む（はじめ「進まない」と書いていたのを、計算に合わせて直した）。
- Browser ペインが隠れていると requestAnimationFrame が止まる → `__snmo.simRun(秒)`。`setTimeout(location.reload)` と次のスクリプトが前後する → 開き直しは navigate で。
