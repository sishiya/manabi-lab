## v1 で合わなかったところ（ふり返り）
- **眺めるだけ**だった。時間のつまみを動かし、グラフと図を見るだけで、自分の手で何かしてカビが目の前で反応する感覚がない。
- カビは「カビ指数」という1つの数で育ち、絵はその数に合わせて描いていただけ。**生き物として広がり、増えていく**ようには見えない。
- 場所4つ × 大きさ3つ × グラフ × 長い説明のパネル、と広げすぎて、どこを見ればいいか分からない。

## 新しい芯（ひとことで）
**「カビの箱庭」** — 浴室の壁の一部（タイルと目地とゴムパッキン、実物で横 10cm ほど）を大きく拡大した箱庭で、カビが**本当に菌糸をのばし、胞子を作って飛ばし、増えていく**。そこへ自分の指で水をかけ、汚し、ふき、薬を吹きかけて、**どうすれば生えないか**をためす。

要望の9項目は、説明の文章ではなく、**見て・さわって分かる**ことを先にする。

| 知りたいこと | 箱庭でどう分かるか |
|---|---|
| 空気や壁にどれだけいるか | 箱庭の上の空気に胞子が漂い、ときどき落ちてくる（数は実際の濃度から）。「見えないものを見る」スイッチで、きれいに見える壁にも胞子がもう落ちているのが分かる |
| 何を餌にするか | 石けんかす・皮脂の汚れを指で塗ると、そこへ菌糸がのび、汚れが溶けて減っていく。きれいなタイルの上では育ちにくい |
| どれだけ時間をかけて | 時計（1日の明るさと入浴）が回る。「はじめて発芽」「はじめて目に見えた」の日にちが記録に残る |
| どんな過程で育つか | 落ちた胞子 → 水でふくらむ → 発芽 → 菌糸の先がのびる・枝分かれ → 網になる → 色がつく（胞子ができる） |
| どう増えるか | 色がついた所から胞子が空気に出て、風（換気扇）で流され、離れた湿った所に落ちて、新しい点になる |
| どんな形か | **ルーペ**: マウス（指）を当てた所を顕微鏡の大きさで丸い窓に表示。菌糸・胞子・胞子の柄（種類ごとの形）、溶けていく汚れ、死んだ菌糸 |
| どんな条件で増えやすいか | 湿り気・温度・汚れ・換気を変えると、のびる速さがその場で変わる。乾くと先が止まり、湿るとまた動く |
| カビハイターで何が起こるか | 塩素系をスプレーすると、表面の菌糸は死に、色が消える。でもゴムパッキンの奥に入った菌糸は残り、数日〜数週間後に**同じ場所から**また出てくる |
| 防カビスプレーは何をしているか | 吹いた所に薄い膜（効いている所）が残り、落ちてきた胞子がそこでは発芽できない。日がたつと・水で流れると薄れていく |

## 遊び方（試行錯誤）
1. **自由に試す**: 道具を選んで、指でなぞる。
   - 水をかける／ふき取る／ドライヤーで乾かす
   - 汚す（石けんかす・皮脂）／スポンジでこする
   - 塩素系カビ取り剤／アルコール／防カビ剤スプレー（なぞった所だけに効く）
   - 換気扇のオン・オフ、季節（温度と湿度）
2. **毎日の習慣**: 「入浴後に換気扇を○時間」「水を切る」「週1回こする」などをオンにして、8週間を早回し。毎晩21時の入浴で壁は自動でぬれる。
3. **ためした記録**: 早回しを終えるたびに、「どの習慣・道具で、何日目に目に見えたか（または見えなかったか）」が1行ずつ並ぶ。並べて見比べると、どの対策がよく効くかが分かる（ここが「ふだんのカビ対策」の答えになる）。点数・手間の計算などのゲームの要素は入れない（2026-10-06 ユーザーの希望）。
4. **発見カード**: はじめて起きたこと（発芽した・目に見えた・胞子が飛んだ・乾いて止まった・塩素で色が消えた・再発した など）が起きると、短い説明のカードが出て、集まっていく。長い説明のパネルは置かない。

## しくみ（どこまで本物にするか）
- **菌糸の先（数千本）を1本ずつ動かす**。先は、その場所の湿り気・温度・えさで決まる速さでのび、ときどき枝分かれし、えさを減らし、通った跡が菌糸になる。古くなった所は胞子を作って色がつく。
- 箱庭の面は細かいマス（0.5mm 程度）に分けて、マスごとに「水」「えさ」「菌糸の量」「奥に入った菌糸」「色素」「死んだ菌糸」「防カビ剤」を持つ。水は蒸発し、換気で速く乾く。
- 胞子は空気の層の中の粒として動き（換気扇の風・落ちる速さ）、落ちた所で湿り気が足りれば発芽する。
- **数値は研究から**（作る前に調べ直して、確かな値と推定を分けて DEVNOTES に書く）: 種類ごとの発芽に必要な湿度と時間（温度・湿度ごと）、菌糸ののびる速さ、建物の材料の上でのコロニーの広がる速さ、目に見えるまでの日数（VTT モデルなどで照らし合わせる）、胞子の大きさと落ちる速さ、塩素・アルコール・銀イオンの働き。
- 見やすくするための演出: 画面の菌糸1本は実際の何十本ぶんの束として描く。時間は早回し。これは画面に書く。

## 画面
- ほぼ全面が**箱庭**（上に空気の層、下に壁の面）。左に道具、下に時計と早回し、右上に小さく「表面の湿り気・カビの面積・空気の胞子」の数字。
- 「湿り気を見る」に切りかえると、水の多い所が色で見える（WiFi の強さの地図のように）。
- 右には、習慣の設定・ためした記録・発見カードだけ。文章は短く。

## 段階
- **段階A**: 浴室の箱庭。育つしくみ（菌糸の先・えさ・水・胞子・空気）、道具、ルーペ、時計と入浴、習慣、発見カード、ためした記録。まずこれだけで「さわって分かる」かを確かめる。
- 段階B: 冬の場面（窓の結露・北の壁と家具の裏）。冷たい所だけが湿る「表面の湿り気」を箱庭の中で見せる。
- 段階C: 食べもの（パン。えさが多いと数日）、カビの種類の図鑑。
