# カビが育つまで 企画書

最終更新: 2026-10-06

## 何を作るか
家のカビは、どこから来て、何を食べ、どれだけの時間でどう育ち、どう増えるのか。浴室のゴムパッキン・窓・北側の壁・押し入れで、**くらし方（換気・水を切る・掃除・家具の置き方・加湿）を選び、12週間の時間を動かして**確かめる。途中でカビ取り剤・アルコール・防カビ剤を「使って」みて、何が起きるか（色が消える／死ぬ／また生えてくる）を見る。**ふだんのカビ対策に役立つ**ことをいちばんの目的にする。

ユーザーの要望（2026-10-06）と、それぞれをどこで見せるか:

| 知りたいこと | どこで |
|---|---|
| 空気中や壁にどれだけカビ（胞子）がいるか | 「数字で見る」（外・家の中の空気、1日に吸う数、1cm² に1日に落ちる数、ほこり1g）。部屋の図に浮かぶ胞子。表面の図の「目に見えないものも表示」 |
| なにを餌にするか | 断面の図（石けんかす・皮脂・ほこり・壁紙ののり・木を、菌糸の先から出す酵素で溶かして吸う）。条件の「掃除」 |
| どれだけ時間をかけて | 時間の帯とグラフ。結果「目に見えるまで ○日」 |
| どのような過程で育つか | 断面の図: 胞子 → 水を吸ってふくらむ → 発芽 → 菌糸 → 枝分かれ（菌糸体）→ 胞子をつくる柄 → 胞子 |
| どう増えるか | 胞子が空気に飛ぶ → 落ちる → 新しい場所で育つ。菌糸の先がのびる。表面の図で、点（コロニー）が増えて広がる |
| どんな形か・育つとどうなるか | 断面の図（顕微鏡の大きさ、種類ごとの胞子の柄の形）、表面の図（コロニーの丸い広がり・色） |
| どういう条件で増えやすいか | 条件（季節・換気・水を切る・掃除・断熱・家具・加湿）とグラフの「表面の湿度」「カビが育てる湿度の線」 |
| カビハイターなどで何が起こるか | 「対策をためす」: 塩素系カビ取り剤。色素がこわれて色が消える／表面の菌糸は死ぬ／材料の奥の菌糸は残って再発 |
| 防カビスプレーなどは何をしているか | 「対策をためす」: 防カビくん煙剤（銀イオン）、防カビ剤スプレー、アルコール、こすり洗い。何の成分が何をするか、いつまで効くか |

見せたい「意外な点」
1. **胞子はどこにでも、もういる**。空気 1m³ に数百〜数千個、人は1日に数千〜数万個を吸っている。育つかどうかを決めるのは**水（表面の湿度）とえさと時間**。
2. 部屋の湿度ではなく、**壁や窓の表面の湿度**が大事。冷たい表面は湿度が高くなり、結露する（冬の北の壁・家具の裏・窓）。目安は「表面の湿度80%」。
3. **黒い色が消えても死んだとは限らない**。塩素系は色素をこわすので色が消えるが、ゴムやシリコンの奥の菌糸が残ると、同じ場所からまた生える。逆にアルコールは殺しても色は残る。
4. 乾くとカビは**死なずに休む**。湿るとまた伸びる。
5. 防カビ剤は「生えているカビを消す」のではなく、**これから生えるのを遅らせる**もの。効き目は数週間〜2か月ほどで弱まる。
6. ピンクのぬめりはカビではなく酵母（ロドトルラなど）。

## 画面
- 左上: **大きな図**（3つの大きさを切りかえ）
  - 部屋（場所の図。目に見えるカビ・湯気・結露・浮かぶ胞子・温度と湿度）
  - 表面（2cm 四方。コロニーの広がり・色・汚れ・水滴。「目に見えないものも表示」で菌糸と落ちた胞子）
  - 断面（顕微鏡。約0.5mm。胞子・菌糸・材料の奥にのびる菌糸・胞子の柄・えさを溶かす酵素・水の膜。髪の毛との大きさ比べ）
- 下: **グラフ**（1日／1週間／全期間）
  - 上の段: 表面の湿度、カビが育てる湿度の線、ぬれている時間、温度
  - 下の段: カビ指数（生きているカビ）、見た目の汚れ、防カビの効き。前の条件を点線で比べる。対策を使った時刻の印。
- 右: いま起きていること、場所と条件、対策をためす、結果、数字で見る、ためしてみよう、カビ対策のまとめ、よくある誤解、まだ分かっていないこと、このアプリについて。
- 時間の帯: 再生（1時間／6時間／1日／1週間 が1秒）、スライダー。

## モデル（1時間きざみ、12週間）
1. **表面の気候**: 場所ごとに、温度と表面の湿度とぬれ（水の膜）を1時間ごとに作る。
   - 浴室: 21時に入浴（ぬれて湿度100%）→ 換気・水切りで乾き方が変わる。
   - 窓・壁・押し入れ: 外と部屋の温度、部屋の水蒸気（加湿・部屋干し）から、**表面温度と表面の湿度**を計算（水蒸気圧と飽和水蒸気圧）。100% をこえると結露。
2. **カビ指数 M（0〜6）**: VTT モデル。材料の感受性クラス（とても弱い／弱い／やや強い／強い）を、材料と**汚れ（えさ）**で決める（汚れでクラスが上がるのはこのアプリの推定）。乾くと少しずつ下がる。
3. **汚れ**: 毎日たまり、掃除で減る（推定）。
4. **対策**: 使った時刻に、生きているカビ・見た目の色・汚れ・防カビの効きを変える（推定。材料の奥にいる菌糸の割合で効き方が変わる）。
5. **空気中の胞子**: 外の空気（季節）＋家の中で胞子をつくるカビから（推定）。落ちる速さはストークスの式（直径3µm で約 0.03cm/秒）。
6. **カビの種類**: クロカビ・アオカビ・コウジカビ・カワキコウジカビ（乾きに強い）。育てる最低の湿度と温度のちがいで、どれが多くなるか（推定）。

## 段階
- **段階A（この版）**: 4つの場所、モデル、3つの図、グラフ、条件、対策5つ、結果、数字、ためしてみよう、誤解、まとめ、注意書き。
- 段階B: 食べもの（パン・もち・みかん。えさが多いと数日で生える）、エアコンの中、カビの種類を選んで比べる表。
- 段階C: 自分の家の値（温湿度計の値を入れる）で「表面の湿度」を見積もる、1年の季節を通して。

## やらないこと
- 健康被害の判断・診断（医療の判断には使えないと書く）。
- 特定の商品のすすめ・比較（成分の種類で説明する。商品名は例として書くだけ）。
