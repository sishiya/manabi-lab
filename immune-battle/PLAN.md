# 免疫のたたかい 企画書

最終更新: 2026-10-04

## きっかけ

ユーザーの希望:「ウイルスがどう体内に侵入して、どう繁殖して、身体はどう反応するか。細菌も。免疫細胞と外敵の数を調整した結果、身体にどんな時間をかけて影響をおよぼし、どう変化するのかがシミュレーションできると良い。スケールはウイルスや免疫細胞レベルにしつつ、小窓で人体の様子をうかがい知れると良い。」

## 何を作るか

- **大きな画面＝ミクロの世界**: 感染した場所の断面（数十µm 四方）。粘膜の細胞・血管・ウイルス・細菌・免疫細胞（マクロファージ・好中球・NK細胞・キラーT細胞・抗体）が動く。ウイルスが細胞にくっつき、中に入り、増えて出てくる。免疫細胞が血管から出てきて追いかけ、食べる・壊す。
- **小窓＝人体**: 全身のシルエット。感染している場所（鼻とのど／傷口）、熱（体温計）、首のリンパ節のはれ、肺や血液へ広がったか、いまの症状。
- **グラフ**: 日ごとの「病原体の数・感染した細胞・自然免疫・キラーT細胞・抗体・体温・組織の傷み」。いまの設定のまま進んだらどうなるかの**予測（点線）**も出す。設定を変えるとすぐ予測が変わる。
- **調整できるもの**: 入ってきた病原体の数、自然免疫の細胞の数、獲得免疫（T・B細胞）の数、からだの例（健康な大人・子ども・高齢者・免疫が弱い人）、前の記憶（なし・ワクチン・前にかかった）。動かしている途中でも変えられる。
- **時間**: 一時停止／1秒=10分／1秒=1時間／1秒=6時間。2週間くらいの経過を数分で見られる。
- 画面の動きは、裏で動く数の計算（微分方程式のモデル）に合わせて出す。画面の中の粒の数は本当の数ではなく「量の目安」（対数で縮めている）と明記する。
- 説明は **確か／推定／演出** を区別する（RULES 9章）。モデルの数値の出どころ・簡単にしたところを DEVNOTES に書く。

## 病原体（はじめ）

| | インフルエンザウイルス | 黄色ブドウ球菌 |
|---|---|---|
| 入り口 | 鼻・のどの粘膜（せき・くしゃみのしぶき） | 皮膚の傷 |
| 増え方 | 細胞の中に入り、細胞の仕組みを使って自分を作らせ、出ていく（6〜8時間で数千個） | 細胞の外で2つに分かれて増える |
| 主に戦う細胞 | インターフェロン・NK細胞・マクロファージ → キラーT細胞・抗体 | 補体・マクロファージ・好中球（うみ）→ 抗体 |
| 体の様子 | 熱・のどの痛み・せき・だるさ。重いと肺へ | 赤み・はれ・痛み・うみ。重いと血液へ（菌血症） |

## 段階

| 段階 | 内容 |
|---|---|
| **A** | 2つの病原体、モデル（数の計算）、ミクロの画面、人体の小窓、グラフと予測、調整のスライダー、からだの例、記憶（ワクチン）、できごとの説明、細胞をタップで説明。 |
| B | くすり: 抗ウイルス薬（ノイラミニダーゼ阻害薬＝ウイルスが細胞から離れられない）、抗生物質（細菌の壁を作れない）、解熱剤（熱は下がるが、ウイルスは減らない）。飲む時刻を選ぶ（早いほど効く）。 |
| C | ほかの病原体: 新型コロナ（症状が出る前から増える）、ノロウイルス（腸）、肺炎球菌、大腸菌（膀胱。「尿の旅」とつなぐ）。異物（とげ・縫い糸）があると少しの菌でも化膿する。 |
| D | 2回目の感染（記憶細胞で速く強く戦う）、ワクチンのしくみを順に見る。 |
| E | 仕上げ: スマホの調整、「このアプリについて」（出典・簡単にしたところ）、公開。 |

## やらないこと（いまは）

- 本当の数を1個ずつ動かすこと（数億個になるので）。数はモデルで計算し、画面は目安。
- 医療の判断に使える精度。「しくみを知るためのもの」と注意書きを出す。
- 怖がらせる演出。重い経過も淡々と、何が起きているかを説明する。
