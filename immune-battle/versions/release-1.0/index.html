菌の種類

抗生物質は何にどう効く？

抗生物質は、菌にはあって、ヒトの細胞にはない（または形がちがう）しくみをねらう。だから菌だけをやっつけられる。番号にさわると、図のその場所が光る。

  1. 細胞の壁を作れなくするβラクタム系（ペニシリン系＝アモキシシリン、セフェム系＝セファレキシン など）、グリコペプチド系（バンコマイシン）菌が分裂するとき、壁（ペプチドグリカン）を作れず破れて死ぬ（殺菌）。ヒトの細胞には壁がない。増えていない菌や、うみ・細胞の中の菌には効きにくい。バンコマイシンは大きくて外膜を通れないので、大腸菌には効かない。このアプリのセファレキシン・アモキシシリン・バンコマイシン
  2. たんぱく質工場（リボソーム）を止めるマクロライド系（クラリスロマイシン など）、テトラサイクリン系、アミノグリコシド系菌のリボソームはヒトのものと形がちがう（菌は70S、ヒトは80S）。たんぱく質が作れず、多くは増えるのが止まる（静菌）。
  3. 遺伝子（DNA）のコピーを止めるニューキノロン系（レボフロキサシン など）DNA のからまりをほどく菌の酵素を止め、コピーも分裂もできなくする（殺菌）。
  4. 葉酸を作らせないST合剤菌は葉酸（DNA の材料づくりに必要）を自分で作るが、ヒトは食べ物からとる。膀胱炎などに使う。
  5. 外膜をこわすポリミキシン系（コリスチン）グラム陰性菌の外膜に穴をあける。副作用が強く、ほかが効かないときの最後の手段。
ウイルスには効かない

ウイルスには壁もリボソームもなく、ヒトの細胞の中で、ヒトの細胞のしくみを使って増える。だからインフルエンザ・コロナ・ノロ・かぜに抗生物質は効かない（ウイルスには抗ウイルス薬）。

効かなくなる菌（耐性菌）

菌は、①薬をこわす酵素を持つ（βラクタマーゼ。大腸菌の ESBL など）②ねらわれる場所の形を変える（MRSA は壁を作る酵素が別もの）③薬をくみ出すポンプを持つ ④薬の入口を減らす、といった方法で生き残る。薬を使うたびに、生き残った耐性の菌が増えやすくなる。必要なときだけ、医師の指示どおりに使うことが大事。

腸の中の良い菌も減る

抗生物質は、腸に住む役に立つ菌も減らす。そのため下痢になることがある。

2回目の感染・ワクチン

一度戦うと、その相手に合うT細胞・B細胞の一部が「記憶細胞」として残る。2回目は早く、強く戦える。ワクチンは、病気にならずにこの記憶を作るしくみ。

    ふしぎに答える

    ウイルスは細胞のまわりをうろうろしているだけ？

    ウイルスは自分では動けず、細胞の外では増えられない。粘液の流れやゆらぎで運ばれ、たまたま細胞の表面にくっつくと、細胞に飲みこまれる。中で遺伝子が核に入り、細胞の仕組みを使って自分のコピーを作らせる。6〜8時間ほどで新しいウイルスが表面から出てくる（1個の細胞から数千個）。画面では ①くっつく ②飲みこまれる ③核でコピー ④出てくる、を吹き出しで知らせる。

    結局、ウイルスは増えているの？

    画面の上の「いまの状況」に、いま1日に「生まれる数」と「消える数」を出している。生まれる方が多ければ増えている。最初の2日ほどは6〜8時間で何十倍にもなり、2〜3日目がいちばん多い。そのあと、守りを固めた細胞が増え、キラーT細胞と抗体が来て減っていく。グラフ上の色の帯（赤＝増えている、橙＝ピーク、緑＝減っている）でも分かる。

    感染した細胞はどうなるの？死ぬの？

    死ぬ。ウイルスを作りつづけた細胞は1日ほどで力尽きる。その前に NK細胞やキラーT細胞が見つけて壊すこともある（ウイルス工場をつぶすので、まわりへの広がりが止まる）。死んだ細胞ははがれ落ち、かけらはマクロファージが食べて片づける。すき間は下にある細胞が分かれて埋め、1〜2週間で元にもどる。線毛のある細胞がそろうまで、せきが長引くことがある。

    なぜ高い熱が出るの？

    ウイルスが熱を出しているのではない。感染した細胞や免疫細胞が出す合図の物質（インターフェロン、IL-1、IL-6、TNF など＝サイトカイン）が血液に乗って脳に届き、体温の中枢（視床下部）がプロスタグランジンE2という物質を作って「目標の体温」を上げる。からだは目標に合わせようとして、ふるえ（寒気）で熱を作り、皮膚の血管をしめて熱を逃がさない。熱は免疫細胞を働きやすくし、ウイルスを増えにくくすると考えられている。解熱剤はこのプロスタグランジンを作らせないので熱は下がるが、ウイルスは減らない。ズームで「頭」まで引くと、合図が体温の中枢に届く様子が見える。

    マクロファージはウイルスを食べているの？

    食べている。ただ、鼻やのどでは、ウイルスを減らしている一番の理由は粘液の流れ（とウイルスが自然にこわれること）で、後半は抗体（IgA）が大きい。マクロファージは数が少なく、多くは上皮の下で死んだ細胞のかけらを片づけている。肺の奥ではマクロファージの役わりがずっと大きい。いま何がどれだけ減らしているかは「いまの状況」の帯に出る。

    粘液は流れた先でどうなるの？

    線毛が粘液をのどの方へ運び、知らないうちに飲みこまれて食道から胃へ行き、胃酸で分解される。鼻をかんだり、くしゃみやせきで外へ出したりもする。粘液の中のウイルスや抗体もいっしょに運ばれる。ズームで「頭」まで引くと、流れの道すじが見える。

    樹状細胞は手をのばして何をしているの？

    上皮細胞のすき間から腕を表面までのばして、外から来たもののかけらを集めている（見張り）。かけらを持つとリンパ管を通ってリンパ節へ行き、そこで「このかけらに合う」キラーT細胞とB細胞を探して知らせる。知らされた細胞が何万倍にも増えて、数日後に戦いに加わる。首のリンパ節がはれるのはこのため。

    2回目にかかると、なぜ軽くすむの？

    1回目に増えたキラーT細胞・B細胞のうち一部が「記憶細胞」として何年も残る。最初は数百個しかいなかった「その相手に合う細胞」が何百倍もいて、しかも少しのかけらにもすぐ反応する。抗体を作り続ける細胞も残る。だから2回目は、働きだすまでが5〜7日から2〜3日に縮まり、増える前に片づくことも多い。ただし、インフルエンザやコロナは表面の形が少しずつ変わるので、前の抗体がくっつきにくくなり、何度もかかる。「2回目の感染・ワクチン」のボタンで試せる。

    ワクチンはなぜ効くの？

    病原体のかけら（または、かけらの設計図）だけを先に見せて、病気にならずに記憶細胞と抗体を作っておくしくみ。本物が来たときには「2回目」と同じように早く戦える。打ったあとに腕が痛くなったり熱が出たりするのは、免疫が反応している印。かからなくするだけでなく、かかっても重くなりにくくする。

    細菌はウイルスとどうちがうの？

    細菌（黄色ブドウ球菌）は自分で栄養をとって、細胞の外で2つに分かれて増える。だから細胞の壁を作れなくする抗生物質が効く。ウイルスは細胞の中でしか増えられないので抗生物質は効かず、抗ウイルス薬はウイルスの増え方の別のところを止める。

    このアプリについて

    裏で、病原体・感染した細胞・免疫細胞・抗体の数の変化を、研究で使われる形の式（微分方程式）で計算している。ミクロの画面とからだの小窓は、その数に合わせて動かしている。

    確かしくみ（何が何をするか）、およその時間（ウイルスが出てくるまで6〜8時間、キラーT細胞は5〜7日目ごろ、など）。

    推定数・体温・傷みの量。モデルの目安で、人によって大きくちがう。

    演出画面の粒の数は本当の数ではない（何億個にもなるので、10倍ごとに十数個ずつ増える「対数」で描いている）。ウイルスや抗体は実際よりずっと大きく描いている。

    簡単にしたところ: どの病原体も、感染した場所を1か所としてまとめた（鼻とのど・小腸・傷のまわり・肺の一部・膀胱）。肺や腎臓への広がりは「傷みや菌の数が大きいと広がるおそれ」として表しただけ。インフルエンザやコロナでも好中球が集まるが、画面とモデルには入れていない。粘液の流れは本当はずっと速い（1分に数mm）が、ゆっくり描いている。くすりは効き目の強さを一定とみなし、飲む回数ごとの上下は省いた。ワクチンは「かけらを数日あたえる」として、種類ごとのちがい（不活化・mRNA・結合型）は強さだけで表した。2回目の感染の間の日々は、病原体のいない状態でモデルを進めて、抗体や記憶細胞の減り方を計算している。ほかの病気・年齢による細かい差は入れていない。

    モデルの形と数値の参考: 標的細胞が限られるウイルスのモデル（Baccam ら, J Virol 2006）、皮膚に化膿を起こす黄色ブドウ球菌の数（Elek, Ann N Y Acad Sci 1957）、ノロウイルスがうつる数（Teunis ら, J Med Virol 2008）、免疫学の教科書（Janeway's Immunobiology など）。数値は、よく知られた経過（熱の日数・治るまでの日数・薬で短くなる日数）に近くなるよう調整した目安。

    しくみを知るためのものです。病気かどうか・治療の判断には使えません。熱が高い・息が苦しい・傷が赤く広がる・吐いて水分がとれない・おしっこが痛くて熱があるなどのときは医療機関へ。
