# 声のものさし 企画書

作成 2026-11-08

## ユーザーの依頼
「声の特徴をこまかくパラメータ化して視覚化するアプリをつくりたい（こえのこゲームにも活きるかも）」
そのあとの指示: こえのこをベースにしない（ゲームのための嘘が入っている可能性がある）。現実の研究データを参考にリアル路線で。**まなびでパーツを作り、その一部をあそびへ移植する順番**（RULES 8.3）。

この夜の試作は、ユーザーが寝ているあいだに進めた。下の「手がすること」「時間の見せ方」はユーザーにまだ確かめていない（RULES 4章）。朝に見てもらう。

## ねらい
自分の声が「何の数でできているか」を、研究で使われている測り方のまま見せる。1つの数を押すと、その数がどこからどう測られたかが図に出る。

## 見る人の手がすること
1. 2通りの録り方を選ぶ。「あー」を3秒のばす（声帯の鳴り方を測る）／ふつうに話す（抑揚・話す速さ・響き）。マイクがなくても「合成した見本の声」で試せる。
2. 録り終えると、声のスペクトログラムに高さ・フォルマントが重なって出る。
3. 数のカードを押すと、上の図が「その数の測り方」に切りかわる（例: ジッター → 波形に周期の印、H1-H2 → その瞬間のスペクトルに倍音の印）。
4. 時間は下のスライダー1本（図をドラッグしても同じ）。録った声を聞き返せる。

## 時間の見せ方
録音が1本のタイムライン。スライダーで好きな瞬間へ。自動では進まない。

## 測るもの（グループ）
| グループ | 例 | 録り方 |
|---|---|---|
| 高さ | 中央値・音域（20〜80%）・ばらつき・上がる／下がる速さ・ビブラート | 両方 |
| 声帯の鳴り方 | ジッター・シマー・HNR・CPP・H1*-H2*・H1*-A3* | ジッターとシマーは「のばす」だけ |
| 響き | F1〜F4・帯域幅・声の筒の長さ（推定） | 両方 |
| 音色 | アルファ比・ハマーバーグ指数・傾き・重心 | 両方 |
| 話し方 | 話す速さ・調音の速さ・間・声の割合 | 話す |
| 大きさ | 相対 dB の幅（絶対の dB は測れない） | 両方 |

## 科学の決めごと（リアル路線）
- 定義は eGeMAPS（Eyben ほか 2016）と Praat のマニュアルにそろえる。こえのこの `features.js` は使わない。
- カードごとに **測定／推定／マイクしだい** を表示する。
- **良し悪しを判定しない**: 病気の境目（MDVP の 1.04% など）・「正常範囲」・性別・年齢・感情の推定は出さない。医療に使えないと画面に書く。
- ものさしの目盛りは表示のための範囲で、「普通」の帯は出さない。比べる基準は出どころを確かめた数が手に入ってから（段階B）。
- 根拠: スマートフォンでは F0・CPP は比較的安定、ジッター・シマーは機種と雑音で大きく変わるという報告がある。ジッターとシマーには画面でそう書く。

## 比べた手法（RULES 6章）
| 候補 | しくみ | ライセンス | 判断 |
|---|---|---|---|
| Praat の定義を自分で実装（Boersma 1993 の自己相関＋経路探索、Burg の LPC） | 論文とマニュアルの定義 | 定義は自由に実装できる。Praat のコードは写さない | **採用** |
| Braat（Praat のブラウザ移植） | Praat の移植 | AGPL-3.0 | 使わない（ライセンス） |
| justinchuby/formants | 自己相関 LPC＋根の計算、F1・F2 のみ | MIT | 考え方だけ参考（根から帯域幅で選ぶ） |
| openSMILE | eGeMAPS の本家 | 商用不可 | コードもデータも使わない。論文の定義だけ |
| chdh/klatt-syn | Klatt 合成器 | MIT | 参考。見本の声は検証に要る分を小さく自作 |

## 構成（まなび → あそび の流れのため）
- `js/engine/`: 測定だけ。DOM・WebAudio なしの ES モジュールで、node から確かめられる。**ここがあそびへ渡すパーツ**。
- あそび用の変換はこのアプリに書かない。こえのこへの移植は別の段階で、あそび側に写して作る。

## 段階A（この版）
測定エンジン、合成の声での検証、録音・見本の声、スペクトログラム、数のカード、測り方の図。

## 段階B以降（案）
- 本物の録音や Praat との突き合わせ（`praat-parselmouth` を検証だけに使う。配布はしない）
- 基準の数（日本語の母音など、出どころを読めたものだけ）
- 2回の録音を比べる、つまみで見本の声を変えて数がどう動くかを見る
- 英語対応（入口へ移すとき）
- こえのこへの一部移植（あそび側で）

## 批判役のあとで変えたこと（くわしくは DEVNOTES）
最初に見せる数は5個、残りは「くわしく」へ。固定する図は1枚。録る前に「外に出ない」を表示し、消すボタンを置く。Praat 未確認を画面に書く。

## やらないこと
声の録音を残す・送る。声で人を当てる。診断。声の良し悪しの点数（点数を付けるとゲームや評価になる）。

## 簡単にするところ（画面にも書く）
話し声でのフォルマントは母音の種類をまたいだ平均。声の筒の長さは一様な管とみなした推定。大きさはマイクの相対値。
