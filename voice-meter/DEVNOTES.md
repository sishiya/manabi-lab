## しくみ
- 内部は 16kHz（5kHz までの帯を見るので足りる）。ジッターとシマーだけ元の細かさ（44.1kHz 以上）で測る。
- 高さ: Boersma 1993 の正規化自己相関＋経路探索（Praat の既定値 75〜600Hz、0.45・0.03・0.01・0.35・0.14）。HNR は 60ms（4.5 周期。Praat の To Harmonicity (ac) の既定）の窓の r から。
- ジッターとシマーは「のばす」だけ（Praat のマニュアルが長くのばした母音に限ると書いている）。となりの比 1.3 倍・1.6 倍をこえる組は数えない（Praat の既定値として知られている数。マニュアルの該当ページでは数値を確かめられなかった）。
- フォルマント: 窓 50ms のガウス形、Burg 10 次、上限の周波数は 4500〜6500 を 500 刻みで試す（のばす声は F1・F2 のばらつき最小。話し声は隣のフレームとのゆれ最小）。
- H1*-H2*: 倍音の強さから F1〜F3 の共鳴の応答を引く。
- CPP: dB のパワーケプストラムを前後2フレームとケプストラム方向 ±3 点でならす。ソフトごとに値は変わる。

## ハマったところ
- 合成の声の「正解」のジッターが測定の2倍に見えた。音が鳴るのは声帯が閉じる瞬間で、閉じる位置は `周期の始まり＋oq×周期`。閉じる瞬間どうしの間隔で正解を数えると合う。エンジンの誤りではなかった。
- 1周の印を「1周ぶんの相関」だけで置くと前後の周期が平均され、頂点へ合わせると響きのさざ波の隣へとぶ。2段階（1周ぶん → 印のまわりの短い窓）にした。
- LPC の根に帯域幅 600〜900Hz の偽物ができ、F2 に選ばれていた（/o/）。500Hz 以上の広い根は 3kHz 未満から除く。
- ブラウザペインが隠れていると screenshot できない。Playwright（`../ゲーム/tools/playwright`）で確かめる。偽のマイク `--use-file-for-fake-audio-capture` で録音の道すじも通せる。

## 確かめた結果（2026-11-08・合成の声）
`tools/verify.mjs` すべて OK。F0 は 0.5% 以内。ジッターは許容 ±0.12 ポイント（σ 1〜2% で ±5% 以内）。シマーは ±1.2 ポイント。F1〜F3 は 10%（F3 は 8%）以内、280Hz の F1 だけ 14% まで広げた（倍音に引かれる限界。画面に注意を出す）。HNR は雑音が主のとき ±2dB。音節の数は 12/12。44.1k と 48k で値が同じ。Windows の音声合成の話し声（手元のみ）は 235Hz・HNR 15dB など、もっともらしい値。

## Praat との突き合わせ（2026-11-09・praat-parselmouth 0.4.7＝Praat 6.1.38）
合成の声 24 本＋Windows の音声合成 1 本（Haruka）。値は「エンジン − Praat」の絶対値の中央値／最大。
| 数 | 中央値 | 最大 | 見立て |
|---|---|---|---|
| F0 中央値 | 0.00% | 0.45% | 一致。1コマごとでも 100 セントをこえるずれ 0。有声の判定は話し声で 3〜5% のコマだけ違う |
| ジッター local / rap | 0.02 / 0.01 pt | 0.10 / 0.07 pt | 一致（同じ範囲で、Praat の印で測った） |
| シマー local / dB / apq3 | 0.06 pt / 0.01 dB / 0.04 pt | 0.61 pt / 0.06 dB / 0.40 pt | 一致 |
| HNR（ac） | 0.76 dB | 2.35 dB | エンジンがやや低い。窓を 80ms から 60ms にして 1.14 / 2.99 から縮めた |
| F1〜F4 | 0.0〜0.03% | 下に書く | 根の値は一致。番号の付け方だけ違う |
| CPP | 2.0 dB | 5.5 dB | **そろっていない**。話し声で 0.4〜1.4 dB、のばす声で最大 5.5 dB、ほとんどはエンジンが低い |

- `To Formant` の出力は根を低い順に並べただけで、番号に偽の極が混じる（合成の声で F3 が +65% など）。`Track` で番号を付け直すと、比べられた合成の声 23 本のうち 19 本は 0.1% 以内（speech-high は `Track` が引けず比べていない）。残る hold-180-o・hold-280-e・speech-rough・speech-low は Praat の `Track`（参照の値が中性母音）の選び方で、エンジンの値は Praat の別の番号の根とほぼ一致する（のばす 2 本は verify.mjs の正解にも合う）。Haruka は F1 2%・F2 3%・F3 1.4%。B3 の比較は同じ理由で意味がない。
- CPP: 時間方向の平均を前後1フレーム、ケプストラム方向を ±4 点に広げてそろえようとしたら差が増えた（中央値 3.4 dB）ので戻した。Praat のコードは GPL で写せないので、これ以上は追わない。画面に「Praat より低め」と書いた。
- H1*-H2*・H1*-A3*・帯の数（alpha など）・話す速さは Praat の決まった命令がないので比べていない。H1*-H2* は verify.mjs の正解で確かめている。

## 本物の声（2026-11-09・PVQD）
Walden, P. R. Perceptual Voice Qualities Database (PVQD), Mendeley Data V4（CC BY 4.0、doi:10.17632/9dz247gnyb.4）。英語、話者 296 録音から等間隔に 24 本。声の障害のある人の声も多くふくむ（荒れた声で確かめられる）。のばす声 19 区間、話し声 21 区間に切り分けて測った。値は「エンジン − Praat」の絶対値。

| 数 | のばす声: 中央値／90%／最大 | 話し声: 中央値／90% |
|---|---|---|
| 高さ（中央値） | 0.00%／0.01%／0.02% | 0.23%／2.06%（1 本だけ有声 28 コマの録音で 5.5%） |
| ジッター local | 0.04／0.27／0.77 pt | － |
| シマー local | 1.18／1.76／2.30 pt（平均 +1.12、エンジンが大きい） | － |
| シマー dB | 0.11／0.17／0.20 | － |
| HNR | 0.19／0.62／0.69 dB | 0.33／0.59 dB |
| F1（Track） | 0.49%／2.98%／18.5% | 3.29%／5.55% |
| F2（Track） | 0.11%／4.44%／6.2% | 6.19%／14.8%（平均 +6.9%） |
| F3（Track） | 1.21%／7.03%／17.7% | 5.24%／9.69% |
| CPP | 2.81／5.76／6.27 dB（平均 −3.3） | 2.26／3.30 dB（平均 +1.9） |

本物の声で初めてわかって直したもの（合成の声では出なかった）:
- シマーが Praat の 2〜4 倍になる人がいた（中央値 1.48・最大 4.53 pt）。振幅を「印にいちばん近い山」で取っていて、響きのさざ波の山を拾っていた。1 周のなかでいちばん高い山に変えた。山と谷の差も試したが、中央値は良くなるのに最大が 5.09 pt に悪化したので採らなかった。
- のばす声で上限の周波数の選びがはずれた（F1 が基本周波数に張りつく、F2 が 3900Hz）。ばらつき最小だけで選んでいたため。F1 が基本周波数の 1.25 倍未満、F2 の中央値が 3500Hz をこえる上限は、のばす声では選ばないようにした。

残っているちがい（原因をしぼれていない・追わない）:
- 話し声で、エンジンだけ有声とするコマが 7.4%（Praat だけは 0.4%）。16kHz への変換が原因ではない（Praat に 16kHz を渡しても 7.2%）。1 をこえる相関の折り返しも効かなかった。声になっている割合はこの分だけ多めに出る。100 セントをこえる高さのずれは 0.63%。
- 話し声の F2・F3 は Praat の `Track`（中性母音への引きよせ）より 5〜6% 高い。本物の声には正解がないので、どちらが正しいかは言えない。

**確かめていないこと**: 日本語の本物の声、実機のスマホのマイク。eGeMAPS の全文（定義は二次資料）、日本語の母音の基準値（表が読めなかったので画面に出さない）。

## 批判役（2026-11-08）で決めたこと
採用: 最初は5個だけ／固定する図は1枚／マイクの自動処理を止める・止まらなければ出す／録る前に「外に出ない」・消すボタン／Praat 未確認を画面に／高い声の注意／話す速さは推定／数のそばに「大きいほど」の1行。
不採用: 「16kHz では 5kHz までの帯がゆがむ」→ ナイキスト 8kHz なので帯は足りる。話し声の HNR などを「母音らしい区間だけ」に → 段階B（声のある時間で測り、秒数は表示）。本物の声と Praat の突き合わせを段階Aに → ここでは Praat を入れられなかったので段階Bの最初に。
